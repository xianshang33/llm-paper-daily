## 文章做了什么
- **背景**：随着大型语言模型（LLM）演变为持久的科学合作者，上下文窗口饱和成为关键瓶颈。在药物发现和基因组研究等高风险、知识密集型领域，科学工作流涉及迭代数据分析和假设 refinement，迅速填满即使是很长的上下文窗口。
- **已有工作的局限**：现有的单体方法面临二次方成本缩放和认知退化问题。尽管出现了百万级 token 的上下文窗口，但完全依赖扩展上下文存在经济不可扩展性（处理历史成本随长度线性或二次增长）以及检索精度下降（相关信息被对话噪音掩盖）。此外， prior social agent memory systems 主要关注社交可信度，无法解决科学领域特有的矛盾参数演化、多跳推理和精确事实保留需求。

## 文章的核心贡献点
- **提出了一个双过程记忆架构（Dual Process Memory Architecture）**：该架构将即时情景需求（固定为最近10条消息的窗口）与长期巩固知识（以每条约3个token的速度增长）解耦，专门针对科学领域的记忆巩固进行了优化。
- **挑战1：长程交互中的上下文溢出与成本爆炸**。难点在于科学工作流长达数周甚至数月，累积的技术内容密集，导致全上下文模型在约10,000条消息时因溢出而失败，且计算成本高昂。解决方法是通过解耦机制，仅保留固定的短期情景窗口，并将长期知识压缩巩固，从而将 token 使用量减少62%，在保持低延迟的同时避免上下文溢出。
- **挑战2：科学领域特有的记忆一致性与时序推理**。难点在于科学假设会随实验进展发生逆转（如从肯定某机制到否定），且需要跨实验阶段进行多跳技术推理，普通 RAG 或社会代理记忆难以处理这种动态矛盾和精确数值保留。解决方法是引入领域特定的巩固机制，专门处理矛盾参数的演化和技术事实的精确留存，确保在长周期内维持逻辑连贯性和数据准确性。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：进行了大规模评估，涵盖15,000条消息，跨越三个家族（OpenAI, Anthropic, Google）的六个 LLM，共计1,440个查询。
- **主要结果**：
    1. **性能与效率**：当全上下文模型在10,000条消息处因上下文溢出而失败时，该架构仍保持70-85%的准确率，延迟仅为1-2秒，且 token 使用量比全上下文限制（120,000+）少62%（仅用45,434 tokens）。
    2. **架构权衡对比**：跨模型验证显示，双过程架构在数值/时间查询上表现优异（准确率65-90%），而传统 RAG 在历史检索上表现更好（准确率60-85%），表明两者具有互补性。
    3. **Sim-to-Real 差距**：发现合成测试中记忆保持恒定，但在真实工作流中记忆呈线性增长（约3 tokens/消息），指出巩固质量是可扩展性的主要瓶颈。
- **能力展示**：成功管理包含14,000+科学事实（约125k tokens）的用户画像，证明了其在超出全上下文限制下的持续运行能力。

#### 总结
本文针对科学智能体在长程交互中面临的上下文饱和和认知退化问题，提出了一种双过程记忆架构。通过解耦短期情景记忆和长期语义记忆，并引入领域特定的巩固机制，有效解决了科学工作流中假设演化、矛盾参数处理和精确事实保留的挑战。实验表明，该架构在显著降低 token 成本和延迟的同时，在长程任务中保持了高准确率，优于传统的全上下文方法和单纯的 RAG 方案，为构建持久的科学 AI 合作者提供了可行的技术路径。
