## 文章做了什么
- **背景**：LLM Agent 基准测试中存在严重的复现性问题。不同论文在使用相同模型和基准时报告的结果往往不一致，且由于缺乏详细的实验配置信息（如脚手架、采样设置、子集选择或评估器版本），研究人员无法判断差异来源。
- **已有工作为什么解决不了**：现有的可复现性研究主要集中在深度强化学习或静态 LLM 提示敏感性上，未能针对“Agent 运行”这一特定单元（即模型、脚手架、环境镜像、停止规则和评分器的组合）进行细致的披露度审计。现有文献缺乏一个标准化的框架来量化评估论文中关于实验执行细节的透明度。

## 文章的核心贡献点
- **提出了一个开放评分 schema（Open Scoring Schema）**：包含五个关键维度（基准身份、Harness 规范、推理设置、成本报告、失败分解）的审计框架及相应的评分代码本，用于系统性地评估 LLM Agent 基准论文的披露完整性。
- **挑战1：评估环境的不透明性**。难点在于 Agent 的运行高度依赖具体的软件环境和脚手架版本，微小的差异会导致结果巨大波动。论文通过定义“Harness 规范”字段，强制检查是否提供了内容寻址的容器镜像或精确的版本控制信息，从而量化这一维度的缺失。
- **挑战2：推理成本与失败模式的忽视**。难点在于大多数论文仅报告最终成功率，忽略计算成本和错误类型分析，导致无法评估效率与鲁棒性。论文通过引入“成本报告”和“失败分解”字段，揭示了当前文献在这些关键工程指标上的系统性空白。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：作者设计了 JSON Schema 格式的审计模式、Markdown 格式的评分代码本，并发布了 CSV 格式的原始评分表。审计由单一审核员对 12 篇经典论文（8 篇 Agent 基准，4 篇经典静态基准）进行一次性评分。
- **Evaluation 结果**：
    - 8 篇 Agent 基准论文的平均审计得分为 0.38（满分 1.0）。
    - 4 篇经典静态基准论文的平均审计得分为 0.66。
    - 最大差距出现在“成本报告”（所有 8 篇 Agent 论文均未披露任何推理成本）和“Harness 规范”（无一完全披露内容寻址的容器镜像）。
- **对比**：相较于传统静态基准，Agent 基准在实验细节披露上显著不足，表明随着系统复杂度的增加，可复现性的实践并未同步跟进，反而出现了倒退或缺失。

#### 总结
本文是一项关于 LLM Agent 基准测试透明度的试点审计研究。通过提出并应用一个包含五个维度的评分 schema，研究揭示了当前顶级 Agent 基准论文在实验细节披露上的严重不足，特别是环境规范和成本报告的缺失。该工作为社区提供了一套开源的审计工具，旨在推动更严格、透明的评估标准，尽管目前仅为单审核员初步结果，但为后续的多审核员审计和标准化奠定了基础。
