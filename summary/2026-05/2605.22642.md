## 文章做了什么
- **背景**：电子表格系统（如 Microsoft Excel）在现代数据驱动的工作流中占据核心地位。随着 AI Agent 能力的提升，构建能够自动化复杂任务的电子表格 Agent 成为重要研究方向。
- **已有工作的局限**：现有的电子表格 Agent 主要依赖通用大语言模型（LLM）结合特定的提示工程（Prompting）。这种方法在处理简单的电子表格操作时具有一定潜力，但在面对现实应用中典型的复杂、多步骤工作流时表现不佳，难以有效管理长程依赖和复杂的工具调用逻辑。

## 文章的核心贡献点
- **提出了一个名为 Spreadsheet-RL 的强化学习微调框架**，旨在真实的 Microsoft Excel 环境中训练专用的电子表格 Agent。
- **挑战1：缺乏高质量、可扩展的训练数据以支持复杂任务学习。**
  - **难点**：真实世界中的电子表格任务往往涉及多步操作和领域特定知识，人工标注成本极高且难以覆盖多样场景。
  - **解决方法**：设计了一个自动化流水线，从在线论坛中大规模收集配对的“起始-目标”电子表格数据，并构建了包含金融和供应链管理等领域的 Domain-Spreadsheet 基准数据集，为 RL 训练提供了丰富的数据基础。
- **挑战2：现有环境难以支持多轮强化学习与精细的工具交互。**
  - **难点**：通用的代码执行环境无法充分暴露 Excel 的全部功能，且缺乏针对电子表格任务优化的工具路由机制，导致 Agent 难以在复杂的多轮交互中正确选择和使用工具。
  - **解决方法**：开发了 Spreadsheet Gym 环境，通过 Python 沙箱暴露广泛的 Excel 功能，并集成了全面的工具集和精心设计的工具路由规则，专门用于支持多轮 RL 训练，使 Agent 能够更准确地理解和执行复杂操作。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：Spreadsheet-RL 包含数据收集流水线、Spreadsheet Gym 训练环境以及 RL 微调流程。代码和数据已开源。
- **评估结果**：
  - 在通用基准 SpreadsheetBench 上，Qwen3-4B-Thinking-2507 模型的 Pass@1 从 12.0% 提升至 23.4%。
  - 在新建的领域特定基准 Domain-Spreadsheet 数据集上，Pass@1 从 8.4% 提升至 17.2%。
- **相关工作对比**：
  - 相比仅依靠提示工程的基线模型（如 GPT-4o、OpenAI o3 等），Spreadsheet-RL 训练后的较小参数模型（Qwen3-4B）在特定任务上表现出更强的竞争力和泛化能力。
  - 实验表明，逐步引入原生交互 Harness、完整工具访问以及最终的 RL 训练，性能呈阶梯式上升，证明了 RL 微调在解决复杂多步工作流中的关键作用。

#### 总结
Spreadsheet-RL 通过引入强化学习微调和专用的训练环境，显著提升了 LLM Agent 在真实电子表格任务中的性能。它不仅解决了现有方法在处理复杂多步工作流时的局限性，还通过开源数据和环境促进了该领域的研究。结果显示，该方法在通用和领域特定任务上均取得了实质性进步，展现了在办公自动化和数据接口交互中的巨大应用潜力。
