## 文章做了什么
- **背景**：开发能够准确捕捉材料在负载下变形行为的本构模型，传统上需要连续介质力学、机器学习和科学编程方面的多年专业知识。大型语言模型（LLM）最近显示出通过按需生成本构模型来降低这一门槛的潜力。
- **已有的工作为什么解决不了**：现有的基于单 agent 的 LLM 流程缺乏系统性的检查机制，无法确保生成的模型遵守基本的物理定律，导致生成的模型可能在物理上无效或不可靠。

## 文章的核心贡献点
- **提出了一个**：首个多 agent LLM 驱动的本构模型生成方法，包含一个“创建者”（Creator）agent 和一个“检查者”（Inspector）agent。
- **挑战1**：如何确保生成的本构模型严格符合物理约束（如热力学一致性、对称性等）？
  - **难点与解决**：单一 LLM 难以同时兼顾数据拟合优度和复杂的物理规则验证。该方法引入 Inspector agent，针对九项物理约束对 Creator 提出的模型进行批判性审计，一旦发现违规即返回修正，从而强制模型满足物理定律。
- **挑战2**：如何在保证物理有效性的同时，不牺牲模型的预测精度和泛化能力？
  - **难点与解决**：严格的物理约束可能会限制模型的灵活性，导致拟合效果下降。该方法通过 Creator 专注于针对数据定制模型，而 Inspector 仅负责合规性检查，两者分离使得最终模型在达到 100% 物理合规的同时，保持了接近基线的准确率和对未见加载路径的良好泛化能力。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：该方法与本构人工神经网络（CANNs）结合演示，使用了两种不同的 LLM 后端（Claude Opus 4.7 和 Kimi K2.5）。数据集包括脑组织、实验橡胶和合成橡胶。
- **Evaluation 结果**：
  - 对于 Claude Opus 4.7，加入 Inspector 后，导出模型真正满足所有物理约束的比例从 91% 提升至完美的 100%。
  - 对于 Kimi K2.5，该比例从 37% 提升至 56%。
  - 模型在保持高精度的同时，展现出对训练数据之外加载路径的卓越泛化能力。
- **对比**：相比传统的单 agent 方法（直接导出模型，无系统性物理检查），该方法显著提高了模型的物理可信度，将 LLM 驱动的本构建模转化为一个真正值得信赖的过程。

#### 总结
本文提出了一种双 agent 协作框架，通过分离模型生成与物理检查，解决了 LLM 在本构模型设计中缺乏物理一致性的关键问题。实验证明，该方法不仅能自动生成符合物理定律的模型，还能保证高精度和强泛化能力，为自动化、物理感知的模型发现开辟了新路径，且该范式与技术无关，可随 LLM 能力提升自动扩展。
