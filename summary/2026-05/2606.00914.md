## 文章做了什么
- **背景**：大型语言模型（LLM）智能体在做出决策前，通常会消费由上游排序器（Ranker）筛选和排序的外部信息流（如社交媒体动态、搜索结果、检索上下文等）。然而，现有的安全评估几乎总是孤立地测试模型本身或用户提示，而忽略了决定智能体在行动前读取内容的上游排序层。
- **已有工作为什么解决不了**：现有的对抗性输入研究主要集中在单个消息的内容上，例如直接提示注入、越狱或检索 poisoning。这些威胁通常包含可识别的恶意 payload（指令、越狱字符串或篡改文档），理论上可通过内容过滤器捕获。然而，现有工作未解决当每个单独项目都是 benign（无害）时，仅通过选择展示哪些项目及其比例（即信息策展）来操纵智能体的情况，也未探讨这种策展是否能引导多步智能体决策而非仅仅翻转单轮输出。

## 文章的核心贡献点
- **提出了一个**：受控实验协议，用于隔离并量化 feed curation（信息流策展）对 LLM 智能体下游决策的因果影响。该协议固定模型、人设、主题和最终决策提示，仅变化智能体在前十轮“滚动”阶段遇到的帖子组成和顺序。
- **挑战1：如何隔离信息流策展的因果效应？**
  - **难点**：智能体的输出是模型权重、用户提示和信息轨迹的共同函数，难以区分是模型固有偏好还是外部信息导致的行为变化。
  - **解决方法**：通过保持除信息流组成和顺序外的所有变量（模型、人设、主题、最终提示）不变，任何决策偏移均可归因于信息流策展，从而精确量化其影响。
- **挑战2：如何表征不同模型对对抗性信息流的响应模式？**
  - **难点**：不同模型对相同的信息流操纵可能表现出截然不同的鲁棒性或敏感性，缺乏统一的分类框架。
  - **解决方法**：通过在四个现代开源指令微调 LLM 上进行 2,785 次决策 rollout，识别出三种响应机制：对抗性屈服（adversarial capitulation）、默认饱和（default saturation）以及默认方向不对称性（default-direction asymmetry），后者表明单边信息流只能扭转模型真正不确定的决策，而无法动摇其已有坚定倾向的决策。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与评估设置**：研究在来自三个独立实验室的四个现代开源指令微调 LLM 上进行了实验。实验涉及多个决策领域，包括与安全相关的选择（如移除部署审批网关或放宽访问控制）。
- **主要结果**：
  1. **剂量反应曲线**：信息流操纵的效果遵循清晰的剂量反应曲线。
  2. **排除写作风格 artifact**：通过生成器交换实验，证明效果并非源于写作风格的差异。
  3. **默认方向不对称性**：在模型真正不确定的情况下，单边信息流可将决策概率从 5% 扭转至 100%（Fisher p 值低至 3 x 10^-10），但无法改变模型已 favor 或坚定持有的立场。
  4. **防御措施**：两种简单的 feed-level 防御措施可部分缓解该效应；前沿模型表现出更强的默认保持能力。
- **与相关工作对比**：不同于传统关注恶意 payload 内容的对抗攻击研究，本文证明了即使没有恶意内容，仅通过控制信息的排序和组合（即推荐系统作为控制面），也能有效操纵智能体决策。这表明当前的安全评估存在盲区，必须审计 feed layer 而不仅是最终提示。

#### 总结
本文揭示了 LLM 智能体面临的一种新型安全威胁：上游推荐器/排序器可作为实际的控制面，通过策划 benign 信息流来 steer 智能体决策。研究指出，智能体评估必须超越对最终提示的孤立测试，转而审计信息流层。虽然前沿模型表现出一定的鲁棒性，但大多数模型在不确定状态下易受信息流操纵，这为构建更安全的智能体系统提供了重要的实证依据和改进方向。
