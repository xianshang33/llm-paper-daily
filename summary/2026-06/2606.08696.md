## 文章做了什么
- **背景**：反事实解释（Counterfactual Recourse）旨在为被预测模型拒绝的用户提供可操作的特征修改建议，以改变不利决策。在实际应用中，用户往往受益于多个可行的替代方案，而不仅仅是单一的最优解。
- **已有工作为什么解决不了**：传统的反事实方法通常只返回单一或少数几个基于距离最小化的解，缺乏多样性。虽然利用大语言模型（LLM）可以生成多种替代方案，但 LLM 的调用次数是主要的计算和经济成本瓶颈。现有的基于 LLM 的搜索框架（如 LATS）主要针对单一路径优化，无法在固定的 LLM 调用预算下高效地生成大量独特且经预言机（Oracle）验证的有效反事实解释。

## 文章的核心贡献点
- **提出了一个 Comp-MCTS 框架**：一种用于固定预算下反事实解释生成的代理树搜索框架，旨在最大化独特且有效的反事实解释数量。
- **挑战1：如何在有限的 LLM 调用预算下探索多样化的干预方向？**
  - **难点**：盲目生成会导致大量冗余或无效的建议，迅速耗尽预算。
  - **解决方法**：Comp-MCTS 通过 LLM 基于当前节点提出多个特征编辑建议，并结合黑盒预言机进行实时验证，将预算集中分配给有潜力的新颖干预方向，而非重复探索已知区域。
- **挑战2：如何避免生成冗余的解释并维持质量与数量的平衡？**
  - **难点**：简单的多候选生成容易产生语义相似或重复的结果，降低用户获得的实际价值。
  - **解决方法**：引入压缩引导的剪枝机制（compression-guided pruning），在搜索过程中动态剔除冗余节点，确保最终输出的集合具有高独特性、稀疏性和邻近性，从而在固定预算下实现更优的数量-质量权衡。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：在四个真实的表格数据集上进行评估，采用无需训练、仅依赖预言机的设置。
- **对比基线**：与单候选的 LATS 风格基线以及更强的多候选变体进行对比。
- **主要结果**：
  - **产量优势**：Comp-MCTS 在独特且经预言机验证的反事实解释产量上显著优于单候选 LATS 基线。
  - **效率与质量权衡**：与更强的多候选变体相比，Comp-MCTS 在四个数据集中的三个上，以相同或更低的预言机评估成本实现了相当或更高的产量。
  - **指标表现**：在邻近性（proximity）、稀疏性（sparsity）和新颖性（novelty）方面表现出竞争力，证明了其在数量、质量和效率之间的良好平衡。

#### 总结
本文针对固定 LLM 预算下的反事实解释生成问题，提出了 Comp-MCTS 框架。通过将问题重构为固定预算的搜索问题，并结合 LLM 提议、预言机验证和压缩引导剪枝，该方法有效地解决了多样性和成本之间的矛盾。实验表明，Comp-MCTS 能在严格控制成本的前提下，为用户提供更多样化、高质量的可操作建议，优于现有的基于 LLM 的搜索基线。
