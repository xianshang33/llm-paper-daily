## 文章做了什么
- **背景**：开源 LLM Agent 生态系统（如 LangChain、Auto-GPT）迅速增长，社区贡献的“技能”（Skills，即扩展 Agent 能力的模块化工具定义）数量庞大。然而，这些技能的安全性 largely unvetted（未经审查）。恶意贡献者可以将有害行为嵌入看似 benign（良性）的技能中，形成新的供应链攻击面。
- **已有工作为什么解决不了**：现有的安全扫描器主要工作在代码层（code layer），基于签名匹配或静态分析。它们在结构上对“指令层”（instruction-layer）和“多 Agent 风险”盲目。例如，通过自然语言指令劫持 Agent、通过编码侧信道泄露数据或在管道中连锁危害的行为，不包含可检测的代码级签名。此外，人工审查无法规模化，而静态方法无法确认风险在运行时是否被触发及其具体影响。

## 文章的核心贡献点
- **提出了一个 SkillVetBench**：这是一个基于 Hugging Face 的实时公共排行榜，利用 LLM-as-Judge（LLM 作为裁判）机制对 Agent 技能进行多维度安全风险评估。
- **挑战 1：指令层风险的语义理解与检测难**。传统工具无法理解自然语言指令中的恶意意图（如提示注入、记忆投毒）。
  - **解决方法**：引入 SARS（Skill Agentic Risk Score，技能代理风险评分），这是一个包含五个维度的代理风险指标，采用原则性的加权公式，专门针对指令遵循系统进行语义层面的风险量化。
- **挑战 2：缺乏标准化且可公开比较的多维度评估体系**。现有工具要么漏报率高，要么无法提供细粒度的风险分解。
  - **解决方法**：集成完整的 CVSS v4.0 向量分解，并提供 ClawHub 双视图（Dual-view），将 LLM 生成的审查结果与官方市场判决并列展示，实现了从静态代码到动态语义的全方位 vetting。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：SkillVetBench 作为一个实时公共排行榜部署在 Hugging Face 上。系统架构包括从 ClawHub/OpenClaw 市场获取技能，通过 LLM-as-Judge 提取意图和能力并进行漏洞分类，最后生成 SARS 评分和 CVSS v4.0 分解。
- **Evaluation 结果**：
  - 在 78 个已确认的恶意技能上实现了 **0 假阴性**（Zero False Negatives）。
  - 在 22 个良性控制样本上实现了 **0 假阳性**（Zero False Positives）。
  - 不同的 LLM 评估器的检测率在 35% 到 95% 之间波动，表明在生产部署中采用集成评分（ensemble scoring）的必要性。
- **相关工作对比**：
  - 最好的静态基线工具 SKILLSIEVE 仍然遗漏了 15% 的威胁。
  - 对于指令层类别（如提示注入和记忆投毒），传统工具的漏报率在 89% 到 100% 之间。例如，CODEBERT 未能检测到 9 个记忆投毒技能中的任何一个。

#### 总结
本文针对开源 LLM Agent 技能生态系统中日益严峻的安全问题，指出了现有基于代码层的静态扫描工具在应对指令层攻击时的结构性缺陷。作者提出了 SkillVetBench，利用 LLM-as-Judge 技术构建了首个针对 Agent 技能的多维度安全评估基准和实时排行榜。通过引入 SARS 评分体系和 CVSS v4.0 分解，该方法在检测提示注入、记忆投毒等复杂语义攻击方面显著优于传统静态分析工具，实现了零假阴性和零假阳性的优异表现，为开源 Agent 生态的安全治理提供了标准化的自动化解决方案。
