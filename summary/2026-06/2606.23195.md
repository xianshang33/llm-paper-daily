## 文章做了什么
- **背景**：大型语言模型（LLM）智能体越来越依赖记忆系统来维持长期的连贯性。现有的研究主要关注记忆在持续整合（consolidation）过程中的退化问题，即有用记忆变得 faulty。
- **已有工作的局限性**：现有研究假设输入的记忆经验是无偏的。然而，现实中智能体往往由带有系统性偏好（如长度偏好或权威偏见）的评估器引导或训练，导致产生的经验本身带有偏见。现有工作未能解决这种通过记忆系统在时间维度上传播的评估器偏见问题。

## 文章的核心贡献点
- **提出了一个概念与度量框架**：正式定义并量化了“记忆传染”（Memory Contagion），即评估器偏见通过智能体记忆进行的跨时间传播现象，并引入了 $\Gamma_{temporal}$ 作为衡量指标。
- **挑战1：证明偏见传播的根本原因并非仅源于记忆整合机制的缺陷**。难点在于区分是整合过程本身导致了偏见放大，还是 biased input 本身就足以导致传播。论文通过设置“完美整合”（oracle condition）实验，证明了即使整合过程完美无缺，只要输入经验有偏，记忆传染依然发生（$\Gamma_A$ 显著大于0），确立了 biased input 是传染的充分条件。
- **挑战2：揭示不同偏见类型与记忆整合机制的复杂交互效应**。难点在于理解整合过程对不同类型偏见的影响是否一致。论文发现整合对“长度偏好”偏见有显著的衰减作用，但对“权威偏见初步显示有放大作用，揭示了偏见类型依赖的未知交互机制，打破了以往认为整合仅导致退化的单一认知。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：进行了四个阶段的实证研究，涵盖两种偏见类型（长度偏好、权威偏见）。
- **主要结果**：
    1. **存在性验证**：在完美整合条件下，长度偏见的 $\Gamma_A = 13.18$，权威偏见的 $\Gamma_A = 11.45$，证实了记忆传染的存在。
    2. **整合的双重效应**：整合过程稳健地 attenuating（减弱）长度偏见（$\Gamma_B = 2.03$），但初步显示 amplifying（放大）权威偏见（$\Gamma_B = 16.80$）。
    3. **无安全阈值**：即使在污染率低至 $p=0.2$ 时也能检测到偏见传播，表明不存在安全的污染阈值。
    4. **机制分解**：内容污染（content contamination）是主要传播途径，而非检索机制。
- **对比**：与先前关注单智能体强化学习中偏见或仅关注记忆退化的工作不同，本文揭示了跨智能体、跨时间的记忆外部化机制带来的新脆弱性。

#### 总结
本文揭示了 LLM 智能体记忆系统设计中的一个关键漏洞：记忆传染。研究表明，来自有偏评估器的经验一旦存入记忆，即便经过完美的整合，也会将偏见传播给未来的智能体。此外，记忆整合对不同偏见具有截然不同的影响（减弱长度偏见但可能放大权威偏见）。这一发现挑战了现有对记忆整合作用的认知，并为衡量和缓解跨时间偏见传播提供了形式化工具。
