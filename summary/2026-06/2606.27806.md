## 文章做了什么
- **背景**：大型语言模型（LLM）智能体通常采用两种世界模型形式：基于代理的世界模型（Agent-based）通过调用 LLM API 进行灵活的语言推理，但容易产生难以量化的幻觉状态变化；参数化世界模型（Parameterized）作为训练好的转移预测器，其误差易于通过 NodeMSE 等指标衡量，但作为独立规划器时语义推理能力较弱。
- **已有工作为什么解决不了**：现有的基于代理的方法虽然推理能力强，但其错误表现为语义幻觉（如虚构未发生的事件或忽略依赖关系），这些错误无法用传统的回归损失有效评分，且会在长程规划中累积传播，导致规划失败。而纯参数化模型虽误差可控，但缺乏处理复杂语义和灵活规划的能力。两者各有优劣，单一方法难以兼顾低幻觉率与高推理能力。

## 文章的核心贡献点
- **提出了一个 Grounded Iterative Language Planning (GILP)**：一种结合小型参数化骨干网络与 API 基于代理推理的混合规划框架。
- **挑战1：如何量化并抑制基于代理模型中的语义幻觉？**
  - **难点**：基于 LLM 的状态转移是自然语言或 JSON 格式，其错误（如实体状态虚构）不像数值预测那样有明确的 MSE 损失，且容易在后续步骤中传播。
  - **解决方法**：论文定义了操作性的幻觉指标（如幻觉状态率、传播深度），并引入一个小型参数化骨干网络来提供有效的动作、预测的状态增量、风险和价值评估，作为“接地”参考。
- **挑战2：如何在保留 LLM 强大推理能力的同时纠正其规划错误？**
  - **难点**：直接替换为参数化模型会丧失 LLM 的语义理解与灵活推理优势，而完全依赖 LLM 则无法保证状态一致性。
  - **解决方法**：设计了一致性门控机制（Consistency Gate）。LLM 起草动作和想象的状态增量，若与参数化骨干网络的预测不一致，则要求 LLM 进行修订。这种迭代过程既利用了 LLM 的推理能力，又通过参数化模型约束了幻觉传播。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：GILP 仅训练一个小型的参数化骨干网络，并结合现成的 LLM API（如 GPT-4o-mini）进行推理。系统通过一致性检查迭代修正规划路径。
- **评估结果**：
  - **真实 API 调用**：在使用 GPT-4o-mini 的实际测试中，GILP 将幻觉状态率从基线的 0.176 显著降低至 0.035。
  - **模拟器消融实验**：在校准的模拟器环境中，GILP 将任务成功率从 0.668 提升至 0.838。
  - **效率对比**：上述性能提升仅增加了约 22% 的额外 LLM 调用次数，证明了该方法在成本与效果之间的良好平衡。
- **相关工作对比**：相比纯基于代理的方法（易产生级联幻觉）和纯参数化方法（规划能力弱），GILP 在四个图结构规划基准测试中均表现出更优的综合性能，有效解决了长程规划中的误差累积问题。

#### 总结
本文针对 LLM 智能体在世界建模中的幻觉传播问题，提出了 GILP 框架。通过结合小型参数化世界模型的精确状态预测能力与 LLM API 的强大语义推理能力，并利用一致性门控机制进行迭代修正，GILP 在显著降低幻觉状态率的同时大幅提升了规划成功率。该方法以较低的额外计算成本实现了更可靠、更准确的自主代理规划，为混合式世界模型的设计提供了新的思路。
