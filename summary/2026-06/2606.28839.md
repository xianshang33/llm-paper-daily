## 文章做了什么
- **背景**：在多智能体大语言模型（LLM）系统中，当多个 LLM 进行交互时，其输出分布会通过重复交换而演变。一个智能体的偏差可能会在网络中传播，导致输出耦合，这种现象在单模型基准测试中无法捕捉。
- **已有工作为什么解决不了**：目前社区缺乏可复用的测量框架来量化这种现象。现有的工作主要集中在单模型偏差探测（如 BBQ、StereoSet）或定性的多智能体案例研究上，缺乏原则性的指标来回答诸如“增加第二种模态会如何放大耦合？”或“记忆是否增加了时间持久性？”等定量问题。

## 文章的核心贡献点
- **提出了一个**：传染张量（Contagion Tensor）框架及耦合放大因子（Coupling Amplification Factor, CAF）。
- **挑战1：缺乏统一且可证伪的耦合度量标准。**
  - **难点**：以往研究中存在多个冲突的符号和定义，导致不同模态、智能体和时间步长之间的耦合效应难以进行统一、无单位的基线参考比较。
  - **解决方法**：定义了传染张量 $T \\in \\mathbb{R}^{M \times N \times T}$，并从中导出 CAF 指标族（形式为 $CAF = E[T_{condition}] / E[T_{baseline}]$）。该指标提供了带有 bootstrap 置信区间的无单位测量，使得输出分布耦合首次成为可定量证伪的对象。
- **挑战2：难以区分真实的耦合效应与模拟器设计 artifacts（人为假象）。**
  - **难点**：在模拟环境中观察到的某些显著效应（如图像条件下的超线性效应）可能并非源于模型本身，而是由模拟器的特定模块设计引入的偏差，传统方法难以剥离这些因素。
  - **解决方法**：提出了一种可迁移的消融协议（ablation protocol）。通过模块化地禁用特定组件（如图像扰动模块），对比消融前后的 CAF 变化，从而区分 genuine coupling 与设计 artifacts。例如，研究发现所谓的图像超线性效应在禁用特定模块后消失，证明其为设计假象。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与实验设计**：
  - **模拟实验**：采用完整的 $2 \times 2 \times 2$ 块正交模拟设计，评估最强的 CAF 变体（$CAF_{base}$），并进行模态特定的消融实验。
  - **真实 API 实验**：在 DeepSeek-Chat 和 GPT-4o-mini 两个模型家族上进行补充实验，涵盖文本-only 和真实视觉条件。
- **Evaluation 结果**：
  - **模拟消融发现**：初始显示图像条件具有超线性效应（CAF = 1.40），但在禁用图像扰动模块后，该效应坍塌为亚线性（CAF = 0.87），偏移量为 -0.53，而文本条件不受影响。这揭示了之前的“分叉”现象是模拟器的设计 artifact。
  - **真实模型验证**：
    - 在统一人设下，纯文本通信在两个模型中均产生 CAF ≈ 1.0。
    - 多样化人设驱动收敛（CAF = 0.88）。
    - 在 GPT-4o-mini 的模型内比较中，文本条件（C3）CAF = 1.02，而真实视觉条件（C5）CAF = 1.72 [1.700, 1.733]，差值为 +0.70。这一结果验证了模拟预测中关于图像条件存在真实超线性效应的部分（在排除 artifact 后）。
- **对比**：相较于仅能提供定性描述或单模型静态偏差测量的先前工作，本文提供的 CAF 框架能够定量区分多智能体系统中的动态耦合强度，并通过消融协议提供了更高的审计可信度。

#### 总结
本文引入了传染张量和耦合放大因子（CAF），填补了多智能体 LLM 系统中输出分布耦合定量测量的空白。通过结合严格的模拟消融分析和真实 API 实验，文章不仅提供了一套可证伪的测量工具，还建立了一种区分真实耦合效应与系统设计假象的方法论标准。研究结果表明，视觉模态在特定条件下确实能显著放大耦合效应，但需谨慎排除模拟器引入的偏差。该框架为未来多智能体系统的安全审计和性能评估提供了基础工具。
