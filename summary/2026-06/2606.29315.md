## 文章做了什么
- **背景**：大型语言模型（LLM）及其智能体在现实世界行动和辅助决策中应用日益广泛，但现有系统主要依赖预训练获得的参数化知识、固定数据的后训练、检索增强生成（RAG）或搜索。这种范式在密集覆盖的训练领域表现良好。
- **已有工作为什么解决不了**：在面对新颖领域或无法仅凭先验知识回答的复杂查询时，现有范式失效。例如，仅知道物理定律不足以让 LLM 在复杂的物理系统中完成长视野任务或回答特定查询，因为它们缺乏通过主动实验探索未知环境、获取针对性数据并从中学习可复用技能的能力。

## 文章的核心贡献点
- **提出了一个**名为 Hierarchical Experimentalist Agents (HExA) 的框架，这是一种基于上下文的、以实验为中心的自我改进框架，旨在通过主动实验进行学习。
- **挑战1：如何在没有先验知识的新颖环境中获取有效信息？**
  - **难点**：传统代理无法针对特定查询设计有效的探索策略，导致在未知环境中盲目行动。
  - **解决方法**：HExA 迭代地设计并优化与查询相关的实验，通过主动干预和假设测试来收集针对性的实验证据，从而弥补知识空白。
- **挑战2：如何从有限的实验经验中提炼通用能力以加速后续任务？**
  - **难点**：每次任务独立求解导致效率低下，无法跨任务迁移知识，且长视野任务需要组合多种技能。
  - **解决方法**：HExA 从经验中增量式地学习一个可复用且可组合的技能库（Skill Bank），并将这些技能整合到后续任务的上下文中，实现跨任务的加速和泛化。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与基准**：为了评估主动实验能力，作者引入了 Interphyre 基准，该基准基于 PHYRE 2D 程序化物理模拟环境，提供工具调用和干预 API，允许代理提出假设并通过模拟进行测试。HExA 是完全基于上下文且无需训练的，兼容任何黑盒模型，不依赖外部监督或离线数据。
- **评估结果**：
  - 在 Interphyre 的最难级别上，基线模型 Claude Sonnet 4.6 的成功率仅为 2%。
  - 引入 HExA 框架后，同一模型的成功率提升至高达 77%。
  - HExA 在开源权重模型上也表现出类似的显著提升。
- **相关工作对比**：HExA 显著优于 ReAct 和 Reflexion 等现有的智能体基线方法。
- **泛化能力验证**：仅使用从较简单级别学习并迁移而来的技能（不进行新的主动实验），HExA 仍能达到 44% 的成功率，证明了其学习技能的可复用性和泛化能力。

#### 总结
HExA 证明了通过主动实验进行学习可以使智能体有效地发现新知识并获取可复用的技能，从而在新颖的长视野任务中取得高效进展。该框架突破了依赖静态参数知识的局限，为 LLM 在复杂、未知物理环境中的推理和行动提供了新的范式。
