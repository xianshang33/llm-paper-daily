## 文章做了什么
- **背景**：医疗预约调度长期存在操作瓶颈，主要受限于人工协调、碎片化的遗留系统以及高昂的管理开销。这些低效问题限制了医生的可用时间，并降低了患者获得护理的机会。
- **已有工作为什么解决不了**：现有的大型语言模型（LLM）系统大多专注于临床决策支持或信息检索，缺乏处理操作性医疗工作流（如预约调度）所需的严格安全性、可靠性和事务正确性。通用 LLM 难以直接部署于现实世界的医疗运营中，因为它们无法有效应对安全范围控制、状态化事务操作的精确编排以及结构化数据库动作与非结构化响应结合的挑战。

## 文章的核心贡献点
- **提出了一个 CareConnect**：这是一个以安全为首要目标的对话式代理，用于医疗物流自动化，结合了 LLM 函数调用、检索增强生成（RAG）和分层确定性安全护栏。
- **挑战1：安全与范围控制**。在医疗场景中，代理绝不能提供医疗建议、进行诊断或未能正确处理紧急情况，这极具风险且难以通过概率模型保证。论文通过确定性的预 LLM 意图过滤机制解决该挑战，利用基于规则的意图分类器在 LLM 调用前拦截紧急、诊断和医疗咨询请求，并通过预定义响应和升级路径处理这些安全关键查询。
- **挑战2：状态化事务操作的精确编排**。调度工作流涉及可用性搜索、预订、修改和取消等有状态操作，错误会导致患者伤害和系统状态不一致，而现有 RAG 系统多侧重于知识检索而非操作上下文。论文通过模式约束的工具编排框架解决该挑战，协调八个领域特定工具，并在工具级别实施状态验证，确保结构化数据库动作与交互逻辑的准确执行。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：CareConnect 整合了确定性预 LLM 意图过滤、感知范围的系统提示和有状态的工具级验证。系统开源，代码可在 GitHub 获取。
- **评估结果**：在包含 680 个任务导向场景（涵盖端到端工作流、多轮交互和边缘案例）的综合基准测试中，CareConnect 实现了 91.8% 的任务完成率，单次请求的中位延迟为 2.2 秒。在专门的安全关键评估子集中，安全合规率达到 96.0%。平均每次预约的操作成本为 0.0324 美元。
- **对比**：相较于人工调度，该系统显著降低了成本，同时证明了经过精心界定范围和严格保护的基于 LLM 的代理可以在保持安全保证的同时，可靠地自动化复杂的医疗运营工作流。

#### 总结
本文提出的 CareConnect 展示了如何通过分层确定性安全护栏和严格的范围约束，将 LLM 安全地应用于医疗后勤自动化。它成功解决了通用 LLM 在医疗操作场景中面临的安全性和事务一致性难题，以极低的成本和较高的任务完成率实现了预约调度的自动化，为可信医疗 AI 代理的部署提供了可行范式。
