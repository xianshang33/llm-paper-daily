## 文章做了什么
- **背景**：随着大语言模型（LLM）从监督预训练转向强化学习（RL）后训练，针对长程智能体（Agentic）任务，传统的同步批量交错式 RL 管道效率低下，因为 GPU 集群需等待最慢的 rollout 完成，导致大量空闲。异步 RL 作为一种更高效的替代方案应运而生，它能在 rollout 到达时立即更新模型。
- **已有工作为什么解决不了**：现有的异步 RL 系统主要关注吞吐量优化，而忽视了训练稳定性和任务有效性。特别是广泛使用的 GRPO 框架采用组级采样（group-wise sampling），这与异步训练天然不匹配：组内样本需等待所有成员完成才能计算优势，导致严重的离线策略（off-policy）问题和延迟，且难以适应动态变化的在线学习环境。

## 文章的核心贡献点
- **提出了一个 Single-rollout Asynchronous Optimization (SAO)**：一种专为异步智能体 RL 设计的优化框架，旨在解决稳定性与离线策略挑战。
- **挑战1：异步环境下的严重离线策略效应与泛化能力不足**。由于异步训练中轨迹由不同版本的旧模型生成，导致分布偏移不可预测且严重，损害训练稳定性。SAO 通过将组级采样替换为单 rollout 采样（即每个 prompt 仅使用一个 rollout），显著减少了离线策略效应并提高了泛化能力，同时结合实用的价值模型训练设计进一步优化该策略。
- **挑战2：异步优化过程中的训练不稳定性**。异步更新容易引发梯度爆炸或震荡。SAO 引入了一种严格的双侧 token 级裁剪策略（strict double-side token-level clipping strategy），有效约束了更新幅度，从而确保了长达一千步的稳定训练。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：SAO 已成功部署于开源 GLM-5.2 模型（750B-A40B）的智能体 RL 训练管道中，证明了其在大规模模型训练中的可行性。
- **评估结果**：在多个智能体编码和推理基准测试中，SAO 均一致优于 GRPO 及其变体。具体包括 SWE-Bench Verified、BeyondAIME 和 IMOAnswerBench 等。例如，在 SWE-Bench Verified 上，SAO 取得了 76.0% 的准确率，而 GRPO 仅为 54.8%；在 BeyondAIME 上，SAO 达到 97.3%，远超 GRPO 的 88.3%。
- **相关工作对比**：与主要关注效率优化的先前异步 RL 工作不同，SAO 在保持高吞吐量的同时，显著提升了任务效果和训练稳定性。此外，SAO 在模拟的在线学习设置中表现出更强的适应性，能够应对不断演变的环境，这是传统同步方法或标准 GRPO 难以做到的。

#### 总结
本文提出的 SAO 框架通过单 rollout 采样和严格的 token 级裁剪策略，有效解决了异步 RL 中的离线策略效应和训练不稳定问题。实验表明，SAO 不仅在推理和编码基准上全面超越 GRPO，还具备优秀的在线适应能力，并成功应用于超大规模模型 GLM-5.2 的训练，为高效、稳定的智能体 RL 后训练提供了新的范式。
