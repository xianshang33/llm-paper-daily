## 文章做了什么
- **背景**：数字采用平台（DAP）广泛用于在网页系统上提供操作指引，帮助用户快速上手陌生界面。然而，完成真实任务通常涉及跨多个页面状态的一系列操作，且目前的DAP指引主要依赖人工编写和维护，成本高昂。
- **已有工作为什么解决不了**：现有研究将“自动化Web代理动作执行”和“指引文本生成”视为两个独立的问题。此外，大多数现有方法使用DOM树或无障碍树等文本化页面表示，而非人类实际操作的渲染屏幕截图，导致模型难以捕捉真实的视觉交互细节，且缺乏统一评估动作与指引质量的基准。

## 文章的核心贡献点
- **提出了一个 MAG 基准与框架**：这是第一个将任务执行和指引写作统一为单一“多模态动作与指引”任务的基准，支持基于截图的两种定位方案（Set-of-Mark元素选择和原始像素坐标），并构建了涵盖标注、训练、实时环境评估及联合指标的完整框架。
- **挑战1：动作执行与指引生成的割裂与多模态 grounding 难题**
  - **描述与难点**：传统方法要么只关注任务完成，要么仅基于文本结构生成单页指引，无法处理跨页面的复杂任务序列，且难以将自然语言指令精确映射到视觉界面上的具体元素。
  - **解决方法**：MAG 要求单个智能体在完成每一步动作的同时生成对应的指引文本，并引入 Set-of-Mark (SoM) 和原始像素坐标两种 grounding 机制，使模型能直接基于视觉截图进行精确的元素定位和操作。
- **挑战2：缺乏高质量的多模态 Web 代理训练数据与评估体系**
  - **描述与难点**：现有的开源多模态模型在复杂 Web 任务上表现不佳，部分原因是缺乏结合专家轨迹的高质量强化学习训练方法，且缺乏同时衡量动作成功率和指引可用性的联合评估指标。
  - **解决方法**：设计了结合专家轨迹的 GRPO（Group Relative Policy Optimization）训练方法，显著提升了模型性能；同时建立了包含 LLM 辅助标注和人工验证的数据构建流程，以及针对动作和指引的联合评估指标。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：构建了完整的 MAG harness，包括利用 LLM 辅助和人工验证进行数据标注，支持在实时 Web 环境中进行评估。提出了基于 GRPO 的训练策略，利用专家轨迹增强 9B 参数规模的监督模型。
- **评估结果**：
  - **性能提升**：经过 GRPO 训练后，9B 代理的任务成功率从 6.9% 提升至 13.2%，几乎翻倍，同时指引质量也得到了改善。
  - **前沿模型表现**：即使是最强的 API 模型和开源多模态模型，完成的任务比例也不足 40%，表明该任务具有极高的挑战性。
  - **对比分析**：相较于以往仅关注 DOM 树或单一任务完成的基准，MAG 揭示了当前模型在处理视觉 grounding 和多步推理生成指引方面的不足，为未来研究提供了更真实的评估场景。

#### 总结
本文介绍了 MAG，首个统一 Web 代理动作执行与指引生成的多模态基准。通过引入基于截图的 grounding 方案和完整的评估框架，解决了现有研究中动作与指引割裂、以及缺乏真实视觉交互评估的问题。实验表明，结合专家轨迹的 GRPO 训练能显著提升模型性能，但当前最强模型仍面临巨大挑战，证明了 MAG 作为未来 Web 代理研究基准的重要价值。
