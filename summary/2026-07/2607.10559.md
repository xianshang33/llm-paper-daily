## 文章做了什么
- **背景**：金属有机框架（MOFs）因其高度模块化的结构，在吸附性气体分离领域展现出巨大潜力。然而，其巨大的网状设计空间使得在同时满足化学有效性、分离性能和结构多样性约束下的逆向设计变得极其困难。
- **已有工作局限性**：传统的高通量计算筛选依赖于固定的实验或假设数据库，无法探索未知的广阔化学空间；现有的生成式模型或优化算法往往难以同时保证生成的MOF结构的化学合理性、高性能以及结构的多样性，且缺乏对失败案例的有效利用机制。

## 文章的核心贡献点
- **提出了一个 LEMO Agent**：这是一个基于大语言模型（LLM）的智能体框架，用于在 MOFid 空间中对气体分离 MOF 进行闭环逆向设计。
- **挑战1：如何在巨大的组合空间中保证生成结构的化学有效性和合理性？**
  - **难点**：MOF由金属节点、有机连接体和拓扑结构组成，随意组合极易产生化学上无效或不稳定的结构。
  - **解决方法**：LEMO Agent 将基于语言的候选生成与 MOFid 标准化、显式的有效性检查相结合，并通过迭代“生成-验证-评估-记忆”循环，利用成功和失败候选者的反馈来指导受化学约束的搜索。
- **挑战2：如何避免陷入局部最优并保持结构的多样性，同时提升分离性能？**
  - **难点**：传统的优化方法容易收敛到少数几种已知的高性能结构，导致多样性丧失，且难以平衡性能与新颖性。
  - **解决方法**：引入结构化设计记忆和多岛探索策略（multi-island exploration），结合基于 Transformer 的性质预测模型，使智能体能够广泛探索连接体、金属和拓扑的选择，从而丰富高性能候选者并维持广泛的化学和拓扑多样性。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：LEMO Agent 整合了语言模型生成、MOFid 标准化、有效性检查、Transformer 性质预测、结构化记忆和多岛探索模块。选定的候选分子经过重建，通过巨正则蒙特卡洛（GCMC）模拟进行评估，并基于化学可行性和配体可购买性通过实验下行选择工作流程，最终进行了初步的湿法合成和扫描电子显微镜（SEM）表征。
- **评估结果**：在 CH4/N2 和 CO2/N2 分离任务上进行了评估。
- **对比相关工作**：与代表性的生成式、优化式和基于智能体的基线方法相比，LEMO Agent 显著丰富了高性能候选者的数量，提高了预测的分离性能，同时保持了更广泛的化学和拓扑多样性。实验验证证明了其从计算设计到实际合成的可行性。

#### 总结
本文展示了 LLM 智能体可以作为可解释且可扩展的设计引擎，加速 MOF 的发现过程，突破了传统固定库筛选的限制。LEMO Agent 通过闭环反馈机制有效解决了逆向设计中的化学有效性、性能优化和多样性保持难题，并为实验合成提供了切实可行的候选材料，证明了 AI 驱动的材料逆向设计在实际科研中的应用价值。
