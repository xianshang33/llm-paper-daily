## 文章做了什么
- **背景**：智能体系统（Agentic Systems）正通过编辑技能（如提示词、规则、计划、工具契约等）来实现自我改进。现有的方法如 SKILL OPT 将技能优化视为一个实验循环：提出修复建议，运行智能体，并根据验证性能决定是否接受编辑。
- **已有工作为什么解决不了**：现有的优化方法通常假设编辑是向量空间中的独立坐标，忽略了技能作为结构化 artifacts 的本质。主要问题在于：1) 不同的编辑可能产生相同的即时可见效果，但在路由上下文、模板状态或未来组合性上存在差异；2) 编辑的顺序至关重要（非交换性），例如先修复 schema 再应用规范化规则，与反向操作的效果不同。传统的暴力枚举或短视的单步验证无法有效捕捉这种复杂的几何结构和顺序依赖性，导致计算成本极高且容易陷入局部最优。

## 文章的核心贡献点
- **提出了一个 LASKO (Lie Algebroid SKill Optimization) 框架**：该框架将类型化、锚定的 Markdown 技能建模为基础范畴，将可用的编辑策略建模为受控李代数胚（Lie algebroid）的截面。
- **挑战1：编辑的非交换性与顺序依赖**。难点在于编辑操作的顺序会影响最终结果，传统的组合优化难以高效处理这种路径依赖。LASKO 利用李代数胚的括号（algebroid bracket）来度量编辑组合的非交换性，从而在数学上精确刻画编辑顺序对技能状态的影响。
- **挑战2：高昂的验证成本与隐藏状态不可见**。难点在于每次编辑都需要通过大型语言模型（LLM）进行昂贵的 rollout 和验证，且许多潜在的结构变化（如路由逻辑）在表面不可见。LASKO 引入锚映射 $\rho$，将编辑策略映射到可见的 Markdown 效果，其核 $\\ker(\rho)$ 表示潜在的模板或实现结构。通过在执行昂贵验证前进行微秒级的廉价李括号筛选测试，大幅减少了无效编辑的评估次数。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：LASKO 框架通过数学结构优化搜索空间，无需改变底层 LLM 架构，而是优化编辑策略的选择过程。它结合了无穷小因果性（Infinitesimal Causality）理论，用局部干预替代有限的反事实猜测。
- **Evaluation 结果**：在初步基准测试中，LASKO 实现了数量级的速度提升。在从自然语言中进行因果提取的任务上，与暴力方法相比，LASKO 实现了近 **15倍** 的加速。
- **相关工作对比**：对比对象为 brute-force 方法，即通过运行 DeepSeek V3.1 4-bit 模型（671B 参数）来验证所有编辑。LASKO 的优势在于利用廉价的数学筛选测试替代了大部分昂贵的 LLM 推理调用，从而在保证优化质量的同时显著降低了计算资源消耗。

#### 总结
本文提出了 LASKO 框架，首次将李代数胚几何引入智能体技能优化领域。通过建模编辑的非交换性和隐藏结构，LASKO 解决了传统方法中编辑顺序敏感和验证成本高昂的问题。实验表明，该方法在保持优化效果的同时，相比基于超大参数模型的暴力验证方法取得了显著的效率提升，为智能体自我改进提供了几何化的理论基础和高效实践路径。
