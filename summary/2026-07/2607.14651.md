## 文章做了什么
- **背景**：持久化外部记忆增强了 LLM Agent 的连续性，但也引入了持久的安全漏洞。攻击者可以通过标准交互通道注入对抗性内容，这些内容被保留并在后续回合中扭曲下游行为。
- **已有工作的不足**：现有评估支离破碎，主要关注简化的威胁模型（如孤立的单条记录注入），且仅评估狭窄的记忆抽象层。缺乏统一的基准测试框架来表征更真实的攻击模式（如组合腐败和上下文触发的休眠行为）。此外，现有的写入时防御（如一致性检查）的有效性在直接注入之外的场景中尚不清楚，且缺乏对失败如何产生和传播的深入可见性。

## 文章的核心贡献点
- **提出了一个 MemPoison 基准与分析框架**：包含 1227 个手工验证的案例，涵盖 4 种攻击类型、3 种注入通道和 3 种代表性记忆基底，并在 7 个开源和 3 个闭源模型家族上进行了评估。
- **挑战 1：复杂攻击模式的系统性评估缺失**。难点在于现有工作难以捕捉多记录组合或上下文触发的隐蔽攻击。论文通过引入三层分类法（L1 直接单记录腐败、L2 组合多记录腐败、L3 上下文触发休眠腐败）解决了这一挑战，全面覆盖了从简单到复杂的攻击谱系。
- **挑战 2：写入时防御的结构盲点难以解释**。难点在于传统防御能拦截 L1 攻击，但对 L2/L3 失效，且原因不明。论文通过机制影响分解（MID）技术，揭示了写入时防御的结构盲点，证明了看似良性的记录如何通过联合检索组合或触发条件激活而在后期变得有害，从而解释了防御失败的根本原因。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：评估了 7 个开源权重模型家族和 3 个闭源模型家族，覆盖三种代表性记忆基底。
- **主要结果**：基线写入时防御（如一致性检查）能显著抑制直接的 L1 攻击，但无法可靠地抑制 L2（组合腐败）和 L3（上下文触发休眠腐败）攻击。
- **对比分析**：与仅关注单条记录注入的先前工作相比，MemPoison 揭示了防御的前沿界限。通过 MID 分析发现，现有防御存在结构盲点，允许看似无害的记录进入记忆库，这些记录在后续通过组合或特定上下文触发时产生危害。这表明静态过滤不足以应对高级威胁。

#### 总结
本文提出了 MemPoison，首个针对 LLM Agent 持久化记忆威胁的综合基准和分析框架。通过建立 L1-L3 三级攻击分类法，研究揭示了当前主流的写入时防御策略在处理组合式和上下文触发式攻击时的结构性盲点。研究结果强烈建议将防御策略从静态过滤转向自适应、上下文敏感的记忆防御机制，以应对日益复杂的持久化记忆安全风险。
