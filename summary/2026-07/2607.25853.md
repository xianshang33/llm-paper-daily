## 文章做了什么
- **背景**：在长程交互任务中，技能（Skills）已成为大型语言模型（LLM）智能体重用历史经验的关键抽象。现有的方法通常从交互轨迹中自动提取技能，以提高多步任务解决的效率和稳定性。
- **已有工作的不足**：现有的“轨迹到技能”方法主要存在两个局限：一是生成的技能通常是扁平化的高层文本描述集合，导致高层技能与具体可执行动作之间存在鸿沟，LLM难以仅凭文本推断具体的动作参数和执行时机；二是技能被独立存储和检索，忽视了技能之间以及共享动作模式之间的结构关系，导致这些关系未被充分利用。

## 文章的核心贡献点
- **提出了一个 HiSkill 框架**：一种分层技能图框架，将交互轨迹组织为包含技能节点、原子操作（AtomicOp）节点和类型化边的有向图。
- **挑战1：高层技能与底层可执行动作之间的语义鸿沟**。难点在于高层技能仅提供策略指导，缺乏具体的动作 grounding 信息。HiSkill 通过在图中直接连接高层技能节点与可执行的 AtomicOp 节点，并捕捉分解、时序转换等关系，使得智能体在推理时能依据子图引导，从高层技能逐步落地到具体的原子操作和动作参数。
- **挑战2：技能间关系的利用不足导致检索效率低且上下文冗余**。难点在于传统扁平存储无法体现技能间的依赖和共享结构。HiSkill 通过构建包含兼容性、支持和恢复关系的类型化边，在推理时检索紧凑的任务相关子图，既保留了必要的结构上下文，又显著减少了输入 LLM 的 token 消耗，提高了决策的准确性。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：HiSkill 在推理阶段检索与任务相关的紧凑子图，结合符号任务状态、当前活跃技能和检索到的子图，引导 LLM 智能体迭代地进行技能切换、AtomicOp 选择和动作落地。
- **评估结果**：在三个交互式环境中的实验表明，HiSkill 的性能优于现有的最先进基线方法（如 SkillRL, D2Skill, CoEvoSkills 等）。
- **对比优势**：除了成功率提升外，HiSkill 还显著降低了推理过程中的 token 消耗，证明了通过分层技能图桥接高层技能与底层动作落地的有效性。

#### 总结
HiSkill 通过引入分层技能图结构，有效解决了现有 LLM 智能体技能学习中高层抽象与底层执行脱节以及技能关系利用不足的问题。该方法不仅提升了长程交互任务的成功率，还通过结构化检索优化了推理效率，为 LLM 智能体的经验重用提供了新的范式。
