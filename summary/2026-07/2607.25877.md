## 文章做了什么
- **背景**：保险行业的精算风险建模是一个高风险的决策支持场景，对准确性、公平性和合规性要求极高。大型语言模型（LLM）驱动的多智能体系统（MAS）有望自动化数据准备、建模和解释等复杂工作流，但 LLM 固有的概率性质导致了输出不可靠。
- **已有工作的不足**：现有的方法缺乏透明度，被视为“黑盒”，且无法充分解决多步智能体工作流中错误和不确定性的产生及传播问题。单个智能体的幻觉或变异可能传播到后续阶段，导致难以检测的错误结果，这在受严格监管的精算领域是不可接受的。

## 文章的核心贡献点
- **提出了一个**基于贝叶斯网络的 LLM 多智能体系统运行时不确定性监控框架。
- **挑战1：如何量化 LLM 输出的原始不确定性并使其具有可比性？**
  - **难点**：LLM 生成的 token 级 log-probabilities 不能直接等同于任务成功的概率，且受输出长度影响大，直接使用会导致偏差。
  - **解决方法**：论文提出将长度归一化的 log-probability 摘要转换为校准后的任务级置信度估计，而不是将其视为直接的正确答案概率，从而获得更可靠的局部不确定性指标。
- **挑战2：如何建模和追踪多智能体工作流中的不确定性传播？**
  - **难点**：智能体之间存在依赖关系，前序步骤的不确定性会影响后续步骤，简单的独立评估无法捕捉这种连锁反应。
  - **解决方法**：引入贝叶斯网络（Bayesian Network）来捕捉工作流各阶段之间的依赖关系，将校准后的任务级置信度纳入网络，实现端到端的运行时不确定性传播监控。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：构建了一个包含中心枢纽和多角色智能体（数据准备、建模、审查、解释）的框架。核心机制是利用 LLM 输出的 token 级 log-probabilities，经过长度归一化和校准后，作为证据输入到贝叶斯网络中。
- **评估结果**：实验表明，该框架在保持基线精算性能的同时，能够提供关于工作流稳定性和运行时不确定性传播的额外洞察。
- **对比**：与传统缺乏不确定性量化的 LLM 多智能体方法相比，该方法不仅提供了最终结果，还结构化地展示了不确定性如何在各个步骤间传递，增强了系统的可解释性和安全性监控能力。

#### 总结
本文针对保险精算这一高风险领域，提出了一种结合 token 级 log-probabilities 和贝叶斯网络的新型不确定性传播方法。通过校准置信度并建模智能体间的依赖关系，该框架有效解决了 LLM 多智能体系统在复杂工作流中的透明度和安全性问题，为高风险决策支持提供了可靠的运行时监控机制。
