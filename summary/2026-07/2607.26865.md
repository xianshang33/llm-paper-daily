## 文章做了什么
- **背景**：基于 ReAct 范式的 LLM Agent 在复杂多步任务（如多跳问答、代码生成、物理 AI 控制）中表现出色。然而，在边缘设备部署时，面临计算资源受限的问题，必须在保证可靠性的同时严格管理推理预算，并仅在本地不确定性过高时才将任务推迟（defer）到云端模型。
- **已有工作的不足**：现有的方法通常单独处理推理长度控制或云侧推迟机制。一方面，边缘模型可能在动作决策已经稳定后继续生成冗余的思维令牌，造成计算浪费，甚至导致模型对次优动作产生过度自信，干扰基于不确定性的推迟判断；另一方面，缺乏一种联合校准机制来同时保证端到端的任务奖励和云调用率，导致要么计算开销过大，要么可靠性无法得到理论保证。

## 文章的核心贡献点
- **提出了一个 Think Short, Defer Smart (TSDS) 框架**：该框架协同集成了轻量级的收敛探针和基于困惑度（perplexity）的推迟规则，并通过多目标 Learn-Then-Test (LTT) 过程进行联合校准，提供有限的样本保证。
- **挑战1：如何避免过度的本地推理计算而不牺牲决策质量？**
  - **难点**：思维链生成占据了大部分推理计算，且模型常在决策收敛后继续生成无用令牌，甚至因过度思考而变得过度自信。
  - **解决方法**：引入轻量级收敛探针（convergence probe），监测隐藏表示以检测预期动作何时稳定，一旦稳定即停止本地推理，从而大幅减少每步的计算开销。
- **挑战2：如何在资源受限下保证可靠性并最小化昂贵的云调用？**
  - **难点**：需要在本地不确定性高时准确触发云侧大模型介入，同时需对云调用率和最终任务奖励提供严格的统计保证，单一机制难以兼顾效率与可靠性。
  - **解决方法**：设计基于困惑度的推迟规则，将不确定的动作升级至云端，并利用多目标 LTT 程序对收敛阈值和推迟阈值进行联合校准，从而在有限样本下同时保证期望episode奖励和云调用率上限。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **评估基准**：在四个 ReAct 基准上进行评估，包括算术推理（GSM8K）、多跳问答（HotpotQA）、代码生成（MBPP）和多步具身规划（家庭机器人任务）。
- **对比基线**：与仅进行思维校准（thought-calibration-only）和仅进行校准推迟（calibrated-deferral-only）的独立基线进行比较。
- **主要结果**：
  - TSDS 在 HotpotQA、MBPP 和家庭机器人任务中，相比仅推迟的基线，每个 episode 的思考计算量减少了 43%-73%。
  - 在显著降低计算成本的同时，TSDS 保持了经认证的奖励性能和云调用率保证，证明了其在效率和可靠性之间的优越平衡。

#### 总结
本文针对边缘 LLM Agent 的资源受限与可靠性矛盾，提出了 TSDS 框架。通过结合动作收敛探测以缩短本地推理路径，以及基于困惑度的智能云侧推迟机制，并利用多目标 LTT 进行联合校准，TSDS 在多个复杂任务基准上实现了计算效率的大幅提升（减少 43%-73% 的思考计算），同时提供了严格的性能与成本保证，为边缘智能体的高效可靠部署提供了新思路。
