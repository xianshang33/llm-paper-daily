## 文章做了什么
- **背景**：随着大型语言模型（LLM）在医疗、法律等高风险场景中的部署，理解其欺骗能力对于确保系统安全至关重要。现有的基准测试（如 MMLU、GSM8K）已趋于饱和，且缺乏对对抗性行为（如 persuasion 和 deception）的稳健评估。
- **已有工作的不足**：传统的博弈论游戏（如囚徒困境、最后通牒博弈）虽然能模拟信息不对称，但无法捕捉社交互动中保守秘密和策略性欺骗的复杂性。现有的社交推理游戏（如狼人杀、阿瓦隆）要么缺乏合理的推诿空间，要么强制要求 bluffing，无法真实反映现实世界中基于奖励驱动的可选欺骗行为。

## 文章的核心贡献点
- **提出了一个名为 ParliamentBench 的开源基准框架**：基于游戏《Secret Hitler》构建，用于评估 LLM 在信息不对称环境下所需的欺骗、说服和推理能力。
- **挑战1：如何量化复杂的社交推理与欺骗行为？**
  - **难点**：社交欺骗涉及多轮交互、信息隐藏和动态策略，传统指标难以剥离具体的推理能力与欺骗一致性。
  - **解决方法**：引入了三个新颖的指标，分别隔离评估社交推理能力、逻辑推理能力以及欺骗一致性（deceptive consistency），从而更精细地衡量模型表现。
- **挑战2：如何在可控环境中进行大规模且真实的对抗评估？**
  - **难点**：LLM 之间的交互或与人交互的实验成本高且难以标准化，缺乏与真实人类玩家数据的对比基线。
  - **解决方法**：进行了约 1,600 场模拟比赛（包括 LLM 对战 LLM 和 LLM 对战人类），并将结果与 25,000 场在线人类玩家的游戏数据进行对比，提供了可复现的沙盒环境。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：评估了 16 种不同的 LLM，在《Secret Hitler》游戏中进行对抗。游戏机制涉及自由派多数派与秘密法西斯少数派的博弈，包含提名、投票和政策执行等多阶段决策。
- **主要结果**：
  - **顶尖模型集群**：GPT-5.4、Kimi K2.5、Grok 4.1 Fast 和 DeepSeek 3.1 Terminus 表现出强大的性能，无论是在合作角色还是欺骗角色中均表现优异。
  - **落后模型表现**：最弱的模型表现甚至低于随机基线（33%）和简单算法基线（45%）。
  - **欺骗一致性缺陷**：大多数 LLM 难以在整个游戏过程中保持一致的欺骗人设，欺骗保持率（deception retention）低于 50%，表明模型在长期策略维持上存在困难。
- **对比分析**：通过与大量在线人类游戏数据的对比，揭示了当前前沿模型在特定社交推理任务上已接近或超越人类平均水平，但在长期欺骗策略的稳定性上仍逊于熟练的人类玩家。

#### 总结
本文通过引入 ParliamentBench 基准，填补了 LLM 在复杂社交欺骗和推理能力评估方面的空白。研究结果表明，虽然前沿模型在短期战术和即时推理上表现强劲，但在维持长期一致的欺骗策略方面仍存在显著缺陷。这为未来提升 LLM 在高风险环境下的安全性和鲁棒性提供了重要的评估工具和洞察方向。
