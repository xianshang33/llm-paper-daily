## 文章做了什么
- **背景**：记忆系统已被证明能显著提升大型语言模型（LLM）智能体的性能，通过复用成功的行为模式和避免过往失败来提高效率。然而，对于小型语言模型（Small LLMs），记忆系统的潜力尚未得到充分探索。
- **已有工作为什么解决不了**：小型智能体由于自身能力有限，任务成功率较低，导致其自建的记忆库中充斥着大量失败的轨迹，缺乏足够的成功经验供学习。虽然可以通过反思失败来改进，但成功轨迹的稀缺从根本上限制了记忆效用的发挥。此外，简单地将大型教师模型的原始记忆转移给小型学生模型，往往因为两者之间存在巨大的“能力差距”（Capability Gap），导致学生模型难以理解或利用这些知识，收益甚微。

## 文章的核心贡献点
- **提出了一个 Agent Memory Distillation (AMD)**：这是一个无需训练（training-free）的框架，通过分层记忆机制将结构化知识从大型教师智能体转移到小型学生智能体。
- **挑战1：如何弥合教师与学生之间的能力差距，使知识对学生可理解？**
    - **难点**：直接转移教师的复杂思维链或原始日志超出了小模型的理解和处理能力。
    - **解决方法**：AMD 构建了三种互补的分层记忆类型：工作流记忆（Workflow memory）编码任务级策略，子任务记忆（Subtask memory）提供中间粒度的具体行为示例，函数记忆（Function memory）捕获每个函数的调用约定和常见陷阱。这种结构化、分层级的表示使得知识更易于被小模型消化。
- **挑战2：如何在不同阶段高效注入记忆以最大化效用？**
    - **难点**： indiscriminate（不加区分地）注入所有记忆会导致上下文冗余或干扰，且无法针对性地解决执行中的具体错误。
    - **解决方法**：采用主动与被动相结合的注入策略。工作流和子任务记忆在任务开始时主动注入，为学生提供宏观指导和具体参考；而函数记忆则在检测到工具调用错误时被动检索并注入，针对性地纠正具体操作失误。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：AMD 是一个无需训练的框架，使用 GPT-5-mini 作为教师模型，针对四个参数量在 4B 到 8B 之间的小型学生模型进行评估。该方法不依赖微调，而是通过提示工程将分层记忆注入到学生模型的上下文中。
- **评估结果**：在三个工具使用基准测试（AppWorld, BFCL V3, ToolSandbox）上进行了评估。相比基线，AMD 分别取得了 27.2%、11.2% 和 3.4% 的平均准确率提升。
- **对比相关工作**：AMD  consistently outperforms（持续优于）现有的基于记忆的基线方法。分析显示，子任务记忆对性能提升贡献最大。此外，研究发现 4B 参数规模的学生模型从 AMD 中受益最多，且教师的有效性取决于教师自身的能力以及与学生模型的兼容性。

#### 总结
本文针对小型 LLM 智能体因成功轨迹稀缺而导致记忆系统失效的问题，提出了 Agent Memory Distillation (AMD) 框架。通过构建包含工作流、子任务和函数三个层级的分层记忆，并结合主动注入与被动检索机制，AMD 有效地将大型教师模型的知识蒸馏给小型学生模型。实验表明，该方法在多个基准测试上显著提升了小型智能体的工具使用能力，且无需额外的训练成本，为资源受限环境下的高性能智能体部署提供了新思路。
