## 文章做了什么
- **背景**：大型语言模型（LLM）智能体越来越多地使用外部自然语言技能作为可重用和可编辑的指导来解决复杂任务。然而，技能的有效性不仅取决于技能本身的质量，还取决于策略能否将提供的指导转化为适当的动作。
- **已有工作的局限性**：现有的基于技能的智能体通常使用以任务级奖励为中心的强化学习（RL）目标进行训练。这种稀疏的奖励信号提供的监督有限，难以捕捉策略在利用所提供技能方面的细微差异。此外，现有的自蒸馏方法通常依赖于单一的特权上下文，无法充分评估技能利用的有效性。

## 文章的核心贡献点
- **提出了一个 BCSD (Bidirectional Context Self-Distillation) 框架**：该框架结合自蒸馏与强化学习，旨在训练 LLM 智能体更有效地利用外部技能。
- **挑战1：稀疏奖励导致技能利用监督不足**。传统的 RL 仅依赖任务完成与否的最终奖励，难以区分哪些决策是真正由技能指导产生的。**解决方法**：BCSD 引入双向上下文视图，通过生成细粒度的 token 级信号来重新缩放 RL 的优势函数，从而提供更丰富的监督信号。
- **挑战2：单一上下文视角无法全面评估技能价值**。 prior 自蒸馏方法仅使用单一特权上下文，忽略了不同抽象层次技能的作用。**解决方法**：BCSD 从两个互补的视角评估轨迹：增强视图引入高层的 Meta-Skill 指导，缩减视图剪枝通用指导以突出特定任务技能。两者结合的 token 级信号共同优化策略。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：在 ALFWorld 和 WebShop 两个基准数据集上进行实验，测试了不同模型规模下的性能。
- **结果对比**：BCSD 在所有模型规模上均取得了最强的整体性能，显著优于现有的基线方法（如 OPSD + RL, GRPO 等）。消融实验进一步验证了增强视图和缩减视图的互补贡献，证明了双向上下文设计的必要性。
- **部署与复现**：论文承诺将发布代码以确保完全的可复现性。

#### 总结
本文针对基于技能的 LLM 智能体在利用外部指导时面临的监督稀疏问题，提出了 BCSD 框架。通过引入双向上下文自蒸馏机制，BCSD 能够从增强和缩减两个互补视角提取细粒度信号，有效提升了智能体对技能的利用能力。实验结果表明该方法在多个基准任务上均达到了 SOTA 性能，为提升 LLM 智能体的技能利用效率提供了新的思路。
