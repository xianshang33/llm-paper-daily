## 文章做了什么
- **背景**：预测干预性“如果……会怎样”的问题（即从未采取过的行动的结果）需要机制性的因果模型，而不仅仅是曲线拟合。学习此类模型需要实验，因为被动观察数据无法识别其内在机制。由于实验成本高昂，核心问题在于数据效率。
- **已有工作的局限**：传统的贝叶斯实验设计虽然能选择信息量最大的干预措施，但通常局限于固定的假设空间，缺乏科学发现所需的开放式假设生成能力。被动数据存在多义性，无法区分在观察数据上一致但在干预下表现不同的机制，且现有方法难以在真实机制超出当前假设类（M-open 设置）时进行扩展。

## 文章的核心贡献点
- **提出了一个 Model Discovery Agent (MDA)**：将大型语言模型（LLM）作为候选结构提议者，与标准贝叶斯机制（用于参数和结构后验的序列蒙特卡洛 SMC、用于难处理似然的基于模拟的推断 SBI、以及用于实验设计的信息价值 VoI）相结合，从少量干预中发现潜在的机制性世界模型。
- **挑战1：如何在 M-open 设置下处理真实机制超出当前假设类的情况？**
  - **难点**：传统方法假设真值在假设空间内，若模型不充分则无法发现新机制。
  - **解决方法**：引入预测检查机制，当发现当前假设类不足时，LLM 提议者会扩展假设空间并生成新模型，随后通过设计的实验识别其参数。
- **挑战2：如何实现发现与设计的有效协同以提高数据效率？**
  - **难点**：单独的结构搜索或实验设计往往效率低下，难以在极少实验次数下收敛到正确机制。
  - **解决方法**：实现“发现与设计相互强化”循环：设计步骤识别发现步骤提出的机制，已识别的机制提高预测能力，从而利用剩余未解释残差推动进一步发现。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **基准测试**：在三个不同领域的基准上进行了评估，包括物理学（FORCE BENCH）、化学（CHEM BENCH）以及生物学（NEURON BENCH，这是一个新创建的部分观测单神经元电生理学基准）。
- **结果对比**：MDA 在数据高效模型学习和可靠的干预预测能力方面设立了新的最先进水平（SOTA）。相比现有方法，MDA 能够用更少的实验次数准确识别潜在机制，并在跨物理、化学和生物领域的复杂系统中展现出优越的泛化能力和鲁棒性。

#### 总结
本文提出了 Model Discovery Agent (MDA)，通过结合 LLM 的假设生成能力与贝叶斯实验设计的严谨性，解决了在昂贵实验条件下高效发现机制性世界模型的难题。MDA 特别适用于 M-open 场景，能够通过预测检查和假设空间扩展来应对未知机制。实验结果表明，该方法在多个科学领域均达到了状态-of-the-art 的性能，为自动化科学发现提供了强有力的工具。
