## 文章做了什么
- **背景**：Anthropic 于 2025 年 10 月推出了“Agent Skill”（代理技能）的开放规范，这是一种包含 SKILL.md 文件及可选脚本的文件夹结构，用于指导语言模型代理执行特定任务。截至 2026 年 7 月，公共 GitHub 仓库中已存在数百万个此类文件。
- **已有的工作为什么解决不了**：Agent Skills 与传统软件工程研究的工件不同，它们主要由自然语言编写，由模型在运行时概率性地选择，且没有编译器或类型检查器验证其正确性。此外，缺乏中央注册表或包管理器，导致技能通过复制文件夹在不同仓库间传播。现有的数据集无法记录这一群体，也无法支持对开发者如何编写、复用和维护这些技能的大规模实证研究。

## 文章的核心贡献点
- **提出了一个 GitSkills 数据集**：这是一个包含 3,797,117 个 SKILL.md 文件的大型数据集，收集自 282,200 个公共 GitHub 仓库，旨在填补 Agent Skills 实证研究的数据空白。
- **挑战1：非确定性选择与缺乏静态验证**。由于技能由模型 probabilistically（概率性）加载且无编译器验证，传统的代码分析工具难以检测描述模糊或指令不清导致的问题。GitSkills 通过保留每个文件的出现记录、内容哈希及丰富的元数据（如解析后的 front matter），使研究人员能够关联技能描述质量与其被选中及复用的情况，从而实证分析这些问题。
- **挑战2：去中心化传播导致的复用追踪困难**。技能没有包管理器，通过复制文件夹传播，使得追踪其来源和演化变得复杂。GitSkills 将相同内容的文件分组为 1,877,981 个独特内容，并为每组提供代表文件的完整文本、文件夹内容及部分提交历史，同时保留所有副本的仓库路径信息，从而支持对技能采用、复用模式和作者归属的深度分析。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：研究团队使用只读管道，针对 GitHub 代码搜索和 REST API 进行数据采集。数据集最终封装在一个独立的 SQLite 文件中，便于分发和查询。数据保留了每个文件实例的仓库、路径和内容哈希，并对独特内容进行了 enrichments（增强），包括完整文本、解析的元数据、文件夹内容、仓库元数据以及子集的提交历史。
- **Evaluation 结果**：文章主要贡献在于数据集的构建而非算法性能评估。通过该数据集，研究者可以量化 Agent Skills 的早期采用情况、结构特征及维护模式。例如，数据显示了技能在仓库中的分布、重复率以及元数据的使用情况。
- **相关工作对比**：与传统的软件仓库挖掘数据集不同，GitSkills 专门针对 LLM Agent 的新型工件（自然语言为主的技能文件）。现有工作多关注代码片段或配置文件，缺乏对这种由模型动态加载、无类型系统约束的自然语言指令集的系统性记录。GitSkills 提供了首个大规模、结构化的 Agent Skills 语料库，支持此前无法进行的实证研究。

#### 总结
本文介绍了 GitSkills，这是第一个大规模公开可用的 Agent Skills 数据集，涵盖了 2026 年 7 月之前 GitHub 上的近 380 万个技能文件。该数据集解决了因 Agent Skills 的非传统特性（自然语言、概率加载、去中心化）而导致的研究数据缺失问题。通过提供详细的文件内容、元数据和复用追踪信息，GitSkills 为软件工程社区研究 LLM 代理技能的采用、维护、安全性和最佳实践奠定了基础，有助于理解这一新兴软件工件的演化规律。
