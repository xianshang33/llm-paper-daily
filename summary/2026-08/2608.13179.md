## 文章做了什么
- **背景**：大型语言模型正从单纯的问答系统演变为能够进行多轮交互、使用工具的多步自主智能体。强化学习（特别是带有可验证奖励的 RLVR）是训练此类智能体的主流范式，因为它提供了由奖励质量决定的性能上限。
- **已有的工作为什么解决不了**：
    1. **RLVR 的信用分配问题**：标准的 RLVR 将单一轨迹级奖励广播到所有 token 上。在多轮会话中，不同轮次的结果相互独立却共享同一奖励信号，导致信用分配不当（inter-turn dilution），即成功的轮次和失败的轮次被同等对待，严重影响了长轨迹和严格会话级别的表现。
    2. **在线蒸馏（On-policy Distillation）的局限**：虽然能提供密集的 token 级监督信号，但通常受限于教师模型的性能上限（teacher-bounded），或者在自蒸馏场景中容易出现梯度集中崩溃（gradient concentration collapse），即梯度过度集中在低熵的格式 token 上，而非实质性的推理内容。

## 文章的核心贡献点
- **提出了一个 CrEST 框架**：一种分层信用分配框架，旨在保留 RL 的可验证奖励上限，同时融入来自特权自教师（privileged self-teacher）的密集 token 级信号。
- **挑战1：多轮交互中的轮间信用稀释（Inter-turn Dilution）**
    - **描述与难点**：在多轮会话中，每一轮的成功或失败是独立的，但传统 RL 将整个会话视为一个整体给予单一奖励，导致模型无法区分哪一轮做对了，哪一轮做错了，尤其在长轨迹中噪声极大。
    - **解决方法**：CrEST 引入了“轮次分割的验证优势”（turn-segmented verified advantages），将奖励信号按轮次拆分并计算优势函数，从而精确地解决轮间的信用分配问题，避免错误轮次被错误强化。
- **挑战2：轮内 Token 级的梯度集中与教师上限（Intra-turn Gradient Collapse & Teacher Ceiling）**
    - **描述与难点**：自蒸馏方法虽然提供了细粒度信号，但往往导致梯度集中在简单的格式 token 上，且性能受制于教师模型的质量，难以突破教师上限。
    - **解决方法**：CrEST 采用“熵门控自教师调制”（entropy-gated self-teacher modulation）。它不利用教师来决定更新方向（即不直接模仿教师输出），而是仅用教师信号来调制更新的幅度（magnitude）。通过熵门控机制，抑制低熵（简单/格式）token 的梯度贡献，聚焦高熵（复杂/推理）token，从而在保持 RL  verifier-bounded 上限的同时，利用密集信号优化策略。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：在 BFCL V3 和 WildToolBench 两个基准测试上进行评估，涵盖两种模型规模。
- **对比基线**：与标准的 RL 基线（如 GRPO）和蒸馏基线（如 OPSD）进行对比。
- **主要结果**：
    - CrEST 在所有设置下均一致优于 RL 和蒸馏基线。
    - 在长轨迹任务和严格的会话级别（session-level）指标上取得了最大的性能提升。
    - 解决了 WildToolBench 上模型会话准确率低于 15% 且随轮次增加性能急剧下降的问题。
- **核心发现**：证明了在策略优化中，教师的角色可以从“决定更新方向”简化为“调制更新幅度”，从而在不牺牲验证器上限的前提下解锁密集信用分配。

#### 总结
本文针对多轮多步 LLM 智能体训练中的信用分配难题，提出了 CrEST 框架。该框架创新性地结合了 RL 的验证器上限优势和蒸馏的密集信号优势。通过轮次分割的优势计算解决轮间信用混淆，通过熵门控的教师幅度调制解决轮内梯度集中和教师上限问题。实验表明，CrEST 在复杂的多轮工具使用任务中显著提升了智能体的性能和鲁棒性，为高效训练自主 Agent 提供了新的范式。
