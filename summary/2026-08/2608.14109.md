## 文章做了什么
- **背景**：自主 LLM 智能体在复杂工作流中执行 API 调用、发送邮件等实际操作时，容易遭受“运行时行为漂移”（Behavioral Drift）。这是一种静默的偏离初始目标的现象，可能导致对外部系统产生不可逆的副作用（如错误转账、删除数据），且仅重置模型记忆无法修复环境状态。
- **已有工作的局限**：现有方法主要集中在输入层面的预防（如隔离不可信内容或指令层级训练），缺乏针对漂移发生后的结构化检测、风险评估和恢复决策机制。此外，由于主任务执行智能体通常是昂贵的大型模型，无法在每个部署环境中重新训练，因此需要一种即插即用的外部恢复模块。

## 文章的核心贡献点
- **提出了一个基于图的强化学习框架（Graph-Based RL Framework）**：该框架作为一个外部插件，使用单个小型语言模型（SLM）通过强化学习进行训练，专门处理漂移诊断与恢复。
- **挑战1：多步骤恢复任务的复杂性与结构化需求**。漂移恢复需要逆向追踪漂移起点、检测已执行的操作、评估风险并决定回滚或升级人工，单一提示词难以兼顾所有子任务且自由形式的思维链缺乏结构约束。**解决方法**：构建恢复图，每个节点对应特定角色（漂移分类、操作检测、风险评估、最终决策），训练 SLM 在每个节点生成适应角色的结构化 XML 格式推理，确保输出符合 schema 规范。
- **挑战2：小模型在语义质量与格式合规性之间的平衡**。小模型可能在遵循严格输出格式的同时牺牲语义准确性，或反之。**解决方法**：采用混合奖励机制进行强化学习训练，结合基于规则的结构奖励（评估 schema 和长度合规性）与“LLM-as-Judge”的语义质量信号（评估内容合理性），使模型同时优化“如何回答”和“回答什么”。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：该方法设计为即插即用模块，独立于主代理。使用一个小语言模型，在 AppWorld 基准测试上进行实验。训练过程结合了规则奖励和语义奖励。
- **评估结果**：实验表明，该方法能够利用疑似漂移起始点的信息，使用小语言模型做出正确的恢复决策。训练后的小模型能够可靠地遵守规定的输出 schema，并根据其分配的角色在每个字段中生成语义适当的内容。
- **对比**：相较于仅在提示层面解决漂移或缺乏结构化机制的现有方法，本方法提供了步骤级的检测、风险评估和恢复决策能力，且无需重新训练昂贵的主模型。

#### 总结
本文针对自主 LLM 智能体在真实世界中面临的行为漂移问题，提出了一种基于图的强化学习恢复框架。通过将恢复过程分解为多个专用节点，并利用混合奖励机制训练小型语言模型，该方法实现了高效、结构化且语义准确的漂移诊断与恢复。这不仅解决了大型模型无法频繁重训的限制，还有效降低了因漂移导致的外部系统不可逆损害风险，在 AppWorld 基准测试中展现了良好的性能。
