## 文章做了什么
- **背景**：基于大语言模型（LLM）的 Text-to-SQL 研究进展迅速，但结果分散在不同的基准测试（如 Spider, BIRD, Spider 2.0）、骨干模型和推理协议中。现有的比较往往因为实验设置异构而变得脆弱，难以进行公平的系统级对比。
- **已有工作的不足**：现有的综述通常按训练范式（如上下文学习、微调、强化学习后训练）分类，但这无法隔离日益主导基准表现的推理时结构差异。此外，重新运行所有系统进行统一评估成本高昂且不可行（尤其是闭源 API 变动频繁），导致跨系统比较缺乏一致性和可追溯性。

## 文章的核心贡献点
- **提出了一个基于推理自主性（Inference-Autonomy）的分类法与聚合排行榜**：将文献本身视为基准，通过收集作者报告的指标，沿“约束生成、上下文学习、迭代、代理式、推理内化”这一自主性轴进行组织，并为每个数据点提供可追溯的来源。
- **挑战1：异构推理协议导致的公平比较难题**。不同系统外部化的结构化推理程度不同，导致直接比较准确率忽略了对鲁棒性和成本的权衡。**解决方法**：定义了一个“自主性轴”，根据系统在问题与最终 SQL 之间外部化结构化推理的程度对系统进行分类，从而在统一的维度上评估不同方法的效率与效果。
- **挑战2：缺乏可控的实证锚点来验证分类法的有效性**。仅靠文献聚合可能缺乏对特定变量（如思维链 CoT）影响的深入理解。**解决方法**：在 Spider 基准上进行聚焦案例研究，对比了带有和不带 CoT 监督的 8B 开源骨干模型与 Few-shot 基线，揭示了 CoT 增益主要集中在高难度查询以及自主性带来的鲁棒性与成本之间的权衡关系。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：发布了一个 Python 工具包（Harness），镜像了自主性轴的结构。未来新方法只需通过一个适配器文件和配置文件即可直接添加到排行榜中，无需重新运行旧系统，保证了可扩展性和维护性。
- **Evaluation 结果**：
    1. **迁移性不均**：在 Spider 上的性能提升并不能均匀地迁移到 BIRD 和 Spider 2.0 上。
    2. **自主性的代价**：更高的自主性（如 Agent 模式）带来了鲁棒性，但也伴随着显著的 Token 消耗、延迟和编排成本。
    3. **推理内化的定位**：推理内化（Reasoning Internalization）位于“仅答案解码”和“外部编排代理”之间的自主性-成本前沿上，提供了一种折中方案。
    4. **CoT 的效果分布**：CoT 监督的收益主要集中在 Hard 和 Extra-Hard 难度的查询上，而非均匀分布在所有难度级别。
- **对比**：与传统按训练方法分类的综述不同，本文提供了带有引用来源的透明排行榜，并实证对比了 Qwen3-8B、LLaMA3.1-8B 与 DeepSeek V3、GLM-4 等模型在不同自主性设置下的表现。

#### 总结
本文通过提出基于推理自主性的分类法，解决了 LLM Text-to-SQL 领域因实验设置异构导致的比较困难问题。通过构建可追溯的聚合排行榜和进行实证案例研究，文章揭示了自主性、鲁棒性与成本之间的复杂关系，并指出推理内化是一种有效的中间路径。发布的 Python 工具包为未来研究的标准化比较提供了基础设施。
