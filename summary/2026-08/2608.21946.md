## 文章做了什么
- **背景**：基于结果导向目标（如 GRPO）的强化学习使 LLM 智能体能够解决复杂的长程任务，但交互轨迹中嵌入的可重用探索模式（如有效的任务分解、恢复策略）在单次策略更新后往往被丢弃，导致智能体必须从头重新发现这些模式，这在稀疏奖励环境中效率极低。
- **已有工作为什么解决不了**：现有的经验增强方法通常在推理时检索历史指导，但存在两个主要局限：一是未考虑策略 evolving capability（演进能力），即对欠训练策略有用的指导在行为内化后可能变得冗余甚至有害；二是造成对外部检索的持久依赖，导致推理时的 token 开销增加及对检索噪声敏感。

## 文章的核心贡献点
- **提出了一个 EDGE (Experience-Distillation for Guided Exploration) 框架**：该框架将检索到的经验视为临时的训练时“脚手架”，并逐步将其益处内化到参数化策略中，实现经验的动态生命周期管理。
- **挑战1：如何在不增加额外采样成本的情况下，准确评估经验带来的边际增益并避免负面引导？**
  - **难点**：经验的有效性高度依赖于当前策略状态，盲目注入可能导致性能下降，且传统方法难以区分正负边际贡献。
  - **解决方法**：EDGE 将每个 rollout 组划分为“经验条件”和“无经验”轨迹，通过对比估计仅接纳具有正向边际增益的经验，无需额外采样即可过滤无效或有害指导。
- **挑战2：如何将外部经验有效内化为策略本身的参数能力，从而消除推理时的外部依赖？**
  - **难点**：现有方法多依赖推理时检索，导致能力存储在上下文而非模型参数中，无法真正提升模型内在能力且增加推理负担。
  - **解决方法**：通过在其自身经验支持上的反向 KL 散度目标，将经验诱导的行为蒸馏到基础策略中；同时引入协同进化的经验库，根据策略演进合成新指导并修剪过时条目，最终实现无需推理时脚手架的高效部署。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：EDGE 包含经验引导探索脚手架和协同进化经验库。在训练阶段使用经验作为临时指导，通过蒸馏将行为内化；在推理阶段无需任何外部检索或专有反射器（reflector），完全依赖内化后的参数策略。
- **Evaluation 结果**：在具身智能、Web 操作和基于搜索的 QA 任务上进行评估。
- **对比结果**：EDGE 相比强大的 RL 基线方法（如 vanilla GRPO 及其他记忆增强方法）性能提升高达 12.5 个点。实验表明， naive memory augmentation（如 EvolveR, GRPO+Mem0）因未过滤经验注入导致性能低于 vanilla GRPO，而 EDGE 既避免了性能退化，又消除了推理时的 token  overhead。

#### 总结
EDGE 提出了一种新的智能体强化学习范式，通过将外部经验从“推理时检索”转变为“训练时蒸馏”，解决了经验复用中的策略依赖性和外部依赖性问题。该方法不仅显著提升了长程复杂任务的性能，还实现了更轻量、更鲁棒的推理部署，为 LLM 智能体的持续学习和能力内化提供了有效路径。
