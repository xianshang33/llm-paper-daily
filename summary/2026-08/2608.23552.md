## 文章做了什么
- **背景**：大型语言模型（LLM）本质上是受限的顺序处理器，其决策仅依赖于模型权重和当前活跃上下文。然而，长视野代理任务（Long-horizon agency）需要超出模型权重和上下文窗口的外部信息存储与计算能力。
- **已有工作的局限**：现有的代理框架往往将工作流硬编码，或者在上下文管理上存在瓶颈（如简单的上下文压缩），导致“ harness 失败”被误判为“模型失败”。现有方法缺乏足够的表达力来让模型在推理时动态构建程序、子代理和反馈循环，无法充分利用测试时计算（test-time compute）和外部状态管理。

## 文章的核心贡献点
- **提出了一个名为 Prime Agent 的开源自改进递归语言模型（RLM）Harness**，旨在标准化长视野评估和编码代理工作流，通过低摩擦、高表达力的接口释放模型的潜在最大能力。
- **挑战1：长视野任务中的状态保持与信息管理难题**。随着任务进行，关键信息容易超出上下文窗口或丢失，且传统方法难以有效利用历史数据。**解决方法**：引入“持续 Harness”（Continual Harness）机制，跨轨迹保留历史、记忆、技能和提示词；结合持久化的 IPython REPL 作为 L2 级缓存，使模型能够像冯·诺依曼架构一样读写可寻址的外部状态，实现程序化的上下文处理。
- **挑战2：复杂任务的并行化与协调困难**。单一模型难以同时处理多线任务或进行自我修正与验证。**解决方法**：采用递归子代理（Recursive subagents）架构，支持直接的代理间通信（agent-to-agent communication），允许模型在推理时动态构建子代理 swarm 进行并行工作和协同，同时通过 Agents View 让人类可 inspect 和管理守护进程会话。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：Prime Agent 是一个开源框架，标准化了执行、恢复、验证和资源计数。它提供了一个低摩擦的膜（membrane），防止因框架缺陷导致的任务失败，确保评估反映模型的真实能力。
- **评估结果**：
    - 在 ARC-AGI-3 RHAE Best@1 基准上，性能从 30% 显著提升至 95.5%。
    - 在长上下文编码、GPU 内核生成、模拟器构建和自主 nanoGPT 速跑等任务中，其表现匹配或超过了原生及流行的 Harness。
    - 在 Factorio 游戏中，展示了通过精炼实现连续技术 progression，以及专用子代理实现并行工作的能力。
- **对比**：相比其他流行 Harness，Prime Agent 在长视野任务中更能挖掘模型的上限，避免了因资源计数错误或过早终止导致的性能低估。

#### 总结
Prime Agent 通过引入递归语言模型抽象和持续 Harness 机制，解决了 LLM 在长视野任务中状态管理和计算扩展的瓶颈。它将模型从单纯的序列处理器转变为能够利用外部存储和并行计算的类冯·诺依曼系统，显著提升了在复杂推理和编码任务中的表现，为评估和提升 AI 代理的真实能力提供了标准化的基础设施。
