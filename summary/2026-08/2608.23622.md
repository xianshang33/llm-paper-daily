## 文章做了什么
- **背景**：大型语言模型（LLM）在推理、规划和工具使用方面表现出色，但许多科学和工程任务（如制药工艺设计）不仅需要生成合理的文本或代码，更需要理解系统对干预措施的响应。这依赖于通过控制变量法进行的受控实验。
- **已有工作的局限**：现有的基于 LLM 的系统即使配备了外部工具，通常也仅用于检索信息或执行孤立功能，缺乏结构化的实验比较逻辑。因此，其输出往往是建议性的而非证据性的，难以在需要对比不同干预结果的任务中得出可靠结论。

## 文章的核心贡献点
- **提出了一个多智能体框架**：该框架使 LLM 智能体能够利用科学仿真模型进行受控实验，支持通过干预、比较和观察进行推理。
- **挑战1：如何将自然语言查询转化为可执行的受控实验设计？**
  - **难点**：用户查询通常模糊，而科学实验需要严格的变量控制和基线对比，LLM 难以直接映射这种严谨的逻辑。
  - **解决方法**：系统首先构建结构化的任务表示，明确基线配置和待优化参数，由智能体自动设计对比实验方案，确保每次只改变特定因素而保持其他条件固定。
- **挑战2：如何从仿真数据中提取因果见解并生成可操作建议？**
  - **难点**：高保真仿真模型产生大量复杂数据，单纯的语言模型无法准确解读数据背后的物理/化学意义及因果关系。
  - **解决方法**：智能体执行 comparative simulation（对比仿真），解释结果差异，并综合证据生成基于数据的工艺参数优化建议，从而实现从“语言推理”到“证据推理”的转变。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：该系统应用于制药工艺设计的工业场景中，结合了 LLM 与高保真仿真模型。工作流程包括：接收用户查询和基线配置 -> 构建结构化任务 -> 设计实验 -> 执行对比仿真 -> 解释结果 -> 合成建议。
- **评估结果**：
  - **输出特异性**：相比仅依赖语言推理的方法，该方法生成的输出具有更高的特异性。
  - **用户评分**：在工业应用设置中，用户对输出的正确性和有用性评分显著提高。
  - **消融实验与案例分析**：通过消融研究证明了仿真集成实验推理的有效性；可视化案例分析展示了其在实际实用中的价值。
- **对比**：与传统 LLM 仅作为文本生成器或简单工具调用者相比，该方法通过引入受控实验循环，提供了更具证据支持和可操作性的结论。

#### 总结
本文提出了一种将 LLM 与科学仿真模型相结合的多智能体框架，专门用于解决制药工艺设计等需要受控实验的科学工程问题。通过让 LLM 智能体在仿真环境中进行假设测试、干预和对比观察，系统克服了传统 LLM 输出缺乏证据支持的局限。实验结果表明，该方法在工业应用中能提供更具体、更正确且更有帮助的工艺优化建议，验证了仿真集成实验推理在实际科学发现中的潜力。
