## 文章做了什么
- **背景**：LLM-as-a-Judge（大语言模型作为裁判）已成为评估自然语言生成任务的流行范式，因其灵活性和可扩展性而被广泛应用。然而，LLM 输出具有内在随机性，导致评估结果存在不确定性，这在医疗、金融等高风险领域限制了其可靠性。
- **已有工作为什么解决不了**：现有的不确定性量化方法主要依赖共形预测（Conformal Prediction），但通常仅应用于单个 LLM 裁判。这种方法忽略了不同 LLM 评估器之间因训练数据、架构和对齐策略差异而产生的变异性，导致不确定性估计高度依赖于特定模型，可能产生过于自信或狭窄的预测区间，缺乏鲁棒性。

## 文章的核心贡献点
- **提出了一个**：鲁棒共形共识框架（Robust Conformal Consensus），用于多智能体 LLM-as-a-Judge 的区间评估。
- **挑战1：单模型偏差与变异性忽略**。难点在于单一 LLM 的评分无法反映评估过程中的真实 variability，且不同模型间存在显著分歧。论文通过引入多个独立的 LLM 裁判，构建基于多模型评分的共形预测区间，显式地捕捉并量化了模型间的差异性，从而获得更稳定的不确定性估计。
- **挑战2：多源不确定性的有效聚合**。难点在于如何将来自不同分布和偏好的多个 LLM 的预测区间进行合理整合，以保证统计覆盖率的同时提高评估稳定性。论文提出了一种区间适应框架，对多个 LLM 裁判生成的预测区间进行重新校准和聚合，确保最终结果既具有统计保证的覆盖率，又能通过共识机制减少个别模型的极端偏差。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：该框架可集成到现有的共形预测方法中，无需对底层 LLM 进行微调，仅需少量校准数据。实验涉及九个不同的 LLM 作为裁判。
- **Evaluation 结果**：大量实验表明，该方法生成的预测区间具有有效的覆盖率保证（valid coverage guarantees）。与仅使用单个 LLM 裁判的传统共形预测方法相比，基于多裁判的区间聚合产生了更稳定、更可靠的评估结果。
- **对比**：相较于现有的单模型共形预测方法，本文方法在处理 inter-LLM 变异性方面表现更优，避免了因选择特定 LLM 而导致的鲁棒性下降问题，提供了更可信的不确定性量化。

#### 总结
本文针对 LLM-as-a-Judge 评估中未被充分探索的不确定性问题，提出了一种基于多智能体共形预测的鲁棒框架。通过整合多个 LLM 裁判的评分并构建预测区间，该方法有效克服了单模型评估的局限性和变异性，为高风险应用中的自动化评估提供了具有统计保证的、更稳定可靠的不确定性量化方案。
