## 文章做了什么
- **背景**：大型语言模型（LLM）代理的能力不仅取决于底层模型，还很大程度上依赖于运行时 Harness（如任务规划、工具交互和上下文管理机制）。自我演进的运行时 Harness 能够通过基于执行反馈自动修改代码来优化代理执行，是一个有前景的范式。
- **已有工作为什么解决不了**：现有的 Harness 演进方法通常依赖迭代搜索，即根据任务实例的执行反馈反复评估和修订候选 Harness。这种方法存在两个主要问题：一是由于需要重复执行代理和修改代码，导致巨大的时间开销；二是容易过拟合于观察到的任务和特定失败模式，导致对未见任务的泛化能力下降。其核心瓶颈在于缺乏原则性的失败诊断，无法区分是模型本身的缺陷还是 Harness 的系统性缺陷，直接针对个别失败进行优化会导致不必要的模型特定适配。

## 文章的核心贡献点
- **提出了一个名为 Ecdysis 的高效且有效的框架**，该框架能够区分模型特定的适配与 Harness 级别的修复，并通过识别跨任务的重复失败模式，将适应偏向于系统性的 Harness 缺陷。
- **挑战1：效率低下与过拟合风险**。传统的逐实例迭代优化导致训练时间长且易过拟合特定失败模式。**解决方法**：Ecdysis 采用批量级跨实例失败聚合范式，联合分析多个任务实例的失败证据，从而识别出系统性的而非偶然的失败模式，减少了无效的迭代次数并提升了泛化性。
- **挑战2：缺乏 principled 的失败归因**。难以判断失败是由模型能力不足还是 Harness 逻辑错误引起，导致优化方向偏差。**解决方法**：引入了失败驱动的协同细化（Failure-Driven Collaborative Refinement, FDCR）机制，通过多角色诊断来诊断失败原因并迭代细化 Harness 修改规范，确保优化针对的是 Harness 层面的系统性缺陷。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验结果**：在多个 LLM 和基准测试上的实验表明，与现有的 Harness 演进方法相比，Ecdysis 实现了高达 1.84 倍的训练速度提升。
- **性能提升**：生成的 Harness 推理准确率提高了 18.56%。
- **泛化与效率**：使用 Ecdysis 训练的 Harness 在不同 LLM 之间表现出更强的泛化能力，并减少了推理时的 Token 消耗。
- **对比优势**：相较于传统方法的高耗时和过拟合问题，Ecdysis 在保证更高准确率的同时显著降低了端到端的训练时间。

#### 总结
Ecdysis 通过引入跨实例失败分析和多角色协同诊断机制，解决了现有 LLM Agent Harness 演进方法中效率低和泛化差的问题。它能够有效区分模型缺陷与 Harness 缺陷，专注于修复系统性的 Harness 问题，从而在大幅缩短训练时间的同时，显著提升了 Agent 的推理准确性和跨模型泛化能力。
