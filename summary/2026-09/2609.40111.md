## 文章做了什么
- **背景**：随着大型语言模型（LLM）在复杂推理、编码和长程代理任务中的能力增强，智能体（Agent）系统被广泛应用于交互式软件和网页任务。然而，智能体的失败 rollout 包含了比最终奖励更丰富的信息（如观察、动作和环境响应），如何有效利用这些失败经验进行学习是一个关键问题。
- **已有工作的局限**：现有的代理后训练方法（如 AgentTuning、RAGEN）主要依赖奖励过滤的轨迹或策略优化，往往忽略了失败过程中的具体错误诊断和修正细节。它们通常只关注成功轨迹或简单的重试，缺乏对失败原因的细粒度分析和基于证据的修正验证，导致无法充分利用失败数据中的学习信号。

## 文章的核心贡献点
- **提出了一个 Agent Error Dataset (AED) 和 Agentic Error-to-Training (AET) 管道**：构建了包含 50,228 个错误-诊断对的大规模数据集，涵盖 33 种环境、19 种 harness 家族和 23 种策略模型，并设计了五阶段管道来收集自然失败、生成诊断与修正，并基于记录证据进行验证。
- **挑战1：如何从非结构化的失败轨迹中提取可学习的错误诊断和修正方案？**
  - **难点**：失败轨迹包含大量噪声，且自动生成的诊断可能不准确或幻觉，难以直接用于训练。
  - **解决方法**：AET 管道通过生成诊断和建议的修正，并利用记录的执行证据（如环境响应）进行检查和验证。在支持重放的环境中，通过将修正建议与相同检查点下的原始动作重试进行对比，确保修正的有效性，从而构建高质量的训练视图。
- **挑战2：如何将诊断知识和修复能力有效地融入模型训练中？**
  - **难点**：传统的微调可能混淆诊断逻辑和执行逻辑，或者仅关注最终成功而忽略中间步骤的正确性。
  - **解决方法**：文章构建了独立的诊断和演员恢复（actor recovery）训练视图。通过全诊断微调（full-diagnosis fine-tuning）提升模型对内部教师标签的步骤一致性；并通过动作修复训练（action-only repair training）专门强化模型在失败后的纠正能力，相比仅使用成功轨迹的训练显著提升了性能。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **数据集与管道**：AED 包含 50,228 个错误-诊断对，源自 9,961 个源任务。AET 管道保留了源轨迹和执行元数据，支持跨设置故障分析而无需重复原始 rollout。
- **修正效果验证**：在 3,062 个匹配的重放对中，首次提出的修正将验证器通过率从 18.4% 提高到 51.1%，提升了 32.7 个百分点，显著优于原始动作重试。
- **模型微调效果**：使用冻结的诊断发布版本，在 1,656 个源任务上进行全诊断微调，使 Qwen3-8B 在 943 个保留案例上的内部教师标签精确步骤一致性从 47.2% 提高到 63.6%。相比之下，最强的提示参考模型（Claude Opus 5）得分为 54.7%，Qwen3-8B 基线为 47.2%。随着训练集规模的增加，平均一致性持续提高。
- **演员训练对比**：在单种子比较中，动作修复训练在 WebShop-lite 上的得分比仅成功训练高出 6.67 个百分点，证明了利用失败修正数据进行训练的优势。

#### 总结
本文引入了 Agent Error Dataset (AED) 和 Agentic Error-to-Training (AET) 管道，系统地解决了如何利用智能体失败经验进行后训练的问题。通过大规模收集错误-诊断对并验证修正方案，文章证明了基于错误诊断和修复的微调能显著提升模型的性能和步骤一致性，超越了传统的仅成功轨迹训练和强大的提示工程基线。这项工作为智能体系统的故障分析和误差感知后训练提供了新的数据资源和方法论。
