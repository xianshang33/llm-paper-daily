## 文章做了什么
- **背景**：随着 LLM Agent 的普及，团队通常使用小型提示注入检测器来筛选工具输出，并依据公共基准测试（如 BIPIA）的得分来选择检测器。
- **已有工作为什么解决不了**：现有的评估实践存在两个未经验证的假设。首先，基准测试中的文本格式与 Agent 实际处理的序列化工具输出不同，导致基准高分无法反映真实场景下的误报率（False Positive Rate, FPR），而误报会导致任务失败。其次，现有研究未审查检测器训练数据与基准测试数据是否存在重叠，导致分数可能仅反映了对特定数据分布的记忆而非泛化检测能力。

## 文章的核心贡献点
- **提出了一个基于差分重放（Differential Replay）的真实 Agent 环境评估框架**：通过在不使用 LLM 的情况下重放基准测试中的真实工具调用，构建由构造保证为良性的工具输出，并通过差分对比生成可靠的注入标签，从而在真实的 Agent 输入分布上评估检测器。
- **挑战1：基准测试分数与实际部署性能脱节**。难点在于不同基准的数据分布差异巨大，且传统基准未模拟 Agent 看到的序列化输出。论文方法通过直接在 AgentDojo 和 tau-bench 的真实工具输出上评估，揭示了检测器排名在不同基准间几乎无法迁移（例如 BIPIA 最佳检测器在 AgentDojo 上仅捕获 2% 的注入）。
- **挑战2：训练数据泄露导致的虚假高性能**。难点在于难以量化检测器是否仅仅“记住”了攻击字符串而非学会检测。论文方法通过审计公开的训练数据，发现表现最好的检测器并未使用任何基准测试数据训练，而是使用了类似 Agent 风格的输入，证明了检测效果取决于输入形式的相似性而非通用的注入检测能力。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与评估设置**：评估了 15 种检测器（包括 Meta 的 Prompt Guard 2、DeBERTa 分类器等）和 2 个任务感知的 LLM Judge。评估数据集包括 AgentDojo、tau-bench 的工具输出以及 BIPIA 基准。
- **主要结果**：
    - **排名迁移性差**：在 BIPIA 上表现最佳的检测器在 1% FPR 下仅能捕获 AgentDojo 中 2% 的注入；在 AgentDojo 上捕获 72% 注入的检测器在 tau-bench 上仅捕获 15%。
    - **误报率（FPR）具有迁移性**：尽管检测率不迁移，但工具输出上的 FPR 在两个 Agent 基准之间是保持一致的，范围从 0% 到超过 90%。
    - **训练数据决定性能**：BIPIA 的领先模型是在完整的 BIPIA 输入上训练的，但这无助于其在工具输出中发现攻击字符串。在两个 Agent 基准上表现最好的检测器与任何基准测试数据均无重叠，且专门针对 Agent 风格输入进行了训练。
- **对比结论**：与传统认为某些检测器（如 PIGuard）能有效检测间接注入的观点不同，本研究表明这些高分主要源于数据分布的匹配。现有的基准测试未能提供关于部署可行性的可靠指导。

#### 总结
本文指出当前提示注入检测器的评估存在严重缺陷，基准测试分数不能预测其在 LLM Agent 中的实际行为。核心发现是检测器的性能高度依赖于其训练数据形式与评估输入形式的相似性，而非通用的检测能力。作者建议，旨在指导部署的评估应使用 Agent 自身的工具输出，报告低误报率下的检测性能，并严格审计检测器的训练数据来源。
