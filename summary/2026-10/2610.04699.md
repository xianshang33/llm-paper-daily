## 文章做了什么
- **背景**：在金融、医疗和法律等受监管领域，AI Agent 必须执行外部制定的规则。验证器（Verifier）需要区分哪些规则可以通过固定的代码检查（可判定）解决，哪些需要人工或高级模型判断（需裁决）。这一决策必须在运行时对每个动作的每个谓词频繁进行。
- **已有工作为什么解决不了**：现有的升级方案通常假设模型具有“自决性”（self-decidability），即模型能自己判断某个规则是否可由固定检查解决。然而，研究表明不同模型在监管文本边界上的错误方向相反，且在同一部署规则集上会共同犯错（过度声称某事可被固定检查解决），导致无法信任单一模型或简单的一致性投票作为保守选择。

## 文章的核心贡献点
- **提出了一个 CoVer (corroborate-then-verify) 算法**：该算法将模型间的一致性视为提名，仅当合成的检查通过干预测试（读取 Agent 无法写入的字段并在确定性重述下保持稳定）时才接受该谓词为可判定。
- **挑战1：模型在边界情况下的不可靠性与错误方向不一致**。难点在于不同模型在简单案例上一致，但在监管文本的模糊边界上表现各异且错误方向相反，导致无法选出统一的“保守”模型。CoVer 通过引入严格的验证门控（intervention test），拒绝了大多数被一致性错误接纳的案例，从而构建了可靠的边界。
- **挑战2：参考法官（Reference Judge）的共谋盲区**。难点在于使用来自同一分布的参考法官进行校准只会确认共享的盲点，随着校准带变化，一致性看似提高但真正可判定的比例并未改变。CoVer 不依赖此类一致性认证，而是通过构造性的验证手段（如读取只读字段）来确立可判定性，证明了自决性是验证器必须构建的边界而非模型固有的能力。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：在六个语料库（包括欧盟 AI 法案、FINRA 指南和已部署的信贷 Agent 规则）上收集了约 22,000 个标签，涉及三个实验室开发的四个模型。
- **评估结果**：
    - 模型在答案明显时几乎完全一致，但在监管文本上崩溃。
    - 在已部署 Agent 的规则集上，模型共同犯错，过度声称固定检查即可解决，这种错误方向永远不会触发升级，风险极大。
    - 传统的“与参考法官一致”的方法无效：一致性从 30% 升至 77%，但真正可判定的份额未变，因为法官与被指控群体共享盲点。
- **CoVer 表现**：CoVer 的门控机制拒绝了大量被一致性错误接纳的谓词，虽然牺牲了一定的覆盖率（coverage），但报告了这一成本而非通过调整掩盖，确保了高精确度的可判定边界。

#### 总结
本文核心观点是“自决性”并非模型的一种能力，而是验证器必须构建的边界。通过实证分析揭示了 LLM 在区分可代码化检查与需人工裁决规则时的系统性失败，特别是模型间的共谋错误。提出的 CoVer 算法通过“先佐证后验证”的策略，利用干预测试和确定性重述来严格界定可判定性，为高风险领域的 Agent 验证提供了更可靠的方法论基础。
