## 文章做了什么
- **背景**：黑盒优化（BBO）广泛应用于科学和工程领域，其目标函数评估昂贵且无解析形式或梯度。传统方法（如贝叶斯优化、进化算法）主要依赖数值观测，忽略了任务描述、变量语义和领域知识等非数值信息。大型语言模型（LLM）代理能够结合语义理解、计算工具及反馈决策，为利用这些额外信息提供了新途径。
- **已有工作为什么解决不了**：现有的基于代理的 BBO 研究使用了不同的任务域和系统配置，导致结果难以横向比较，且难以隔离单个设计选择对性能的具体影响，缺乏统一的标准来评估不同 LLM 代理在 BBO 中的真实能力。

## 文章的核心贡献点
- **提出了一个 AgenticBBO-Bench**：这是一个跨领域的黑盒优化基准测试平台，涵盖合成函数、超参数优化、数据库调优、芯片设计和分子设计五个领域，并在统一的有限预算评估协议下运行。
- **挑战1：缺乏统一的评估标准导致性能对比困难**。难点在于不同研究使用异构的任务和配置。**解决方法**：构建了包含五个不同领域的标准化基准，采用统一的有限预算评估协议，使得不同代理系统和 LLM 的性能可以直接比较。
- **挑战2：代理设计中各要素（工具、先验、LLM角色）的作用机制不明确**。难点在于难以量化特定设计选择对最终优化效果的贡献。**解决方法**：通过消融实验深入研究了优化工具、任务信息与先验知识、以及 LLM 在搜索过程中的角色这三个关键因素，揭示了数值工具并非总是有效，而任务语义具有广泛实用性等关键发现。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：代码已开源。基准测试集成了多种任务环境，并支持通过 Codex agent harness 评估不同的 LLM。
- **Evaluation 结果**：
    - 在所有五个领域中，基于代理的 BBO 方法取得的家族平均得分均高于直接基于 LLM 的方法。
    - 在四个领域中，基于代理的 BBO 方法优于最佳的数值优化器。
    - 在前沿挑战中，评估了七种 LLM。结果显示 GPT-6 Astra 和 DeepSeek-V4.1-Flash 在性能和成本之间处于帕累托前沿。
- **相关工作对比**：
    - 相比传统数值优化器，代理方法能更好地利用语义信息，在大多数复杂任务中表现更优。
    - 相比直接调用 LLM 生成解的方法，引入代理框架（结合工具和反馈循环）显著提升了优化效果。
    - 研究发现，额外的数值工具并不总能提升性能，特定的先验知识有时不如通用的任务语义可靠，且数值优化器可以有效吸收代理建立的搜索轨迹增益。

#### 总结
本文指出了当前基于代理的黑盒优化研究缺乏统一基准的问题，提出了 AgenticBBO-Bench。通过广泛的实验，证明了代理方法在跨领域 BBO 任务中的优越性，并深入分析了影响代理性能的关键因素。该基准为未来通用模型和代理系统的比较提供了标准化平台，推动了通过代理操作实现通用黑盒优化的发展。
