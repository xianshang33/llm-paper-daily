## 文章做了什么
- **背景**：在长视界、部分可观测的环境中控制 LLM Agent 时，需要在每一步决定是信任其动作、放弃还是移交给人类。这需要一种能预测当前尝试最终是否成功的逐步骤置信度信号。
- **已有工作的局限**：现有的强化学习校准方法通常针对单步决策的正确性进行校准。这种贪婪的优化信号只能训练模型具备局部预测能力，无法保证对多步任务最终结果的预测有效性，且未经专门训练的小型 LLM 置信度校准较差。

## 文章的核心贡献点
- **提出了一个基于结果 grounding 的置信度校准方法**：在 GRPO（组相对策略优化）框架下，利用任务的一组 rollout 提供成功标签，并使用适当的评分规则根据实际结果对每一步的置信度进行评分和奖励。
- **挑战1：如何将局部置信度与全局最终结果关联？**
  - **难点**：传统方法仅关注单步对错，忽略了长程依赖和累积不确定性，导致置信度无法反映最终成败。
  - **解决**：通过引入以最终episode结果为ground truth的奖励函数，直接优化步骤置信度与最终结果的一致性，使Agent学会从第一步就预判整体任务的可行性。
- **挑战2：如何准确评估和分离置信度提升的来源？**
  - **难点**：传统的聚合指标混合了任务难度、episode深度和尝试级别的预见性，难以区分Agent是学会了识别难任务还是学会了区分同一任务下的成败尝试。
  - **解决**：引入新的评估协议，分离episode深度、任务难度和尝试级预见性，发现训练后的Agent能在第一步识别出注定失败的任务，但在区分同一任务下不同尝试的成败上较难，仅在TextWorld中显示出早期窗口信号。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：在 ALFWorld、TextWorld 和 WebShop 环境中，使用 Qwen2.5-7B Agent 进行离线和在线 RL 训练。离线阶段使用记录轨迹，在线阶段在实时 ALFWorld Agent 上应用四种校准奖励。
- **Evaluation 结果**：
  - **离线 RL**：步骤置信度相对于 episode 结果的 AUROC 从接近随机水平提升至 0.68-0.85。Agent 最自信的 top-10% 步骤的成功率比平均水平高约 4.3 倍。
  - **在线 RL**：早期步骤的 AUROC 得到改善，预期校准误差（ECE）从 0.42 降至 0.12 以下。选择性执行（Selective Execution）的效果优于未训练 Agent 和仅格式化的 RL 对照组，且未降低任务成功率。
- **对比**：相比现有专注于单步正确性的校准工作，该方法显著提升了长程任务结果预测的可靠性，并通过新协议揭示了增益主要来源于对注定失败任务的早期识别。

#### 总结
本文提出了一种基于最终结果 grounding 的 LLM Agent 置信度校准方法，解决了传统单步校准无法预测长程任务最终结果的问题。通过 GRPO 框架和适当的评分规则，Agent 能够生成可靠的逐步骤置信度信号。实验表明，该方法在多个环境中显著提升了置信度校准质量（AUROC 和 ECE），并使 Agent 能够在早期识别潜在失败的任务，为运行时控制和人工介入提供了有效依据。
