## 文章做了什么
- **背景**：大型语言模型（LLM）智能体的能力不仅取决于模型权重，还很大程度上取决于其“Harness”（包括提示词、工具、中间件和控制逻辑）。自动 Harness 优化（AHO）可以在不修改模型权重的情况下显著提升智能体性能。
- **已有工作为什么解决不了**：现有的 AHO 方法主要专注于优化响应质量，而忽略了实际部署中至关重要的成本因素。当尝试同时优化质量和成本时，如果在中间更新步骤直接应用最终的部署偏好（如特定的质量-成本权衡），会导致过早丢弃那些在当前看来不佳但对后续迭代有价值的候选方案，从而限制了最终优化的上限。

## 文章的核心贡献点
- **提出了一个 ParetoSaddler**：一种帕累托引导的智能体 Harness 优化框架，旨在联合优化任务响应质量和 LLM Token 成本。
- **挑战1：中间候选者的过早淘汰问题**。在多目标优化中，直接应用部署偏好会丢弃那些在某一方面（如成本）有潜力但另一方面（如质量）暂时落后的中间候选者，导致搜索空间受限。**解决方法**：ParetoSaddler 将“中间候选者晋升”与“最终部署选择”分离。它使用贝叶斯 bootstrap 帕累托支持度来评估候选者，只要候选者在质量或成本任一维度上显示出可信的进步，就会被保留并作为后续优化的父代，从而保留了多样化的搜索路径。
- **挑战2：优化结果的不稳定性与噪声**。由于 LLM 输出的随机性，单次执行的结果可能无法真实反映 Harness 的性能变化，导致基于噪声的无效优化。**解决方法**：通过重复执行和贝叶斯 bootstrap 方法进行筛选，只有那些在多次运行中获得统计支持的显著改进才会被认可，从而过滤掉由随机波动引起的弱增益候选者，确保优化的稳健性。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：在 ClawMark 和 GAIA2 两个基准测试上进行评估，使用域不相交的数据划分以确保泛化能力。
- **对比结果**：
    - **ClawMark**：ParetoSaddler 将质量从 70.86% 提升至 81.35%，同时将每个任务的成本从 $1.17 降低至 $1.01。
    - **GAIA2**：质量从 56.22% 提升至 62.89%，成本从 $0.78 大幅降低至 $0.45。
- **相关工作对比**：与仅优化质量的基线方法（如 AutoSaddler-Quality）和其他多目标方法（如 Meta-Harness-Pareto）相比，ParetoSaddler 能够在更低的成本区域发现更高质量的 Harness。分析表明，传统的部署偏好筛选会丢弃对后续改进至关重要的中间候选者，而 ParetoSaddler 通过帕累托感知优化保留了这些候选者，实现了更好的质量-成本权衡前沿。

#### 总结
ParetoSaddler 解决了 LLM 智能体 Harness 优化中质量与成本联合优化的难题。通过引入贝叶斯 bootstrap 帕累托支持机制，它有效地分离了中间探索与最终选择，避免了因早期偏好应用导致的局部最优陷阱。实验证明，该方法在多个基准测试上均能同时提升智能体的回答质量并显著降低推理成本，优于现有的单目标及多目标优化基线。
