## 文章做了什么
- **背景**：随着大语言模型（LLM）应用的广泛部署，推理工作负载急剧增加。由于代理（Agentic）和推理工作负载中常见的长输入提示和生成长序列，键值（KV）缓存的使用量巨大，导致 GPU 内存成为关键瓶颈。
- **已有工作的局限**：传统的排队论模型无法直接应用于 LLM 推理调度，因为 LLM 推理的处理步骤持续时间不仅取决于计算能力，还严重依赖于 KV 缓存的 I/O 速度和内存占用情况。现有的调度策略往往未能充分联合考虑计算速度、内存带宽和内存容量对服务能力的共同决定作用。

## 文章的核心贡献点
- **提出了一个基于流体模型的 $c\\mu$ 优先级调度规则**：该规则中的有效服务率 $\\mu$ 由计算速度、内存带宽和内存容量共同决定。
- **挑战1：多维资源耦合下的服务能力建模难**。LLM 推理的服务速率并非固定，而是动态受限于计算和内存访问的双重约束，难以用经典单维参数描述。**解决方法**：文章开发了一个流体模型，将系统简化为具有有效服务率的多类单服务器排队系统，该有效服务率综合捕捉了计算、内存访问和内存容量的影响。
- **挑战2：离散随机系统的渐近最优性证明难**。在实际有限的离散请求系统中，如何保证调度策略在重负载下依然保持最优性能是一个理论难题。**解决方法**：文章证明了该 $c\\mu$ 规则在流体模型中最小化累积持有成本，并构建了原始有限系统的可行调度策略，证明其缩放动态收敛于最优流体策略，从而在有限工作负载下最小化完成时间并最大化吞吐量。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实验设置**：在使用 NVIDIA H800 GPU 的真实 LLM 服务引擎上进行实验。
- **结果对比**：与现有的调度策略相比，所提出的优先级规则的实际实现显著降低了平均延迟，同时保持了高吞吐量。
- **性能优势**：实验验证了理论分析的有效性，表明在内存受限的场景下，联合优化计算和内存资源的调度策略优于仅考虑单一维度的传统方法。

#### 总结
本文从排队论角度研究了内存约束下的 LLM 在线推理调度问题。通过建立包含计算和内存因素的流体模型，推导出了渐近最优的 $c\\mu$ 优先级规则。理论证明和真实硬件实验均表明，该策略能有效平衡响应速度和资源利用率，显著降低延迟并提升吞吐量，为解决大规模 LLM 推理中的内存瓶颈提供了有力的理论支持和实践方案。
