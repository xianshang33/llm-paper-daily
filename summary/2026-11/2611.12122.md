## 文章做了什么
- **背景**：AI Agent Harness（代理框架）为大型语言模型（LLM）提供了与计算环境交互的接口，支持如代码修复、终端操作等长程任务。随着模型上下文窗口的扩大，Agent 的执行成本显著增加。
- **已有的工作为什么解决不了**：现有研究表明，Agent 的任务执行准确率主要取决于所使用的 LLM，而 Harness 层面的差异（如系统提示词或工具选择）对准确率影响微乎其微。然而，这些 Harness 层面的变体对执行成本有巨大影响（最高可达 2.6 倍差异）。现有的优化多集中于模型本身或提示工程，缺乏针对 Harness 系统层面的统一成本优化机制，导致在长程任务中产生高昂的 Token 消耗和 API 调用费用。

## 文章的核心贡献点
- **提出了一个名为 Agency 的 Harness 介入平台**：该平台提供统一的抽象层，允许在现有的商用 Harness（如 Claude Code 或 OpenAI Codex）上轻松、可移植地实现系统级优化。
- **挑战1：上下文读取成本高昂**。即使有缓存机制，读取现有上下文仍是实际执行中最大的成本来源（占总成本的 73%），因为长上下文导致每次 LLM 调用都需要处理大量历史 Token。**解决方法**：Agency 通过分析成本累积模式，实施优化技术以减少不必要的 Token 使用和 LLM 调用次数，从而在不修改模型的情况下降低读取开销。
- **挑战2：工具调用的低效与信息稀疏**。工具调用会在不显著增加 Token 数量的情况下导致成本激增（同 Token 数下成本增加高达 26 倍），且工具输出往往信息稀疏，Agent 仅利用其中一小部分信息。**解决方法**：Agency 作为介入层，能够拦截和优化这些交互，通过证明概念的实现展示了如何在不牺牲准确率的前提下，针对这些系统机会进行优化，减少冗余的工具调用和处理开销。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：研究者设计了 Agency 平台，并基于其分析实现了概念验证的优化技术。该平台旨在与现成的 Harness 兼容，无需修改底层模型。
- **评估结果**：在各种真实世界的基准测试中，使用 Agency 实现的优化技术在现有 Harness 上实现了高达 35% 的成本降低。
- **对比**：与未优化的标准 Harness 执行相比，该方法在保持任务准确率不变的情况下，显著减少了 Token 使用和 LLM 调用次数。研究指出，相较于仅仅依赖模型能力的提升，Harness 层面的系统优化提供了另一种极具潜力的成本节约途径（此前研究显示 Harness 变体可带来高达 2.6 倍的成本差异，本文在此基础上进一步通过系统化方法实现了 35% 的额外节省）。

#### 总结
本文指出了 AI Agent 系统中被忽视的 Harness 层面成本优化机会。通过分析发现，上下文读取和低效的工具调用是主要成本驱动因素。为此，作者提出了 Agency，一个用于 Harness 介入的系统平台，能够在不改变模型且不牺牲准确率的情况下，通过系统级优化显著降低 Agent 的执行成本（最高达 35%）。这项工作为构建更具成本效益的 AI Agent 系统提供了新的系统视角和实用工具。
