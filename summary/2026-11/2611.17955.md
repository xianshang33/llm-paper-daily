## 文章做了什么
- **背景**：由大型语言模型和视觉语言模型驱动的 Web 智能体正被应用于跨越异构应用、多模态内容和有状态工作流的真实浏览器任务中。
- **已有工作的局限性**：现有的可复现 Web 智能体基准测试覆盖的应用数量少且类别单一，仅局限于文本和视觉模态；而在线基准测试虽然覆盖范围广，但因页面和数据漂移牺牲了可复现性。此外，现有基准未能有效评估智能体理解和利用网页中嵌入的音频和视频内容的能力。

## 文章的核心贡献点
- **提出了一个名为 WebArena-Pro 的基准测试**：包含 300 个任务，涵盖 6 个领域类别中的 20 个自托管 Web 应用程序，提供目前最广泛的应用覆盖和最全面的多模态支持。
- **挑战1：多模态内容（音频/视频）的理解与交互难**。难点在于传统基准忽略音视频，且缺乏针对这些模态的标准操作接口。WebArena-Pro 将音频和视频作为核心观察对象，并设计了专门的提取动作（如 Extract_frames, Transcribe），使智能体能有效处理多媒体信息。
- **挑战2：基准测试的广泛性与可复现性难以兼得**。难点在于真实网站动态变化导致结果不可复现，而静态环境往往过于简单或单一。WebArena-Pro 通过自托管 20 个异构应用并隔离运行每个任务，既保证了环境的多样性和真实性，又实现了完全的可复现性和并行评估。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：任务通过专用的标注界面编写，经过 LLM 辅助筛选，并最终由人工验证后发布。基准测试支持任务的隔离运行和并行评估。
- **评估结果**：
    - 表现最好的是 Codex (GPT 6.1 Sol) 和 Claude Code (Claude Opus 5.5)，成功率均为 62.3%。
    - OpenCode (Kimi 3.1 Pro) 以 60.7% 紧随其后。
    - 最强的通用智能体配置 Gemini 3.1 Pro omni 和 Gemma4 31B 均达到 30.3%。
- **对比**：在可复现且经人工策划的 Web 智能体基准测试中，WebArena-Pro 提供了迄今为止最广泛的应用覆盖范围和最全面的多模态支持，解决了现有基准在模态多样性和应用异质性上的不足。

#### 总结
WebArena-Pro 填补了当前 Web 智能体基准测试在异构应用覆盖、多模态（特别是音视频）支持以及可复现性方面的空白。通过构建包含 20 个自托管应用的多样化环境和 300 个精心策划的任务，它为评估下一代多模态 Web 智能体提供了高标准、可复现的测试平台，推动了智能体在复杂真实世界场景中的能力评估。
