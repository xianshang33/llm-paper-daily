## 文章做了什么
- **背景**：代理式人工智能（Agentic AI）有望自动化敏感临床数据的分析，但当前系统主要依赖大型语言模型（LLM）。
- **已有工作的局限性**：云端 LLM 存在患者数据隐私泄露风险；本地部署的 LLM 虽然解决了隐私问题，但容易产生幻觉（hallucination），导致工具调用中生成不存在的参数值或错误工具，且这些错误会在后续步骤中传播。此外，基于文本生成的推理模式效率低下，增加了时间和能源消耗。

## 文章的核心贡献点
- **提出了一个 System 1 Agents 框架**：一种无需生成文本、在本地运行、可靠且快速的代理 AI 构建方法。
- **挑战1：本地模型的可靠性与幻觉问题**。难点在于传统 LLM 通过逐 token 生成文本来构建工具调用，容易捏造用户未提供的值或调用不存在的工具。解决方法是引入确定性编译器，将工具 schema 和用户请求转化为多项选择题，由单次前向传播的决策模型直接选择选项，彻底消除文本生成带来的幻觉。
- **挑战2：隐私保护与执行效率的平衡**。难点在于云模型泄露隐私，而本地小模型能力不足且推理慢。解决方法是采用“System 1”式的快速判断机制，不进行复杂的思维链推理，仅做离散选择，既保证了数据完全本地化处理，又显著提升了响应速度和能效。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与部署**：该框架包含三个核心组件：控制工作流的 Agent、将工具 schema 和请求编译为多项选择题的确定性编译器、以及回答这些问题的单次决策模型。代码已作为开源软件发布。
- **评估结果**：在针对 157 个生物医学工具的 1,952 个请求测试中，最佳的 System 1 agent 在正确选择工具或正确拒绝请求方面的准确率达到 97.0%。在填充 6,056 个声明的参数值时，准确率为 97.0%。
- **对比相关工作**：System 1 agent 的表现显著优于所有 18 种本地 LLM-agent 设置（最佳仅为 95.2%）。最关键的是，System 1 调用中没有任何捏造内容（0% 幻觉率），而 LLM 调用的幻觉率在 5.5% 至 19.7% 之间。

#### 总结
本文提出了一种名为 System 1 Agents 的新方法，通过将工具调用转化为多项选择决策问题，避免了传统 LLM 基于文本生成的幻觉问题。该方法在保持数据本地化以保护隐私的同时，实现了比现有本地 LLM 代理更高的准确性、可靠性和速度，特别适用于对隐私和可靠性要求极高的临床数据分析场景。
