## 文章做了什么
- **背景**：基于大语言模型（LLM）的代理通过搜索网络并推理来预测现实世界事件。评估此类代理的性能不仅取决于模型的推理能力，还取决于其检索到的证据质量。
- **已有工作的不足**：现有的评估方法存在严重缺陷。实时评估将检索与推理混淆，难以区分是模型差还是搜索差； retrospective（回顾性）搜索存在“信息泄露”风险，因为即使使用日期过滤器，搜索引擎当前的排名算法或更新后的页面内容仍可能泄露事后信息，导致评估不公正且不可复现。

## 文章的核心贡献点
- **提出了一个名为 ForecastGym 的基准测试框架**：这是一个实时、可控且可重放的预测代理基准，旨在将证据作为受控实验变量。
- **挑战1：信息泄露与证据重构困难**。难点在于回顾性搜索难以完全还原历史时刻搜索引擎返回的真实结果，容易混入事后更新的信息。ForecastGym 通过在问题未解决时前瞻性地记录四个商业搜索 API 的返回结果，并在事后冻结这些证据进行离线重放，从而彻底杜绝了信息泄露。
- **挑战2：检索与推理耦合及来源差异不可控**。难点在于不同代理自行搜索时，无法分离模型能力与搜索质量的贡献，且难以比较不同搜索源的影响。ForecastGym 固定证据获取策略，允许在相同的证据轨迹上对比不同模型、记忆策略和搜索源，实现了真正的解耦评估。

## 实现与部署，evaluation 结果，要有和相关工作对比
- **实现与数据**：ForecastGym 每两天对开放预测市场的问题查询一次，记录了 150 个问题、614 个证据状态和 13.1 万个搜索结果。涵盖 Tavily, Exa, Serper, Parallel 四个搜索源。
- **评估结果**：
    - **信息泄露验证**：如果在问题解决后重新运行相同查询，高达 92% 的问题结果几乎直接揭示了答案，证明了传统回顾性评估的严重泄露问题。
    - **模型表现**：在冻结证据上，所有测试的 LLM 预测准确率均落后于预测市场。
    - **诊断分析**：高差距状态下的主要误差来源是“遗漏公共信息”而非“误读信息”。
    - **搜索源影响**：切换搜索 API 导致的 Brier 分数变化高达 0.043，这一影响超过了不同模型之间的差异，表明证据来源的重要性不亚于模型本身。
    - **记忆策略**：持久化笔记（persistent notes）的表现与以一半输入 token 重新阅读所有证据的效果相当。

#### 总结
ForecastGym 通过前瞻性地捕获和冻结搜索证据，解决了预测代理评估中的信息泄露和变量耦合问题。研究揭示，对于预测任务而言，代理所看到的证据质量（由搜索源决定）与其推理模型同样重要，甚至影响更大。该基准为未来研究提供了可控、可重放的实验环境，有助于独立优化检索和推理模块。
