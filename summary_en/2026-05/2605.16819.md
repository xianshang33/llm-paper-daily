## 1. What the Paper Did
- **Background**: GPU kernel optimization is critical for efficient deep learning systems but requires substantial low-level expertise. Recent AI coding agents can iteratively refine code by invoking compilers and profilers, mimicking human engineering workflows.
- **Why Existing Work Falls Short**: Existing benchmarks (e.g., SWE-bench, HumanEval, KernelBench) evaluate single LLM calls or light iterative prompting rather than full agent workflows. They lack support for "kernel-to-kernel" optimization scenarios and do not test generalization to unseen input configurations, failing to measure whether optimizations transfer across different shapes.

## Core Contributions
- **Proposed AgentKernelArena**: An open-source benchmark for evaluating AI coding agents on GPU kernel optimization, featuring 196 tasks across three categories: HIP-to-HIP optimization, Triton-to-Triton optimization, and PyTorch-to-HIP translation.
- **Challenge 1: How to comprehensively evaluate full agent workflows instead of single-shot generation?**
  - **Difficulty**: Traditional benchmarks focus on static correctness, ignoring the dynamic multi-turn iteration process involving compilation, testing, and profiling.
  - **Solution**: Designed sandboxed environments with a "compile -> correctness -> performance" gating pipeline, forcing agents to operate in a closed loop and quantifying final optimization effects via a centralized scoring system.
- **Challenge 2: How to measure the generalization capability of optimization results?**
  - **Difficulty**: Agents may overfit to specific input shapes during optimization, leading to failures or performance drops on other configurations; existing benchmarks lack detection for this.
  - **Solution**: Introduced an "unseen-configuration generalization protocol" that tests optimized kernels on input configurations never seen by the agent, verifying if optimization strategies are generic rather than hardcoded assumptions.

## Implementation and Evaluation
- **Implementation & Deployment**: AgentKernelArena is a modular, extensible framework running production agents (e.g., Cursor Agent, Claude Code, Codex Agent) in isolated workspaces. It integrates gated compilation, correctness checks, and performance benchmarking.
- **Evaluation Results**:
  - **Compilation & Correctness**: Near-perfect compilation success rates and high correctness rates across most task categories.
  - **Performance Speedup**: Strongest configurations achieved mean speedups of up to 6.89x on PyTorch-to-HIP, 6.69x on HIP-to-HIP, and 2.13x on Triton-to-Triton tasks.
  - **Generalization Findings**: Optimizations for HIP-to-HIP and Triton-to-Triton largely transfer to unseen input shapes. However, PyTorch-to-HIP shows substantial correctness drops on unseen configurations, indicating agents often hardcode shape-specific assumptions when generating kernels from scratch.
- **Comparison**: Unlike KernelBench and TritonBench which assess single-generation or light iteration, AgentKernelArena reveals actual efficacy in real iterative workflows and highlights generalization limitations, offering a more rigorous evaluation perspective.

#### Summary
AgentKernelArena fills the gap in evaluating AI agents for GPU kernel optimization, emphasizing both workflow efficiency and generalization of optimization results. The study shows that while current agents achieve significant speedups in specific tasks, their robustness in generalization—especially when generating kernels from scratch for unseen inputs—needs improvement due to hardcoded assumptions. This framework provides a crucial standard for developing more general and robust AI-assisted kernel optimization tools.
