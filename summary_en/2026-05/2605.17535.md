## 1. What the Paper Does
- **Background**: Core systems in telecommunications, finance, and healthcare rely on legacy code (e.g., COBOL, PL/SQL) built decades ago. These systems contain implicit business rules, edge-case handling, and cross-module constraints refined through years of production use, but they are costly to maintain and suffer from expertise loss.
- **Why Existing Work Fails**: Current tools and LLM-based approaches treat modernization as mere "syntax translation" (e.g., COBOL to Java). This approach ignores undocumented implicit business logic, resulting in code that compiles but silently breaks critical behavioral semantics in production. Monolithic prompt methods are limited by context windows and lack mechanisms to verify behavioral preservation.

## Core Contributions
- **Proposed AgentModernize Framework**: A multi-agent LLM framework that reframes modernization as a "behavioral preservation" problem. Its key intermediate artifact is the Behavioral Specification Graph (BSG), which forces extracted business logic to be explicit and inspectable before code generation.
- **Challenge 1: Loss and Uninterpretability of Implicit Business Logic**. Difficulty: Business rules are scattered across control flows and configurations, making them hard to capture in a single pass. Solution: Specialized extraction and specification agents construct a BSG as a decoupled, checkable intermediate layer, capturing 91.2% of gold-standard rules.
- **Challenge 2: Lack of Behavioral Equivalence Verification and Feedback**. Difficulty: Traditional methods cannot confirm if the generated modern code behaves identically to the legacy system. Solution: A validation agent and feedback loop strictly compare outputs against gold-standard tests, iterating on failures to significantly improve Behavioral Equivalence Rate (BER).

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on the LegacyModernize-8 benchmark (8 scenarios in telecom and banking) using GPT-4o-mini, GPT-4o, and GPT-5.3-codex under a fair protocol (same gold-standard tests, 3 trials, temperature 0.0).
- **Comparison Results**:
    - **Baselines Failed**: Single-Prompt LLM (SP-LLM) and Chain-of-Thought LLM (CoT-LLM) achieved 0.0% mean BER across all scenarios and models.
    - **AgentModernize without Feedback**: Achieved 0.0% BER on GPT-4o-mini and GPT-5.3-codex; only 5.6% mean BER on GPT-4o.
    - **Full AgentModernize (with Feedback)**: The only configuration with non-zero BER across all backbones. Mean BERs were: GPT-4o-mini (9.4%), GPT-4o (8.1%), and GPT-5.3-codex (19.4%).
- **Key Finding**: The BSG captures 91.2% of gold-standard rules, indicating the bottleneck is code generation, not extraction. The feedback loop is decisive for performance.

## 4. Conclusion
AgentModernize successfully addresses the core issue of business logic loss in legacy modernization through multi-agent collaboration and Behavioral Specification Graphs (BSG). Experiments demonstrate that treating modernization as behavioral preservation with strict verification feedback vastly outperforms traditional syntax translation. The framework not only improves behavioral equivalence but also provides auditable artifacts (rule inventories, BSGs, equivalence reports), offering significant practical value for regulated industries.
