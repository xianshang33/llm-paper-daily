## 1. What the Paper Does
- **Background**: Long-horizon LLM agents rely on persistent memory to support cross-session interactions. Existing memory systems typically retrieve context using semantic similarity or broad history inclusion, implicitly assuming that all retrieved memories are useful.
- **Limitations of Prior Work**: This assumption is fragile because memories may be topically related yet irrelevant, stale, ambiguous, or even adversarially misleading. Current methods struggle to distinguish between memories that merely "look relevant" and those that genuinely improve answer quality, leading models to confidently incorporate harmful or misleading information.

## Core Contributions
- **Proposed Causal Memory Intervention (CMI)**: A causal memory-selection technique that estimates how candidate memories affect the model's answer under controlled interventions, selecting memories that improve task performance while suppressing unstable, irrelevant, or harmful ones.
- **Challenge 1: How to quantify the actual causal utility of a memory on the final answer, rather than just semantic relevance?**
  - **Difficulty**: Semantic similarity fails to capture whether a memory truly aids reasoning and may introduce noise.
  - **Solution**: CMI uses controlled interventions (selectively including or excluding specific memories) to observe changes in model output, thereby estimating the causal contribution of each memory and retaining only those with a positive causal impact on the correct answer.
- **Challenge 2: Lack of benchmarks for evaluating the robustness of memory selection, particularly against misleading memories.**
  - **Difficulty**: Existing benchmarks mainly evaluate information recovery from long contexts but do not specifically test resistance to irrelevant distractors or synthetic harmful memories.
  - **Solution**: Introduced Causal-LoCoMo, a causally annotated benchmark derived from long conversational data. Each example includes user requests, structured memory banks, useful memories, irrelevant distractors, and synthetic harmful memories to comprehensively evaluate selection accuracy and robustness.

## Implementation and Evaluation
- **Experimental Setup**: CMI was compared against baselines including vector retrieval, graph retrieval, reflection, summarization, full-history, and no-memory approaches.
- **Results**: CMI achieved a stronger balance between answer quality and robustness to misleading memory. Compared to relevance-based methods, CMI more effectively filtered out irrelevant and harmful memories, significantly enhancing the reliability of long-horizon agents.
- **Comparison Advantage**: Traditional methods (e.g., vector similarity) are susceptible to semantically similar but factually wrong or harmful memories. CMI demonstrates through causal inference that reliable long-term memory requires selecting context based on "causal usefulness" rather than mere "relevance."

## 4. Conclusion
This paper highlights the limitations of semantic similarity-based retrieval in existing long-horizon LLM agent memory systems and proposes Causal Memory Intervention (CMI) to assess the actual utility of memories via causal intervention. It also constructs the Causal-LoCoMo benchmark to evaluate system performance in the presence of distractions and harmful memories. Experiments show that memory selection based on causal usefulness significantly improves the robustness and answer quality of agents in complex long-horizon tasks.
