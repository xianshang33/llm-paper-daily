## 1. What the Paper Did
- **Background**: Large language model (LLM) agents increasingly operate over long and recurring external contexts, such as document corpora and code repositories, where the context remains largely static while tasks vary.
- **Why Existing Work Falls Short**: Current approaches preserve agent trajectories, passive access to raw material, or task-level strategies. Shared chats accumulate noise; history compaction discards reusable context knowledge; RAG and context offloading lack curated understanding of the context itself; and prompt learning focuses on task strategies rather than contextual orientation. None preserve the reusable "orientation knowledge" (what the context contains, its organization, and useful entities) critical for repeated same-context workloads.

## Core Contributions
- **Proposed PEEK**: A system that caches and maintains orientation knowledge as a "Context Map," a small, constant-sized artifact in the agent's prompt that provides a persistent peek into the external context.
- **Challenge 1: How to extract transferable knowledge from inference signals?**
  - **Difficulty**: Raw contexts are large and unstructured, making direct processing costly and key structures hard to identify.
  - **Solution**: PEEK introduces a "Distiller" module that extracts transferable knowledge from inference-time signals and translates it into structured edits, capturing the essence of the context.
- **Challenge 2: How to maintain map effectiveness and relevance under a fixed token budget?**
  - **Difficulty**: Knowledge accumulation leads to context overflow or inclusion of outdated information, degrading agent performance.
  - **Solution**: PEEK employs a priority-based "Evictor" and a "Cartographer" module to enforce a fixed token budget, retaining only the most valuable orientation knowledge to keep the map compact and precise.

## Implementation and Evaluation
- **Implementation**: PEEK consists of three modules: Distiller (extracts knowledge), Cartographer (translates to structured edits), and Evictor (priority-based cleanup). It operates as a programmable cache policy compatible with various LMs and agent architectures, including OpenAI Codex.
- **Evaluation Results**:
  - On long-context reasoning and information aggregation, PEEK improves over strong baselines by 6.3-34.0%, using 93-145 fewer iterations.
  - Compared to the state-of-the-art prompt-learning framework ACE, PEEK incurs 1.7-5.8x lower cost.
  - In context learning tasks, PEEK improves solving rate by 6.0-14.0% and rubric accuracy by 7.8-12.1%, at 1.4x lower cost than ACE.
- **Comparison**: Significantly outperforms ACE and other baselines, demonstrating strong generalization across different base models like GPT-5-mini.

## 4. Conclusion
PEEK successfully addresses the lack of efficient orientation knowledge for LLM agents handling recurring long contexts by introducing the "Context Map." Through distillation, mapping, and eviction mechanisms, it significantly enhances agent accuracy and efficiency in long-context tasks at minimal cost and token usage, proving that maintaining reusable contextual orientation knowledge is crucial for improving LLM agent performance.
