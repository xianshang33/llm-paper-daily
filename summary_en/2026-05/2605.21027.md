## 1. What the Paper Does
- **Background**: Enterprise analytics aims to support data-driven decision-making, but non-technical users face barriers with traditional BI tools or Text-to-SQL systems. Modern enterprise analytics rely on governed APIs that encapsulate complex business logic for consistency, auditability, and security.
- **Limitations of Existing Work**: Current LLM-based Text-to-SQL approaches focus on direct raw database access and fail in enterprise settings relying on governed APIs. Delegating mathematical or aggregation logic to LLMs introduces reliability and compliance risks. Furthermore, existing methods often lack multi-step reasoning, integration with broader analytics ecosystems, and the ability to enforce data governance policies.

## Core Contributions
- **Proposed Analytic Agent**: An LLM-based agentic system that translates natural language intents into secure interactions with enterprise analytics APIs.
- **Challenge 1: Complex Intent Parsing and Target Disambiguation**. User queries in enterprise settings are often ambiguous and involve specific business semantics, making direct mapping to API endpoints difficult. The paper addresses this by introducing a Target Search Agent and an Orchestrator Agent, which use multi-step reasoning to parse user goals, match entities, and validate permissions, thereby accurately identifying required API endpoints and metrics.
- **Challenge 2: Compliant Execution and Secure Visualization**. Generating query results directly within an LLM can lead to data leaks or violations of business rules. The paper solves this by using a Database Querying Agent for endpoint selection and query construction, combined with a strict validation loop to enforce business rules. Additionally, a Visualization Agent generates policy-compliant chart configurations, ensuring the safety and规范性 of the final output.

## Implementation and Evaluation
- **Implementation and Deployment**: The system consists of an Orchestrator Agent, Target Search Agent, Database Querying Agent, and Visualization Agent, forming an end-to-end workflow. It is deployed in a real-world industrial setting, handling the entire process from natural language queries to secure API interactions.
- **Evaluation Results**: Evaluated on 90 real enterprise use cases constructed by domain experts and judged by GPT and Claude, Analytic Agent achieved 77.22% end-to-end accuracy and a 96.67% query execution success rate.
- **Comparison**: Compared to traditional Text-to-SQL methods and single-step LLM pipelines, this system demonstrates higher reliability and compliance in scenarios involving governed APIs, proving the feasibility of an API-grounded analytics path.

## 4. Conclusion
This paper addresses the challenge of non-technical users accessing governed data in enterprise analytics by proposing Analytic Agent. The system overcomes the limitations of traditional Text-to-SQL methods in API environments and data governance. Through multi-agent collaboration, it achieves intent parsing, permission validation, secure query execution, and compliant visualization. Experimental results show high accuracy and execution success rates in real-world enterprise scenarios, providing a practical path for building trustworthy, API-based enterprise analytics systems.
