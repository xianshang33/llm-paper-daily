## 1. What the Paper Did
- **Background**: There is a severe reproducibility crisis in LLM Agent benchmarks. Different papers often report conflicting results for the same model and benchmark, yet fail to provide sufficient details (such as scaffolds, sampling settings, subsets, or evaluator versions) to explain these discrepancies.
- **Why Existing Work Falls Short**: Prior reproducibility efforts in deep reinforcement learning or static LLM prompt sensitivity do not address the specific unit of analysis for agents: the "agent run" itself (the composition of model, scaffold, environment image, stopping rules, and grader). There lacks a standardized framework to quantify the transparency of experimental execution details in current literature.

## Core Contributions
- **Proposed an Open Scoring Schema**: A five-field audit framework (Benchmark Identity, Harness Specification, Inference Settings, Cost Reporting, Failure Breakdown) along with a scoring codebook to systematically evaluate the disclosure completeness of LLM Agent benchmark papers.
- **Challenge 1: Opacity of Evaluation Environments**. The difficulty lies in the high sensitivity of agent performance to software environments and scaffold versions. The paper addresses this by defining the "Harness Specification" field, which checks for content-addressed container images or precise version control, thereby quantifying the lack of environmental transparency.
- **Challenge 2: Neglect of Inference Costs and Failure Modes**. The challenge is that most papers only report final success rates, ignoring computational costs and error analysis, which hinders efficiency and robustness assessment. The paper introduces "Cost Reporting" and "Failure Breakdown" fields, exposing systematic gaps in these critical engineering metrics.

## Implementation and Evaluation
- **Implementation**: The authors released the audit schema as a JSON Schema file, the codebook as a Markdown document, and the raw scoring data as a CSV. The audit was conducted by a single auditor on 12 canonical papers (8 agent benchmarks, 4 classical static benchmarks).
- **Evaluation Results**:
    - The mean audit score for the 8 agent benchmark papers was 0.38 (out of 1.0).
    - The mean audit score for the 4 classical static benchmark papers was 0.66.
    - The largest gaps were found in "Cost Reporting" (none of the 8 agent papers disclosed inference costs) and "Harness Specification" (none fully disclosed content-addressed container images).
- **Comparison**: Compared to classical static benchmarks, agent benchmarks show significantly poorer disclosure of experimental details, indicating that reproducibility practices have not kept pace with increasing system complexity.

## 4. Conclusion
This paper presents a pilot audit of transparency in LLM Agent benchmarking. By applying a novel five-dimensional scoring schema, it reveals significant deficiencies in current top-tier agent benchmark papers, particularly regarding environment specifications and cost reporting. The work provides open-source auditing tools to the community, aiming to promote stricter and more transparent evaluation standards, serving as a foundation for future multi-rater audits and standardization.
