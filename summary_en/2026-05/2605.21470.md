## 1. What the Paper Does
- **Background**: Computer-use agents (CUAs) automate web tasks via natural language by generating sequences of tool calls (e.g., click, type). Current implementations rely on a sequential "fetch-screenshot-execute" loop, requiring an LLM call for each step.
- **Limitations of Existing Work**: Prior approaches are constrained by static tool sets and strict sequential execution. This results in high latency, high costs, and frequent errors due to incorrect tool usage, as they fail to explore optimized execution schedules like parallelism or request hedging.

## Core Contributions
- **Proposed Agent Just-In-Time (JIT) Compilation**: A framework that compiles task descriptions directly into executable code, allowing for LLM calls, tool invocations, and parallelization, rather than generating single-step actions.
- **Challenge 1: How to generate efficient and correct execution plans?**
  - **Difficulty**: Directly generating code from natural language can lead to syntax errors or invalid plans that violate tool specifications, within a vast search space.
  - **Solution**: Introduces **JIT-Planner**, which generates multiple code plan candidates, validates them against tool specifications, and selects the minimum-cost candidate based on learned latency distributions, ensuring feasibility and efficiency.
- **Challenge 2: How to optimize latency and concurrency during execution?**
  - **Difficulty**: Web tasks often contain parallelizable sub-tasks, but traditional serial agents cannot explore parallel scheduling or request hedging strategies.
  - **Solution**: Introduces **JIT-Scheduler**, which uses Monte Carlo cost estimation to explore parallelization strategies (serial, parallel, hedging) and dynamically selects the optimal execution schedule to minimize overall latency.

## Implementation and Evaluation
- **Implementation Components**: The system consists of three parts: (1) JIT-Planner (plan generation and validation); (2) JIT-Scheduler (parallel strategy exploration based on latency distributions); (3) An invariant-enforcing tool protocol (specifying pre/post-conditions to reduce errors).
- **Evaluation Results**: Across 5 web application benchmarks:
  - **JIT-Planner** achieved a **10.4x** speedup and **+28%** accuracy improvement over Browser-Use.
  - **JIT-Scheduler** achieved a **2.4x** speedup and **+9%** accuracy improvement over OpenAI CUA.
- **Comparison**: The approach significantly outperforms existing serial CUA methods and static RPA scripts, demonstrating lower latency and higher robustness, especially for tasks requiring multi-step interactions and parallel queries.

## 4. Conclusion
This paper proposes a novel Agent JIT compilation method that breaks the bottleneck of sequential execution in traditional Web Agents. By compiling tasks into parallelizable code and integrating intelligent planning and scheduling mechanisms, the method significantly reduces latency while improving task accuracy. This provides a new technical pathway for building low-latency, high-efficiency automated web agents.
