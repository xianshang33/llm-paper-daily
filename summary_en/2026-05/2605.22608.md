## 1. What the Paper Did
- **Background**: As agentic systems become more capable in defining strategies, executing actions, and interacting with environments, their autonomy poses significant challenges for oversight and evaluation. While observability platforms like LangSmith are widespread, developers still need to manually inspect numerous traces to identify systemic issues.
- **Why Existing Work Falls Short**: Current tools are limited to basic metric aggregation or coarse LLM-as-a-judge assessments on full traces, lacking granular insights. Meanwhile, academic error taxonomies are static and hand-crafted, failing to dynamically adapt to new domains or bespoke tasks, making it difficult to detect subtle failure modes, loops, and error propagation.

## Core Contributions
- **Proposed Agentic CLEAR**: An automatic, dynamic, and easy-to-use evaluation framework that generates textual insights into agent behavior at three levels of granularity: system, trace, and node. It is provided as a pip-installable Python package with seamless integration and an intuitive UI.
- **Challenge 1: Static evaluation cannot adapt to dynamic and varied agent tasks**. The difficulty lies in the rigidity of hand-crafted error taxonomies which cannot cover novel errors in bespoke tasks. Agentic CLEAR addresses this by generating dynamic, data-driven feedback without predefined rules, automatically identifying recurrent failure patterns across new domains.
- **Challenge 2: Lack of fine-grained attribution analysis makes it hard to pinpoint root causes**. The difficulty is that final outputs or overall trace scores do not explain "why" a failure occurred. Agentic CLEAR solves this by performing multi-level LLM judging at both node (step-level) and trace levels, providing structured textual diagnostics to help developers quickly understand logical breaks or error propagation in specific steps.

## Implementation and Evaluation
- **Implementation & Deployment**: Agentic CLEAR is released as a pip-installable Python package operating above the observability layer. It involves two main stages: applying multi-level per-trace evaluation via an LLM Judge, and aggregating insights using CLEAR into system-wide and node-specific patterns, visualized through an interactive UI.
- **Evaluation Results**: Experiments across four benchmarks, seven agentic settings, and tens of thousands of LLM calls demonstrate that Agentic CLEAR produces high-quality, data-driven, and insightful feedback.
- **Comparison & Analysis**: The analysis shows strong alignment between Agentic CLEAR's diagnostic outputs and human-annotated errors, as well as the ability to predict task success rates. Compared to existing tools that offer only basic logging or static classifications, it provides deeper causal analysis and surfaces systemic issues more effectively.

## 4. Conclusion
Agentic CLEAR bridges the gap between current agent observability tools and the need for dynamic evaluation. By automating multi-level textual insight generation, it significantly reduces reliance on human annotation and hand-crafted rules, thereby enhancing developer efficiency in debugging and optimizing complex agent systems, particularly in handling subtle failure modes and cross-step error propagation.
