## 1. What the Paper Did
- **Background**: "Skills" (structured workflow instructions distilled for LLMs) are increasingly crucial for enhancing agent performance in real-world downstream tasks. However, the rapid expansion of the open-source skill ecosystem has created uncertainty regarding how different models and frameworks interact with skills, how to evaluate skill quality, and how users should select skills given cost-performance trade-offs.
- **Why Existing Work Falls Short**: Current evaluations rely heavily on static benchmarks that fail to capture the evolving nature of real-world tasks. There is a lack of systematic evaluation frameworks to assess the actual effectiveness of skill augmentation across different agent frameworks, leading to difficulties in selecting appropriate agents and skills. Additionally, the proliferation of redundant or low-quality skills imposes maintenance overhead and complicates decision-making.

## Core Contributions
- **Proposed OpenSkillEval**: An automatic evaluation framework designed to audit both skill-augmented agent systems and the skills themselves.
- **Challenge 1: Lack of Dynamic and Realistic Task Evaluation**. Static benchmarks cannot adequately reflect the complexity and evolution of real-world tasks. OpenSkillEval addresses this by automatically constructing over 600 dynamic task instances from evolving real-world artifacts across five categories (presentation generation, front-end web design, poster generation, data visualization, and report generation), ensuring task-grounded and realistic evaluation.
- **Challenge 2: Unclear Interaction Mechanisms and Selection Difficulty**. It is unclear how different models and frameworks effectively utilize skills, making it hard to balance performance and cost. The framework collects and organizes 30 open-source community-contributed skills for controlled comparison under unified settings, systematically analyzing the interplay between skill availability, model capability, and framework execution efficiency to provide empirical guidance for skill selection and deployment.

## Implementation and Evaluation
- **Implementation & Deployment**: OpenSkillEval automates the generation of task instances from real-world artifacts and integrates a repository of community skills. Additional cases and benchmark resources are available at https://yingjiahao14.github.io/OpenSkillEval-Web/.
- **Evaluation Results**:
    1. **Skill Availability ≠ Effective Usage**: Merely having access to skills does not guarantee their effective utilization by agents.
    2. **Strong Dependency**: The benefits of skill augmentation are heavily dependent on both the underlying LLM and the specific agent framework used.
    3. **Popular Skills Not Always Superior**: Many publicly popular skills do not consistently outperform base agents without skills, sometimes adding cost without significant performance gains.
- **Comparison**: Unlike traditional methods relying on static datasets, OpenSkillEval offers a dynamic, task-driven evaluation perspective, uncovering nuances and inefficiencies in skill-framework interactions that static benchmarks miss.

## 4. Conclusion
This paper addresses the challenges in the rapidly expanding LLM agent skill ecosystem by introducing OpenSkillEval, an automated auditing framework. By constructing dynamic, realistic task instances and standardizing the comparison of community skills, the study reveals that the efficacy of skill augmentation is highly contingent on the model-framework combination, with many popular skills failing to deliver expected improvements. This work underscores the necessity for dynamic, task-grounded evaluation and provides practical insights for the design, selection, and deployment of skills for LLM agents.
