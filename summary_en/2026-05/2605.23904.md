## 1. What the Paper Did
- **Background**: As frontier language models are increasingly deployed as agents, domain adaptation requires improving procedural behaviors (evidence gathering, tool usage, etc.) rather than just model weights or prompts. Agent skills serve as portable natural-language artifacts for this adaptation.
- **Why Existing Work Falls Short**: Current methods rely on hand-crafting, one-shot generation, or loosely controlled self-revision. These lack the discipline of deep-learning optimizers, failing to reliably improve over starting points and often resulting in unstable semantic jumps or suboptimal performance.

## Core Contributions
- **Proposed SkillOpt**: The first systematic, controllable text-space optimizer for agent skills. It treats skill editing as training the external state of a frozen agent, using a separate optimizer model to convert scored rollouts into bounded edits (add/delete/replace), accepted only if they strictly improve held-out validation scores.
- **Challenge 1: Instability and Uncontrollability in Text-Space Optimization**. The difficulty lies in the lack of clear convergence directions in natural language editing, leading to semantic drift. SkillOpt addresses this via a "textual learning-rate budget" (limiting edit magnitude), a "rejected-edit buffer" (using failures as negative feedback), and epoch-wise slow/meta updates to ensure stable training.
- **Challenge 2: Balancing Optimization Quality with Inference Efficiency**. The challenge is improving skills without adding inference-time overhead. SkillOpt performs all optimization offline; the deployed agent uses only the final optimized skill document, incurring zero additional model calls at inference time.

## Implementation and Evaluation
- **Setup**: Evaluated across 6 benchmarks, 7 target models, and 3 execution harnesses (Direct Chat, Codex, Claude Code).
- **Results**: SkillOpt achieved best or tied-best performance in all 52 evaluated cells, outperforming human-written skills, one-shot LLM skills, and existing methods like Trace2Skill, TextGrad, GEPA, and EvoSkill.
- **Performance Gains**: On GPT-5.5, it improved average no-skill accuracy by +23.5 points in direct chat, +24.8 in Codex, and +19.1 in Claude Code.
- **Generalization**: Transfer experiments showed that optimized skills retain value across model scales, between different execution environments (e.g., Codex to Claude Code), and on nearby math benchmarks without further optimization.

## 4. Conclusion
SkillOpt introduces deep-learning-style optimization discipline to text-space agent skill training. By combining bounded edits, strict validation, and stabilization mechanisms, it solves the reliability issues of traditional skill evolution. The method significantly outperforms state-of-the-art baselines and demonstrates strong cross-model and cross-environment generalization, offering an efficient and reproducible paradigm for adapting frozen models.
