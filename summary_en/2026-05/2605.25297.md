## 1. What the Paper Did
- **Background**: Predictive model performance relies heavily on feature quality. However, creating effective features requires deep domain expertise, limiting scalability across applications. This is particularly challenging in scenarios like Alibaba Cloud's GPU resource demand prediction, where workloads are bursty and irregular.
- **Why Existing Work Fails**:
    1. **Manual Feature Engineering**: Relies on expert intuition, resulting in poor generalization across different applications.
    2. **Automated Feature Engineering (AutoFE)**: Scales feature generation but lacks semantic understanding, failing to capture bursty demand patterns.
    3. **LLM-based Feature Engineering**: Typically operates as static generators without feedback loops for post-deployment iteration, making them unable to adapt to irregular changes in AI workloads.

## Core Contributions
- **Proposed Eureka**, an LLM-driven framework for intelligent feature engineering that treats features as executable programs rather than static data transformations.
- **Challenge 1: How to translate domain knowledge into structured, executable feature designs?**
    - **Difficulty**: Direct code generation by LLMs often overlooks deep domain logic, leading to invalid or inefficient features.
    - **Solution**: Introduced the "Eureka Expert" agent, fine-tuned via SFT with domain knowledge to produce structured JSON feature design plans. This encodes heuristic constraints and templates to guide the exploration of meaningful feature interactions.
- **Challenge 2: How to ensure generated feature code is both semantically aligned and high-utility, while enabling continuous evolution?**
    - **Difficulty**: Code correctness alone does not guarantee predictive utility, and static generation cannot adapt to shifting data distributions.
    - **Solution**: Developed a "Self-Evolving Alignment Engine" using Reinforcement Learning (GRPO) with dual-channel rewards (metric-based utility + semantic alignment). This converts feature hypotheses into runnable Python programs and iteratively optimizes code quality, enabling pattern transfer across domains.

## Implementation and Evaluation
- **Implementation & Deployment**: Eureka consists of three stages: (1) Expert Agent generates design plans; (2) LLM Feature Factory translates plans into executable Python code via Chain-of-Thought; (3) Self-Evolving Alignment Engine optimizes via RL. The system is fully integrated into Alibaba Cloud's production services.
- **Evaluation Results**:
    - **Public Benchmarks**: Evaluated on 7 public benchmarks in healthcare, finance, and social domains, Eureka consistently outperformed both traditional AutoFE and LLM-based baselines.
    - **Industrial Impact**: In Alibaba Cloud's GPU resource demand prediction, Eureka improved the demand fulfillment rate by 16% and reduced computing resource migration rates by 33%.
- **Comparison**: Unlike traditional AutoFE (lacking semantics) and existing LLM methods (lacking feedback), Eureka leverages executable code and an RL feedback loop to significantly enhance generalization and capture bursty patterns.

## 4. Conclusion
Eureka innovatively reframes feature engineering as an agentic code generation problem. By combining domain-knowledge fine-tuning, Chain-of-Thought code generation, and Reinforcement Learning alignment, it addresses the limitations of semantic understanding and dynamic adaptation in traditional methods. Experiments demonstrate its superior performance on public datasets and significant efficiency gains in large-scale production environments at Alibaba Cloud, highlighting the potential of LLMs in optimizing enterprise AI infrastructure.
