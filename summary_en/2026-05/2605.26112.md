## 1. What the Paper Does
- **Background**: The dominant narrative in AI progress has been model scaling (larger models, more data). However, in Agentic AI, once foundation models are embedded into tools, terminals, browsers, and memory stores, their behavior is determined by the entire system, not just the model.
- **Why Existing Work Falls Short**: Current evaluations remain largely model-centric, reducing agents to final-task success rates while treating memory, retrieval, tool use, orchestration, verification, and governance as secondary implementation details. This framing is inadequate because agent performance emerges from the complex interactions among the foundation model, memory substrate, context constructor, skill-routing layer, orchestration loop, and verification/governance layers.

## Core Contributions
- **Proposed a "System Scaling" Framework for Agent Harnesses**: The paper introduces the concept of "scaling the harness," treating the structured execution layer around a foundation model as a first-class object for design, evaluation, and optimization, shifting focus from mere model scaling to system scaling.
- **Challenge 1: Context Governance**: As agents execute long-horizon tasks, context windows become cluttered and inefficient, scattering model attention. **Solution**: The paper proposes treating context construction as a distinct governance layer, optimizing context efficiency and communication fidelity to ensure the model receives filtered, structured, high-quality inputs rather than raw data dumps.
- **Challenge 2: Trustworthy Memory and Dynamic Skill Routing**: Agents must maintain consistent memory states over long periods and dynamically select the correct tools or sub-agents, posing challenges in state consistency and routing accuracy. **Solution**: The authors design an auditable, persistent, and modular memory subsystem combined with verification mechanisms to constrain skill routing, ensuring memory hygiene and action verifiability to enhance long-term behavioral reliability.

## Implementation and Evaluation
- **Implementation**: The authors developed and open-sourced **CheetahClaws**, a Python-native reference harness designed to make harness-level design choices explicit.
- **Comparison**: CheetahClaws is compared against **Claude Code** and **OpenClaw**, analyzing differences in harness design across these systems.
- **Evaluation Perspective**: Rather than focusing solely on traditional one-shot task success, the paper outlines a harness-level benchmarking agenda that includes trajectory quality, memory hygiene, context efficiency, communication fidelity, verification costs, and safe evolution over time. Comparative analysis demonstrates that system architecture design significantly impacts overall agent performance, proving that system design is as critical as foundation model capabilities.

## 4. Conclusion
This paper argues that future progress in Agentic AI depends as much on system design as on stronger foundation models. By introducing the concept of "scaling the harness," it identifies three core bottlenecks: context governance, trustworthy memory, and dynamic skill routing. It provides CheetahClaws as a reference implementation and calls for a community shift from model-centric evaluation to system-level evaluation, focusing on process metrics and safe evolution in long-term agent operations.
