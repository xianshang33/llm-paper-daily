## 1. What the Paper Did
- **Background**: Large language model (LLM) agents rely on reusable skills to solve complex, real-world problems. As tasks grow in scope, raw model reasoning is insufficient; skills encapsulating procedures, code, or instructions are needed as natural abstractions for scalable agent systems.
- **Why Existing Work Falls Short**: Current skill creation approaches (e.g., AutoSkill, Voyager) treat skills as isolated and static artifacts, lacking unified lifecycle management. This results in four gaps: (i) creation-usage mismatch due to lack of runtime context during generation; (ii) absence of structured per-skill memory for accumulating experience; (iii) static, unvalidated skills without unit-test-driven evaluation; and (iv) poor context handling in flat conversation histories.

## Core Contributions
- **Proposed MUSE-Autoskill Agent**: A skill-centric framework that enables continuous improvement of task-solving capabilities through a unified lifecycle: creation, memory, management, evaluation, and refinement.
- **Challenge 1: Reliability and Continuous Improvement of Skills**. Existing static skills lack guarantees of correctness across scenarios and cannot self-evolve. **Solution**: Introduces evaluation and refinement via unit tests and runtime feedback, treating skills as testable assets that automatically correct errors through feedback loops.
- **Challenge 2: Efficiency and Adaptability of Skill Reuse**. Traditional methods lack tracking of individual skill performance history, hindering optimal selection and adaptation. **Solution**: Introduces skill-level memory that accumulates free-form experience for each skill across tasks, enabling more effective reuse and adaptive adjustment over time.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on SkillsBench, covering 51 tasks across four domains: Science & Engineering, Data Analysis, Document Processing, and Ops & Planning.
- **Baselines**: Compared against Hermes and Codex agents, testing configurations with no skills, human-authored skills, and MUSE-Autoskill generated skills.
- **Results**:
    - MUSE-Autoskill achieved the highest overall accuracy of 68.4%, outperforming Codex (67.3%) and Hermes (61.2%).
    - It led in 3 out of 4 sub-domains and the total score.
    - The framework provided a +15.2 percentage point lift compared to no-skill baselines, demonstrating improvements in task success, efficiency, reuse, and cross-agent transfer.

## 4. Conclusion
MUSE-Autoskill addresses the limitations of isolated and static skills by treating them as long-lived, experience-aware, and testable assets. Its core innovations in unified lifecycle management and skill-level memory significantly enhance the performance and robustness of LLM agents in complex tasks.
