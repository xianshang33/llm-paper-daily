## 1. What the Paper Did
- **Background**: In the era of autonomous agents, machine-actionable data is critical for data-driven workflows. For over a decade, semantic metadata like schema.org has anchored the FAIR principles (Findable, Accessible, Interoperable, Reusable) and enabled tools like Google Dataset Search.
- **Why Existing Work Falls Short**: The rise of LLMs capable of navigating the unstructured web has raised questions about the necessity of semantic metadata. Existing general web search or pure LLM retrieval methods often fail to distinguish narrative prose from machine-readable data, leading to "Last-Mile Utility" failures where agents retrieve landing pages or text instead of actionable datasets, lacking reliability for execution-oriented tasks.

## Core Contributions
- **Proposed a** comparative study framework for agentic data retrieval, contrasting a "Baseline Agent" searching billions of open-web documents against a "Semantic Agent" leveraging a corpus of 90 million datasets with schema.org metadata.
- **Challenge 1: How to evaluate the practical utility of data retrieved by agents?**
  - **Difficulty**: Traditional metrics struggle to measure if data is truly machine-executable and usable (addressing FAIR's accessibility and reusability).
  - **Solution**: Deployed an "LLM-as-a-judge" evaluation pipeline mapped directly to FAIR principles, assessing semantic relevance, data accessibility, and computational utility.
- **Challenge 2: Can unstructured retrieval replace structured metadata for reliable data discovery?**
  - **Difficulty**: The open web contains numerous portal homepages and text-heavy pages, causing agents to miss actual machine-readable download links.
  - **Solution**: Demonstrated through comparative experiments that the Semantic Agent significantly reduces these errors via structured metadata, while the Baseline Agent suffers from low precision despite high coverage, defining clear boundaries for their respective use cases.

## Implementation and Evaluation
- **Implementation**: Two agent environments were constructed. The Baseline Agent searched billions of open-web documents, while the Semantic Agent operated on a curated corpus of 90 million datasets marked with schema.org.
- **Evaluation Results**:
  - **Semantic Agent Superiority**: Excelled in retrieving actionable data. It achieved 44.9% higher precision for metadata-rich registries and 46.6% higher precision for pages with machine-readable downloads. Overall, it delivered 65.7% higher precision in retrieving FAIR-compliant datasets.
  - **Baseline Agent Limitations**: Frequently suffered "Last-Mile Utility" failures, with 20.1% of results being prose-heavy pages and 8.5% being portal landing pages rather than actual data.
  - **Coverage Comparison**: The Baseline Agent achieved higher coverage by answering 40% more questions, making it suitable for broad exploratory tasks.
- **Comparison Conclusion**: While unstructured retrieval supports exploratory tasks, structured ecosystems remain the indispensable foundation for reliable, execution-oriented autonomous workflows.

#### Summary
This paper empirically answers whether agents need semantic metadata. The results indicate that while LLMs enhance information retrieval from the unstructured web, structured semantic metadata (like schema.org) remains irreplaceable for high-precision, machine-actionable data retrieval. Semantic metadata significantly improves the accuracy and efficiency of obtaining FAIR-compliant data, preventing noise from invalid information, and serves as the cornerstone for building reliable autonomous data workflows.
