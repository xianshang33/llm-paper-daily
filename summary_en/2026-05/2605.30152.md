## 1. What the Paper Did
- **Background**: With the rise of Large Language Model (LLM) agents, there is a growing expectation for proactive assistants that offer help without waiting for explicit instructions. This requires continuous monitoring of user activity to make two critical decisions: when to intervene (triggering) and what context to ground the intervention on (anchoring).
- **Why Existing Work Falls Short**: Current proactive agents typically render user activity into text and invoke an LLM for every event to decide on action. This approach has two major flaws:
    1. **Inefficiency and High Cost**: User activity is natively a structured event stream (actor, verb, object, timestamp) maintained by the OS. Converting this to text and asking an LLM to reconstruct it is an unnecessary "round-trip." The high latency and computational cost of LLMs make them unsuitable as real-time, always-on triggers.
    2. **Ungrounded Suggestions**: Because triggering and context selection are often decoupled or rely on generic session topics, suggestions frequently fail to reference the specific artifacts (e.g., specific files or webpages) the user is interacting with, leading to imprecise assistance.

## Core Contributions
- **Proposed a Lightweight Triggering and Routing Architecture based on Temporal Graph Learning (TGL)**: This architecture treats user activity as graph updates directly, using a small TGL model as the encoder. The LLM is only invoked downstream when necessary to generate natural language responses.
- **Challenge 1: The Conflict Between Real-Time Performance and Computational Cost**. The difficulty lies in processing high-frequency user events with millisecond-level latency and low resource usage, whereas LLM forward passes are too slow and expensive. The paper addresses this by replacing the LLM trigger with a small TGL model. A single forward pass yields the trigger probability, achieving speeds 4-83x faster than LLM-based schemes with a memory footprint of only ~220 MiB, enabling on-device deployment.
- **Challenge 2: Accuracy of Context Selection and Lack of Structure**. The challenge is to precisely identify entities relevant to the current intent from complex activity streams to avoid vague suggestions. The paper introduces a routing head in the TGL model that scores entity nodes, directly selecting highly relevant structured context (e.g., specific file IDs). This solves the problem of ungrounded suggestions common in traditional methods.

## Implementation and Evaluation
- **Implementation & Deployment**: The system uses a "graph-first" architecture. Input structured event streams form a session graph. The TGL model has two heads: a Trigger head (wake/suppress) and a Routing head (select entities). The downstream LLM Agent is only called if the trigger probability is high, receiving the selected structured context to generate a response. The model supports BF16 precision, with a ~220 MiB resident memory footprint, runnable on consumer laptops and GPU servers.
- **Evaluation Results**:
    - **Accuracy**: The TGL method improved F1 scores by an average of 16.7% (up to 46.0%) across 14 different backbone settings. In trigger architecture comparisons, this TGL checkpoint achieved the strongest trigger AUCs and the most stable deployment thresholds.
    - **Efficiency**: Processing time per event was 11.13 ms on a GPU server and 13.99 ms on a consumer laptop.
- **Comparison**: Compared to all tested "LLM-as-trigger" configurations, this method is 4-7x faster on GPUs and 12-83x faster on laptops. Traditional methods incur full LLM costs for every event regardless of output, whereas this method only invokes the LLM when necessary.

#### Summary
This paper challenges the necessity of invoking an LLM for every decision in proactive agents, identifying it as an inefficient architectural choice. By introducing Temporal Graph Learning (TGL) models to handle structured user activity streams, the authors propose an efficient, lightweight triggering and routing mechanism. This approach significantly reduces latency and computational costs, enabling deployment on privacy-sensitive edge devices, while also improving suggestion accuracy and grounding through structured entity routing. Experiments demonstrate that the proposed scheme outperforms existing LLM-based trigger architectures in both speed and accuracy, offering a new paradigm for building real-time, efficient proactive assistants.
