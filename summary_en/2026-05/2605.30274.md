## 1. What the Paper Did
- **Background**: While Large Language Models (LLMs) excel in sentence and short-segment translation, they face significant challenges in long-document translation (e.g., transcripts, manuals, literature). Key issues include limited context windows hindering global cohesion and redundant contextual information degrading translation quality.
- **Why Existing Work Falls Short**: Current approaches either rely on extended context windows for direct full-document translation or employ complex chain-of-thought reasoning. However, many agent-based methods treat contextual signals indiscriminately, incorporating extraneous noise that leads to suboptimal performance. Traditional chunking methods suffer from continuous performance degradation or failure in ultra-long documents due to loss of long-term consistency.

## Core Contributions
- **Proposed Loong**, a human-like long document translation agent with "Observe-and-Act" adaptive context selection.
- **Challenge 1: How to effectively manage long-term dependencies within limited context windows while avoiding information redundancy?**
  - **Difficulty**: Inputting all historical context exceeds window limits or introduces noise, while sliding windows lose global consistency.
  - **Solution**: Loong introduces a **3E Memory Module** (Essence-Exemplar-Entity) to store summaries, sentence pairs, and entity records. Instead of passively attending to all history, it performs deep reasoning to adaptively identify the optimal context for translation guidance.
- **Challenge 2: How to optimize the context selection policy to mimic human judgment?**
  - **Difficulty**: Static rules or simple retrieval mechanisms lack the dynamic adaptability required for diverse document structures and translation needs.
  - **Solution**: Loong optimizes its context policy via **Reinforcement Learning**. It generates preference data from its own sampled "observe-and-act" reasoning trajectories, enabling the model to learn to filter key information like a human.

## Implementation and Evaluation
- **Setup**: Evaluated across English ↔ Chinese, German, and French translation directions.
- **Baselines**: Compared against standard chunking methods (Sentence, Segment), full-history variants (Doc2Doc), and unfiltered memory agents (DELTA).
- **Results**:
  - Loong achieved average gains of up to **13.0 points** across three evaluation metrics.
  - In ultra-long document translation (e.g., Chinese ⇒ Portuguese), while baselines exhibited continuous degradation or failure due to context limits, Loong successfully distinguished useful information from retrieved memory, sustaining stable, high-quality translations.
  - Demonstrated strong generalization across domains and robustness against contextual noise.

## 4. Conclusion
Loong addresses the conflict between context window limitations and information redundancy in long-document translation by simulating human "observe-and-act" mechanisms. Its core innovations lie in the 3E memory module and the RL-based adaptive context selection strategy. Experiments confirm that Loong significantly outperforms state-of-the-art methods in translation quality and exhibits superior stability and robustness in ultra-long document processing.
