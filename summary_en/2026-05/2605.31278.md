## 1. What the Paper Did
- **Background**: Reliable evaluation of agentic systems requires unbiased estimates with valid uncertainty quantification. Current practices oscillate between two extremes: costly and slow human annotation (reliable but unscalable) and fast but biased "LLM-as-judge" proxy metrics (cheap but biased).
- **Why Existing Work Falls Short**: Prediction-Powered Inference (PPI) combines both approaches to generate unbiased estimates with valid confidence intervals using small sets of human labels and large sets of cheap proxy predictions. However, existing PPI methods are scattered across various papers with heterogeneous notation and partial implementations. Foundational libraries like `ppi_py` predate many recent advancements and prioritize generality over depth in mean estimation, leaving practitioners to stitch together methods from disparate academic repositories.

## Core Contributions
- **Proposed GLIDE (Generated Label Inference and Debiasing Engine)**: An open-source Python library that unifies state-of-the-art PPI estimators and samplers under a scipy-style API specialized for mean estimation.
- **Challenge 1: Fragmentation and Engineering Difficulty**. PPI variants (e.g., PPI++, Stratified PPI, Active Statistical Inference) are dispersed across literature without a unified interface, making integration difficult. **Solution**: GLIDE integrates these estimators and samplers (uniform, stratified, active, cost-optimal) into a single library with a standardized API, significantly lowering the barrier to entry.
- **Challenge 2: Method Selection and Efficiency in Complex Scenarios**. Agentic evaluation involves data heterogeneity and extreme cost asymmetry, where no single method is optimal for all cases. **Solution**: GLIDE provides an empirically grounded decision tree for method selection, supports stratified estimation to handle heterogeneity, and incorporates active sampling and cost-optimal budget allocation to substantially reduce annotation costs while maintaining precision.

## Implementation and Evaluation
- **Implementation**: GLIDE is an open-source Python library featuring a reproducible Monte Carlo validation suite to ensure statistical validity. It uses a modular design allowing easy switching between estimators and sampling strategies.
- **Evaluation Results**: A case study on agentic evaluation demonstrates that GLIDE achieves substantial annotation savings at equivalent precision levels compared to traditional full human annotation or simple LLM-as-judge approaches.
- **Comparison**: Unlike the foundational `ppi_py` library, GLIDE covers more recent methods (such as stratified and active learning variants), is optimized specifically for mean estimation, and provides a decision tree to guide users, addressing gaps in depth and usability found in existing tools.

## 4. Conclusion
This paper introduces GLIDE to industrialize Prediction-Powered Inference (PPI) for evaluating Generative AI and agentic systems. By unifying scattered SOTA methods, providing an user-friendly API, and offering empirically driven guidance, GLIDE enables practitioners to significantly reduce reliance on expensive human annotations while ensuring statistical rigor (valid confidence intervals), providing practical infrastructure for large-scale agentic evaluation.
