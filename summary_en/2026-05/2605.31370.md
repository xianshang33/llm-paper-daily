## 1. What the Paper Does
- **Background**: Abductive reasoning over knowledge graphs (KGs) aims to generate logical hypotheses explaining observed entities. Existing controllable methods allow user guidance via explicit conditions but are limited in interactive settings.
- **Limitations of Previous Work**: Current methods struggle to ground evolving natural language intents into executable KG conditions across multi-turn dialogues and lack fine-grained diagnostic capabilities when generated hypotheses fail.

## Core Contributions
- **Proposed HypoAgent**: An agentic framework for interactive abductive hypothesis generation over KGs, integrating three specialized agents: Intent Recognition, Hypothesis Generation, and Root Cause Analysis.
- **Challenge 1: Grounding dynamic intents in multi-turn interactions**. The difficulty lies in mapping ambiguous, evolving user intents to static KG conditions. HypoAgent addresses this via an Intent Recognition Agent that grounds user utterances and dialogue history into executable KG conditions dynamically.
- **Challenge 2: Lack of fine-grained diagnosis for failed hypotheses**. Traditional methods cannot pinpoint unreliable fragments. HypoAgent employs a Root Cause Analysis Agent to diagnose unreliable hypothesis parts and leverages KG neighborhood probing to identify supported refinements.

## Implementation and Evaluation
- **Implementation & Deployment**: The framework orchestrates three agents for intent grounding, hypothesis generation, and error diagnosis. Code is publicly available.
- **Evaluation Results**: Experiments on commonsense and biomedical KGs demonstrate that HypoAgent achieves state-of-the-art semantic similarity in single-turn, multi-turn, and unconditional settings.
- **Comparison**: Outperforms existing abductive reasoning methods (e.g., Bai et al., 2024; Gao et al., 2025) by effectively handling interactive intent shifts and providing robust hypothesis refinement mechanisms.

## 4. Conclusion
HypoAgent effectively addresses the challenges of intent grounding and error diagnosis in interactive KG-based abductive reasoning through a multi-agent architecture. It significantly improves hypothesis accuracy and interpretability, achieving SOTA performance across various benchmarks, thereby offering a robust tool for scientific discovery and clinical diagnosis.
