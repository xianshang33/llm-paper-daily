## 1. What the paper does
- **Background**: Deploying lightweight Large Language Model (LLM) agents on edge servers reduces latency and brings services closer to users, but resource-constrained edge models struggle with long-horizon tasks requiring persistent memory, subgoal tracking, and reflection.
- **Why existing work fails**: Traditional memory paradigms cause context explosion; existing hierarchical memory architectures have high computational and storage overheads, making them unsuitable for resource-constrained environments. Furthermore, frequent fine-tuning across heterogeneous edge nodes is costly and hard to scale, while purely local memory leads to isolated experiences and lacks cross-agent knowledge sharing.

## Core Contributions
- **Proposed CoMIC Framework**: A parameter-update-free cloud-edge framework for Collaborative Memory and Insights Circulation, following a "Centralized Reflection, Decentralized Execution" design paradigm.
- **Challenge 1: Conflict between limited edge resources and long-horizon task complexity**. The difficulty lies in the limited compute power of edge models, which cannot maintain large contexts or perform complex logical reflection. CoMIC addresses this by offloading computationally intensive cross-trial long-term memory maintenance and complex reflection to the cloud, while edge nodes maintain only lightweight, selectively expandable memories for immediate decision-making.
- **Challenge 2: Inefficient learning and poor generalization due to isolated experiences**. The difficulty is that individual edge agents cannot leverage successes from other agents, and local memory grows inefficiently over time. CoMIC solves this by using a cloud-side LLM critic to asynchronously evaluate completed trajectories, filter reusable experiences, and aggregate cross-agent guidance keyed by semantic subgoal identifiers, enabling efficient knowledge circulation.

## Implementation and Evaluation
- **Implementation & Deployment**: CoMIC uses a cloud-edge architecture. Edge agents execute locally using subgoal-oriented hierarchical memory. The cloud LLM acts as a critic, asynchronously processing trajectories, extracting insights, and updating a global memory bank without updating edge model parameters.
- **Evaluation Results**: Evaluated on five long-horizon agent tasks spanning symbolic planning and text interaction. Results show that CoMIC improves the progress rate and action grounding for weak edge agents and yields task-dependent success-rate gains.
- **Comparison**: Compared to methods requiring frequent fine-tuning or relying on pure local memory, CoMIC effectively overcomes resource constraints and experience isolation without parameter updates, demonstrating better scalability and task completion capabilities.

## 4. Conclusion
CoMIC proposes an innovative cloud-edge collaborative mechanism that successfully addresses memory management and knowledge sharing challenges for long-horizon LLM agents on resource-constrained edge devices through a "Centralized Reflection, Decentralized Execution" strategy. This method significantly enhances agent performance without parameter updates, offering new insights for efficient edge AI deployment.
