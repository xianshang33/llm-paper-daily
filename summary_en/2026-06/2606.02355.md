## 1. What the Paper Did
- **Background**: Long-horizon LLM agents can benefit from reusable skills, but existing skill-based methods often rely on external skill generators during training or persistent skill retrieval at inference. This increases engineering complexity, context length, and deployment latency.
- **Why Existing Work Falls Short**: Current methods delegate trajectory-to-skill conversion to external modules (e.g., trajectory distillers or hierarchical skill managers), creating a disconnect between training and inference. Inference requires maintaining and retrieving from large skill banks, leading to high latency and excessive context usage, making efficient deployment difficult.

## Core Contributions
- **Proposed SIRI Framework**: A three-phase framework (Self-Internalizing Reinforcement learning with Intrinsic skills) that enables agents to discover, validate, and internalize skills without external skill generators or inference-time skill banks.
- **Challenge 1: How to extract effective skills from self-experience without external teacher models?**
  - **Difficulty**: Raw trajectories from the agent itself often contain noise, leading to invalid or redundant skill descriptions if summarized directly.
  - **Solution**: SIRI employs a "self-skill mining" strategy where the current policy summarizes compact skills from its own successful plain rollouts and validates them through paired comparisons of "skill-augmented" vs. "skill-free" rollouts, ensuring the extracted skills genuinely improve performance.
- **Challenge 2: How to efficiently integrate validated skills into the policy without increasing inference burden?**
  - **Difficulty**: Traditional methods still require skill bank retrieval at inference, causing latency; simple fine-tuning might introduce harmful skill guidance.
  - **Solution**: SIRI uses trajectory-level utility and action-level advantage as filtering mechanisms to distill only beneficial skill-guided action tokens into the plain policy. The final agent runs with only the original prompt at inference, achieving complete skill internalization.

## Implementation and Evaluation
- **Implementation & Deployment**: Implemented on Qwen2.5-7B-Instruct. The inference phase requires no additional skill bank retrieval or external modules, using only the original prompt, which significantly reduces engineering complexity and latency.
- **Evaluation Results**:
  - On **ALFWorld**, SIRI improved performance over GiGPO from 0.908 to **0.930**.
  - On **WebShop**, SIRI improved performance over GiGPO from 0.728 to **0.813**.
- **Comparison with Related Work**: SIRI outperforms prompt-based, RL-based, and memory-augmented baselines. Further analysis shows that its self-mining strategy achieves performance comparable to distillation with closed-source large models, but without relying on external LLMs.

## 4. Conclusion
SIRI proposes an innovative self-internalizing reinforcement learning framework that resolves the conflict between skill reuse and deployment efficiency in LLM agents. Through self-mining, validation, and distillation, SIRI successfully transforms external explicit skills into implicit internal capabilities. It significantly improves performance on ALFWorld and WebShop tasks while maintaining simplicity and efficiency during inference, offering a new paradigm for deploying lightweight, high-performance LLM agents.
