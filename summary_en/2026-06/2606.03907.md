## 1. What the Paper Does
- **Background**: Agentic AI coding tools increasingly autonomously decide whether to import external libraries ("buy") or implement functionality from scratch ("build"). These decisions have direct implications for software security, licensing compliance, performance, and maintainability.
- **Why Existing Work Falls Short**: There is a lack of controlled experimental studies examining what governs these build-vs-buy decisions in agentic AI tools. While configuration mechanisms are primary means for developers to influence tool behavior, it remains unclear which configurations are most effective in shaping these decisions.

## Core Contributions
- **Proposed**: A pre-registered study protocol to investigate how configuration mechanisms alter build-vs-buy behavior in two popular agentic AI coding tools: Claude Code and OpenAI Codex.
- **Challenge 1: Uncertainty of Configuration Impact**. The difficulty lies in the high autonomy of AI agents and the diversity of configuration methods (e.g., context files, Skills, MCP tools), making it hard to quantify their specific effects on dependency choices. The paper addresses this by designing staged project benchmarks with identifiable decision points and manipulating configurations to isolate and measure their impact.
- **Challenge 2: Lack of Reproducible Benchmarks for Longitudinal Study**. Existing studies often lack reproducibility and cannot track changes across rapidly evolving model versions. The paper designs a reproducible experimental pipeline with nine pre-registered hypotheses and releases a benchmark dataset and analysis artifact to support longitudinal evaluation of future tools.

## Implementation and Evaluation
- **Implementation & Deployment**: As a Registered Report, the paper details the experimental design rather than final results. It targets Claude Code and OpenAI Codex. The experiment uses a benchmark of staged projects with clear build-vs-buy trade-offs. Configurations manipulated include no configuration, context files with soft/hard constraints, autonomously discoverable Skills, MCP-enabled library discovery, and permission controls.
- **Evaluation Metrics**: The study measures which libraries are selected, whether new dependencies are disclosed, and the completeness and accuracy of such disclosures.
- **Comparison with Related Work**: Unlike prior work focusing mainly on code quality or security vulnerabilities, this study specifically targets the dependency management decision process. It addresses the gap in controlled experiments and reproducibility by providing a standardized protocol and reusable artifacts.

## 4. Conclusion
This paper presents a rigorous pre-registered protocol to address the gap in understanding build-vs-buy decisions in agentic AI coding tools. By systematically manipulating configurations and testing against Claude Code and OpenAI Codex on a controlled benchmark, it aims to provide empirical evidence for managing risks associated with AI-autonomous dependency introduction. The resulting dataset and pipeline will serve as a critical resource for the community to evaluate future AI coding tools.
