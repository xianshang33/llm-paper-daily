## 1. What the Paper Did
- **Background**: With the rise of Large Language Models (LLMs) and multi-agent systems, automating Root Cause Analysis (RCA) using observability data is critical for network system reliability. However, Site Reliability Engineering (SRE) capabilities have lagged behind the rapid pace of system construction, making RCA a significant bottleneck.
- **Why Existing Work Fails**: Current observability frameworks are archaic, suffering from fragmented data silos, incompatible schemas, and insufficient semantic metadata, which prevent agents from establishing necessary complex relationships. Traditional supervised learning methods rely on "memorizing" historical data, leading to sharp performance degradation in zero-shot scenarios (which constitute over 40% of real-world faults), while multimodal fusion techniques have only yielded marginal improvements.

## Core Contributions
- **Proposed UModel**: A unified ontological framework that shifts observability modeling from "data-centric" to "object-centric".
- **Challenge 1: Fragmented Heterogeneous Data and Lack of Semantics**. Telemetry, entities, and expert knowledge are scattered and inconsistent, making it hard for agents to understand correlations. UModel constructs a virtual ontological layer that standardizes these heterogeneous inputs into "objects" interconnected via semantic graphs, providing a unified structured view for agents.
- **Challenge 2: Difficulty in Agent Autonomous Exploration and Multimodal Correlation**. Traditional interfaces do not support autonomous topology traversal by agents. UModel introduces U-SPL, a pipeline-based query interface that enables agents to autonomously explore system topologies and correlate multimodal data, facilitating more accurate reasoning.

## Implementation and Evaluation
- **Implementation & Deployment**: UModel has been deployed at Alibaba Cloud for over a year, serving tens of thousands of users, sustaining millions of operations per second, and delivering sub-second query latency, demonstrating its scalability.
- **Evaluation Results**: Re-modeling the "AIOps 2025 Challenge" dataset with UModel improved root cause localization precision by 8%, showing that enhanced data organization significantly boosts downstream task accuracy.
- **Comparison**: Unlike traditional RCA methods reliant on supervised learning and historical memory, UModel's object-centric modeling and semantic graphs better support LLM agents' zero-shot reasoning capabilities, addressing the performance decay of traditional methods in unseen fault scenarios.

## 4. Conclusion
UModel addresses the incompatibility of existing observability data models with LLM agents by introducing a unified ontological framework and object-centric modeling. By standardizing heterogeneous data and providing a query interface (U-SPL) that supports autonomous exploration, it significantly improves RCA precision and system scalability, laying a solid infrastructure foundation for next-generation AIOps.
