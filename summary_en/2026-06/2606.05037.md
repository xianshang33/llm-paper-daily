## 1. What the Paper Did
- **Background**: As Large Language Models (LLMs) act as autonomous agents calling APIs, they fail differently than humans. While developers can infer missing context to fix requests, agents often burn tokens guessing until they give up when facing validation errors.
- **Why Existing Work Fails**: Current API error reporting (e.g., RFC 7807) provides generic codes and short prose intended for humans. These unstructured natural language diagnoses do not provide actionable, structured guidance for agents. This is particularly problematic when constraints involve proprietary business logic, specific certifications, or real-time state—knowledge absent from the LLM's training data, making it impossible for the LLM to infer the correct fix from general priors.

## Core Contributions
- **Proposed a "Self-Reflective API"**: Upon validation failure, the API returns a machine-readable `recovery_feedback.suggestions[]` payload containing sufficient structured suggestions for the agent to repair the request and retry without external reasoning.
- **Challenge 1: Lack of Proprietary Domain Knowledge**. When validation rules depend on company-specific cultural norms, certification standards, or complex technical constraints, general LLMs cannot guess the correct answer. The proposed method solves this by converting proprietary knowledge held within the API into structured repair suggestions directly consumable by the LLM, eliminating the need for guessing.
- **Challenge 2: Inefficiency of Unstructured Error Messages**. Traditional plain-text error diagnoses force LLMs to perform additional semantic parsing and reasoning, leading to low token efficiency and higher error rates. The proposed method provides typed, machine-consumable suggestion fields, significantly improving token efficiency per success (1.8–2.2x) by allowing direct execution of fixes.

## Implementation and Evaluation
- **Experimental Setup**: A leak-audited pilot study using 3 LLMs (Claude Haiku 4.5, Claude Sonnet 4.6, GPT-4o-mini) and 10 adversarial tasks (involving proprietary domains like recipe conversion), with N=30 per cell.
- **Key Results**: On Anthropic models, structured suggestions improved task completion rates by +36.7–40.0 percentage points over plain-English diagnoses (Fisher's exact p ≤ 0.0022) and achieved 1.8–2.2x better token efficiency per success.
- **Comparison & Limitations**: The lift was not significant on GPT-4o-mini (p=0.435), suggesting model-dependent efficacy. A replication in a billing API domain confirmed the pattern. The study emphasizes that valid comparisons require auditing for undocumented answer leakage in LLM benchmarks.
- **Infrastructure Contribution**: Released `audit_prompt_leakage.py` as reusable CI infrastructure for detecting prompt leakage.

## 4. Conclusion
The paper demonstrates that "structure beats verbosity" when APIs hold proprietary knowledge unknown to the LLM. Self-Reflective APIs significantly enhance AI agent recovery capabilities and efficiency in complex validation scenarios by returning machine-readable repair suggestions. This approach is not recommended for generic validations already understood by LLMs but offers substantial value for handling proprietary business logic, external states, and specialized rules.
