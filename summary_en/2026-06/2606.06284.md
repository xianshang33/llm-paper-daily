## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents increasingly rely on external tools. However, larger tool menus reduce reliability and efficiency by increasing wrong-tool calls, premature actions, and token costs. Existing methods typically treat tool selection as a semantic relevance problem, exposing tools whose names or descriptions match the user request.
- **Why Existing Work Fails**: Semantic relevance is insufficient for reliable multi-step tool use. A tool may be semantically related to the task but unnecessary, premature, or distracting at the current step. This leads to "ToolChoiceConfusion," where agents make errors due to the presence of plausible but causally unnecessary tools. Current approaches fail to distinguish between "semantically relevant" and "causally necessary," leading to inefficient and error-prone agent behavior.

## Core Contributions
- **Proposed**: Causal Minimal Tool Filtering (CMTF), a training-free method that selects tools based on causal sufficiency rather than just semantic relevance.
- **Challenge 1: How to identify tools truly needed at the current step?**
  - **Difficulty**: In multi-step tasks, many tools are semantically related to the goal, but only those satisfying specific preconditions and advancing the state are necessary. Distinguishing these from irrelevant or premature tools is complex.
  - **Solution**: CMTF uses lightweight "precondition-effect" contracts for each tool. It constructs a dependency graph of state transitions based on the current state and user goal, exposing only the minimal next-step tool frontier required to advance.
- **Challenge 2: How to reduce cost and complexity without sacrificing success rates?**
  - **Difficulty**: Reducing visible tools risks omitting the correct tool, while keeping all tools incurs high token costs and decision difficulty.
  - **Solution**: By filtering based on causal sufficiency, CMTF reduces visible tools from 100 to an average of 1 per step, matching the success rate of strong causal baselines while significantly simplifying the LLM's decision space.

## Implementation and Evaluation
- **Setup**: Evaluated on a benchmark with 102 tasks and 100 tools, using 4 LLM backends (2448 total runs). Baselines included all-tools exposure, keyword retrieval, state-aware filtering, and causal-path ablations.
- **Metrics**: Task success rate, wrong-tool calls, premature actions, tool exposure count, and token cost.
- **Results**:
  - **Success Rate**: CMTF matches the aggregate success rate of the strongest causal baseline.
  - **Efficiency**: Reduces visible tools from 100 to 1 per step compared to all-tools exposure.
  - **Cost**: Reduces token usage by approximately 90% relative to all-tools exposure.
  - **Reliability**: Significantly reduces wrong-tool calls and premature actions, demonstrating that causal filtering is more reliable than semantic relevance-based filtering.

## 4. Conclusion
The paper addresses "ToolChoiceConfusion" in LLM agents, highlighting that semantic relevance is inadequate for reliable multi-step tool use. The proposed CMTF method employs lightweight causal contracts and state dependency analysis to achieve training-free, minimal tool filtering. Experiments show that CMTF maintains high task success rates while drastically reducing token costs and decision complexity, offering a new paradigm for building efficient and reliable LLM agent systems.
