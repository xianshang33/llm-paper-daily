## 1. What the Paper Did
- **Background**: Large language model (LLM) agents increasingly rely on "Skills"—reusable procedural documents encoding workflows, tool usage, implementation patterns, validation checks, and domain rules. To reduce inference costs, skill rewriting is often treated as prompt compression.
- **Limitations of Existing Work**: Current methods typically employ uniform compression strategies, ignoring sparse but critical "operational anchors" (e.g., API constructors, command-line flags, validation thresholds). Blindly shortening skills may reduce direct token costs but can remove key information needed for exploration, debugging, and recovery, thereby increasing downstream execution costs (e.g., extra tool calls, error recovery loops) and resulting in higher total costs.

## Core Contributions
- **Proposed a** cost-aware skill rewriting framework from an economic perspective, repositioning skill design as cost-aware operational knowledge engineering rather than simple text compression.
- **Challenge 1: How to balance skill length with execution stability?**
  - **Difficulty**: Uniform compression removes sparse operational anchors, causing agents to require more exploration or enter error recovery cycles, which increases downstream token consumption.
  - **Solution**: By profiling skill structure, the method identifies and preserves key operational anchors (such as API/code anchors, workflow guards, and rule/formula anchors). It employs information-preservation strategies to rewrite skills, ensuring execution path stability while reducing length.
- **Challenge 2: Significant variation in dependency on skill structure across different task families; is there a universally optimal template?**
  - **Difficulty**: Different task types (e.g., code generation vs. data querying) have varying sensitivities to specific anchors, making it difficult for a single rewriting strategy to achieve the best quality-cost trade-off across all scenarios.
  - **Solution**: The authors built a controlled framework to profile skill structures and evaluated different rewriting strategies on SkillsBench. The study found no universally dominant template; instead, a learned policy dynamically selects the best rewriting approach (e.g., API anchoring, workflow guarding) based on task characteristics to achieve optimal trade-offs for specific task families.

## Implementation and Evaluation
- **Implementation & Evaluation Framework**: Experiments were conducted on SkillsBench, featuring a pipeline for skill structure profiling, rewriting via information-preservation strategies, and evaluation under fixed task instructions, environments, and verifiers.
- **Key Results**:
  - In the main held-out evaluation, the learned policy reduced total cost by 7.0% and downstream agent-token cost by 6.0%.
  - In frozen cross-model transfer scenarios, total cost and downstream agent-token cost were reduced by an average of 14.7% and 13.7%, respectively, while maintaining verifier quality (i.e., task success rates did not drop).
- **Comparison**: Compared to traditional uniform compression methods, this approach demonstrates the importance of retaining specific operational anchors. The experiments reveal that different strategies (API/code anchoring, workflow guarding, rule/formula anchoring) offer distinct advantages for different task families, indicating that fine-grained rewriting focused on operational knowledge engineering is more effective than simple global compression.

## 4. Conclusion
This paper challenges the traditional view of equating skill rewriting with prompt compression, highlighting that sparse operational anchors in skills are crucial for agent execution efficiency. By introducing a cost-aware rewriting framework, the authors demonstrate how to significantly reduce total costs while maintaining task execution quality. The results suggest that skill design should be treated as operational knowledge engineering, requiring a careful balance between quality and cost based on task specifics, rather than blindly pursuing text length reduction.
