## 1. What the Paper Did
- **Background**: Long-term memory for LLM agents is currently treated primarily as a retrieval problem (e.g., vector stores, temporal knowledge graphs) aimed at surfacing relevant text chunks during queries after long-term user interaction.
- **Limitations of Existing Work**: Current systems collapse belief revision, causal coupling, and cross-domain abstraction into a single retrieval surface tuned for surface recall. Consequently, they fail at implicit personalization tasks that require reasoning about how a user has evolved, losing intermediate belief states, causal links, and higher-order patterns across domains.

## Core Contributions
- **Proposed DCPM (Dual-Process Cognitive Memory System)**: Reorganizes agent memory along a cognitive capability hierarchy, inspired by dual-process theory, ascending from raw inputs to cross-domain core schemas.
- **Challenge 1: Tracking Dynamic Belief Evolution**. The difficulty lies in traditional systems storing only current facts, losing the path of belief revisions and causal connections. DCPM addresses this via a synchronous "Daytime Writer" (System 1) that records belief revisions as doubly linked supersedes chains, preserving the full trajectory of belief evolution.
- **Challenge 2: Abstracting Cross-Domain Implicit Intentions**. The challenge is that behaviors across different life domains may have low semantic similarity but high behavioral pattern similarity, making them hard to detect via traditional retrieval. DCPM solves this with an asynchronous "Nighttime Engine" (System 2) that clusters facts, induces schemas, and sweeps for cross-domain collisions, abstracting them into higher-level core schemas for deep cognitive evolution.

## Implementation and Evaluation
- **Benchmarks**: Evaluated on LongMemEval, PersonaMem, and PersonaMem-v2.
- **Results**: Enabling System 2 contributed most in benchmarks rewarding implicit cross-session inference, achieving up to +5.20 improvement on PersonaMem-v2, while contributing least to simple span recall tasks. This validates the architectural prediction that DCPM excels in deep reasoning rather than surface retrieval, outperforming existing systems confined to the passive foundation tier.

## 4. Conclusion
The paper identifies the root flaw in current LLM agent memory systems: conflating "memory-as-storage" with "memory-as-cognition." It proposes DCPM, which employs a dual-process mechanism (System 1 for fast recording of belief revision chains, System 2 for slow abstraction of cross-domain patterns). This enables a leap from passive fact storage to active cognitive evolution, effectively addressing challenges in implicit personalization and cross-domain reasoning.
