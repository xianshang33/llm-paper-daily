## 1. What the Paper Did
- **Background**: Large Language Model (LLM) agents are evolving from conversational interfaces into software components capable of planning, tool invocation, memory maintenance, and acting on external environments. This transition shifts security risks beyond unsafe text generation to include control flow redirection, tool privilege misuse, persistent state corruption, sensitive data leakage, and harmful external actions.
- **Why Existing Work Falls Short**: Current research on LLM agent security is fragmented across attack families, defense layers, and evaluation settings. Existing defenses are weakly compositional, and benchmarks fail to adequately represent long-horizon, stateful, and deployment-sensitive risks, lacking a unified systems-oriented perspective on the interaction between information flow, delegated authority, and persistent state.

## Core Contributions
- **Proposed a** lifecycle-based, systems-oriented framework that synthesizes 247 papers to model agent security around the interaction of information flow, delegated authority, and persistent state.
- **Challenge 1: Fragmentation and Evolution of Threat Surfaces**. The difficulty lies in the shift from simple prompt injections to complex tool-mediated control-flow hijacking and multi-agent propagation. The paper addresses this by systematically categorizing threats, identifying that while prompt injection remains dominant, persistent state corruption and multi-agent propagation are emerging as central concerns, thereby clarifying defense priorities.
- **Challenge 2: Weak Composability of Defenses and Inadequate Benchmarks**. The challenge is that current defenses are isolated building blocks lacking systemic integration, and benchmarks are disconnected from real-world deployment. The paper argues that secure agents require explicit trust boundaries, principled privilege control, provenance-aware state management, and evaluation practices aligned with realistic operational settings, providing a theoretical basis for composable defenses.

## Implementation and Evaluation
- As a survey paper, it does not propose a new algorithm or single deployment system but provides a comprehensive evaluation of existing literature.
- **Evaluation Results**: Analysis of 247 papers reveals that attacks are dominated by prompt injection and tool-mediated control-flow hijacking. Defenses are useful but lack composability. Benchmarks significantly underrepresent long-horizon, stateful, and deployment-sensitive risks.
- **Comparison**: Unlike previous works focusing solely on text safety or isolated attack vectors, this paper offers a holistic system view, highlighting the paradigm shift from "text safety" to "agent system security" and identifying gaps in trust boundaries and privilege control.

## 4. Conclusion
This paper systematically reviews the state of LLM agent security, highlighting new challenges arising from the transition to autonomous agents. By constructing a lifecycle-based systems framework, it exposes deficiencies in threat modeling, defense composability, and evaluation realism. It calls for explicit trust boundaries, strict privilege control, and evaluation standards aligned with real-world deployment, charting a course for future research in building secure LLM agent systems.
