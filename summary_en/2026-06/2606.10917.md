## 1. What the Paper Does

**Background**
While Large Language Model (LLM) agents show strong performance on complex tasks, their learning is often constrained by inefficient interaction feedback and static training environments, hindering broader generalization. Existing Agentic Reinforcement Learning (ARL) methods optimize policies via environment feedback but typically treat the environment as a fixed source of tasks.

**Why Existing Work Falls Short**
Current approaches face two main limitations: static environments provide sparse, non-specific feedback that limits exploration efficiency, while constructing synthetic environments to adapt to agents incurs high labor and runtime costs. Furthermore, most self-evolving methods only evolve the agent itself, failing to dynamically adapt the environment to diagnose hidden weaknesses or provide feedback targeted at specific failure modes.

## Core Contributions

**Proposed Role-Agent Framework**
The paper introduces Role-Agent, a framework that leverages a single LLM to function concurrently as both the agent and the environment, enabling bootstrapped co-evolution. It consists of two synergistic components: Agent-In-World (AIW) and World-In-Agent (WIA).

**Challenge 1: How to provide dense, environment-aware process rewards without relying on expensive external synthetic environments?**
Traditional methods struggle to obtain fine-grained process supervision signals. Role-Agent addresses this via the WIA component: the LLM, acting as the agent, predicts future states after each action. The alignment between predicted and actual states serves as a process reward, encouraging environment-aware reasoning without requiring extra annotations or costly simulations.

**Challenge 2: How to automatically identify agent weaknesses and dynamically adjust training data distribution for targeted practice?**
Static training data cannot optimize for specific agent failure modes. Role-Agent solves this through the AIW component: the LLM analyzes failure modes from failed trajectories and retrieves tasks with similar failure patterns. This reshapes the training data distribution, allowing the agent to focus on reinforcing its weak points.

## Implementation and Evaluation

**Implementation and Deployment**
Role-Agent is a framework based on a single LLM that achieves co-evolution through a role-switching mechanism. The code is open-sourced on GitHub (AMAP-ML/roleagent).

**Evaluation Results**
Experiments across multiple benchmarks demonstrate that Role-Agent consistently improves performance, yielding an average gain of over 4% compared to strong baselines. This proves that the dual-role evolution mechanism enables agents to achieve stronger generalization and reasoning capabilities through self-play and targeted training, without the need for complex external environments.

**Comparison**
Compared to traditional static environment training and high-cost synthetic environment methods, Role-Agent achieves a more efficient feedback loop and more targeted capability evolution at a lower cost.

#### Summary

Role-Agent proposes a novel paradigm for training LLM agents by allowing a single model to switch roles between agent and environment, addressing the issues of inefficient feedback and static environments in traditional methods. Its core innovations lie in using state prediction alignment as process rewards (WIA) and reshaping data distribution based on failure mode analysis (AIW). Experimental results confirm that this method significantly enhances agent performance, offering a new direction for low-cost, high-efficiency agent self-evolution.
