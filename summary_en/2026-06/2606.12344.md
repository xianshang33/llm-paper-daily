## 1. What the Paper Did
- **Background**: General-purpose agents like OpenClaw are increasingly used as autonomous tool users, but their coding capabilities on real software engineering tasks are difficult to measure using existing SWE-bench standards.
- **Why Existing Work Falls Short**: Current SWE-bench-style evaluations typically bundle prompt templates, agent loops, tool interfaces, and timeout settings into specific systems. This conflates three distinct factors: the LLM, the agent harness (the "claw"), and the task instances. Since different systems vary in scaffolds, budgets, and termination policies, it is impossible to fairly compare harness designs or attribute performance differences across systems.

## Core Contributions
- **Proposed Claw-SWE-Bench**: A multilingual SWE-bench-style benchmark and adapter protocol that enables fair comparison of heterogeneous agent harnesses under fixed conditions, including prompts, runtime budgets, workspace contracts, patch extraction procedures, and evaluators.
- **Challenge 1: Generic agents fail to meet strict SWE-bench scoring contracts**. The difficulty lies in the fact that generic agents do not inherently satisfy requirements for clean Docker workspaces, patch formats, and prediction contracts. The paper addresses this by designing a specialized adapter protocol that standardizes the extraction of patches from raw agent outputs, allowing general harnesses like OpenClaw to participate in fair evaluations.
- **Challenge 2: Lack of independent evaluation dimensions for harness design and cost efficiency**. Previous studies often overlook the significant impact of harness selection on performance and the substantial cost differences among systems with similar accuracy. The paper treats harness design and cost accounting as first-class citizens, revealing through full (350 instances) and lite (80 instances) benchmarks that harness choice impacts Pass@1 by 27.4 percentage points and highlights significant API cost disparities.

## Implementation and Evaluation
- **Dataset Construction**: The full benchmark comprises 350 GitHub issue-resolution instances across 8 languages and 43 repositories, derived from SWE-bench-Multilingual and SWE-bench-Verified-Mini with future-commit cleanup. Claw-SWE-Bench Lite, an 80-instance subset selected via cost-and-rank-aware procedures, is released for rapid validation.
- **Evaluation Results**:
    - **Importance of Adapters**: With the same GLM 5.1 backbone, OpenClaw achieved only 19.1% Pass@1 with a minimal direct-diff adapter, compared to 73.4% with the full adapter, demonstrating that adapter design is critical for effective coding tasks.
    - **Impact of Model and Harness**: In a sweep of OpenClaw × 9 models, model choice changed Pass@1 by 29.4 percentage points. In a sweep of 5 claws × 2 models, harness choice changed Pass@1 by 27.4 percentage points under fixed models.
    - **Cost Disparities**: Systems with similar accuracy exhibited substantial differences in total API costs, underscoring the importance of cost accounting in evaluation.
- **Comparison**: Unlike single-harness systems (e.g., SWE-agent, AutoCodeRover) that report aggregated metrics, Claw-SWE-Bench decouples model and harness effects, providing a reproducible baseline for horizontal comparison.

## 4. Conclusion
Claw-SWE-Bench fills the gap in evaluating general-purpose agents on repository-level coding tasks. By standardizing adapter protocols and enforcing strict evaluation contracts, it enables fair comparisons across different agent harnesses. The results indicate that harness design and adapter quality are decisive for final performance, and cost efficiency is a key metric. This benchmark provides essential reference standards and data support for developing efficient, low-cost coding agents in the future.
