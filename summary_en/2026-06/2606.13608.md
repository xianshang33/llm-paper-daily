## 1. What the Paper Did
- **Background**: LLM-based agent systems are advancing rapidly, but their evaluation remains fragmented. Most existing benchmarks rely on fixed, LLM-centric harnesses.
- **Limitations of Existing Work**: Traditional methods require heavy integration, create a mismatch between test and production environments, and limit fair comparison across diverse agent designs. The root cause is the lack of an open, agent-agnostic assessment interface.

## Core Contributions
- **Proposed Agentified Agent Assessment (AAA) framework and its implementation, AgentBeats**: Advocates for evaluation performed by judge agents, where all participants interact via standardized protocols (A2A for task management, MCP for tool access), separating assessment logic from agent implementation.
- **Challenge 1: High Integration Complexity and Fragmented Interfaces**. Traditional benchmarks define separate interfaces for each benchmark and agent, leading to N*M integration complexity. **Solution**: AAA requires only one unified interface using A2A and MCP standards, reducing complexity to N+M. This yields a generic framework that enables reproducible, interoperable, and multi-agent evaluation.
- **Challenge 2: Compatibility of Standardized Assessment with Real-world Constraints**. Balancing openness, privacy, and reproducibility is difficult in practical scenarios. **Solution**: Introduced five practical operation modes to make standardized assessment compatible with real-world constraints, along with recommended practices for minimal-effort adoption by developers and benchmark designers.

## Implementation and Evaluation
- **Large-scale Field Study**: Conducted a five-month open competition involving 467 subject agents and 298 judge agents across 12 categories from independent participants. Results showed that AAA applies across a heterogeneous range of benchmarks, demonstrating coverage and practicality.
- **Coding Agent Case Study**: A controlled study on coding agents confirmed that agentified evaluation preserves fidelity with public records while surfacing previously missing head-to-head results, yielding insights into agent design.
- **Comparison**: Compared to traditional benchmarks, AAA eliminates test-production mismatch, supports fairer cross-architecture comparisons, and maintains high fidelity in large-scale heterogeneous scenarios.

## 4. Conclusion
The paper presents the AAA framework and AgentBeats system, addressing fragmentation and integration challenges in agent evaluation through standardized protocols (A2A/MCP) and judge agents. Community-scale competitions and case studies verify the method's effectiveness in openness, standardization, and reproducibility, offering a clear path forward for agent assessment.
