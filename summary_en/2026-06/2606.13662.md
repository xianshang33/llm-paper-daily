## 1. What the Paper Did
- **Background**: LLM-based agents show increasing potential in automating scientific discovery by proposing, validating, and iterating solutions based on optimizable metrics. As model capabilities improve, the bottleneck is shifting from prescribing agent workflows to designing agent environments (resources, constraints, and interfaces).
- **Limitations of Existing Work**: Current research focuses heavily on workflow optimization or prompt engineering, neglecting how the environment shapes agent behavior. This leads to issues like reward hacking, lack of systematic artifact management, inefficient open-ended exploration, and high-friction human oversight, limiting reliability and efficiency in complex scientific tasks.

## Core Contributions
- **Proposed EurekAgent**, an environment-engineered agent system for metric-driven autonomous scientific discovery, designed to amplify productive behaviors and suppress harmful ones.
- **Challenge 1: How to ensure execution safety and evaluation isolation to prevent reward hacking?**
  - **Difficulty**: Uncontrolled agents may exploit loopholes for high scores without solving problems, and evaluations can be easily interfered with.
  - **Solution**: **Permissions Engineering** implements bounded agent execution and isolated evaluation, strictly limiting operational scope to ensure result authenticity and security.
- **Challenge 2: How to enable efficient long-term exploration, collaboration, and cost control?**
  - **Difficulty**: Scientific discovery requires long-term iteration and versioning, while API costs are high, and convenient human intervention is needed.
  - **Solution**: **Artifact Engineering** uses filesystems and Git for collaboration; **Budget Engineering** enables budget-aware exploration; **Human-in-the-loop Engineering** provides low-friction supervision and intervention interfaces.

## Implementation and Evaluation
- **Implementation**: EurekAgent is an open-source system integrating permission controls, Git versioning, budget monitoring, and human-in-the-loop interfaces.
- **Evaluation Results**:
  - **Mathematics**: Achieved a new State-of-the-Art (SOTA) in the 26-circle packing problem (score 2.635999), surpassing the best human (~2.634) and AI (2.635986) results, with total API costs under $11.
  - **Kernel Engineering**: Set new SOTA results in Erdős’ Minimum Overlap and 1st Autocorrelation Inequality tasks.
  - **Machine Learning**: Achieved 2005.03 µs in TriMul kernel optimization, outperforming the previous best AI result (2247.78 µs); ranked first on the evaluated MLE-Bench subset with 85.71% accuracy.
- **Comparison**: EurekAgent set new SOTAs in all tested mathematics and kernel engineering tasks and performed competitively in machine learning benchmarks, significantly outperforming previously published best human and AI baselines.

## 4. Conclusion
EurekAgent demonstrates that "environment engineering" is a core direction for developing reliable autonomous research agents. By carefully designing four environmental dimensions (permissions, artifacts, budget, and human-in-the-loop), the system significantly lowers the barrier and cost of automated scientific discovery while surpassing human experts and existing AI systems in multiple hard scientific tasks. The work calls for a community shift from workflow design to comprehensive environment engineering.
