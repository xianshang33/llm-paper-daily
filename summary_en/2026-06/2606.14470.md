## 1. What the Paper Did
- **Background**: LLM reasoning is ephemeral; chains of thought vanish with context windows, pruned branches leave no records, and memory buffers lack diff/merge/audit capabilities. Unlike code or data, reasoning processes are not version-controlled.
- **Limitations of Existing Work**: Current agent memory systems (vector stores, graphs, text buffers) lack immutability, provenance, and mergeability. This hinders reproducibility (replaying specific steps), auditing (detecting leakage or memorization), and cross-agent experience transfer.

## Core Contributions
- **Proposed GitOfThoughts**: A framework that stores an agent's reasoning tree as a Git repository, where scored thoughts are commits, scores are notes, and outcomes are tags. Retrieval is performed via "git log" over the agent's history.
- **Challenge 1: Unauditable and Irreproducible Reasoning**. The difficulty lies in the lack of fine-grained historical tracking and merging in traditional memory substrates. GitOfThoughts solves this by leveraging mature Git protocols to enable replayability, auditability, and cross-agent merging at near-zero engineering cost.
- **Challenge 2: Does Memory Actually Improve Accuracy on Novel Problems?** The challenge is distinguishing "method transfer" from "answer retrieval" and verifying the utility of different memory forms. Through rigorous pre-registered evaluation, the paper finds that no memory format reliably improves accuracy on novel problems. Memory only helps when retrieved cases are near-duplicates (similarity >~0.8, the "copyability threshold"), indicating gains come from answer retrieval, not method learning.

## Implementation and Evaluation
- **Implementation**: GitOfThoughts serves as a pluggable memory interface, allowing swapping of substrates (None, Markdown, Vector, Graph, Git) while keeping the agent model fixed.
- **Evaluation Setup**: Controlled experiments across two benchmarks (GPQA-Diamond, MATH-500), two model scales, five memory substrates, including pre-registered replications.
- **Key Results**:
    1. **H-memory Hypothesis Rejected**: No memory substrate reliably improved accuracy on novel problems. An early observed +15pp gain for Git did not survive pre-registered replication.
    2. **The Copyability Threshold**: Memory significantly boosts accuracy (+12 to +13.5pp) only when the retrieved case has a cosine similarity > 0.8 to the test problem. Below this threshold, it is ineffective.
    3. **Answer Retrieval vs. Method Transfer**: Even a 4.5x larger model failed to extract transferable methods from examples, only doubling the gain for near-duplicate answer retrieval (+22.5~28.5pp).
    4. **Comparison Conclusion**: Git's advantage lies in auditability, provenance, and mergeability at accuracy parity with other methods, not in superior precision. The only general lever for improvement remains test-time sampling.

#### Summary
This paper introduces GitOfThoughts to address the lack of version control in LLM reasoning, enabling replayability and auditability. Crucially, through strict pre-registered experiments, it refutes the common assumption that general memory enhances solving capabilities for novel problems. It demonstrates that memory is only effective in high-similarity "copyable" scenarios, functioning as answer retrieval rather than method transfer. The study advocates for higher evaluation standards in the field (including documenting retracted results) and highlights Git's operational value in engineering robustness rather than just accuracy gains.
