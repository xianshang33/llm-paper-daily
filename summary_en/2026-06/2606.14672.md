## 1. What the Paper Does
- **Background**: Large Language Models (LLMs) are increasingly used as execution engines for agentic systems but still rely on a sequential text interface for context consumption. This creates a mismatch with modern structured agent workflows, which often involve independent parallel branches (e.g., exploring subtasks, retrieving evidence, or generating candidates) before a final synthesis step.
- **Limitations of Existing Work**: Current systems typically merge these branches by concatenating their textual outputs. This approach discards the original parallel DAG structure, imposing artificial dependencies and incurring redundant prefill computation costs by re-encoding information already processed during worker decoding.

## Core Contributions
- **Proposed Parallel-Synthesis**: A plug-and-play framework that enables a synthesizer to directly consume the KV caches produced by parallel worker agents, bypassing the need for text concatenation.
- **Challenge 1: Distributional mismatch in independently generated branch caches.**
  - **Difficulty**: KV caches from independent parallel branches lack unified contextual alignment, making direct merging prone to semantic conflicts or attention failures.
  - **Solution**: Introduces a cache mapper that calibrates and aligns the independently generated branch caches, ensuring consistency in the latent space for subsequent processing.
- **Challenge 2: LLMs natively do not support generation from non-sequential cache interfaces.**
  - **Difficulty**: Standard LLM architectures are designed for autoregressive processing of linear sequences and cannot inherently interpret or generate from discontinuous KV caches sourced from multiple parallel paths.
  - **Solution**: Develops and fine-tunes a synthesizer adapter capable of generating from this non-sequential cache interface. The model is trained on data exposing it to parallel cache contexts and distills reasoning behaviors from standard text-concatenation-based synthesis.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated across nine downstream datasets spanning math, science QA, code generation, GAIA, and multi-agent database diagnosis.
- **Performance Comparison**: Parallel-Synthesis matches or outperforms text-based synthesis methods on seven datasets and remains competitive on the other two, demonstrating that direct cache synthesis maintains high accuracy.
- **Efficiency Gains**: The method reduces Time-to-First-Token (TTFT) by 2.5x to 11x. This significant speedup is achieved by eliminating redundant prefill computations through the direct reuse of KV caches from parallel branches.
- **Comparison Conclusion**: Compared to traditional text concatenation, Parallel-Synthesis offers a more native and efficient interface for parallel agent branches, significantly reducing latency while preserving reasoning quality.

#### Summary
This paper addresses the mismatch between parallel structures in LLM agent workflows and the sequential nature of LLM context interfaces by proposing Parallel-Synthesis. By directly leveraging KV caches from parallel branches instead of concatenating text, the framework eliminates redundant computation and preserves structural information. Experimental results show that the method maintains high accuracy across complex tasks while significantly reducing latency, offering a promising direction for building more efficient, native parallel agentic systems.
