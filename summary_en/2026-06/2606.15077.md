## 1. What the Paper Does
- **Background**: Leveraging advances in Large Language Models (LLMs), this paper presents a framework for automating geospatial workflows. It enables intelligent retrieval of remote sensing data from cloud-based catalogs using natural language queries, converting user intent into structured API calls.
- **Limitations of Existing Work**: Current methods often lack robust safety and policy enforcement mechanisms when interfacing directly with large-scale satellite imagery repositories. Prompt-level safety instructions are insufficient against adversarial multi-turn attacks, leading to rare but high-impact API manipulation failures, highlighting the need for system-level defenses.

## Core Contributions
- **Proposed a Risk-Aware LLM Agent Framework**: The architecture integrates three coordinated agents: Guardrail, General-QA, and Recommender-Analyst, to safely interpret intent and generate precise API calls.
- **Challenge 1: How to ensure safety and policy compliance in interactions with external data services?**
  - **Difficulty**: LLMs are vulnerable to prompt injection or malicious manipulation, generating unsafe API requests. Prompt engineering alone cannot fully mitigate complex adversarial attacks.
  - **Solution**: Introduces a "Guardrail" agent built on NeMo Guardrails as an intercept-level risk identification and prevention mechanism, enforcing security policies at the system level to complement prompt-level defenses.
- **Challenge 2: How to achieve portability across different geospatial platforms and maintain semantic alignment?**
  - **Difficulty**: Diverse geospatial platforms have unique API schemas. Hard-coding logic reduces portability, and mapping natural language intent to specific API parameters is complex.
  - **Solution**: Adopts a modular design where the "Recommender-Analyst" agent handles schema-aware API generation. The framework supports portability by simply substituting API schemas, ensuring semantic alignment between user intent and data retrieval.

## Implementation and Evaluation
- **Implementation**: The system comprises three agents: Guardrail (safety), General-QA (intent understanding), and Recommender-Analyst (API generation). Designed for SkyWatch, its modular nature allows adaptation to other platforms like Google Earth Engine by swapping API specifications.
- **Evaluation Results**: Preliminary experiments in adversarial multi-turn settings show that while prompt-level instructions improve robustness, high-impact failures persist in API manipulation scenarios. This validates the necessity of the intercept-level Guardrail agent for balancing safety, usability, and cost.
- **Comparison**: Compared to methods relying solely on LLM capabilities or simple prompt engineering, this multi-agent collaborative architecture significantly enhances reliability and policy compliance in sensitive geospatial data retrieval tasks through explicit risk interception.

## 4. Conclusion
This paper proposes a risk-aware LLM agent framework for geospatial data retrieval. By integrating safety, intent understanding, and API generation agents, it achieves safe and reliable conversion from natural language to structured API calls. Preliminary evaluations confirm the value of system-level protection (Guardrail) against adversarial attacks, offering a scalable solution for automated Earth observation workflows in environmental monitoring and disaster response.
