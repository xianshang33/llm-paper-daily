## 1. What the Paper Did
- **Background**: Tool-augmented Large Language Model (LLM) agents increasingly operate over large tool libraries, making the visible "tool menu" a central part of the agent interface. Existing evaluations primarily focus on whether a model can correctly call an individual tool, neglecting how tool-menu construction impacts reliability, efficiency, and safety-relevant risk exposure.
- **Why Existing Work Falls Short**: Current benchmarks often treat the available tool set as fixed or given, failing to isolate the "tool-menu design" problem. They do not adequately evaluate which tools should be visible at each decision step, how menu size affects reliability, the impact of distractors, or how filtering strategies trade off task success, token cost, and safety risks. Semantic relevance alone is insufficient, as semantically related tools may not be causally appropriate for the current task state.

## Core Contributions
- **Proposed ToolMenuBench**: A benchmark for evaluating tool-menu construction in multi-step LLM agents. It varies tool-menu size, distractor types, state-dependent task structures, and risk exposure, reporting both filter-level and downstream agent metrics (e.g., visible tool count, risky-tool exposure, task success, wrong-tool calls, premature actions, and token usage).
- **Challenge 1: How to maintain high task success while reducing the number of visible tools?**
    - **Difficulty**: Exposing all tools increases wrong calls and token consumption, but aggressive filtering may omit necessary tools. Semantic filtering often includes irrelevant but semantically similar distractors.
    - **Solution**: The paper introduces and evaluates Causal Minimal Tool Filtering (CMTF), which shapes the tool menu based on preconditions, effects, and task-state progress rather than just semantic relevance, significantly improving success rates while drastically reducing visible tools.
- **Challenge 2: How to quantify and reduce safety risk exposure for agents?**
    - **Difficulty**: Traditional evaluations lack fine-grained metrics for "risky-tool exposure," making it hard to distinguish between safe and dangerous tool selection scenarios.
    - **Solution**: ToolMenuBench specifically designs evaluation settings with risk exposure variables. By comparing different filtering methods (e.g., unfiltered, lexical, state-aware), it demonstrates that CMTF effectively reduces risky-tool exposure and premature actions.

## Implementation and Evaluation
- **Experimental Setup**: Controlled evaluation across 7 model backends, 3 tool-menu sizes, 6 filtering methods, and 7 evaluation settings.
- **Key Results**:
    - **CMTF Performance**: Causal Minimal Tool Filtering (CMTF) improved task success from 32.1% (under all-tools exposure) to 85.7%.
    - **Efficiency Gain**: Average token usage was reduced by approximately 98%.
    - **Overall Trade-off**: Compared to unfiltered exposure, lexical filtering, state-aware filtering, and broader causal-path baselines, CMTF achieved the strongest overall trade-off by reducing visible tools, wrong-tool calls, premature actions, and risky-tool exposure.
- **Comparison Conclusion**: Existing methods (such as those relying solely on semantic retrieval) perform poorly when handling complex state-dependent tasks and distractors. Causality-based filtering strategies are proven to be more effective in addressing the agent-interface problem.

#### Summary
This paper introduces ToolMenuBench, filling a gap in LLM agent evaluation regarding tool-menu construction. It highlights that reliable agents require more than correct tool-call syntax; they need systematic interface evaluation to determine which tools to show, when, and under what cost or risk constraints. Experiments demonstrate that Causal Minimal Tool Filtering (CMTF) is an effective approach to enhancing agent reliability, efficiency, and safety, providing a reusable evaluation framework and guiding principles for future agent interface design.
