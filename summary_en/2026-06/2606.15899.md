## 1. What the Paper Did
- **Background**: The open-source LLM agent ecosystem (e.g., LangChain, Auto-GPT) is expanding rapidly, with a vast number of community-contributed "Skills" (modular tool definitions). However, the security of these skills remains largely unvetted, creating a new supply-chain attack surface where malicious behaviors can be embedded in seemingly benign skills.
- **Why Existing Work Fails**: Current security scanners operate at the code layer using signature matching or static analysis. They are structurally blind to "instruction-layer" and multi-agent risks, such as hijacking agents via natural language directives, exfiltrating data through encoded side channels, or chaining harm across pipelines. These threats lack code-level signatures, making them invisible to traditional tools, while human review does not scale.

## Core Contributions
- **Proposed SkillVetBench**: A live public leaderboard on Hugging Face that utilizes an LLM-as-Judge mechanism to vet agent skills across multiple security dimensions.
- **Challenge 1: Difficulty in Semantic Understanding and Detection of Instruction-Layer Risks**. Traditional tools fail to interpret malicious intent hidden in natural language instructions (e.g., prompt injection, memory poisoning).
  - **Solution**: Introduced SARS (Skill Agentic Risk Score), a five-dimensional agentic-risk metric with a principled weighted formula designed specifically for instruction-following systems to quantify semantic risk.
- **Challenge 2: Lack of a Standardized, Publicly Comparable Multi-Dimensional Evaluation System**. Existing tools suffer from high false-negative rates or lack granular risk decomposition.
  - **Solution**: Integrated full CVSS v4.0 vector decomposition and a ClawHub dual-view that places LLM-generated reviews alongside official marketplace verdicts, enabling comprehensive vetting from static code to dynamic semantics.

## Implementation and Evaluation
- **Implementation & Deployment**: SkillVetBench is deployed as a real-time public leaderboard on Hugging Face. The architecture involves fetching skills from ClawHub/OpenClaw, analyzing them with an LLM-as-Judge to extract intent and classify vulnerabilities, and generating SARS scores and CVSS v4.0 decompositions.
- **Evaluation Results**:
  - Achieved **Zero False Negatives** across 78 confirmed-malicious skills.
  - Achieved **Zero False Positives** across 22 benign control samples.
  - Detection rates varied from 35% to 95% across four different LLM evaluators, highlighting the need for ensemble scoring in production.
- **Comparison with Related Work**:
  - The best static baseline, SKILLSIEVE, still missed 15% of threats.
  - For instruction-layer categories like Prompt Injection and Memory Poisoning, conventional tools missed between 89% and 100% of threats. For instance, CODEBERT detected none of the nine memory-poisoning skills.

## 4. Conclusion
This paper addresses the critical security gaps in the open-source LLM agent skill ecosystem, highlighting the structural inability of code-layer static scanners to handle instruction-layer attacks. The authors propose SkillVetBench, leveraging LLM-as-Judge technology to create the first multi-dimensional security evaluation benchmark and live leaderboard for agent skills. By introducing the SARS scoring system and CVSS v4.0 decomposition, the method significantly outperforms traditional static analysis tools in detecting complex semantic attacks like prompt injection and memory poisoning, achieving zero false negatives and zero false positives. This provides a standardized, automated solution for securing the open-source agent ecosystem.
