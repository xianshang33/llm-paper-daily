## 1. What the Paper Did
- **Background**: In complex real-world systems like OpenClaw, Large Language Model (LLM) agents must solve tasks through tool use, multi-step reasoning, and dynamic environment interaction. Introducing "Skills"—compact, reusable procedural strategies—is crucial for enhancing agent reliability and generalization.
- **Why Existing Work Falls Short**: Current skill construction methods suffer from three main limitations: (1) **Skill Fragmentation**, capturing only local procedures for isolated subtasks without correlation; (2) **Limited Diversity**, constrained by the inherent biases of single models leading to homogeneous skills; and (3) **Poor Transferability**, showing significant performance drops across different LLM backbones. Additionally, manual skill construction is costly and unscalable, while existing automatic methods fail to adequately address these structural and generalization issues.

## Core Contributions
- **Proposed Collective Skill Tree Search (CSTS)**: A novel tree-search-based framework that constructs structured, diverse, and generalizable trees of skills, complemented by Collective Skill Reinforcement Learning.
- **Challenge 1: How to overcome single-model bias to achieve skill diversity and comprehensive exploration?**
  - **Difficulty**: Skills generated by a single model are often limited by its training distribution, resulting in homogeneity and inadequate coverage of the solution space.
  - **Solution**: The **Collective Skill Node Generation (CSN-Gen)** phase leverages collective knowledge from multiple models to explore diverse candidate skills for each subtask, enabling comprehensive and diverse skill exploration.
- **Challenge 2: How to ensure constructed skills are both high-quality and generalizable across different models?**
  - **Difficulty**: Many skills perform well on specific models but lack robustness across different architectures, failing in new environments or with different backbones.
  - **Solution**: The **Collective Skill Node Assessment (CSN-Assess)** phase employs multiple models as judges with two scoring mechanisms: (1) **Collective Quality Scoring**, which aggregates independent evaluations for a robust estimate of effectiveness; and (2) **Collective Transferability Scoring**, which explicitly verifies cross-model generalization, selecting only high-quality and highly transferable skill nodes.

## Implementation and Evaluation
- **Implementation**: The study constructs a comprehensive skill tree and skill-augmented training data. It introduces **Collective Skill Reinforcement Learning**, which actively selects multiple relevant skills from the tree during training to broaden solution-space exploration and avoid suboptimal solutions trapped by single skills. The resulting model is named **OpenClaw-Skill**.
- **Evaluation & Comparison**:
  - OpenClaw-Skill demonstrates outstanding agentic capabilities in long-horizon planning, tool use, and generalization on challenging benchmarks.
  - Compared to existing automatic skill construction methods (e.g., SkillRL), CSTS produces skills with better structure and diversity.
  - Experiments show that the method significantly mitigates skill fragmentation and poor transferability, with much smaller performance drops across different LLM backbones compared to baselines, proving superior cross-model generalization.

## 4. Conclusion
This paper addresses the issues of fragmentation, low diversity, and weak transferability in existing LLM agent skill construction by proposing the Collective Skill Tree Search (CSTS) framework. By leveraging collective intelligence from multiple models for skill generation and assessment, CSTS automatically builds structured, diverse, and highly generalizable skill trees. Combined with collective skill reinforcement learning, the resulting OpenClaw-Skill model achieves significantly better performance in complex task handling, tool use, and cross-model generalization than existing works, offering a new paradigm for automated efficient LLM agent skill construction.
