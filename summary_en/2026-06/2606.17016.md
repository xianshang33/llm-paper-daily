## 1. What the Paper Does
- **Background**: As LLM agents are deployed in long-horizon sessions, context accumulation significantly drives up inference costs. Existing approaches typically use text pruning or dynamic memory eviction to minimize token footprints.
- **Limitations of Prior Work**: Existing methods introduce unconstrained sequence mutations (such as truncation and compaction) to reduce tokens, which alter input layouts, causing prefix mismatches and KV cache invalidation. This reveals a critical trade-off between text sparsity and prompt cache continuity: aggressive compression reduces token counts but shatters hardware cache alignment, leading to severe pre-fill penalties.

## Core Contributions
- **Proposed TokenPilot**: A dual-granularity context management framework designed to balance text compression efficiency with hardware cache hit rates.
- **Challenge 1: Global Prefix Stability and Environmental Noise**. The difficulty lies in open-world noise contaminating context and traditional compression breaking prompt prefix structures, leading to cache misses. TokenPilot addresses this via "Ingestion-Aware Compaction," which acts as a framework harness to stabilize prompt prefixes and eliminate environmental noise at the ingestion gate, preserving cache layout continuity.
- **Challenge 2: Local Context Lifecycle Management and Precise Eviction**. The challenge is determining the residual utility of context segments; premature eviction hurts performance, while delayed eviction increases costs. TokenPilot employs "Lifecycle-Aware Eviction" to monitor the ongoing residual utility of context segments, enforcing a conservative batch-turn schedule to offload content only when task relevance expires, ensuring efficient cache utilization.

## Implementation and Evaluation
- **Implementation**: TokenPilot has been integrated into the LightMem2 system, with code available on GitHub.
- **Evaluation Results**: Experiments were conducted on PinchBench and Claw-Eval benchmarks under both isolated and continuous modes.
- **Comparison with Prior Work**:
    - In isolated mode, TokenPilot reduced costs by 61% and 56% compared to prior systems.
    - In continuous mode, cost reductions were even more significant, reaching 61% and 87%.
    - While substantially reducing costs, TokenPilot maintained competitive performance comparable to previous systems, demonstrating its effectiveness in resolving cache invalidation issues.

## 4. Conclusion
TokenPilot addresses the context management challenge in long-session LLM agents by proposing a dual-granularity solution that balances text sparsity with cache continuity. By stabilizing prefixes globally through ingestion-aware compaction and optimizing resource release locally via lifecycle-aware eviction, it effectively solves the KV cache invalidation problem caused by traditional pruning methods. Experiments show that TokenPilot significantly reduces inference costs while maintaining performance, especially in continuous interaction scenarios, providing efficient infrastructure support for the sustainable deployment of LLM agents.
