## 1. What the Paper Does
- **Background**: Big-Data-as-a-Service (BDaaS) platforms require reliable automation across the entire machine learning lifecycle, including data ingestion, cleaning, feature engineering, model development, deployment, and monitoring. Despite cloud infrastructure advancements, end-to-end workflows still heavily rely on human expertise for pipeline design, validation, and drift management.
- **Why Existing Work Falls Short**: Current LLM-based data science agents and AutoML systems primarily focus on isolated workflow stages (e.g., only data cleaning or only model training). They lack support for lifecycle-level orchestration, failing to address the tight coupling between stages, artifact governance, human oversight, reproducibility, and adaptation to data drift.

## Core Contributions
- **Proposed a**: Trustworthy Self-Composable BDaaS framework based on LLM-orchestrated multi-agent collaboration. The architecture decomposes the lifecycle into specialized agents (ingestion, cleaning, feature engineering, AutoML, evaluation, MLOps, monitoring, drift detection) coordinated by a central LLM layer.
- **Challenge 1: Complex Orchestration and Context Management across Lifecycle**. The difficulty lies in the tight coupling of stages where changes in one affect others, making it hard for single agents to maintain long-range context and compatibility. The paper addresses this by using a central LLM orchestration layer to coordinate agent execution, validate intermediate outputs, manage workflow context, and enable dynamic workflow composition.
- **Challenge 2: Trustworthiness and Drift Adaptation in Production**. The challenge is ensuring reproducibility, artifact traceability, and responsiveness to post-deployment data distribution shifts (drift), which traditional AutoML lacks. The solution incorporates shared artifact governance, human-in-the-loop checkpoints, and drift-aware feedback loops that trigger retraining or rollback upon detecting covariate drift.

## Implementation and Evaluation
- **Implementation & Setup**: A prototype was evaluated using controlled tabular benchmark datasets featuring missing values, categorical variables, outliers, class imbalance, and simulated covariate drift.
- **Baselines**: Compared against Manual ML, AutoML-only systems, and single-agent LLM baselines.
- **Results**:
    - **Predictive Performance**: The proposed multi-agent BDaaS pipeline achieved competitive predictive performance comparable to baselines.
    - **Lifecycle Reliability**: It significantly outperformed all baselines in workflow completion rates, artifact traceability, deployment readiness, reproducibility, and drift recovery capabilities.
    - **Conclusion**: The results demonstrate that LLM-orchestrated multi-agent systems can extend conventional AutoML towards trustworthy, adaptive, and production-oriented BDaaS automation.

#### Summary
This paper addresses the limitations of existing AutoML and LLM agents in full-lifecycle BDaaS automation by proposing an LLM-orchestrated multi-agent framework. By decomposing the lifecycle into specialized agents and integrating central orchestration, artifact governance, and drift-aware mechanisms, the framework maintains competitive predictive performance while significantly enhancing engineering reliability, reproducibility, and adaptability, offering a new pathway for building production-grade trustworthy big data services.
