## 1. What the Paper Does
- **Background**: As LLM agents evolve from stateless chatbots to persistent assistants with memory, existing benchmarks primarily assume single-user settings, focusing on maximizing recall. However, real-world deployments in hospitals, workplaces, campuses, and households involve multiple principals writing to and querying a common memory pool with varying roles, scopes, and relationships.
- **Why Existing Work Fails**: Current benchmarks treat agent memory as a private cache, ignoring governance in shared environments. In these settings, high recall without strict access control and forgetting mechanisms is a security vulnerability rather than an achievement, as it risks leaking sensitive or deleted information to unauthorized users. There is a lack of systematic evaluation for this complex shared memory governance.

## Core Contributions
- **Proposed GateMem**: A benchmark specifically designed to evaluate the governance capabilities of multi-principal shared-memory agents across medical, office, education, and household domains.
- **Challenge 1: Context-Aware Access Control**
  - **Description & Difficulty**: Agents must precisely determine access rights based on the querier's role and contextual boundaries. The difficulty lies in preventing privacy leaks across permission boundaries while maintaining utility, requiring fine-grained semantic understanding and permission reasoning.
  - **Solution**: GateMem evaluates this by constructing long-form multi-party interaction episodes with hidden checkpoints and leak-target annotations, structurally assessing the agent's ability to refuse or respond appropriately to different roles.
- **Challenge 2: Balancing Active Forgetting and Utility**
  - **Description & Difficulty**: Agents must completely "forget" explicitly deleted information while remaining useful for legitimate long-horizon requests. The challenge is that existing methods struggle to balance these: they either retain deleted data for utility or over-forget, degrading service quality.
  - **Solution**: GateMem introduces incremental memory injection and explicit deletion requests, jointly evaluating utility for authorized updates, access control across contexts, and active forgetting after deletion, highlighting the current trade-off difficulties.

## Implementation and Evaluation
- **Experimental Setup**: GateMem spans four domains (medical, office, education, household) featuring long-form multi-party episodes, incremental memory injection, hidden checkpoints, structured judging, and leak-target annotations.
- **Results**: No method across diverse baselines and backbone models simultaneously achieves strong utility, robust access control, and reliable forgetting.
- **Comparison**:
  - **Long-context Prompting**: Often yields the best governance scores, handling access control and forgetting well, but at a high token cost.
  - **Retrieval-based and External Memory Methods**: Reduce costs significantly but fail to prevent unauthorized access or ensure complete forgetting of deleted information, leading to persistent leakage risks.
- **Conclusion**: Current memory agents are far from being reliable for shared institutional deployment.

#### Summary
GateMem fills the gap in evaluating multi-principal shared-memory agents, emphasizing that "governance" is as critical as "recall" in shared environments. The results demonstrate that current mainstream memory architectures (whether long-context or retrieval-augmented) have significant defects in balancing utility, security, and privacy forgetting. This benchmark provides essential evaluation standards and research directions for developing safer, more ethical shared agents in the future.
