## 1. What the Paper Did
- **Background**: Production LLM agents increasingly rely on real-time search for factual grounding. The prevailing approach is "Native Search Grounding," where model providers bundle retrieval policies, evidence injection, and generation within a single API boundary.
- **Limitations of Existing Work**: This tight coupling makes the grounding process difficult to inspect, tune, reuse, or port. Crucially, it triggers "Search-Induced Verbosity," causing models to violate strict output contracts (e.g., returning explanatory text instead of just entities), which breaks downstream parsing and processing pipelines.

## Core Contributions
- **Proposed Decoupled Search Grounding (DSG)**: A vendor-agnostic architecture that moves grounding outside the reasoning model via an MCP-compatible gateway, exposing provider routing, caching, and context rendering as first-class controls.
- **Challenge 1: Lack of granular control over retrieval cost and latency**. Native solutions are black boxes, leading to high costs and unoptimized performance. DSG addresses this by exposing exact plus semantic caching, retrieval-depth control, and configured fallbacks as explicit controls.
- **Challenge 2: Search-Induced Verbosity breaking output contracts**. Native search often causes models to generate verbose outputs, violating strict format requirements. DSG solves this by decoupling retrieval from generation, ensuring the model receives only cleaned, source-aware context, thereby maintaining high accuracy while strictly adhering to concise output contracts.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated across five frontier models on SimpleQA, FreshQA, and HotpotQA datasets, and deployed in DoorDash's large-scale e-commerce Query Understanding (QIU) production workload.
- **Comparison Results**:
    - **Accuracy vs. Cost**: On SimpleQA, DSG nearly matched native search accuracy (86.1% vs. 87.7%) while reducing search costs by 91%.
    - **Latency & Caching**: DSG achieved a 99.4% warm-cache hit rate, resulting in a 68% reduction in latency.
    - **Production Performance**: In the e-commerce QIU workload, DSG matched or slightly exceeded native search accuracy while cutting search costs by over 98%.
    - **Specific Scenarios**: While native search retains an advantage on recency-sensitive tasks like FreshQA, DSG demonstrates superior overall performance in scenarios requiring control, cost-efficiency, and strict output formatting.

## 4. Conclusion
The paper argues that real-time grounding should be treated as an optimizable interface boundary rather than a fixed model feature. The DSG architecture successfully decouples search from reasoning, significantly reducing cost and latency with negligible accuracy loss, while resolving output format uncontrollability issues inherent in native search. This provides a new architectural paradigm for building efficient, portable, and production-grade LLM agents.
