## 1. What the Paper Does
- **Background**: Software engineering education relies heavily on project-based learning where students produce complex documentation like requirements specs, UML diagrams, and architectural designs. As class sizes grow, the bottleneck in reviewing these technically dense artifacts limits the frequency and quality of formative feedback.
- **Why Existing Work Falls Short**: While automated tools for code grading (via static analysis/unit testing) are mature, providing formative feedback on open-ended software architecture documentation remains challenging. Direct application of LLMs to complex, multi-modal architectural documents lacks robust orchestration, leading to risks of hallucinations or redundant critiques that can misguide students.

## Core Contributions
- **Proposed CAPRA (Configurable Architecture Proficiency Report Assessment)**: A multi-agent LLM system designed to analyze software architecture deliverables and generate personalized, template-compliant LaTeX feedback.
- **Challenge 1: Accurate Multi-modal Document Parsing**. The difficulty lies in simultaneously processing text and complex UML diagrams while maintaining context. CAPRA addresses this by employing a Python-based microservice for multi-modal extraction, using PyMuPDF for text and vision-enabled LLMs (specifically gpt-4o) to parse UML diagrams, ensuring complete structural extraction.
- **Challenge 2: LLM Hallucinations and Educational Reliability**. The challenge is preventing unfounded technical critiques or repetitive advice that reduce pedagogical value. CAPRA introduces a deterministic "Evidence Anchoring" step using fuzzy matching (normalized Levenshtein distance) to verify citations, along with a ConsistencyManager agent that cross-verifies, deduplicates, and merges findings to mitigate hallucinations.

## Implementation and Evaluation
- **Implementation & Deployment**: CAPRA coordinates specialized agents with a Python backend for document extraction. It outputs feedback in a structured LaTeX format.
- **Evaluation Results**: A preliminary empirical evaluation on 10 student reports showed that CAPRA satisfied 88.8% of evaluated criteria under a strict two-rater aggregation rule. It achieved moderate inter-rater agreement with human evaluators (Kappa = 0.582) and processed each report in slightly over 4 minutes.
- **Comparison**: Unlike traditional tools focused solely on code, CAPRA addresses the gap in architectural document feedback. Compared to naive LLM usage, its multi-agent architecture and evidence anchoring significantly enhance feedback credibility and structure, though human oversight remains necessary for subjective dimensions.

## 4. Conclusion
CAPRA demonstrates the viability of multi-agent LLM systems for scaling formative feedback in software architecture education. By combining multi-modal extraction, deterministic evidence verification, and consistency management, it effectively reduces instructor workload. However, human supervision is still essential for highly subjective assessment aspects, indicating room for future improvements in fully automated reliability.
