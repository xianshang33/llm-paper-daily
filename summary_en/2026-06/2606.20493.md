## 1. What the Paper Did
- **Background**: In multi-agent Large Language Model (LLM) systems, agents evaluate each other's outputs to guide collaboration, task allocation, and response selection, forming a closed feedback loop.
- **Why Existing Work Falls Short**: Current multi-agent frameworks (e.g., AutoGen, MetaGPT) lack analytical methods for understanding how evaluator biases propagate. Prior work (e.g., MM-EPC) focused on cross-modal preference collapse but did not address how systematic biases in LLM-as-a-judge scenarios propagate across agents within the same modality, potentially leading to system-wide preference homogenization.

## Core Contributions
- **Proposed "Contagion Networks"**: A formal framework for quantitatively measuring how evaluator biases spread across interacting LLM agents.
- **Challenge 1: How to quantify bias propagation among N agents in arbitrary topologies?**
  - **Difficulty**: Traditional 2x2 cross-modal contagion matrices cannot scale to complex multi-agent interaction networks, making it hard to capture higher-order propagation dynamics.
  - **Solution**: Introduced the Cross-Agent Contagion Matrix $\\Gamma_N$, modeling bias propagation as matrix operations to quantitatively measure bias flow in any agent topology.
- **Challenge 2: How to determine the dynamical state of bias propagation and prevent system collapse?**
  - **Difficulty**: Identifying conditions under which biases attenuate, persist, or cascade, and finding practical ways to suppress such propagation.
  - **Solution**: Established the Propagation Regime Theorem, proving that the spectral radius $\rho(\\Gamma_N)$ governs three regimes (suppression/persistence/cascade), with $\rho(\\Gamma_N) > 1$ being the condition for cascading in fully-connected networks. Demonstrated that increasing the evaluator committee size from k=1 to k=3 reduces effective contagion by 72.4%, keeping the system in the suppression regime.

## Implementation and Evaluation
- **Experimental Setup**: Controlled 3-agent experiment using DeepSeek-chat with three distinct evaluator bias profiles (structured, balanced, evidence-based).
- **Key Results**:
  - Measured the Cross-Agent Contagion Matrix $\\Gamma_3$, finding consistent bias propagation between agents ($\\gamma \\in [0.157, 0.352]$) even within the same underlying model.
  - Observed rapid bias attenuation across hops ($\beta_3 = 0.0055$), confirming the "suppression regime" for homogeneous-model agents.
- **Comparison with Related Work**:
  - Prior work (MM-EPC) reported cross-model contagion coefficients of $\\gamma \\approx 0.85-1.3$.
  - This study shows that homogeneous-model agents produce contagion coefficients 3-5x weaker than cross-model coefficients, indicating a natural advantage in bias suppression.
- **Mitigation Strategy Validation**: Increasing the evaluator committee size from k=1 to k=3 reduced the effective contagion coefficient by 72.4%.
- **Open Source**: Released the Contagion Network experimental framework for community use.

## 4. Conclusion
This paper introduces the "Contagion Networks" framework, formally quantifying evaluator bias propagation in multi-agent LLM systems for the first time. Through theoretical derivation and empirical study, it reveals three propagation regimes governed by the spectral radius and highlights that homogeneous-model agent networks typically reside in a bias suppression state. Crucially, it proposes an actionable strategy—increasing evaluator diversity via committee size—to significantly reduce bias propagation, offering both theoretical insights and practical guidance for building more robust and diverse multi-agent systems.
