## 1. What the Paper Does
- **Background**: Natural Language to Repository Generation (NL2Repo) requires constructing an entire software repository from natural language requirements. Unlike function-level generation, this task demands longer planning horizons, stable cross-file interfaces, and iterative debugging of inconsistencies.
- **Limitations of Existing Work**: Current methods struggle to simultaneously handle long-range planning, maintain interface consistency across multiple files, and manage complex dependencies, leading to deficiencies in structural rationality and functional correctness.

## Core Contributions
- **Proposed CodeTeam**, an LLM-powered multi-agent framework that separates planning, decision-making, and implementation into distinct, coordinated stages.
- **Challenge 1: Complex Global Planning and Interface Consistency**. The difficulty lies in designing software architecture at a macro level while ensuring module interface compatibility. CodeTeam addresses this by having multiple Architect agents draft competing Software Design Sketches (SDS), which are then evaluated, selected, and normalized by a CTO agent into a machine-checkable contract specifying file ownership, public interfaces, and dependency constraints.
- **Challenge 2: Dependency-Aware Implementation and Iterative Repair**. The challenge involves maintaining context boundaries and handling cross-file errors during multi-file generation. CodeTeam employs Developer agents to generate code under a dependency-aware scheduler with lightweight Git-based coordination, while a QA agent runs tests to drive iterative repairs, ensuring functional correctness.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on the synthesis-based SketchEval benchmark and the execution-based NL2Repo-Bench. Compared CodeTeam's Prompt Engineering (PE) and Supervised Fine-Tuning (SFT) variants against corresponding CodeS baselines.
- **Key Results**:
    - On SketchEval, CodeTeam (PE) and CodeTeam (SFT) improved overall SketchBLEU by 4.1 and 2.9 absolute points, respectively.
    - On NL2Repo-Bench, CodeTeam achieved the highest average test pass rates (34.6% for PE, 42.3% for SFT), confirming that design improvements translate to functional correctness.
- **Ablation Studies**: Project-specific developer allocation and retrieval-augmented planning contributed significantly to SketchBLEU improvements (9.9% and 8.1% relative increase, respectively), while Git-based coordination provided smaller but consistent complementary gains.

## 4. Conclusion
CodeTeam effectively addresses long-range planning and cross-file consistency challenges in repository-level code generation through a multi-agent collaboration mechanism with clear role divisions (Architect, CTO, Developer, QA). Experiments demonstrate that the method outperforms existing baselines in both code structure quality and functional correctness, with retrieval-augmented planning and specific resource allocation being critical to performance gains.
