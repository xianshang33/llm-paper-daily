## 1. What the Paper Did
- **Background**: Memory safety vulnerabilities remain a significant threat even in projects with extensive fuzzing and manual auditing. While Large Language Models (LLMs) show promise in detecting these vulnerabilities, they suffer from unreliability, hallucination risks, and scalability challenges for repository-scale codebases.
- **Why Existing Work Falls Short**: Current LLM-based methods either have high false positive rates (due to hallucinations), high false negative rates (due to limited model capability or coverage), or prohibitive costs (running advanced models on entire repositories). Traditional methods like fuzzing and static analysis struggle with bugs requiring complex semantic reasoning.

## Core Contributions
- **Proposed**: Revelio, a cost-efficient, end-to-end agentic framework for memory-safety vulnerability discovery.
- **Challenge 1: Hallucination leading to high false positives.**
  - **Difficulty**: LLMs may generate plausible but non-existent vulnerability reports, making them untrustworthy.
  - **Solution**: Revelio generates an executable "Proof-of-Vulnerability" and verifies it with a deterministic sanitizer. It only reports vulnerabilities that can be reproduced and confirmed, effectively eliminating hallucinations.
- **Challenge 2: High cost and scalability issues for repository-scale analysis.**
  - **Difficulty**: Directly using frontier LLMs for full-repository analysis is prohibitively expensive.
  - **Solution**: Revelio uses inexpensive LLMs and lightweight static analysis to generate and rank vulnerability hypotheses, performing deep verification only on high-confidence candidates, thereby significantly reducing token usage and computational costs.

## Implementation and Evaluation
- **Evaluation Setup**: Evaluated on seven production-quality projects fuzzed for 5-8 years and 100 randomly selected Arvo projects from the CyberGym benchmark.
- **Key Results**: Revelio discovered 19 previously unknown memory-safety vulnerabilities with approximately one hour per project and a total cost of $300.
- **Comparison**: On benchmarks, Revelio outperformed frontier coding agents across diverse backbone models at comparable token costs. The results demonstrate scalable and trustworthy end-to-end LLM-based memory-safety vulnerability detection.

## 4. Conclusion
Revelio effectively addresses the hallucination and high-cost issues of LLMs in vulnerability detection by introducing executable proof mechanisms and a layered cost-control strategy. It successfully identified new memory safety vulnerabilities in mature software projects, demonstrating its efficiency and reliability for practical deployment and offering a new solution for security auditing of large-scale codebases.
