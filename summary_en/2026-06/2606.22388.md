## 1. What the Paper Did
- **Background**: LLM agents increasingly operate in large-scale tool ecosystems where real-world tasks require discovering relevant tools, inferring implicit sub-goals, and adapting over long horizons. Due to context limits, agents rely on retrieval to access only subsets of tools, making tool use a retrieval-mediated process.
- **Why Existing Work Falls Short**: Existing benchmarks rarely evaluate planning under retrieval-limited tool visibility. They often assume fixed, fully visible toolsets, explicit intermediate goals, clean tool descriptions, or one-shot retrieval, thereby abstracting away the uncertainty and noise inherent in real-world large-scale tool environments.

## Core Contributions
- **Proposed PlanBench-XL**: An interactive and dynamic benchmark comprising 327 retail tasks over 1,665 tools, designed to test long-horizon planning in large-scale tool ecosystems.
- **Challenge 1: Partial Tool Visibility and Implicit Sub-goal Exploration**. In massive tool spaces, agents cannot see all tools at once and must iteratively retrieve tools to uncover intermediate evidence. PlanBench-XL addresses this by designing multi-step workflows that force agents to iteratively discover and invoke tools to infer implicit sub-goals.
- **Challenge 2: Tool Unreliability and Dynamic Adaptation**. Real-world tools may be missing, failing, or misleading. PlanBench-XL introduces an optional "blocking mechanism" that simulates unpredictability (e.g., failed or distracting functions), forcing agents to detect disrupted paths and adapt their plans at runtime.

## Implementation and Evaluation
- **Implementation**: The benchmark is situated in the retail domain, with each instance averaging ~25 turns. It evaluates 10 leading LLMs under both block-free and various blocking conditions.
- **Results**: Massive-tool planning remains challenging. GPT-5.4 achieves 51.90% accuracy in block-free settings but collapses to 11.36% under the most severe blocking condition.
- **Comparison**: Unlike prior benchmarks (e.g., ToolBench, RestBench) that assume clean or fixed toolsets, PlanBench-XL reveals agent vulnerabilities when error signals are absent or recovery requires long alternative paths. It demonstrates a significant performance drop in noisy environments, highlighting the limitations of current models compared to the idealized settings of previous works.

## 4. Conclusion
PlanBench-XL fills the gap in evaluating LLM agents' long-horizon planning capabilities in large, imperfect tool environments. By introducing partial visibility and dynamic blocking, it realistically simulates real-world uncertainties. The results show that while top models perform adequately in ideal conditions, they lack robustness against tool failures and retrieval noise, underscoring the urgent need for more adaptive and robust planning algorithms.
