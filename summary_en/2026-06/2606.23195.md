## 1. What the Paper Did
- **Background**: Large Language Model (LLM) agents increasingly rely on memory systems for long-term coherence. Recent studies highlight memory degradation during continuous consolidation.
- **Limitations of Existing Work**: Prior research assumes that input experiences are unbiased. However, agents are often guided by biased evaluators (e.g., reward models with systematic preferences), leading to biased experiences. Existing works fail to address how these biases propagate across time through memory systems.

## Core Contributions
- **Proposed a Concept and Metric**: Formally defined "Memory Contagion"—the cross-temporal propagation of evaluator bias via agent memory—and introduced $\Gamma_{temporal}$ as a metric to measure this phenomenon.
- **Challenge 1: Isolating the root cause of bias propagation**. It is difficult to distinguish whether bias amplification stems from flawed consolidation mechanisms or biased inputs. The paper demonstrates that Memory Contagion occurs even under "perfect consolidation" (oracle condition), proving that biased input is a sufficient cause for contagion ($\Gamma_A > 0$).
- **Challenge 2: Understanding the interaction between consolidation and bias types**. It is challenging to predict how consolidation affects different biases. The paper reveals a bias-type-dependent interaction: consolidation robustly attenuates length bias but preliminarily amplifies authority bias, uncovering a previously unknown dynamic.

## Implementation and Evaluation
- **Experimental Setup**: A four-phase empirical study covering two bias types: length preference and authority bias.
- **Key Results**:
    1. **Existence**: Memory Contagion is confirmed with $\Gamma_A = 13.18$ for length bias and $\Gamma_A = 11.45$ for authority bias under oracle conditions.
    2. **Dual Effect of Consolidation**: Consolidation attenuates length bias ($\Gamma_B = 2.03$) but potentially amplifies authority bias ($\Gamma_B = 16.80$).
    3. **No Safe Threshold**: Bias propagation is detected at contamination rates as low as $p=0.2$.
    4. **Mechanism**: Content contamination is the dominant propagation channel, not the retrieval mechanism.
- **Comparison**: Unlike prior work focusing on single-agent RL bias or simple memory degradation, this work exposes a critical vulnerability in cross-agent, cross-temporal memory externalization.

## 4. Conclusion
This paper identifies "Memory Contagion" as a critical vulnerability in LLM agent memory designs. It shows that biased experiences, when stored, propagate bias to future agents even with perfect consolidation. Furthermore, consolidation has divergent effects on different bias types (attenuating length bias vs. amplifying authority bias). These findings challenge existing assumptions about memory consolidation and provide formal tools for measuring and mitigating cross-temporal bias propagation.
