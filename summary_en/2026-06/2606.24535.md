## 1. What the Paper Did
- **Background**: As LLM systems evolve from isolated assistants to fleets of interacting agents, memory management transitions from a simple retrieval problem to a governed distributed-systems challenge involving scoped access, temporal correctness, provenance, and policy-controlled propagation.
- **Limitations of Existing Work**: Current memory systems are designed around single-agent abstractions (one user, one conversation) and fail to address fleet-scale requirements. Relying solely on long-context retrieval is insufficient for production environments, leading to failures such as unauthorized leakage, stale propagation, contradiction persistence, and provenance collapse due to a lack of explicit system-level abstractions.

## Core Contributions
- **Proposed MemClaw**, a production-grade multi-tenant memory service, and **ArgusFleet**, an evaluation harness. The paper formalizes the "fleet-memory" problem and defines four system-level primitives: scoped retrieval, temporal supersession, provenance tracking, and policy-governed memory propagation.
- **Challenge 1: How to ensure traceable memory provenance without compromising performance?**
  - **Difficulty**: Tracking the origin and derivation chains of information in complex agent interactions is computationally expensive and error-prone.
  - **Solution**: By implementing explicit provenance tracking primitives, MemClaw successfully reconstructed 100% of depth-four derivation chains with correct writer identity at sub-second per-hop latency.
- **Challenge 2: How to achieve efficient memory propagation while maintaining strict isolation?**
  - **Difficulty**: Balancing security (preventing cross-tenant leakage) with availability (ensuring rapid intra-fleet visibility) is difficult; naive batched probing introduces significant latency.
  - **Solution**: Through policy-governed memory propagation, the system achieved zero cross-fleet leakage and optimized write-to-visible latency to a single search round-trip under strong write mode, avoiding the tens-of-seconds delay of naive approaches.

## Implementation and Evaluation
- **Implementation & Deployment**: The authors implemented MemClaw, a live production multi-tenant memory service, and developed ArgusFleet to empirically measure its performance against four governance dimensions via a live REST API.
- **Evaluation Results**:
  - **Provenance**: All 50 depth-four derivation chains were reconstructed with correct writer identity at sub-second latency.
  - **Propagation & Isolation**: High intra-fleet visibility was demonstrated with zero observed cross-fleet leakage. Latency was minimized to one search round-trip.
  - **Negative Results & Architectural Issues Discovered**:
    1. **Asymmetric Scope Enforcement**: Tenant isolation held, but sub-tenant scope was initially bypassed on direct GET-by-id requests for agent-scoped credentials (remediated during the study).
    2. **Pipeline Ordering Conflict**: A synchronous near-duplicate gate could prematurely reject contradictory writes before the asynchronous contradiction detector could evaluate them, undermining the contradiction supersession mechanism.
- **Comparison**: Instead of traditional baseline comparisons, this study focuses on measuring a live production service. It highlights real-world architectural insights and negative results, demonstrating that design-only treatments miss critical enforcement and pipeline-ordering failures exposed by live evaluation.

## 4. Conclusion
The paper argues that production multi-agent memory cannot rely solely on long-context retrieval but must be treated as a governed distributed-systems problem. By introducing explicit system-level abstractions (scope, temporality, provenance, and policy), MemClaw demonstrates effective shared state management at fleet scale. Crucially, the live evaluation uncovered key architectural flaws, such as scope enforcement gaps and pipeline race conditions, underscoring the necessity of empirical assessment in real-world deployments to identify failures that theoretical designs overlook.
