## 1. What the Paper Did
- **Background**: As autonomous agents handle increasingly complex multi-step and multi-agent tasks, their execution trajectories have grown beyond the limits of even the largest context windows. Fault attribution, which involves isolating the specific agent or step responsible for a failure, is critical for system monitoring and reliability.
- **Why Existing Work Fails**: Current methods typically load the entire trajectory into an LLM's context window. This approach suffers from attention dilution as trajectories lengthen and fails completely when traces exceed context limits. State-of-the-art fault detectors show significant performance drops on benchmarks like Who&When and TRAIL when dealing with million-token trajectories.

## Core Contributions
- **Proposed SAFARI**: A framework for Scaling long-horizon Agentic Fault AttRibution via active Investigation, replacing passive linear context loading with an active, tool-augmented diagnostic loop.
- **Challenge 1: Context Window Limits and Attention Dilution**. Processing entire long trajectories passively leads to diluted attention and hard constraints on input length. **Solution**: SAFARI equips LLMs with a specialized toolbox to read and search specific trajectory segments on demand, decoupling diagnostic accuracy from architectural context limits.
- **Challenge 2: Cross-turn Reasoning over Long Horizons**. Identifying faults in long trajectories requires maintaining logical connections across many steps, which is difficult without persistent state. **Solution**: The framework introduces a persistent Short-Term Memory (STM) for cross-turn reasoning, allowing the model to effectively track and attribute faults even when they are distant from the failure point.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on the Who&When dataset (within a 1M token budget) and the TRAIL GAIA subset (within a 25K token budget).
- **Results vs. SOTA**:
    - SAFARI outperforms state-of-the-art results by 20% on the Who&When dataset.
    - It exceeds SOTA by 19% on the TRAIL GAIA subset.
- **Extreme Scenario Performance**: Significantly, SAFARI maintains a precision of 0.58 even when the target fault resides 5x beyond the model's native context window, a scenario where traditional evaluators fail entirely.

## 4. Conclusion
SAFARI introduces a novel paradigm for fault attribution in long-horizon agentic systems by leveraging "active investigation." By combining specialized tools for segment retrieval with persistent short-term memory, it overcomes the physical limitations of LLM context windows and the issue of attention dilution. Experiments demonstrate that SAFARI not only significantly outperforms existing SOTA methods on standard benchmarks but also maintains robust diagnostic capabilities in extreme long-range dependency scenarios, offering a crucial advancement for the observability and reliability of large-scale multi-agent systems.
