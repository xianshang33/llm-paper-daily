## 1. What the Paper Does
- **Background**: Reinforcement learning (RL) post-training for Large Language Model (LLM) agents has shifted towards long-horizon, multi-turn interactions. The central challenge is assigning sparse terminal rewards to intermediate decisions. Group-based RL methods (e.g., GRPO, GiGPO) are attractive as they avoid learning a value network (Critic) by reusing sampled rollouts to estimate local advantages.
- **Why Existing Work Fails**: Current group-based methods rely on a fundamental but flawed assumption: that steps grouped together are equivalent for credit assignment. This leads to a "state-action credit mismatch":
    1. On the state side, observation-hash partitioning is too fine-grained, creating singleton groups with zero step-level signal.
    2. On the action side, using a single within-group mean is too coarse, mixing state-value estimation with action-specific credit.

## Core Contributions
- **Proposed**: BiPACE (Bisimulation-Guided Policy Optimization with Action Counterfactual Estimation), a drop-in advantage estimator that fixes both state and action mismatches without adding a Critic, auxiliary loss, or extra rollouts.
- **Challenge 1: Sparse Signal from Overly Fine State Grouping**. Traditional hashing creates many singleton groups, preventing effective relative advantage calculation. BiPACE addresses this via BiGPO, which clusters steps based on cosine distance in the actor's hidden-state geometry. This serves as an empirical, policy-induced proxy for bisimulation, substantially reducing the singleton rate and ensuring behavioral equivalence within groups.
- **Challenge 2: Coarse and Mixed Action Credit Assignment**. Traditional methods use a single group mean as a baseline, failing to distinguish the value of different actions in the same state. BiPACE addresses this via PACE, which recenters returns within each behavioral cluster using action-conditioned peer baselines. Its Q-style instance non-parametrically estimates local $Q(s,a) - V(s)$, precisely isolating action-specific credit.

## Implementation and Evaluation
- **Implementation & Overhead**: BiPACE is a drop-in replacement. The measured BiPACE-specific overhead is only 11.3% of a single training step's wall-clock time on ALFWorld/Qwen2.5-7B.
- **Evaluation Results**:
    - **ALFWorld (Qwen2.5-7B)**: BiPACE_Q raises overall validation success from GiGPO's 90.8% to $97.1\\pm0.9$. Crucially, it crosses the 95% threshold on every seed, which GiGPO never achieves within the same budget.
    - **ALFWorld (Qwen2.5-1.5B)**: BiPACE reaches $93.5\\pm1.2$, outperforming GiGPO's 86.7%.
    - **Other Benchmarks**: On WebShop and TextCraft, BiPACE improves over both GRPO and GiGPO at both model scales.
- **Comparison**: By changing the estimator's comparison unit from surface identity to approximate behavioral equivalence plus action-side counterfactuals, BiPACE achieves superior stability and performance compared to SOTA methods like GiGPO and GRPO.

#### Summary
BiPACE addresses the state-action credit mismatch in group-based RL for long-horizon LLM agents. By introducing BiGPO for hidden-state clustering and PACE for action-conditioned baselines, it significantly improves credit assignment accuracy without the cost of a Critic network or additional sampling. Experiments demonstrate that BiPACE substantially outperforms existing SOTA methods (GiGPO, GRPO) across multiple benchmarks with manageable computational overhead, offering a superior advantage estimation strategy for critic-free LLM agent training.
