## 1. What the Paper Does
- **Background**: For LLM agents in multi-step interactive environments, a key challenge is effectively utilizing accumulated interaction experience. Existing approaches typically separate this into two paths: storing experience as external natural-language rules for prompting, or using trajectories and feedback to update model parameters.
- **Limitations of Existing Work**: External rules are interpretable but can fall out of sync with the evolving policy, becoming stale or misleading. Parameter updates improve global policy but offer limited correction for local mistakes in sparse-reward settings, failing to address specific errors timely.

## Core Contributions
- **Proposed JERP (Joint Learning of Experiential Rules and Policies)**: A framework that jointly updates a long-term experiential-rule pool and the agent's policy from the same interaction trajectories.
- **Challenge 1: Desynchronization between rules and policy**. As the policy evolves during training, static rules may become obsolete, while internal model memory lacks explicit guidance. **Solution**: JERP dynamically revises the rule pool after each episode by comparing current rollouts with reference successful trajectories, ensuring the rule pool remains aligned with the evolving policy.
- **Challenge 2: Difficulty in correcting local errors under sparse rewards**. In complex tasks, sparse feedback makes it hard to correct consequential local mistakes early. **Solution**: JERP retrieves task-relevant rules at decision time to condition the agent, providing immediate correction for recurring local errors, while gradually absorbing stable behaviors into the model parameters for robust generalization.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on AlfWorld and WebShop benchmarks, which represent complex interactive task environments.
- **Results**: JERP yields consistent gains in decision performance for complex interactive tasks compared to baseline methods.
- **Comparison**: By coupling rule updates with policy optimization, JERP outperforms methods that rely solely on external rules or parameter fine-tuning. It combines the quick error-correction capability of rule-based methods with the global generalization of learning-based methods.

## 4. Conclusion
This paper addresses the inefficiency in experience utilization for LLM agents by proposing JERP. By jointly learning experiential rules and policies, the framework synchronizes dynamic rule maintenance with parameter updates, effectively overcoming challenges related to rule obsolescence and local error correction in sparse-reward settings. Experiments on AlfWorld and WebShop demonstrate the effectiveness and superiority of JERP, offering a new perspective for enhancing the long-term learning capabilities of LLM agents.
