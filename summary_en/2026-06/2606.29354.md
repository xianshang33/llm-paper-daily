## 1. What the Paper Does
- **Background**: Chain-of-Thought (CoT) significantly improves Large Language Models (LLMs) on complex reasoning tasks, but the generated natural language rationales are verbose and misaligned with efficient machine reasoning, leading to high computational costs and latency.
- **Why Existing Work Falls Short**: Prompt optimization methods only refine surface instructions without creating reusable symbolic systems; program-based methods rely on human-designed intermediate languages; RL-based approaches incur high training costs and instability; compression methods reduce length but do not yield evolvable discrete "languages" for multi-agent sharing.

## Core Contributions
- **Proposed a framework** called Communicative Language Symbolism Routing (CLSR). This test-time framework enables multiple LLM agents to autonomously invent, evolve, and share compact Language Symbolism Frameworks (LSFs), while a latent-free router adaptively selects and composes these languages per query to optimize the accuracy-token trade-off.
- **Challenge 1: How to autonomously invent efficient and reusable symbolic languages?**
  - **Difficulty**: Natural language is redundant, and enabling LLMs to create compact, logical symbol systems from scratch that are mutually intelligible among agents is highly challenging.
  - **Solution**: CLSR treats each LSF as a reusable protocol with compact symbols, usage rules, and message-passing contracts. It improves LSFs through an evolutionary loop driven by correctness and token cost, creating a socialized symbolic system shared among agents.
- **Challenge 2: How to dynamically balance efficiency and accuracy during inference?**
  - **Difficulty**: Queries vary in difficulty, requiring different reasoning complexities; fixed patterns cannot simultaneously optimize speed for simple queries and precision for hard ones.
  - **Solution**: A latent-free router adaptively selects strategies based on query difficulty: invoking a single low-cost LSF for simple queries, ensembling multiple LSFs for medium ones, or executing multi-round LSF composition protocols for harder queries, thereby allocating computational resources on demand.

## Implementation and Evaluation
- **Implementation & Deployment**: CLSR is a test-time framework requiring no expensive pre-training or fine-tuning. It involves multiple agents for LSF evolution and a router for query adaptation. The code is publicly available.
- **Evaluation Results**: Across challenging benchmarks, CLSR reduces latency-oriented generated token completion by 3~6x compared to standard CoT while maintaining accuracy.
- **Comparison with Related Work**:
  - Vs. Prompt Optimization: CLSR generates persistent, composable symbolic systems rather than just optimizing text instructions.
  - Vs. Program-based Methods: CLSR achieves self-discovered symbolic languages instead of relying on human-designed intermediates.
  - Vs. RL Methods: CLSR avoids high training costs and instability, offering a lighter and more modular approach.
  - Theoretical Contribution: Derives an information-theoretic lower bound on token cost under arbitrary symbolism and shows that multi-round LSF protocols conditionally subsume program-execution pipelines.

## 4. Conclusion
This paper proposes the CLSR framework to address the inefficiency of LLMs using CoT. By enabling agents to autonomously evolve and share compact symbolic language frameworks combined with adaptive routing, CLSR significantly reduces token consumption and latency while preserving reasoning accuracy. The method outperforms existing CoT and various optimization strategies empirically and establishes theoretical links between symbolic communication and information costs, providing a new paradigm for efficient multi-agent reasoning.
