## 1. What the Paper Does
- **Background**: Multi-agent deliberation among LLMs improves reasoning, but deployment requires deciding when an answer is reliable enough to act on autonomously versus when to defer to human review.
- **Limitations of Existing Work**: Current approaches either operate at fixed rounds with only marginal coverage (e.g., split conformal prediction) or rely on heuristic consensus thresholds without explicit wrong-action budgets. They fail to provide per-instance, per-round reliability bounds necessary for adaptive stopping.

## Core Contributions
- **Proposed a Budgeted Act-or-Defer Decision Framework with Local Reliability Bounds**: This framework prospectively converts a user-declared wrong-action budget into an auditable operating point before deployment under explicitly stated assumptions.
- **Challenge 1: How to provide fine-grained reliability guarantees during dynamic multi-round debates?**
  - **Difficulty**: Traditional conformal prediction offers distribution-free guarantees that struggle to capture local features of evolving debate states and cannot adapt to confidence changes across rounds.
  - **Solution**: The paper maps debate prefixes to a low-dimensional state space and computes a k-nearest-neighbor (k-NN) lower confidence bound on state-conditional correctness using calibration data. Action is taken only when this bound exceeds a user-specified reliability threshold, enabling adaptive per-round decisions.
- **Challenge 2: How to strictly control wrong-action risks across tasks of varying difficulty?**
  - **Difficulty**: The same absolute error budget has different implications for tasks of different difficulties, and multiple error sources (calibration failure, residual risk, representation gap) must be separated.
  - **Solution**: The method controls wrong actions via the decomposition $\beta = \\delta + \\alpha + \\varepsilon_{\\mathrm{act}}$. It sets budgets relative to each task's final-round error using training data and evaluates safety via normalized budget usage, supported by falsification-style diagnostics for each assumption.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on six benchmarks against nine baselines.
- **Key Results**:
  - The method used only 9–12% of the pre-declared budget on activated datasets.
  - It achieved up to 84% automation rate and 96% acted-on accuracy.
  - On stress-test datasets, it preferred deferring over forcing unreliable automation, demonstrating robust safety.
- **Comparison**: Unlike methods relying on post-hoc threshold search, this approach prospectively establishes an auditable act-or-defer point. It significantly reduces human intervention while maintaining high accuracy and strict error control compared to baselines.

## 4. Conclusion
This paper introduces a novel stopping mechanism for multi-agent LLM deliberation by constructing local reliability lower bounds for adaptive act-or-defer decisions. It provides theoretical error control guarantees and adapts to task difficulties through relative budgeting. Experiments demonstrate that the method effectively controls wrong-action risks while achieving high automation and accuracy, offering an auditable solution for safe LLM deployment.
