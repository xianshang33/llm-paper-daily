## 1. What the Paper Did
- **Background**: Coding agents are rapidly becoming a major application of agentic LLMs, but efficient serving remains challenging. Progress requires understanding real workload patterns.
- **Limitations of Existing Work**: Existing public traces and benchmarks fail to capture real, day-to-day coding-agent usage across multiple agents and model families. For instance, Splitwise focuses on general user interactions without multi-step tool calls, while benchmarks like SWE-bench measure model accuracy on narrow tasks rather than capturing the diversity needed for serving-system analysis.

## Core Contributions
- **Proposed TraceLab Dataset and Analysis Framework**: Collected and released a trace of ~4,300 coding-agent sessions, containing ~350,000 LLM steps and ~430,000 tool calls from daily use of Claude Code and Codex.
- **Challenge 1: Lack of real-world workload characterization for coding agents hinders system optimization.**
  - **Difficulty**: Coding agents involve long autonomous loops, complex tool chains, and dynamic contexts, which existing benchmarks do not reflect.
  - **Solution**: Built a pipeline to extract, normalize, and anonymize data from real usage, providing the first large-scale cross-provider trace that reveals key characteristics like long contexts, short outputs, and heavy-tailed tool calls.
- **Challenge 2: Current serving systems are not optimized for specific coding agent load patterns (e.g., prefix cache efficiency, tool latency).**
  - **Difficulty**: High overhead from repeated prefilling of history and variable tool latencies are not adequately addressed by traditional caching and scheduling.
  - **Solution**: Identified concrete optimization opportunities based on data analysis, including lower-overhead tool calling, append-length-aware prefill, semantic-aware tool-latency prediction, and improved KV-cache management around human-paced gaps.

## Implementation and Evaluation
- **Scale and Coverage**: TraceLab includes data from 43 developers over ~8 months, spanning 20+ model versions. In contrast, benchmarks like SWE-bench contain limited static tasks lacking real-world interaction dynamics.
- **Key Findings**:
  - **Session Characteristics**: Average request involves 8.8 LLM calls and 10.8 tool calls, taking 4.3 minutes on average (P90 > 6.4 mins), showing significant long-tail behavior.
  - **Context Management**: Context grows with iterations but undergoes compaction near limits; Codex shows unique micro-context reduction.
  - **Cache Efficiency**: Prefix cache hit rates are high but imperfect. While reading from cache is ~10x cheaper than fresh prefill, accumulated history length makes efficient KV-cache management critical.
- **Comparison Advantage**: Unlike accuracy-focused benchmarks, TraceLab provides empirical evidence from a system-serving perspective, guiding latency and throughput optimizations.

## 4. Conclusion
This paper fills the gap in real-world coding agent workload data by releasing the TraceLab dataset. Analysis reveals that coding agent workloads feature long autonomous loops, long contexts with short outputs, diverse/heavy-tailed tool calls, and imperfect prefix cache hit rates. These insights point to specific serving optimizations such as reduced tool calling overhead, better prefill strategies, and enhanced KV-cache management, laying the groundwork for efficient future serving systems.
