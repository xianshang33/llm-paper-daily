## 1. What the Paper Did
- **Background**: World models provide LLM agents with foresight by predicting action consequences before execution, which is crucial for long-horizon planning. However, existing approaches often rely on static, offline-trained models.
- **Why Existing Work Falls Short**: Frozen or offline-tuned world models suffer from distribution shifts during deployment. Unreliable foresight can be ignored, misused, or even degrade downstream decision-making because these models lack mechanisms to self-correct based on real-time interaction feedback without expensive parameter updates.

## Core Contributions
- **Proposed WorldEvolver**: A self-evolving world model framework that revises its deployment-time context while keeping the downstream agent and all model parameters frozen.
- **Challenge 1: How to leverage real action transition experiences for better prediction?**
  - **Difficulty**: Pre-trained knowledge may not cover specific environment dynamics, and online parameter updating is computationally prohibitive.
  - **Solution**: Introduces Episodic Memory, which exploits accumulated real action transitions through retrieval-based simulation, providing concrete cases as prompt-level evidence without weight updates.
- **Challenge 2: How to extract generalizable rules from errors and prevent noise from bad predictions?**
  - **Difficulty**: Automatically extracting heuristic insights from prediction-observation mismatches is complex, and low-confidence predictions introduce noise into reasoning.
  - **Solution**: Introduces Semantic Memory to extract persistent heuristic rules from mismatches, and Selective Foresight to filter out low-confidence predictions before integrating them into the agent's reasoning context.

## Implementation and Evaluation
- **Implementation & Deployment**: WorldEvolver operates as a standalone module that dynamically constructs prompts using external memories (episodic and semantic) at test time, requiring no changes to the underlying LLM weights.
- **Evaluation Results**:
  - Evaluated on ALFWorld and ScienceWorld datasets.
  - Measured world model prediction accuracy on Word2World and downstream agent success rate on AgentBoard.
  - Achieved the highest prediction accuracy across three different backbone models.
  - Outperformed other world model baselines in terms of downstream agent success rate.
- **Comparison**: Compared to frozen and offline-tuned models, WorldEvolver significantly enhances predictive fidelity and planning performance by leveraging test-time memory revision to handle distribution shifts effectively.

## 4. Conclusion
The proposed WorldEvolver framework addresses the reliability issue of world models in long-horizon LLM agent tasks by decoupling parameter updates from context revision. By synergizing Episodic Memory, Semantic Memory, and Selective Foresight, it continuously optimizes foresight capabilities using test-time interaction feedback without additional training costs, thereby significantly improving agent planning efficiency and success rates.
