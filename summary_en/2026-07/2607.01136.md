## 1. What the Paper Did
- **Background**: As Large Language Model (LLM) agent skills rapidly grow (reaching 1.43 million), they evolve from isolated files into artifacts with complex dependencies. Developers build new skills by reusing existing skills, software packages, and external services, creating layered dependency structures.
- **Why Existing Work Fails**: Current dependency management mechanisms have not kept pace with this reuse practice. Skill dependencies are implicitly scattered across metadata, natural language instructions, and scripts rather than being explicitly declared. This opacity leads to duplicated dependencies, inconsistent installations, and difficulties in tracking provenance and versions. Traditional package-centric SBOM tools fail to handle this mixed structure of natural language and code dependencies.

## Core Contributions
- **Proposed Agent Skill Supply Chains (ASSCs) and SkillDepAnalyzer**: Borrowing from Software Bill of Materials (SBOMs), this framework characterizes mixed skill-package-service dependency graphs to close the management gap.
- **Challenge 1: How to extract implicit dependencies from unstructured natural language and code?**
  - **Difficulty**: Unlike traditional code with standard declaration files, skill dependencies are hidden in natural language instructions, metadata, and script logic, making them hard for traditional parsers to identify.
  - **Solution**: Designed SkillDepAnalyzer to capture natural-language dependency evidence and model skills as dependency-bearing artifacts, accurately recovering skill metadata and complete dependency graphs.
- **Challenge 2: How to comprehensively assess structural risks and security signals in a large-scale skill ecosystem?**
  - **Difficulty**: Inspecting individual skill documents misses security signals hidden in deep dependency chains. The million-scale dependency network is complex, featuring recursive reuse and hidden package inventories.
  - **Solution**: Applied SkillDepAnalyzer to over 1.43 million skills to construct ASSCs. Analyzed structural diversity (identifying four structural patterns) and used dependency chain analysis to uncover malicious skills and security risks that single-point inspections miss.

## Implementation and Evaluation
- **Benchmark Performance**: On the SKILL-DEP benchmark, SkillDepAnalyzer accurately and comprehensively recovers skill metadata and dependency graphs.
- **Comparison Results**: Substantially outperforms both LLM-based baselines and traditional package-centric SBOM tools, which struggle with natural language dependency evidence and mixed dependency graphs.
- **Large-Scale Empirical Analysis**: Analysis of 1.43M+ skills revealed four structural patterns: skill metadata is "activation-ready but governance-poor"; dependency graphs span skills, packages, and services with concentrated reuse; recursive reuse expands graphs and creates hidden package inventories; and skill dependency clusters form around related workflows.
- **Security Findings**: Demonstrated that inspecting skills alone is insufficient for security, as relevant signals hide in dependencies. The team identified and reported known malicious skills persisting in ASSCs to their developers.

## 4. Conclusion
This paper highlights the critical lack of dependency management in the LLM agent skill ecosystem. It proposes the ASSCs concept and SkillDepAnalyzer tool to address the opacity and security risks caused by implicit dependencies. Through large-scale empirical study, it proves the importance of dependency chain analysis for discovering hidden security risks. The paper provides concrete recommendations for skill infrastructure maintainers (e.g., registry managers) and developers, including typed dependency manifests, first-class dependency-cluster management, risk-warning audit commands, and lockfile-like records, to enhance the security and governability of the entire skill supply chain.
