## 1. What the Paper Did
- **Background**: Memory for long-horizon LLM agents is a "contract" defining what information future decisions can access. The common approach appends past observations, tool calls, and reflections to every prompt, which, while easy to implement, creates a jumbled mixture where the impact of individual memory components is difficult to isolate.
- **Limitations of Existing Work**: Traditional accumulating context methods lead to unbounded prompt growth and mix disparate information sources, making it impossible to precisely evaluate the independent contribution of specific memory layers (e.g., skill retrieval or state storage) due to lack of ablativity and interpretability.

## Core Contributions
- **Proposed AgenticSTS**: A bounded-memory testbed instantiated in *Slay the Spire 2*. It introduces a "bounded contract" where each decision is made from a fresh user message assembled via typed retrieval, without appending raw cross-decision transcripts. This keeps prompts bounded and allows for modular ablation studies.
- **Challenge 1: Context Bloat and Noise in Long-Horizon Tasks**. As decision steps increase, traditional methods exhaust context windows and accumulate irrelevant noise, diluting model attention. **Solution**: The bounded contract assembles prompts from scratch for each decision, retrieving only structured memory fragments relevant to the current step, ensuring concise and relevant context without无序 accumulation of history.
- **Challenge 2: Difficulty in Attributing Performance to Specific Memory Components**. In complex interactions, it is hard to distinguish whether success/failure stems from memory retrieval mechanisms, skill libraries, or base reasoning. **Solution**: The framework enables isolated ablation experiments, allowing specific memory layers (e.g., strategic skills) to be toggled on/off. By comparing win rates across configurations, it quantitatively analyzes how explicit memory layers shape long-horizon decisions.

## Implementation and Evaluation
- **Implementation**: The testbed is built on *Slay the Spire 2*, a closed-rule, stochastic deck-building game requiring hundreds of tactical and strategic decisions. The authors released a reproducible suite including 298 completed trajectories, condition tags, frozen memory/skill snapshots, prompt records, and analysis scripts.
- **Evaluation Results**:
    - **Baseline Comparison**: Public benchmarks show frontier LLMs achieving 0% win rates at the lowest difficulty across five configurations, compared to a 16% human win rate, indicating the task is challenging but not saturated.
    - **Ablation Study**: In fixed-A0 ablations, enabling the triggered strategic skills layer yielded the largest observed performance difference. The no-store baseline won 3/10 games, while adding the skill layer increased wins to 6/10. While statistical significance is limited by sample size (Fisher exact p ≈ 0.37), the directional improvement is clear.
    - **Nature of Comparison**: Comparisons with other backbones and public accumulating-context baselines are operational rather than strictly controlled tests of the contract variable, focusing on validating the methodology's utility.

## 4. Conclusion
This paper presents AgenticSTS, a bounded-memory testbed for studying long-horizon LLM agent memory. By introducing a typed-retrieval bounded memory contract, it addresses the issues of information mixing and non-ablativity in traditional accumulating context methods. Experiments in *Slay the Spire 2* demonstrate that explicit strategic skill memory layers significantly improve agent win rates. The platform provides standardized trajectory data and reproducible tools, offering a validated methodology for the community to study how explicit memory layers influence long-horizon decision-making.
