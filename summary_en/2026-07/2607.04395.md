## 1. What the Paper Did
- **Background**: The rapid scaling of deep learning models has increased demand for hardware-specific kernel optimization. While NVIDIA GPUs benefit from a mature CUDA ecosystem, emerging AI accelerators like AWS Trainium and Inferentia lack automated kernel generation and optimization solutions.
- **Why Existing Work Falls Short**: Current LLM-based agentic approaches (e.g., CUDA-Agent) are tailored to CUDA and do not address the unique challenges of Neuron hardware. Programming via the Neuron Kernel Interface (NKI) involves complex multi-engine architectures, tile-based programming, and explicit data movement across memory hierarchies. Furthermore, there is a lack of public training data, benchmarks, or tool-augmented agents for this domain.

## Core Contributions
- **Proposed NKI-Agent**: The first system combining domain-specific Supervised Fine-Tuning (SFT) with a compile-verify-fix agent loop for NKI kernel generation.
- **Challenge 1: High complexity of NKI programming and lack of quality training data**. NKI requires managing four specialized compute engines and explicit memory transfers, with no existing datasets. The paper curates 6,000 NKI kernel generation tasks (NKI-Agent-Ops-6K) for SFT and constructs NKIBench, a 250-task benchmark with three difficulty levels, providing essential domain knowledge and evaluation standards.
- **Challenge 2: Low success rate of single-shot generation and high inference costs**. Claude Opus 4.8 achieved only a 6% pass rate in single-shot mode without tools. The paper introduces a multi-turn agent loop with compile/verify tools and rank-aware system prompts, boosting Opus 4.8's pass rate to 77.3%. It also demonstrates that an SFT-trained Qwen3-Coder-30B-A3B achieves a 25.0% pass rate at 1/100th the cost, outperforming Claude Sonnet 4.

## Implementation and Evaluation
- **Implementation & Deployment**: NKI-Agent adapts the CUDA-Agent framework for Neuron hardware, integrating compilation and verification tools. It supports models like Qwen3-Coder-30B-A3B (trained with SFT and GRPO) and closed-source models like Claude Opus 4.8.
- **Evaluation Results**: Evaluated on real Trn1 hardware, NKI-Agent with Claude Opus 4.8 achieved a 77.3% pass rate on a 150-task subset of NKIBench. In contrast, the single-shot mode without agent tools scored only 6%, highlighting the critical role of tool use.
- **Comparison with Related Work**: On a 60-task subset, the SFT-trained Qwen3-Coder-30B-A3B achieved a 25.0% pass rate, significantly outperforming Claude Sonnet 4 (15.0%) at 1/100th the cost. Additionally, the study found that Group Relative Policy Optimization (GRPO) with binary compilation rewards did not improve over SFT, offering insights into reward design for RL-based kernel generation.

#### Summary
This paper addresses the gap in kernel generation for AWS Neuron hardware by proposing NKI-Agent. By constructing specialized datasets and benchmarks, and combining domain-specific SFT with an agentic tool loop, it effectively tackles the challenges of NKI's multi-engine architecture and complex memory management. Experiments show significant improvements in pass rates on real hardware, demonstrating that properly fine-tuned open-source models can outperform some closed-source counterparts at a fraction of the cost, while also identifying limitations in current RL reward designs for this domain.
