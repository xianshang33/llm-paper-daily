## 1. What the Paper Did
- **Background**: Large Language Model (LLM) agents increasingly rely on persistent memory to store factual knowledge, prior decisions, reasoning histories, tool usage, and context, enhancing functionality and continuity across tasks. However, this introduces a new attack surface: the integrity of the agent's own remembered reasoning.
- **Why Existing Work Falls Short**: Previous memory poisoning research (e.g., AgentPoison, MINJA, MemoryGraft) primarily targets retrieved passages, stored examples, or past experiences, leaving the agent's internal reasoning history unexplored. Furthermore, existing defenses like keyword filters or consensus-based mechanisms fail to detect forged reasoning traces that use evasive language and are amplified through self-referential reinforcement.

## Core Contributions
- **Proposed**: The Forged Amplifying Rationale Memory Attack (FARMA) and a layered defense pipeline called SENTINEL.
- **Challenge 1: How to bypass static defenses based on keywords and content?**
  - Difficulty: Traditional defenses rely on detecting malicious keywords or anomalous content, but attackers can use semantically benign but logically malicious evasive language.
  - Solution: FARMA uses evasive language during the injection phase to insert forged reasoning traces, effectively bypassing keyword-based defenses.
- **Challenge 2: How to overcome dynamic defenses based on consensus or majority voting?**
  - Difficulty: Systems using multiple queries or consensus mechanisms might identify single forged entries as outliers.
  - Solution: FARMA introduces an amplification phase where self-referential reinforcement consolidates the forged reasoning in the agent's memory, defeating consensus-based defenses.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated across multiple agents and different LLM models with 50 trials.
- **Attack Performance (FARMA)**: Achieved up to 100% attack success rate under baseline conditions. It successfully defeated existing defense mechanisms, including keyword filters and A-MemGuard.
- **Defense Performance (SENTINEL)**: The core component, "Reasoning Guard," structurally analyzes candidate entries using five weighted signals. Evaluation showed that SENTINEL reduced FARMA's success rate to as low as 0%, with no false positives observed across 326 benign agent traces.
- **Comparison**: Unlike prior works focusing on external knowledge poisoning, this paper demonstrates the vulnerability of reasoning processes and the inadequacy of current defenses against such attacks.

## 4. Conclusion
This paper reveals a critical but overlooked security vulnerability in LLM agent persistent memory: reasoning history poisoning. By proposing FARMA, the authors demonstrate that attackers can poison the agent's reasoning process rather than just factual knowledge, amplifying the effect via self-reference. The proposed SENTINEL defense framework effectively detects and blocks these attacks through structural analysis, achieving zero false positives and high defense success. This work underscores the necessity of protecting both retrieved content and the integrity of reasoning history in secure LLM agent systems.
