## 1. What the Paper Does
- **Background**: LLM agents tackling long-horizon, open-ended tasks often rely on external reusable procedural knowledge ("skills"). However, fixed, hand-authored skills are rarely optimal and cannot adapt to task diversity. Existing self-improving agents rewrite skill files from execution traces to enhance capabilities.
- **Why Existing Work Falls Short**: Current self-evolution methods (e.g., EvoSkill, GEPA) are non-recursive. They optimize only the task skill (what the agent does) while keeping the improvement procedure (how it improves) fixed and hard-coded. This rigidity prevents agents from adapting their diagnosis, editing, or resource allocation strategies based on error types, limiting long-term evolutionary potential.

## Core Contributions
- **Proposed MetaSkill-Evolve Framework**: A two-timescale recursive self-improvement framework that allows the skill improvement process itself to evolve.
- **Challenge 1: Limitations of Non-Recursive Evolution**. Existing methods use fixed meta-level logic, unable to adaptively adjust diagnosis and repair strategies for different errors, creating a bottleneck in improvement efficiency. **Solution**: Introduces branch-local Meta-Skills, parameterizing five components (Analyzer, Retriever, Allocator, Proposer, Evolver) to make the improvement strategy itself an optimizable object.
- **Challenge 2: Achieving Recursive Evolution without Extra Cost**. Simultaneously optimizing task skills and meta-skills under a single model backbone risks chaos or high computational overhead. **Solution**: Employs a two-timescale mechanism where task skills evolve on a fast loop, while meta-skills evolve on a slower loop by applying the same pipeline to themselves. This requires no additional models or objectives, with all agents sharing a single frozen backbone.

## Implementation and Evaluation
- **Implementation**: All five pipeline agents share a single frozen LLM backbone. The meta-skill consists of five parameterized components controlling the improvement pipeline's behavior.
- **Evaluation Results**: Evaluated on three agentic benchmarks: OfficeQA, SealQA, and ALFWorld.
- **Comparison**: MetaSkill-Evolve outperforms no-skill, static-skill, and single-level evolution baselines. It improves held-out test accuracy over the raw backbone by +23.54 points on OfficeQA, +16.09 points on SealQA, and +1.92 points on ALFWorld.

## 4. Conclusion
MetaSkill-Evolve addresses the core limitation of fixed improvement strategies in existing LLM agent evolution by introducing a two-timescale recursive self-improvement mechanism. It enables agents to not only learn better task execution but also to learn how to improve themselves more effectively. Experiments demonstrate significant performance gains over traditional static and single-level evolution methods, highlighting the potential of recursive self-improvement for enhancing long-term agent adaptability and performance.
