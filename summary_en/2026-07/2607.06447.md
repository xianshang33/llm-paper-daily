## 1. What the Paper Does
- **Background**: LLM-based mathematical reasoning agents have started tackling research-level problems and contributing to resolving open questions. However, effectively scaling and orchestrating these agents remains a significant challenge.
- **Limitations of Existing Work**: Current agents (e.g., Aletheia, Rethlas) struggle to coordinate parallel proof searches while keeping intermediate claims organized and reliable. The lack of a global, consistent memory management mechanism leads to state confusion and logical fragmentation when constructing long-form arguments.

## Core Contributions
- **Proposed Danus**: An orchestration system for research-level mathematical reasoning centered on a shared "Fact-Graph" as a global memory-management mechanism.
- **Challenge 1: State Coordination and Consistency in Parallel Proof Search**. The difficulty lies in managing redundancy, conflicts, and isolated conclusions when multiple worker agents explore different paths simultaneously, causing divergence. Danus addresses this by employing a stateless verifier to strictly check proposed mathematical claims before admitting them into the fact graph, ensuring the reliability and structure of the global memory.
- **Challenge 2: Context Management and Direction Guidance in Long-Horizon Reasoning**. As proof steps increase, context windows explode and key information gets lost, causing agents to lose focus. Danus uses a Main Agent to periodically summarize the evolving proof state based on the global fact graph, redirecting workers to promising directions and supporting human interaction via progress reports, enabling incremental construction of long arguments.

## Implementation and Evaluation
- **System Architecture**: Danus consists of a Main Agent for planning/coordination, multiple Worker Agents for parallel proof search, and a Stateless Verifier for checking claims.
- **Evaluation Results**: Evaluated through six research-level case studies in algebraic geometry, singularity theory, and combinatorics. Results demonstrate that the fact-graph memory mechanism enables Danus to construct long, detailed mathematical proofs effectively.
- **Comparison with Related Work**: Compared to Aletheia and Rethlas, which rely on iterative generate-verify loops or local working memory, Danus offers superior scalability for complex tasks. Its explicit global memory structure (fact graph) decouples verification from storage and manages logical dependencies via graph structures, maintaining global consistency during large-scale parallel searches, which is crucial for long-horizon research problems.

## 4. Conclusion
Danus introduces an agent orchestration framework based on a fact-graph memory mechanism, effectively addressing challenges in coordinating parallel searches and managing long-range states in research-level mathematical reasoning. By synergizing main agent planning, worker agent parallel exploration, and strict verifier checks, Danus demonstrates the capability to construct complex proofs across difficult mathematical domains, providing an effective route for scaling LLM mathematical reasoning agents to longer and more complex research tasks.
