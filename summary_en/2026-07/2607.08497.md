## 1. What the Paper Does
- **Background**: Recent unified multimodal models demonstrate that a single architecture can jointly perform vision/language understanding and image generation/editing. However, these monolithic designs typically feed all historical visual and textual inputs repeatedly into a shared context window.
- **Limitations of Existing Work**: This approach limits scalability in long-horizon multimodal dialogue due to two main issues: visual token explosion, which crowds out the context budget for reasoning, and unreliable cross-turn visual referencing caused by reliance on implicit attention over extended contexts. Existing memory-augmented or multi-agent systems fail to simultaneously address cross-turn visual retrieval, mixed-task orchestration, and long-horizon context management.

## Core Contributions
- **Proposed a Cognitive-structured Multimodal Agent (CMA)**: This agent externalizes visual information into an Episodic Visual Memory and selectively reactivates relevant episodes during reasoning. It comprises a Perceptual Abstraction Engine, a Cognitive Retrieval Engine, and a Multimodal Executive Controller.
- **Challenge 1: Visual token explosion and inefficiency in long-context dialogues**. The difficulty lies in the high cost of visual tokens compared to text, where full historical input rapidly exhausts computational resources. The method solves this by using a "Perceptual Abstraction Engine" to structure visual data and an "Episodic Visual Memory" to store it externally, activating only relevant fragments via selective retrieval, thus drastically reducing per-turn token usage.
- **Challenge 2: Lack of fine-grained supervision for cross-turn retrieval**. The difficulty is that existing datasets lack turn-level retrieval annotations, making it hard to optimize retrieval policies. The method addresses this by developing a "Unified Scenario Engine" that programmatically generates structured multi-turn conversations with fine-grained retrieval annotations, enabling reinforcement learning to optimize abstraction and retrieval policies.

## Implementation and Evaluation
- **Implementation & Deployment**: The authors present CMA-Harness, a tool-augmented deployment integrating persistent multimodal memory, web access, image generation/editing/composition tools, and OpenAI-compatible serving.
- **Evaluation Results**: On a constructed long-horizon visual-dialogue benchmark, the 8B-parameter CMA agent achieved 91.4% retrieval accuracy over 20-turn sessions.
- **Comparison with Baselines**: The CMA agent surpassed 32B-parameter baselines by +8.2% in retrieval accuracy while nearly halving the per-turn inference time (from 23.1s to 12.7s). This demonstrates that structured memory and modular decision-making offer a more scalable and efficient paradigm than monolithic parameter scaling.

#### Summary
This paper addresses the context bottlenecks and unreliable referencing in unified multimodal models during long-horizon dialogues by proposing a cognitive-structured agent architecture. By externalizing visual memory, employing structured abstraction, and optimizing via reinforcement learning on synthetically generated data, the method significantly reduces computational costs while substantially improving visual retrieval accuracy and task execution efficiency in long multi-turn conversations, offering a new paradigm for scalable multimodal agents.
