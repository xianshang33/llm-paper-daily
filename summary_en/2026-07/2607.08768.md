## 1. What the Paper Does
- **Background**: The rapid advancement of Large Language Models (LLMs) and Multimodal LLMs has spurred the development of "proactive agents" capable of operating tools and assisting users in real-world environments.
- **Limitations of Existing Work**: Current benchmarks fail to effectively evaluate these agents because they rely on sandboxed environments and single-turn evaluation paradigms. Furthermore, their scenario-based task taxonomies conflate multiple model capabilities within single categories, making it difficult to pinpoint the root causes of agent failures.

## Core Contributions
- **Proposed UniClawBench**: The first capability-driven benchmark designed to evaluate proactive agents in dynamic, real-world settings.
- **Challenge 1: Difficulty in disentangling base model capabilities from framework-level design choices due to mixed task taxonomies.**
  - **Why it's hard**: Traditional benchmarks mix capabilities (e.g., multimodal, reasoning) in complex scenarios and only evaluate final outcomes, obscuring whether failures stem from the model or the agent framework.
  - **Solution**: UniClawBench structures 400 bilingual tasks around five foundational capabilities (Skill Usage, Exploration, Long-Context Reasoning, Multimodal Understanding, Cross-Platform Coordination). By evaluating state-of-the-art models across multiple agent frameworks, it isolates and quantifies the specific impact of model capabilities versus framework design.
- **Challenge 2: Static evaluations cannot simulate complex multi-turn human interactions and dynamic environmental feedback.**
  - **Why it's hard**: Real-world tasks require iterative refinement, user feedback, and exploration in uncertain environments, which static pre-recorded answers cannot capture.
  - **Solution**: Introduces a three-role closed-loop evaluation strategy (Executor, Hidden Supervisor, User Agent) running in live Docker containers. It uses fine-grained, step-by-step checkpoints and simulates realistic multi-turn human feedback without leaking grading criteria, enabling dynamic assessment of agent adaptability.

## Implementation and Evaluation
- **Implementation**: The benchmark comprises 400 tasks covering five core capabilities. Evaluation occurs in live Docker containers using a closed-loop system where the Executor performs tasks, the Supervisor evaluates against hidden rubrics, and the User Simulator provides natural feedback.
- **Results & Comparison**:
  - **Model vs. Framework**: Experiments compared top models (GPT-5.4, Claude Opus-4.8, Kimi-2.6) across various frameworks (OpenClaw, EDICT, Nanobot).
  - **Key Finding**: Framework choice consistently impacts performance more significantly than model choice, indicating that architectural design is a current bottleneck.
  - **Capability Bottlenecks**: Long-context reasoning and multimodal understanding emerged as the primary weaknesses for current agents.
  - **Granular Analysis**: The step-by-step checkpoint system allows for distinguishing between recoverable and fatal errors, offering deeper diagnostic insights than traditional binary pass/fail metrics.

## 4. Conclusion
UniClawBench addresses the gap in evaluating proactive agents in realistic, dynamic environments. By introducing a capability-centric task design and a novel three-role closed-loop evaluation mechanism, it provides more accurate performance metrics and reveals that framework design plays a decisive role in agent performance, alongside identifying multimodal and long-context processing as key areas for improvement. The benchmark and code are publicly available to facilitate future research.
