## 1. What the Paper Did
- **Background**: LLM-based agent systems are increasingly deployed for autonomous tasks (e.g., travel booking, file management). However, existing evaluations primarily focus on task success rates, neglecting whether agents know when to "abstain" (i.e., refrain from acting).
- **Limitations of Existing Work**: Prior research on abstention mostly focuses on question-answering scenarios where decisions do not alter environmental states, with the worst case being an incorrect answer. In contrast, agents in real-world environments may execute irreversible actions. Failure to abstain under ambiguity, conflicting constraints, or tool failures can lead to severe, irreversible consequences. There is a lack of systematic evaluation for agentic abstention involving state-changing actions.

## Core Contributions
- **Proposed AgentAbstain Framework**: The first systematic evaluation framework for agentic abstention, measuring the calibrated ability of tool-using LLM agents to recognize when not to act.
- **Challenge 1: How to construct a comprehensive, paired benchmark to capture nuanced abstention scenarios?**
  - **Difficulty**: Manually authoring diverse tasks is expensive, and it is difficult to distinguish subtle differences between "should act" and "should abstain" across pre-execution reasoning and runtime discovery phases.
  - **Solution**: Developed a taxonomy of 8 abstention scenarios and created 263 paired tasks across 42 executable sandbox environments. Each pair consists of a "should-act" task and a "should-abstain" variant generated via controlled perturbations to instructions, tools, or environment states.
- **Challenge 2: How to address data contamination and ensure scalability?**
  - **Difficulty**: Static benchmarks risk data contamination as models evolve, and generating high-quality fresh test cases continuously is challenging.
  - **Solution**: Proposed AbstainGen, a fully automated pipeline that synthesizes sandbox environments and generates paired tasks end-to-end. It uses deterministic replay and semantic LLM judges for validation, allowing on-demand regeneration of fresh instances. Human annotators rated 94-98% of sampled tasks as well-designed.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated 17 frontier LLMs across 4 agent harnesses.
- **Key Results**: The best-performing agent (Gemini 3.1 Pro) achieved only 59.5% paired accuracy (correct on both the act and abstain sides of each paired task).
- **Key Findings**:
  1. **Independence of Capabilities**: Abstention capability is largely independent of general task-solving capability, indicating that scaling task performance alone will not close this gap.
  2. **Failure Modes**: Identified "post-hoc abstention," where agents execute irreversible actions before recognizing abstention triggers (e.g., canceling a flight before realizing rebooking is impossible).
- **Comparison**: Unlike previous benchmarks focusing on QA accuracy, AgentAbstain reveals significant deficiencies in current frontier models' abstention decision-making in real-world interactive contexts with risks.

## 4. Conclusion
This paper highlights the critical risk of LLM agents lacking the ability to "know when to stop" in autonomous actions. It introduces AgentAbstain, the first systematic evaluation framework, and AbstainGen, an automated generation tool. The study demonstrates that state-of-the-art agents perform poorly in complex abstention scenarios and that this capability cannot be achieved merely by improving task completion rates. The work underscores the need for rigorous abstention evaluation to develop more trustworthy LLM agents and has open-sourced the code and dataset.
