## 1. What the Paper Did
- **Background**: Digital Adoption Platforms (DAPs) are widely used to guide users through web systems. However, completing real tasks involves sequences of actions across changing page states, and current DAP guides rely heavily on expensive manual authoring and maintenance.
- **Why Existing Work Falls Short**: Prior studies treat automated web agent actions and guide text generation as separate problems. Most methods rely on textual page representations (like DOM trees) rather than rendered screenshots, failing to capture the visual context humans interact with, and lack a unified benchmark for evaluating both action execution and guide quality.

## Core Contributions
- **Proposed MAG Benchmark and Harness**: The first benchmark unifying task execution and guide writing into a single "Multimodal Action and Guide" task. It supports two grounding schemes over screenshots (Set-of-Mark element selection and raw pixel coordinates) and provides a complete framework for annotation, training, live evaluation, and joint metrics.
- **Challenge 1: Disconnection between Action Execution and Guide Generation & Multimodal Grounding**
  - **Description & Difficulty**: Traditional approaches either focus solely on task completion or generate single-page guides based on text structures, failing to handle complex cross-page sequences and lacking precise mapping from natural language to visual elements.
  - **Solution**: MAG requires a single agent to generate guide text at each step while performing actions, introducing Set-of-Mark (SoM) and raw pixel coordinate grounding mechanisms to enable precise element localization directly from visual screenshots.
- **Challenge 2: Lack of High-Quality Training Data and Evaluation Systems for Multimodal Web Agents**
  - **Description & Difficulty**: Open-source multimodal models perform poorly on complex web tasks due to the absence of high-quality reinforcement learning training methods incorporating expert trajectories, and the lack of joint metrics for action success and guide usability.
  - **Solution**: Designed a GRPO (Group Relative Policy Optimization) training method augmented with expert trajectories, significantly improving model performance. Established a data construction pipeline with LLM-assisted annotation and human verification, along with joint evaluation metrics for actions and guides.

## Implementation and Evaluation
- **Implementation & Deployment**: Built a complete MAG harness covering data annotation (LLM-assisted + human verified), training, and evaluation in live web environments. Proposed a GRPO-based training strategy using expert trajectories to enhance a 9B parameter supervised model.
- **Evaluation Results**:
  - **Performance Improvement**: GRPO training nearly doubled the success rate of the 9B agent from 6.9% to 13.2%, while also improving guide quality.
  - **Frontier Model Performance**: Even the strongest API and open-source multimodal models completed fewer than 40% of tasks, highlighting the significant challenge of the benchmark.
  - **Comparison**: Unlike previous benchmarks focusing on DOM trees or single-task completion, MAG reveals current models' deficiencies in visual grounding and multi-step reasoning for guide generation, providing a more realistic evaluation scenario.

## 4. Conclusion
This paper introduces MAG, the first benchmark unifying web agent action execution and guide generation. By introducing screenshot-based grounding schemes and a comprehensive evaluation framework, it addresses the separation of actions and guides in existing research and the lack of real-world visual interaction evaluation. Experiments show that GRPO training with expert trajectories significantly boosts performance, yet current state-of-the-art models still face substantial challenges, underscoring MAG's value as a critical benchmark for future web agent research.
