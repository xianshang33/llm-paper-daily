## 1. What the Paper Does
- **Background**: LLM agents accumulate heterogeneous contexts during long-horizon interactions, including system instructions, plans, user turns, retrieved documents, tool outputs, and intermediate reasoning. This causes the Key-Value (KV) cache to grow rapidly, creating a memory bottleneck that limits efficient long-horizon inference and serving.
- **Why Existing Work Fails**: Existing KV cache eviction policies typically apply uniform retention rules based on attention scores or recency to all tokens. These methods ignore the semantic structure known to the agent orchestrator, failing to distinguish between critical long-term information (e.g., system instructions) and transient data (e.g., scratchpad reasoning), leading to suboptimal cache utilization.

## Core Contributions
- **Proposed MemDecay**: A training-free, region-aware KV cache eviction framework.
- **Challenge 1: Differentiated Retention Needs for Heterogeneous Contexts**. Different parts of an agent's context have vastly different lifespans and importance levels, which uniform strategies cannot handle effectively. **Solution**: MemDecay leverages region labels from the orchestration layer to assign region-specific base priorities and decay rates. It allows pinning of critical regions (like system instructions) and dynamically adjusts retention based on semantic structure.
- **Challenge 2: Quantifying and Calibrating Decay Rates**. Determining the specific decay speeds for different token regions to match their actual attention lifetimes is difficult. **Solution**: The paper introduces a measurement protocol to calibrate decay rates by analyzing attention lifetimes in agent traces. It finds that system tokens have much longer half-lives (148-189 steps) compared to scratchpad tokens (14-16 steps), using this data to optimize eviction decisions.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on Qwen2.5-1.5B and 3B models with context lengths of approximately 450 and 1,700 tokens.
- **Key Results**:
    - **Pinning Advantage**: By pinning system regions, MemDecay maintained full-cache accuracy across all settings. In contrast, no baseline preserved accuracy in more than 13 out of 24 test cases.
    - **Region-Aware vs. Recency**: As context length increased, recency-based retention collapsed, whereas MemDecay's region-aware retention remained effective.
    - **Unpinned Content Performance**: For unpinned content, accumulated-attention retention performed better as model scale increased. Ablation studies identified attention score normalization as the primary limitation in the current formulation.
- **Comparison Conclusion**: MemDecay demonstrates that semantic prompt structure is a robust signal for KV cache management, significantly outperforming traditional attention-only or recency-based baselines, especially in long-context agent tasks.

#### Summary
MemDecay addresses the memory bottleneck in LLM agent long-horizon reasoning by introducing a region-aware KV cache eviction mechanism. By leveraging the semantic structure of agent contexts, it sets differentiated priorities and decay strategies for different functional token regions. Experiments show that this method significantly outperforms existing baselines in protecting critical system instructions and is more robust than recency-based methods in long-context scenarios. While there is room for improvement in attention score normalization for unpinned content, this work establishes a new direction for efficient cache management by combining semantic structure with attention signals.
