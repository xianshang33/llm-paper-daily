## 1. What the Paper Does
- **Background**: Agentic systems are increasingly improving themselves by editing skills such as prompts, rubrics, plans, and tool contracts. Existing approaches like SKILL OPT treat skill optimization as an experimental loop: propose a repair, roll out the agent, and accept edits based on validation performance.
- **Why Existing Work Falls Short**: Current methods often treat edits as independent coordinates in a vector space, ignoring the structured nature of skills. Key limitations include: 1) Distinct edits may have identical immediate visible effects but differ in latent routing or composability; 2) Edit order is critical (non-commutativity), meaning the sequence of repairs affects the outcome. Traditional brute-force or short-sighted single-step validation fails to capture this complex geometric structure and order dependency, leading to prohibitive computational costs and suboptimal results.

## Core Contributions
- **Proposed LASKO (Lie Algebroid SKill Optimization)**: A new framework that models typed, anchored Markdown skills as the base category and edit policies as sections of a controlled Lie algebroid.
- **Challenge 1: Non-commutativity and Order Dependency of Edits**. The difficulty lies in the fact that the order of operations impacts the final skill state, which is hard to optimize with traditional methods. LASKO addresses this by using the Lie algebroid bracket to measure the non-commuting composition of edits, mathematically capturing how edit sequences influence skill evolution.
- **Challenge 2: High Validation Costs and Invisible Latent States**. The challenge is that every edit typically requires expensive LLM rollouts for validation, while latent structural changes remain hidden. LASKO introduces an anchor map $\rho$ that maps edit policies to visible Markdown effects, with the kernel $\\ker(\rho)$ representing latent structures. By performing inexpensive microsecond-scale Lie-bracket screening tests before expensive validations, it drastically reduces the number of futile evaluations.

## Implementation and Evaluation
- **Implementation**: LASKO optimizes the search space via mathematical structures without altering the underlying LLM architecture. It leverages Infinitesimal Causality theory, replacing finite counterfactual guesses with local interventions.
- **Evaluation Results**: In preliminary benchmarks, LASKO achieved order-of-magnitude speedups. Specifically, on a causal extraction from natural language task, it achieved nearly a **15x speedup**.
- **Comparison with Related Work**: The baseline was a brute-force approach validating all edits using the DeepSeek V3.1 4-bit model (671B parameters). LASKO outperforms this by substituting most expensive LLM inference calls with cheap mathematical screening tests, significantly reducing computational overhead while maintaining optimization quality.

## 4. Conclusion
This paper introduces LASKO, pioneering the application of Lie algebroid geometry to agentic skill optimization. By modeling edit non-commutativity and latent structures, LASKO addresses the challenges of order sensitivity and high validation costs. Experiments demonstrate significant efficiency gains over brute-force methods using large-scale models, offering both a theoretical geometric foundation and a practical, efficient pathway for agent self-improvement.
