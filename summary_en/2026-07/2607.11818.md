## 1. What the Paper Did
- **Background**: Evaluating LLM-based agents on tool-augmented tasks is an active research area, but existing benchmarks are predominantly text-centric and fail to evaluate realistic assistant tasks involving visual inputs (e.g., screenshot diagnosis, event scheduling from posters).
- **Why Existing Work Falls Short**: Current benchmarks incorporating visual inputs typically treat images as static prefixes in initial queries or limit tasks to single-turn interactions. Furthermore, they often operate with small tool spaces (15–100 tools). There is no unified framework for systematically studying multimodal agents' visual tool-calling capabilities in dynamic, multi-turn, and large-tool-space settings.

## Core Contributions
- **Proposed MM-ToolSandBox**: A unified benchmark and evaluation framework for visually grounded tool-calling agents.
- **Challenge 1: Multi-turn visual interaction and state management in complex dynamic environments**. The difficulty lies in requiring agents to ground progressively arriving visual inputs into executable tool calls while handling realistic phenomena like goal revisions and state mutations. The paper addresses this by providing a stateful execution environment spanning 500+ tools across 16 domains, supporting multi-image, multi-turn tasks.
- **Challenge 2: Automated generation of high-quality, diverse visual scenarios**. The challenge is generating diverse and visually grounded realistic scenarios. The paper introduces an automated scenario generation pipeline using information-flow-guided planning and multi-stage quality filtering, yielding 258 human-verified nominal scenarios and 50 interactive UI variants.

## Implementation and Evaluation
- **Implementation & Deployment**: The framework extends ToolSandBox with explicit image handling and visual-specific tools. It supports evaluation of models ranging from 4B open-weight to frontier proprietary systems.
- **Evaluation Results**: Evaluation of 12 state-of-the-art models reveals a lack of robust visual tool-calling capability, with even the best model achieving below 50% success rate.
- **Failure Analysis & Comparison**: Analysis shows visual precision is a primary bottleneck; 53% of failures stem from incorrect information extraction from images despite correct workflows. A "planning-to-precision crossover" emerges with scale: smaller models fail at planning (deciding what to do), while larger models fail at perception (seeing correctly). This contrasts with existing works that often overlook the distinct challenges of visual grounding in large-scale, dynamic tool use.

## 4. Conclusion
MM-ToolSandBox fills the gap in evaluating multimodal agents for visual tool calling in complex, dynamic, and large-scale tool spaces. The study highlights that current SOTA models struggle significantly with these tasks, particularly regarding visual information extraction accuracy. The framework provides a critical benchmark and insights, suggesting fundamentally different research directions for improving models at different capability levels.
