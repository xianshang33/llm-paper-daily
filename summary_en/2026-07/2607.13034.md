## 1. What the Paper Did
- **Background**: Large language model (LLM) agents are increasingly automating multi-step engineering and informatics workflows, yet they rarely assess the actual effort required for a task.
- **Limitations of Existing Work**: Current agents often adopt a "maximum-context-first" strategy, re-reading files and dependencies they have already seen. This turns simple one-line edits into small code-base audits, leading to significant waste of computational resources and tokens.

## Core Contributions
- **Proposed**: The E3 (Estimate, Execute, Expand) framework for task-aware execution, along with the formalization of "minimum-sufficient execution" and the "Agent Cognitive Redundancy Ratio" (ACRR).
- **Challenge 1: How to accurately estimate task complexity and avoid over-reading?**
  - Difficulty: Agents struggle to determine the true scope of information needed before execution, often falling into the trap of blindly expanding context.
  - Solution: E3 enables the agent to estimate an initial operating point and execute only the minimum viable path, expanding the scope only when verification fails, thereby mechanically curbing unnecessary file reads.
- **Challenge 2: How to significantly reduce execution costs while maintaining success rates?**
  - Difficulty: Reducing context reading risks missing critical information, which could lower task success rates.
  - Solution: By adhering to the "minimum-sufficient execution" principle, the agent operates within the smallest scope necessary to meet task requirements. Experiments show this approach maintains a 100% success rate while drastically reducing token consumption and the number of inspected files.

## Implementation and Evaluation
- **Benchmark (MSE-Bench)**: On a deterministic benchmark of 121 edits, E3 matched the 100% success rate of the strongest baseline. In comparison, E3 reduced costs by 85%, token usage by 91%, and the number of inspected files by 92%. It also outperformed a strong adaptive retrieval baseline by 16%, with gains remaining robust across varied instruction wordings and cost weightings.
- **Real-Model Validation (LLM-Case)**: In experiments using a live gpt-4o agent to edit a real open-source library, patches were graded by running the project's actual pytest suite. Results confirmed that while over-reading is milder in real scenarios, it is present. E3 proved to be the leanest and fastest policy at comparable success rates, with its only limitation being provider rate limits rather than incorrect edits.
- **Comparison Conclusion**: E3 effectively addresses execution redundancy, demonstrating significant advantages in efficiency and cost over traditional full-context reading and adaptive retrieval methods.

#### Summary
This paper highlights the severe cognitive redundancy in current LLM agent task execution and emphasizes the importance of task-aware execution scope estimation. By introducing the E3 framework, it implements an "Estimate-Execute-Expand" control loop that greatly enhances execution efficiency while ensuring task success. This work is positioned as a step toward "Engineering-Grounded AI" (EGAI), where agent effort is anchored in the engineering reality of the task. The authors have released the associated framework and benchmarks.
