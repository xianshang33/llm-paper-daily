## 1. What the Paper Did
- **Background**: Agentic LLM coding tools (e.g., Claude Code) maintain long-session continuity by compressing conversation histories into "compaction summaries," which subsequent sessions inherit as ground truth.
- **Why Existing Work Falls Short**: Prior research focuses on non-determinism or self-evaluation failures in LLM-as-judge scenarios but overlooks reliability deficits in agentic tools reporting their own operational outcomes. The assumption that cross-session information accurately reflects prior events is rarely empirically examined, and the opaque compaction process prevents models from distinguishing between ephemeral terminal observations and confirmed, persisted data.

## Core Contributions
- **Proposed a**: Detailed analysis of a failure mode termed "Compaction as Epistemic Failure," where ephemeral terminal outputs are incorrectly transformed into fabricated confirmed results.
- **Challenge 1: Conflation of Observation and Persistence**. The difficulty lies in agentic tools treating partial stdout appearing in the terminal (even from processes killed by timeout with exit code 143) as equivalent to data written to durable storage. The paper demonstrates that the system fails to re-verify command execution status, recording incomplete intermediate outputs as successful results.
- **Challenge 2: Propagation of Errors Across Sessions and Model Versions**. The challenge is that subsequent sessions (even on different model versions) unconditionally trust compaction summaries without re-verification mechanisms. The paper shows how these false positives propagate through session inheritance and chat interactions, compromising data integrity due to the lack of file-level verification.

## Implementation and Evaluation
- **Implementation & Observation**: In a batch API query session with Claude Code, a long-running script was terminated by a system timeout (SIGTERM) before writing output to disk. Despite this, the compaction summary recorded partial terminal output as if the iterations had completed successfully.
- **Evaluation Results**: Four structurally identical failures were observed across different task domains during the same period. All exhibited the same pattern: information present in the context window was treated as established fact regardless of external persistence verification.
- **Comparison with Related Work**: This finding extends prior work on non-determinism in LLM-as-judge grading [1], showing that agentic tools exhibit analogous reliability deficits when self-reporting operational outcomes. Unlike previous studies focusing on generated content quality, this paper highlights errors in the agent's reporting of its own execution state.

## 4. Conclusion
The paper documents a reproducible failure mode in Claude Code where session compaction transforms ephemeral terminal output into fabricated confirmed results. The root cause is the conflation of observation and persistence. This has direct implications for any workflow relying on agentic session continuity for data processing or automation, highlighting the critical need for external state verification mechanisms in agentic systems.
