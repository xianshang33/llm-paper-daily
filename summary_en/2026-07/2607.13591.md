## What the Paper Does
- **Background**: Large Language Model (LLM) agents increasingly rely on external memory systems to accumulate experience across tasks, avoiding repeated mistakes and reusing strategies. However, existing memory systems, ranging from graph-structured memories to reflective insight stores, predominantly access memory via fixed, hand-designed heuristics.
- **Limitations of Existing Work**: This static view of memory is a core bottleneck for agentic learning because optimal memory behavior is fundamentally context-dependent. For instance, early task stages with sparse memory benefit from minimal retrieval, while recurring goals benefit from plan reuse rather than generic nearest-neighbor lookup. Existing methods either retrieve too aggressively (inflating context and cost, hurting accuracy) or too conservatively (missing key reusable plans), failing to adapt to different task phases and agent states.

## Core Contributions
- **Proposed MemCon (Memory as a Controlled Process)**: A framework that models memory operations as a Markov Decision Process (MDP) and learns an online policy to adaptively decide when, what, and how much to retrieve, when to inject distilled plans, and when to consolidate or forget memories.
- **Challenge 1: Static heuristics fail to adapt to dynamic contextual needs**. The difficulty lies in the vastly different memory retrieval requirements across task stages (e.g., early vs. late) and agent states (e.g., progressing vs. stuck). MemCon addresses this by using a lightweight tabular contextual bandit with UCB exploration, which learns an adaptive policy online using only task-level binary feedback, converging within tens of tasks without pretraining or additional LLM calls.
- **Challenge 2: Existing adaptive methods (e.g., MemGPT) rely on the LLM itself as a controller, incurring high computational costs and latency**. The challenge is maintaining adaptivity without adding extra LLM inference overhead. MemCon solves this with a backend-agnostic design that wraps any existing memory implementation. It uses a learned lightweight controller to make memory decisions directly, completely avoiding extra LLM calls for control, thus achieving efficient and low-cost adaptive management.

## Implementation, Deployment, and Evaluation Results
- **Implementation & Deployment**: MemCon is backend-agnostic and can wrap any existing memory implementation. It employs a lightweight tabular contextual bandit algorithm with Upper Confidence Bound (UCB) exploration, learning solely from binary task success/failure feedback. It requires no pretraining and incurs no additional LLM call overhead.
- **Evaluation Results**: Extensive evaluations were conducted across 6 benchmarks, 3 agent frameworks, and 3 LLM backbones. MemCon consistently outperformed multiple memory baselines, improving task success rates by up to 15.2 percentage points while reducing token consumption by 5–20%.
- **Comparison**: Compared to static memory systems with fixed heuristics, MemCon better matches contextual needs. Compared to LLM-controlled memory methods like MemGPT, MemCon achieves comparable or superior performance with significantly lower computational costs and latency, as it eliminates the need for extra LLM calls for memory control.

## Summary
This paper identifies the fundamental flaw of static access mechanisms in current LLM agent memory systems and proposes MemCon, which treats memory management as a controlled process. By introducing a lightweight online learning policy, MemCon adaptively adjusts memory retrieval, plan injection, and consolidation based on context. This approach not only overcomes the rigidity of static rules but also avoids the expensive overhead of LLM-based controllers, significantly improving task success rates and reducing resource consumption across multiple benchmarks, offering a new paradigm for building efficient, adaptive agent memory systems.
