## 1. What the Paper Did
- **Background**: As Model Context Protocol (MCP) servers become core infrastructure for connecting LLMs with external tools, evaluating LLM agents' tool-use capabilities is critical. Existing benchmarks primarily use static or real-time MCP servers for assessment.
- **Limitations of Existing Work**: Current benchmarks overlook the continuous evolution of tool interfaces and functionalities within MCP servers. This static evaluation fails to capture agent adaptability in dynamic tool landscapes, resulting in flawed assessments that do not reflect robustness against tool changes.

## Core Contributions
- **Proposed MCPEvol-Bench**: A novel benchmark for evaluating the task-solving capabilities of LLM agents under dynamic toolset evolution.
- **Challenge 1: How to realistically simulate tool evolution?**
  - **Difficulty**: Tool evolution is diverse and complex; simple random modifications do not reflect real-world interface change patterns.
  - **Solution**: Conducted an empirical study to identify predominant evolution patterns and designed 11 mutation operators. Used an LLM-driven approach to adaptively select these operators for source code modification, generating realistic evolved toolsets across 123 MCP servers.
- **Challenge 2: How to quantify agent adaptability to evolution?**
  - **Difficulty**: Requires a controlled environment to precisely measure performance differences of the same agent across different tool versions and distinguish error types (e.g., planning vs. reasoning errors).
  - **Solution**: Built a cross-version evaluation pipeline to benchmark 12 state-of-the-art LLMs on multiple stages of evolved MCP servers. By comparing success rates and error distributions between original and evolved versions, the study revealed specific weaknesses in model adaptability.

## Implementation and Evaluation
- **Implementation & Data**: Analyzed version histories of remote servers and public repositories, curating 123 MCP servers with 1,272 tools across domains like software development and data analytics. Cross-server tasks were automatically generated via an LLM-based pipeline.
- **Evaluation Results**: Even frontier models struggle to adapt to evolving tools. GPT-5.4 and Claude-Sonnet-4-6 showed performance declines of 13.7% and 14.4%, respectively, on evolved servers, accompanied by substantial increases in planning and reasoning errors.
- **Comparison**: Unlike existing static benchmarks that ignore tool evolution, MCPEvol-Bench exposes the vulnerability of LLM-driven workflows in dynamic environments, providing a more realistic standard for evaluation.

## 4. Conclusion
This paper addresses the gap in evaluating tool adaptability in LLM agent benchmarks by proposing MCPEvol-Bench. Guided by empirical study-derived mutation operators and LLM-driven simulation, the benchmark effectively assesses agent performance in dynamic tool environments. Findings indicate significant performance drops and increased error rates for mainstream LLMs when facing tool interface and functionality changes, highlighting the need for improved agent adaptability and establishing MCPEvol-Bench as a new standard for such evaluations.
