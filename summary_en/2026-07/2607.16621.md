## 1. What the Paper Does
- **Background**: Long-term memory is essential for Large Language Model (LLM) agents handling long-horizon, multi-step tasks. Existing memory systems typically retrieve prior traces as passive context rather than converting them into executable capabilities.
- **Limitations of Existing Work**: Current methods store factual or experiential memory (e.g., reflections, traces) but reuse them merely as prompts, forcing agents to re-reason through past processes. Furthermore, directly distilling skills from raw trajectories is hindered by noise, difficult credit assignment due to sparse terminal feedback, and a lack of applicability boundaries and verification rules, leading to overfitting and inappropriate invocation.

## Core Contributions
- **Proposed MSCE (Memory-Skill Co-Evolution) Framework**: A training-free framework that organizes agent experience into grounded step traces, reusable procedural policies, and declarative environmental cognition to facilitate the transition from memory to skills.
- **Challenge 1: How to extract reliable and generalizable skills from noisy raw trajectories?**
    - **Difficulty**: Raw traces contain failures, blind exploration, and environment-specific artifacts. Direct distillation leads to overfitted skills lacking necessary triggers and verification rules.
    - **Solution**: MSCE employs a three-level memory hierarchy (L1 Trace, L2 Policy, L3 Environmental Cognition) to separate evidence, procedure, and environmental knowledge. It "crystallizes" only L2 policies with positive estimated gain and supporting evidence into callable skills, which retain evidence links, applicability boundaries, decision guidance, verification rules, and reliability estimates.
- **Challenge 2: How to solve the step-level credit assignment problem caused by sparse terminal feedback in long-horizon tasks?**
    - **Difficulty**: Terminal feedback is often sparse and delayed, making it hard to determine the value of intermediate steps and decide which memory fragments should be retained or upgraded.
    - **Solution**: Introduces "reflection-weighted value backfilling." This mechanism propagates sparse terminal feedback through dense local self-reflections to generate evidence-calibrated trace values, thereby governing the evolution and management of memory and skills.

## Implementation and Evaluation
- **Implementation & Deployment**: MSCE is a training-free framework, meaning it does not require fine-tuning the base LLM. It enhances agent capabilities through post-processing and organizational mechanisms. The code is open-sourced.
- **Evaluation Results**: Experiments were conducted on the EvoAgentBench and LoCoMo benchmarks.
- **Comparison**: MSCE significantly outperforms state-of-the-art skill-augmented and memory-driven agent baselines. Results demonstrate strong cross-domain transferability and lifelong evolution capabilities, effectively reducing token consumption and improving task success rates.

#### Summary
This paper addresses the low utilization of memory and the difficulty of skill extraction in long-horizon LLM agents by proposing the MSCE framework. By constructing a hierarchical memory structure and introducing reflection-weighted value backfilling, MSCE successfully transforms passive memory into active, executable, and self-verifying skills. The method significantly improves agent performance in complex long-horizon tasks without training, achieving co-evolution of memory and skills, and providing a new paradigm for building agents with lifelong learning capabilities.
