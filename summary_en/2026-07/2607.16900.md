## 1. What the Paper Does
- **Background**: Training Large Language Model (LLM) agents capable of calling APIs requires massive amounts of high-quality trajectory data, capturing multi-step interactions, state tracking, and error recovery.
- **Limitations of Existing Work**: Current synthetic data generation methods rely heavily on fully implemented environments with executable APIs and pre-populated backend databases. This tight coupling creates a significant scalability bottleneck, as engineering infrastructure and sourcing realistic states for new API sets is labor-intensive and difficult to scale.

## Core Contributions
- **Proposed an Environment-free Synthetic Data Generation Framework (ESAT)**: This approach leverages LLMs as on-the-fly digital world models to generate high-quality agent trajectories using only API specifications, without requiring any executable environment.
- **Challenge 1: How to simulate consistent, stateful API responses without a real backend database?**
  - **Difficulty**: API calls often involve state changes (e.g., transferring money, editing documents), where subsequent results depend on prior operations. Maintaining state consistency across multi-step interactions without a real database is highly challenging.
  - **Solution**: Introduces a "Simulator LLM" that dynamically generates coherent synthetic API responses conditioned on the task context and simulation history, acting as a virtual state manager to ensure logical self-consistency.
- **Challenge 2: How to ensure high quality in terms of logical correctness and feasibility of generated trajectories?**
  - **Difficulty**: Trajectories generated purely by LLMs may contain hallucinations, logical errors, or unexecutable steps, which can degrade model performance if used directly for training.
  - **Solution**: Employs a "Teacher Agent" to iteratively solve tasks and a "Judge LLM" to strictly filter generated trajectories, discarding invalid or low-quality samples to retain only high-confidence data for the final dataset.

## Implementation and Evaluation
- **Implementation Details**: The pipeline consists of three stages: Task Synthesis, Trajectory Synthesis, and Trajectory Filtering. A Task Generator LLM creates diverse tasks based on API specs; a Teacher Agent interacts with the Simulator LLM to generate trajectories; and a Judge LLM filters the data.
- **Evaluation Benchmarks**: Evaluated on the challenging AppWorld and OfficeBench benchmarks, covering both information retrieval and state-changing tasks.
- **Results & Comparison**: Fine-tuning models on this synthetic data yields significant performance gains. The results demonstrate that effective supervision for API-calling agents can be generated without any executable environment, overcoming the scalability limitations of traditional methods that depend on complex environment setup.

## 4. Conclusion
This paper presents an innovative environment-free synthetic data generation method that addresses the dependency on infrastructure for collecting API agent training data. By utilizing LLMs as digital world models through a closed loop of task generation, state simulation, and quality filtering, the method produces high-quality, state-consistent interaction trajectories from API specifications alone. Experiments confirm that models trained on this data perform excellently across multiple benchmarks, offering a practical and scalable pathway for large-scale API agent training.
