## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents solve tasks by generating trajectories that interleave planning, tool calls, and intermediate results. As agent architectures move to production, rigorous process-level evaluation has become a bottleneck.
- **Limitations of Existing Work**:
    1. **Outcome-only evaluation** (e.g., success rates): Cannot distinguish sound solutions from lucky ones and provides no diagnostic signals for failures.
    2. **Exact matching evaluation** (e.g., BLEU/ROUGE, sequence embeddings): Assumes a unique valid decomposition, penalizing valid plans that differ in ordering or granularity.
    3. **LLM-as-a-judge**: High computational cost, non-deterministic, prompt-sensitive, and prone to self-preference biases, making it unreliable for optimization.

## Core Contributions
- **Proposed OTAP (Optimal Transport for Agentic Planning)**: A framework that reframes trajectory evaluation as the distance between an agent's execution graph and a set of valid solution graphs, instantiated via an unbalanced fused Gromov-Wasserstein transport problem over attributed dependency graphs.
- **Challenge 1: How to handle valid plans with different structures (e.g., reordering, granularity)?**
    - **Difficulty**: Traditional sequence matching is order-sensitive and fails to recognize equivalent plans with different execution orders but identical causal dependencies.
    - **Solution**: OTAP compares based on dependency graphs rather than linear sequences, proving invariance to dependency-preserving reorderings and using soft coupling to accommodate variations in plan granularity.
- **Challenge 2: How to handle missing, hallucinated, or redundant steps?**
    - **Difficulty**: Forced one-to-one matching incorrectly penalizes hallucinations or missing steps, failing to reflect true execution quality.
    - **Solution**: Introduces unbalanced marginals to handle missing or hallucinated steps without forcing a match, while maintaining bounded sensitivity to redundant steps.

## Implementation and Evaluation
- **Experiments**: Evaluated on controlled perturbations and three public benchmarks.
- **Results**:
    - OTAP successfully separates valid from invalid trajectories in regimes where semantics-only metrics score below chance.
    - Accuracy is highest when the dependency graph is recovered exactly; performance drops only slightly when graphs are heuristically inferred from free-text traces.
    - Compared to binary success flags or exact matching, OTAP provides finer-grained, process-level evaluation, distinguishing "lucky success" from "robust success."

#### Summary
This paper addresses the lack of granularity and structural robustness in existing LLM agent trajectory metrics by proposing OTAP. By formulating evaluation as an optimal transport distance between graphs, OTAP achieves invariance to dependency-preserving reorderings and flexibly handles missing, hallucinated, or granularly different steps. Experiments demonstrate that OTAP significantly outperforms semantic or matching baselines in distinguishing valid from invalid trajectories, offering a new paradigm for rigorous agent evaluation.
