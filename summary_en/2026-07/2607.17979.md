## 1. What the Paper Did
- **Background**: Efficient LLM serving increasingly depends on specialized runtime and kernel decisions. The FlashInfer AI Kernel Generation Contest provides a controlled benchmark on NVIDIA Blackwell B200 GPUs for operators with irregular shapes and mixed precision, such as MoE routing and sparse attention.
- **Why Existing Work Falls Short**: While LLM coding agents expand the search space, GPU kernel optimization remains a constrained systems problem. Prior automated approaches often fail due to engineering loop issues like stale baselines, incomplete workload coverage, packaging drift, and loss of profiler provenance, making it difficult to reliably constrain, validate, and select generated code.

## Core Contributions
- **Proposed a Harness-Centered System**: A system for LLM-driven GPU kernel optimization that separates the evaluation harness from a profile-backed optimization controller.
- **Challenge 1: Ensuring Reliability and Compliance of Generated Code**
  - **Difficulty**: Candidates must satisfy packaging contracts, compile in target containers, preserve semantics, and improve latency across full workload distributions, where single-metric optimization often leads to systemic failure.
  - **Solution**: The evaluation harness enforces compilation, correctness, official-aligned timing, and artifact archival, ensuring all outputs operate within strict engineering constraints.
- **Challenge 2: Guiding LLMs for Bounded Search to Avoid Inefficiency**
  - **Difficulty**: Fully autonomous agents lack deep understanding of hardware specifics and workload contexts, leading to unstable generation quality and directionless search.
  - **Solution**: Human-authored "Skills" capture operator constraints, references, and promotion rules. The optimization controller translates profiler and workload evidence into bounded candidate-generation decisions, leveraging Codex and Claude Code agents within these defined boundaries.

## Implementation and Evaluation
- **Implementation & Deployment**: Deployed in the MLSys 2026 FlashInfer Contest on NVIDIA B200 GPUs. The architecture splits into an evaluation harness for constraint enforcement and an optimization controller guided by profiler data.
- **Evaluation Results**: Across five operator definitions, the retained official-aligned artifacts achieved mean-latency speedups over FlashInfer baselines of 1.62x, 18.05x, 29.68x, 1.12x, and 13.70x.
- **Comparison**: "Agent-Assisted" kernels (where humans provide optimization directions and high-quality references) outperformed "Full-Agent" artifacts. This indicates that expert guidance and workload context are critical for reliable AI-driven kernel optimization, surpassing purely autonomous search methods.

## 4. Conclusion
This paper highlights the critical role of "Harness Engineering" in LLM-driven systems code generation. By combining human-defined constraints and feedback loops with LLM implementation search, supported by a profile-backed controller and artifact memory, the system achieves auditable and efficient kernel optimization. The findings suggest that future AI-driven system optimization should focus not just on model autonomy, but on the deep integration of engineering constraint frameworks with human expert knowledge.
