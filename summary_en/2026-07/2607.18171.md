## 1. What the Paper Does
- **Background**: The rise of generative models has spurred demand for real-time multimodal applications (e.g., voice agents, interactive video). These applications compose heterogeneous models into complex pipelines, requiring application-specific decisions on placement, streaming, and parallelism for efficient deployment.
- **Why Existing Work Falls Short**: Current serving systems (e.g., vLLM-Omni) and auto-parallelism compilers are limited by: (1) Restricted deployment strategies (static policies like full disaggregation/co-location) that cannot flexibly balance latency and throughput; (2) Limited workload coverage, as they specialize in fixed workloads and fail to generalize to diverse multimodal apps; (3) Insufficient optimization granularity, necessitating unscalable manual implementation for new applications.

## Core Contributions
- **Proposed FlashRT**: An agent harness that guides generic coding agents to transform simple developer-written reference implementations into optimized multi-GPU deployments, flexibly weighing metrics like latency and throughput.
- **Challenge 1: How to accurately capture data dependencies and state scopes in complex multimodal pipelines?**
  - **Difficulty**: Heterogeneous models and complex interactions make it hard for traditional static analysis to understand dynamic data flows and persistent states.
  - **Solution**: FlashRT introduces a "chain-of-program" paradigm, directing agents to convert reference code into an Intermediate Representation (IR) that explicitly captures data dependencies and state scopes, validated via a sequential interpreter.
- **Challenge 2: How to find optimal deployment transformations for different hardware budgets without human intervention?**
  - **Difficulty**: The search space is vast, and performance characteristics vary significantly across hardware (e.g., NVIDIA vs. AMD), making blind exploration inefficient.
  - **Solution**: Agents perform static analysis to identify candidate transformations, then iteratively implement, verify, and benchmark them in a "measurement-gated optimization loop" to ensure optimal performance on specific hardware.

## Implementation and Evaluation
- **Implementation**: FlashRT employs a multi-pass transformation process involving IR generation, validation, static analysis, and measurement-based iterative optimization, supporting deployments across various hardware budgets.
- **Evaluation Results**:
  - **NVIDIA B200 GPUs**: Achieved up to ~70x latency reduction and 2.8x throughput improvement for applications like video world models and multimodal LLMs.
  - **AMD MI355X GPUs**: Matched peak latency reductions and increased peak throughput improvement to 3.6x, demonstrating superior scalability on platforms with less mature expert optimization.
- **Comparison with Related Work**:
  - For Qwen3-Omni text-to-audio inference on AMD MI355X, FlashRT reduced response latency by 65% compared to the expert-handcrafted vLLM-Omni implementation.
  - Unlike auto-parallelism frameworks (e.g., FlexFlow, Alpa) limited to fixed workloads, FlashRT effectively handles the specific deployment needs of diverse multimodal applications.

## 4. Conclusion
FlashRT addresses the rigidity of deployment strategies and the high cost of manual optimization in real-time multimodal applications by introducing a "chain-of-program" paradigm and a measurement-gated optimization loop. It significantly enhances performance on mainstream NVIDIA hardware and demonstrates potential surpassing expert manual optimization on emerging platforms like AMD, proving the scalability and practicality of agent-driven system optimization in multimodal serving.
