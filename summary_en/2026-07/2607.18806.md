## 1. What the paper does
- **Background**: Group travel planning aims to balance multiple objectives (cost, time, preferences) among participants. With the rise of persona-based LLM agents in simulating human behavior, there is a growing need to use LLM agents to simulate absent members and collaboratively create itineraries, reducing costs for large-scale behavioral analysis and evaluating recommender systems.
- **Limitations of existing work**: Existing persona-based agent simulations and general-purpose multi-agent frameworks lack domain-specific abstractions for group travel planning. Users must implement structured itinerary representations, constraint validation, and other functionalities from scratch, which is costly and distracts from specific use cases.

## Core Contributions
- **Proposed AI Tour Meeting**: A group travel planning framework powered by multiple LLM agents with distinct personas that collaborate via natural language discussion to find itineraries satisfying all constraints and preferences. It provides interfaces for configuring personas, orchestrating discussion workflows, monitoring, and deploying LLMs.
- **Challenge 1: Lack of domain-specific structured support in general frameworks makes itinerary coordination difficult**
  - **Difficulty**: Travel planning involves complex constraints (time, location, cost, preferences) that general agent frameworks struggle to handle structurally and consistently.
  - **Solution**: The paper introduces domain-specific abstractions, including structured itinerary representation, explicit proposal-voting workflows, and specialized constraint validation and metric monitoring, enabling efficient collaboration and consensus among agents.
- **Challenge 2: Difficulty in orchestrating and monitoring multi-agent discussions for behavioral analysis**
  - **Difficulty**: Controlling dialogue flows (e.g., round-robin, inviting) and monitoring agent behavior in real-time for simulation purposes is challenging in multi-agent interactions.
  - **Solution**: The framework offers flexible discussion workflow orchestration interfaces and real-time monitoring tools, allowing users to easily configure agent personas and base models to focus on analyzing agent behavior during travel planning discussions.

## Implementation and Evaluation
- **Implementation & Deployment**: The framework supports various LLM backends (e.g., Qwen 3.5, GPT models of different sizes). It allows setting agent personas, base models, and personal goals. The system includes meeting setup, conversation phases (searching, questioning, proposing), voting mechanisms (accept/reject), and final itinerary determination.
- **Evaluation Results**: System validation demonstrates that the framework can successfully complete discussions. Analysis examples prove its effectiveness as a simulation tool, generating itineraries that meet constraints and reflect trade-offs in agent preferences.
- **Comparison**: Compared to general-purpose multi-agent frameworks, AI Tour Meeting provides out-of-the-box domain-specific functionalities (itinerary parsing, constraint checking), significantly lowering the development barrier and enhancing the specificity of simulations without requiring users to build underlying logic from scratch.

#### Summary
This paper proposes AI Tour Meeting, a multi-LLM agent framework designed specifically for group travel planning. By introducing domain-specific structured representations, proposal-voting workflows, and constraint validation mechanisms, it addresses the applicability issues of general frameworks in travel planning scenarios. The framework not only simplifies the implementation of multi-agent collaborative planning but also serves as a powerful simulation tool, supporting in-depth analysis of LLM agent behavior in complex negotiation scenarios and demonstrating its effectiveness in balancing multi-party preferences and constraints.
