## 1. What the Paper Did
- **Background**: Fraud detection systems must scale with rising transaction volumes while remaining explainable and auditable. Financial institutions face a high volume of false positive alerts and need automated tools to assist analysis while maintaining transparency and human oversight.
- **Why Existing Work Falls Short**: While recent studies combine graph neural networks, explainability techniques (e.g., SHAP), and LLM agents, there is a lack of empirical evaluation on the specific conditions under which each component in a layered fraud pipeline contributes. It remains unclear whether an investigation agent adds decision value beyond its underlying classifier and when its outputs should be accepted or escalated to humans.

## Core Contributions
- **Proposed a** layered fraud detection pipeline on the PaySim dataset, combining a gradient-boosted classifier, graph-derived structural features, autoencoder-based anomaly signals, TreeSHAP explanations, and a bounded LLM investigation agent for uncertain cases.
- **Challenge 1: Data Bias and Inflated Baselines**. Simulator-specific balance shortcuts can artificially inflate baseline performance. The paper identifies and removes this shortcut to ensure valid evaluation, revealing that graph features and anomaly signals do not improve Average Precision on the full test set after debiasing.
- **Challenge 2: Decision Validity of LLM Agents**. Despite having access to model explanations, graph context, and reference cases, the LLM agent's decision accuracy often lags behind direct thresholding. Controlled experiments show the agent achieved only 65.0% accuracy compared to the classifier's 71.7%, frequently replacing correct classifier outputs with errors despite generating coherent rationales.

## Implementation and Evaluation
- **Implementation**: The study uses the PaySim dataset to build a pipeline with GBM, graph feature extraction, autoencoder anomaly detection, and an LLM agent. A controlled experiment with injected multi-account fraud rings was also conducted.
- **Evaluation Results**:
    - **Post-Debiasing Performance**: After removing simulator bias, graph features and anomaly signals did not improve AP on the full test set but improved fraud ranking within the subset of cases with intermediate baseline scores.
    - **Structural Feature Efficacy**: In the injected fraud ring experiment, engineered structural features recovered all injected transactions, whereas the tabular baseline missed approximately 25%.
    - **LLM Agent Performance**: The LLM investigation agent underperformed, achieving 65.0% accuracy versus 71.7% for the base classifier on a balanced 60-case sample. Of the eight decisions the agent changed, six replaced correct classifier outputs with errors.
    - **Escalation Mechanism**: An exploratory disagreement-based escalation rule successfully flagged two agent errors without flagging any correct decisions, showing potential for triggering human review.
- **Comparison**: Unlike approaches that assume agentic AI inherently enhances detection, this study critically demonstrates that plausible rationales from agents are not evidence of better decisions. It highlights the conditional utility of each component compared to traditional tabular or single-model approaches.

## 4. Conclusion
The paper concludes that each component of a layered fraud system contributes only under specific conditions. Crucially, it finds that current LLM investigation agents do not yet surpass the decision quality of their underlying classifiers and that coherent explanations can be misleading. Therefore, plausible rationales should not be taken as proof of superior decisions, and mechanisms like disagreement-based escalation are necessary to ensure auditability and reliability.
