## 1. What the Paper Did
- **Background**: In quantitative health and social sciences, data preparation (e.g., variable selection, recoding, handling missingness, merging) is a time-consuming and error-prone bottleneck. While Large Language Models (LLMs) and agents are widely used in code development, they typically rely on sending data to third-party cloud-based models.
- **Why Existing Work Falls Short**: Research involving personal sensitive data is constrained by strict governance requirements that prohibit transmitting individual-level data to external cloud services. Consequently, existing cloud-based LLM solutions cannot be directly applied in Trusted Research Environments (TREs) or local restricted settings, hindering the adoption of AI-assisted data preparation in these critical areas.

## Core Contributions
- **Proposed**: An open-source evaluation framework called RRBench, designed to assess the efficacy of AI agents powered by open-weight LLMs on longitudinal population study data preparation tasks. The framework includes a curated ground-truth dataset (cleaning scripts for six sweeps of a British cohort study), task definitions (e.g., category harmonization, multi-wave merging), and automated routines for evaluating LLM-generated R code and output data.
- **Challenge 1: How to leverage LLMs for data preparation under strict data governance constraints?**
  - **Difficulty**: Sensitive data cannot leave the local environment, restricting the use of high-performance cloud-based closed-source models, while locally deployable models often have smaller parameter sizes and limited capabilities.
  - **Solution**: The paper focuses on open-weight models deployable on consumer-grade hardware. It constructs a standardized benchmark to verify the feasibility of these models in completing complex data preparation tasks without data leakage.
- **Challenge 2: How to objectively quantify the actual efficacy of LLMs in complex longitudinal data processing?**
  - **Difficulty**: Data preparation tasks are diverse and complex, lacking a unified gold standard to measure the correctness of generated code and consistency of output data.
  - **Solution**: A curated ground-truth dataset comprising 20 data preparation tasks (creating 102 variables) was built. Automated routines were developed to precisely calculate task completion rates by comparing the execution results of LLM-generated R code against the real benchmark data.

## Implementation and Evaluation
- **Implementation & Deployment**: The framework is based on the R language environment. It tested open-weight LLMs of various parameter scales on consumer-grade hardware, ranging from smaller models to the current state-of-the-art 31-35B parameter models.
- **Evaluation Results**: Experiments showed that the current state-of-the-art 31-35B parameter open-weight models performed exceptionally well, achieving an average task completion rate of up to 87.9%, nearly saturating the benchmark's performance ceiling. This indicates that even medium-sized open models can effectively handle complex longitudinal data preparation tasks when deployed locally.
- **Comparison**: Compared to traditional manual processing, this method significantly reduces repetitive labor and potential human coding errors. Compared to cloud-dependent closed-source models, it provides a competitive level of automation while meeting data sovereignty and privacy compliance requirements, demonstrating a viable path for using local LLMs in governance-restricted environments.

#### Summary
Addressing the data privacy pain points in AI applications for sensitive data research, this paper proposes the RRBench framework to systematically evaluate the capabilities of locally deployed open-weight LLMs in longitudinal data preparation tasks. Results indicate that 31-35B parameter models can achieve nearly 88% task completion rates on consumer-grade hardware, providing a feasible technical solution and evaluation standard for AI-assisted data cleaning and processing in strictly governed environments.
