## 1. What the Paper Did
- **Background**: Large Language Models (LLMs) are increasingly deployed as agents that interact with stateful environments over multiple steps, a capability termed "multi-step tool use," which involves gathering hidden information, composing tool calls, and committing state changes.
- **Limitations of Existing Work**: Current benchmarks often focus on isolated API calls, short trajectories, or settings that are difficult to scale and control, failing to adequately evaluate agentic behavior in realistic, state-modifying interaction scenarios.

## Core Contributions
- **Proposed E-Bench**: A fully synthetic benchmark featuring 323 state-changing tasks across three real-world product domains: Honor of Kings, QQ Music, and Tencent Meeting.
- **Challenge 1: Controllability and Scalability of Environment Construction**. Real-world environments are hard to replicate at scale and control. The paper decouples environment synthesis from task synthesis, using graph-guided database filling to build reusable, orphan-free product environments, ensuring environment-level controllability and task-level scalability.
- **Challenge 2: Evaluation of Multi-step Reasoning and Hidden Information Discovery**. Existing benchmarks lack simultaneous assessment of "information gaps" and "tool gaps." The paper employs generator-solver asymmetry to create tasks that require agents to discover hidden data and compose multiple tool calls before changing state, evaluated deterministically via database-state diffs.

## Implementation and Evaluation
- **Implementation Details**: E-Bench covers three product domains. Evaluation is performed by deterministically grading outcomes based on differences between the final database state and the ground truth.
- **Evaluation Results**: Benchmarking 11 cutting-edge LLMs reveals that multi-step tool use remains challenging. Even the strongest models achieve a Pass^3 score below 60%.
- **Comparison and Extensions**: In the E-Bench-Code extension with code execution, reliability (Pass^3) remains below 70%. The paper presents the trade-off between performance (Avg@3) and API cost per task. Unlike many open static benchmarks, E-Bench environments and tasks are not open-sourced to prevent overfitting, emphasizing its role as a closed, high-fidelity test set.

## 4. Conclusion
E-Bench addresses the gap in evaluating multi-step tool-use agents by solving the issues of environment controllability and task scalability through a fully synthetic approach. Experimental results indicate that current state-of-the-art LLMs still have significant room for improvement in reliability and success rates when handling complex product scenarios requiring hidden information discovery and multi-step tool composition. This benchmark provides a crucial standard for assessing and enhancing LLM agent capabilities in real-world stateful environments.
