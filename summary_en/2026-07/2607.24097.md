## 1. What the Paper Does
- **Background**: As LLM agents engage in longer-term interactions, long-term memory becomes crucial for multi-hop reasoning, state tracking, and cross-session knowledge updates. Existing memory-augmented agents typically use a "retrieval-as-evidence" paradigm, feeding retrieved memories directly to the answer model.
- **Limitations of Existing Work**: This paradigm assumes retrieved memories are ready for reasoning, forcing the answer model to handle redundancy, conflicts, and weak relevance, which incurs substantial context overhead. Prior works focus on upstream memory construction or retrieval but fail to transform retrieved candidates into compact, answer-oriented evidence.

## Core Contributions
- **Proposed MemChain**: A trainable post-retrieval memory policy that transforms retrieved candidate sets into compact, grounded, active memory evidence contexts.
- **Challenge 1: How to extract effective information from noisy, redundant retrieval results while reducing context overhead?**
  - **Difficulty**: Retrieved memories often contain irrelevant, stale, or conflicting information, leading to context window explosion and reasoning interference.
  - **Solution**: MemChain generates a "question-conditioned evidence plan," constructs an ordered "grounded evidence trace" based on semantic roles and dependencies, and executes explicit memory actions to produce a concise evidence context.
- **Challenge 2: How to train the mediator policy to ensure structurally sound evidence that improves downstream answer quality?**
  - **Difficulty**: Structural validity alone does not guarantee reasoning effectiveness; a balance is needed between evidence support, grounding, and answer stability.
  - **Solution**: A two-stage learning framework is introduced. First, supervised trace learning teaches valid plan/trace generation. Second, Trace-Guided Memory Policy Optimization (TMPO), a reinforcement learning objective, optimizes the policy using downstream answer quality while encouraging trace grounding, evidence support, and stability.

## Implementation and Evaluation
- **Evaluation**: Experiments conducted on LoCoMo and LongMemEval-S datasets using both closed-source and open-weight frozen answer models.
- **Results**: MemChain achieves state-of-the-art performance on both benchmarks. Compared to baselines that pass raw retrieval results, MemChain significantly improves accuracy while substantially reducing the memory context length passed to the answer model, demonstrating an efficient accuracy-cost trade-off.

#### Summary
MemChain addresses the inefficiency and redundancy in traditional memory-augmented LLM agents by introducing a trainable post-retrieval memory policy. By generating structured evidence traces and executing explicit memory actions, it converts messy retrieval results into compact, high-quality evidence contexts. Combined with supervised learning and the proposed TMPO reinforcement learning method, MemChain significantly reduces context overhead while maintaining or improving answer quality, offering a new efficient and interpretable paradigm for long-term memory management.
