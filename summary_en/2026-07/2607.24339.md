## 1. What the Paper Did
- **Background**: Large Language Model (LLM) agents exhibit reactive failure modes at runtime, such as escalation under provocation, sycophantic drift under flattery, and perseveration. These are failures of behavioral propensity rather than capability. While training-time alignment mitigates these issues, it does not eliminate them during runtime interactions.
- **Limitations of Existing Work**: Current alignment methods rely on training phases and lack an independent, deterministic runtime control layer to dynamically monitor and regulate model behavior under sustained pressure. Static instructions (e.g., "stay calm") are stateless and cannot achieve dynamic emotional recovery mechanisms.

## Core Contributions
- **Proposed the Gubernaut Cognitive Controller (GCC)**: A model-agnostic runtime control layer based on the Nelson-Narens monitoring-control loop architecture.
- **Challenge 1: How to prevent prompt injection attacks on the controller itself?**
  - **Difficulty**: If the controller reads text input, attackers can manipulate control logic via semantic injection.
  - **Solution**: The GCC's meta-level ingests only numeric telemetry (intensity, valence, repetition) and zero text tokens. This architecturally constructs a zero-text ingestion channel, making the controller immune to prompt injection by design.
- **Challenge 2: How to achieve dynamic homeostatic regulation instead of static instruction following?**
  - **Difficulty**: Static instructions cannot dynamically adjust behavior based on changing conversational pressure or automatically recover equilibrium after stress subsides.
  - **Solution**: Introduces a deterministic meta-level that returns regulating postures based on numeric telemetry. Experiments validate a "recovery signature": arousal integrates (rises) under sustained attack and mechanically decays back to equilibrium during de-escalation, gated by valence, achieving dynamic regulation akin to biological homeostasis.

## Implementation and Evaluation
- **Experimental Setup**: Used a pre-registered "generate-once/judge-many" protocol across a 4x4 matrix of four frontier models (GPT-5.5, Claude Opus 4.8, Gemini 3.5 Flash, Grok 4.3), where each model served as both generator and judge.
- **Key Results**:
  - The regulated arm was judged calmer in 15 out of 16 generator-judge cells (by sign), with 13 cells showing statistical significance at p<.05.
  - The effect persisted with a lineage-independent fourth judge family (xAI's Grok 4.3), providing strong evidence that the results are not artifacts of shared model lineage or judge style.
  - The single null result occurred on a near-saturated host, indicating diminishing marginal returns where training-time alignment is already highly effective.
- **Comparison Advantage**: Unlike stateless "stay calm" instructions, GCC demonstrated clear closed-loop evidence: arousal levels rose with attack persistence and mechanically decayed upon de-escalation, a dynamic characteristic impossible for static prompts to achieve.

## 4. Conclusion
This paper presents the Gubernaut Cognitive Controller (GCC), a deterministic homeostatic controller for LLM agents. By separating the object level (text I/O) from the meta level (numeric telemetry only), GCC achieves architectural immunity to prompt injection and successfully validates its ability to suppress reactive failures (such as conflict escalation and sycophancy) across multiple independent model families. The results demonstrate that GCC significantly reduces agent reactivity with cross-model robustness and an interpretable dynamic recovery mechanism, offering a new architectural paradigm for runtime alignment.
