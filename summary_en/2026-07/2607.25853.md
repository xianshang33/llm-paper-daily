## 1. What the Paper Does
- **Background**: In long-horizon interactive tasks, skills have become a key abstraction for Large Language Model (LLM) agents to reuse historical experience. Existing methods automatically extract skills from interaction trajectories to improve efficiency and stability in multi-step task solving.
- **Limitations of Existing Work**: Current "trajectory-to-skill" methods have two main limitations: first, they produce flat collections of high-level textual skills, creating a gap between abstract skill descriptions and concrete executable actions, making it difficult for LLMs to infer specific action parameters and timing; second, skills are stored and retrieved independently, underutilizing the structural relationships among skills and shared action patterns.

## Core Contributions
- **Proposed HiSkill Framework**: A hierarchical skill graph framework that organizes interaction trajectories into a directed graph comprising skill nodes, AtomicOp nodes, and typed edges.
- **Challenge 1: The semantic gap between high-level skills and low-level executable actions**. The difficulty lies in high-level skills providing only strategic guidance without concrete action grounding. HiSkill addresses this by directly connecting high-level skill nodes with executable AtomicOp nodes in the graph and capturing relations like decomposition and temporal transitions. This allows the agent to iteratively ground high-level skills into specific atomic operations and action parameters guided by the subgraph during inference.
- **Challenge 2: Underutilization of inter-skill relationships leading to inefficient retrieval and redundant context**. The challenge is that flat storage fails to capture dependencies and shared structures. HiSkill solves this by constructing typed edges representing compatibility, support, and recovery relations. During inference, it retrieves a compact task-relevant subgraph, preserving necessary structural context while significantly reducing token consumption and improving decision accuracy.

## Implementation and Evaluation
- **Implementation & Deployment**: At inference time, HiSkill retrieves a compact subgraph relevant to the task. Combined with the symbolic task state and active skill, this subgraph guides the LLM agent to iteratively switch skills, select AtomicOps, and ground executable actions.
- **Evaluation Results**: Experiments across three interactive environments demonstrate that HiSkill outperforms state-of-the-art baselines (such as SkillRL, D2Skill, and CoEvoSkills).
- **Comparison Advantages**: Beyond higher success rates, HiSkill significantly reduces inference token consumption, proving the effectiveness of bridging high-level skills and low-level action grounding through a hierarchical skill graph.

## 4. Conclusion
HiSkill effectively addresses the disconnection between high-level abstraction and low-level execution, as well as the underutilization of skill relationships in existing LLM agent skill learning. By introducing a hierarchical skill graph structure, it not only improves success rates in long-horizon interactive tasks but also optimizes inference efficiency through structured retrieval, offering a new paradigm for experience reuse in LLM agents.
