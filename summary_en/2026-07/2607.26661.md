## 1. What the Paper Does
- **Background**: As inference workloads diversify, Huawei Ascend NPUs have become a critical alternative to NVIDIA GPUs. The Ascend C programming model, based on the CANN toolkit, differs fundamentally from CUDA (emphasizing vector computation pipelines and Unified Buffer tiling, requiring explicit data flow management). Optimizing Ascend C operators is crucial for NPU inference performance but requires deep hardware expertise.
- **Why Existing Work Fails**: Existing LLM-based automated code generation methods (e.g., KernelBench, EvoEngineer for CUDA) rely heavily on abundant target platform code in pre-training corpora. Ascend C is a severe low-corpus domain with negligible public representation, causing out-of-distribution generalization failures in existing frameworks. Without external knowledge injection, standard LLMs fail to generate even a single compilable solution for non-trivial operators. The primary challenge shifts from performance tuning to achieving code synthesis feasibility under extreme data scarcity.

## Core Contributions
- **Proposed**: AgenticCANN, a knowledge-augmented agentic evolution framework specifically tailored for automated Ascend C operator synthesis in low-corpus NPU environments.
- **Challenge 1: Upstream feasibility bottleneck due to severe platform knowledge deficit**. Due to the scarcity of Ascend C corpora, LLMs lack necessary hardware domain knowledge, leading to high compilation failure rates. **Solution**: Incorporates a knowledge-orchestrated generation system that delivers structured, multi-level domain insights across the development lifecycle, resolving the feasibility issue by injecting essential platform knowledge.
- **Challenge 2: Balancing exploration and convergence efficiency**. Code generation requires both broad exploration to discover potential solutions and fine-grained tuning for performance, which a single interaction mode cannot balance. **Solution**: Features a stage-adaptive agentic evolution strategy that dynamically aligns LLM interaction modes with specific generation and evolution phases, balancing high-exploration candidate discovery with high-convergence performance tuning.

## Implementation and Evaluation
- **Experimental Setup**: Extensive experiments conducted on Huawei Ascend 910B NPUs across six operators spanning five pattern categories.
- **Key Results**:
    - **Feasibility**: Achieves 90% to 100% feasibility on elementwise and normalization operators; 56% feasibility on fusion operators.
    - **Performance Speedup**: Achieves up to 6.65x speedup on 1B Pangu model inference kernels.
    - **Impact of Knowledge Injection**: Analysis shows knowledge injection monotonically improves feasibility from 57% to 86% on elementwise operators, demonstrating its general benefit rather than being operator-specific.
- **Comparison**: Compared to directly transferring existing CUDA automation methods (like EvoEngineer), AgenticCANN solves the fundamental problem of generating compilable code in low-corpus environments and achieves significant advantages in both feasibility and final inference speed.

## 4. Conclusion
AgenticCANN successfully addresses the challenge of using LLMs for automatic operator generation on low-resource, unfamiliar hardware platforms (Ascend C). By combining knowledge augmentation to solve feasibility bottlenecks and a stage-adaptive agentic evolution strategy to optimize performance, the framework not only achieves breakthroughs in code generation feasibility (especially for elementwise and normalization operators) but also delivers significant inference acceleration. This work demonstrates that structured knowledge injection and dynamic agent strategies can effectively overcome LLM out-of-distribution limitations in extreme data-scarce scenarios, providing a new paradigm for automated NPU operator development.
