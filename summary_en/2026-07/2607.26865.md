## 1. What the Paper Does
- **Background**: LLM agents following the ReAct paradigm are effective for complex multi-step tasks but face challenges when deployed on edge devices due to limited compute, memory, and power. They must manage reasoning budgets while ensuring reliability, deferring to cloud models only when local uncertainty is too high.
- **Limitations of Existing Work**: Current approaches often handle reasoning length control or cloud deferral separately. Edge models may continue generating redundant thought tokens after action convergence, wasting compute and potentially leading to overconfidence in suboptimal actions. Furthermore, there is a lack of joint calibration mechanisms that provide simultaneous finite-sample guarantees on both end-to-end task reward and cloud call rates.

## Core Contributions
- **Proposed Think Short, Defer Smart (TSDS) Framework**: A framework that synergistically integrates a lightweight convergence probe with a perplexity-based deferral rule, jointly calibrated via a multi-objective Learn-Then-Test (LTT) procedure.
- **Challenge 1: How to avoid excessive local reasoning compute without sacrificing decision quality?**
  - **Difficulty**: Thought generation consumes most inference compute, and models often generate useless tokens post-convergence, sometimes becoming overconfident in wrong actions.
  - **Solution**: Introduces a lightweight convergence probe that monitors hidden representations to detect when the intended action stabilizes, halting local reasoning immediately to save compute.
- **Challenge 2: How to ensure reliability and minimize expensive cloud calls under resource constraints?**
  - **Difficulty**: Accurately triggering cloud intervention based on uncertainty while providing strict statistical guarantees on both cloud call rates and final rewards is difficult for single-mechanism systems.
  - **Solution**: Designs a perplexity-based deferral rule to escalate uncertain actions to the cloud and uses multi-objective LTT to jointly calibrate convergence and deferral thresholds, ensuring finite-sample guarantees on expected episode reward and cloud call rate.

## Implementation and Evaluation
- **Benchmarks**: Evaluated on four ReAct benchmarks: arithmetic reasoning (GSM8K), multi-hop QA (HotpotQA), code generation (MBPP), and multi-step embodied planning (household robot).
- **Baselines**: Compared against standalone baselines of thought-calibration-only and calibrated-deferral-only.
- **Key Results**:
  - TSDS reduces per-episode thinking compute by 43%-73% compared to deferral-only baselines across HotpotQA, MBPP, and the household robot task.
  - It maintains certified reward performance and cloud call rate guarantees, demonstrating a superior balance between efficiency and reliability.

## 4. Conclusion
This paper addresses the trade-off between resource constraints and reliability in edge LLM agents by proposing the TSDS framework. By combining action convergence probing to shorten local reasoning paths and smart perplexity-based cloud deferral, jointly calibrated via multi-objective LTT, TSDS achieves significant computational efficiency gains (43%-73% reduction in thinking compute) while providing strict performance and cost guarantees, offering a new pathway for efficient and reliable edge agent deployment.
