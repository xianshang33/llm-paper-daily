## 1. What the paper does
- **Background**: Frequency-domain thermoreflectance (FDTR) is a widely used laser pump-probe technique for measuring thermal properties at micro- and nanoscales. However, its data analysis procedure is complex, heavily reliant on domain expertise, and prone to subtle human errors, leading to reproducibility issues.
- **Why existing work fails**: Traditional automation or general LLM agents lack constraints for physical consistency and struggle to translate ambiguous user intents into rigorous, verifiable analysis steps. Pure code-generation agents (Code-agent) or agents without domain knowledge wrappers (Agent-only) exhibit very low success rates in complex multi-step tasks and incur high computational costs.

## Core Contributions
- **Proposed Vibe-FDTR**: An agent-oriented framework that enables Large Language Model (LLM) agents to perform reliable and reproducible FDTR analysis directly from natural language requests.
- **Challenge 1: Ensuring physical and parametric consistency.**
  - **Difficulty**: LLMs are prone to hallucinations or generating physically invalid parameter configurations, rendering analysis results useless.
  - **Solution**: The framework couples a configuration-driven FDTR code package that enforces physical and parametric consistency, ensuring underlying physical validity.
- **Challenge 2: Translating natural language intent into executable, rigorous analysis workflows.**
  - **Difficulty**: User requests are often unstructured and ambiguous; direct code generation by LLMs is error-prone and hard to debug.
  - **Solution**: Introduces procedural agent skills that translate user intentions into organized and verifiable analysis steps, enhancing accuracy and interpretability.

## Implementation and Evaluation
- **Benchmark**: Evaluated using a controlled benchmark with two levels: synthetic single-step tasks and real-data multi-step tasks based on gold-coated graphite samples.
- **Success Rate Comparison**:
  - **Vibe-FDTR**: Achieved **100%** and **98.9%** success rates for single-step and multi-step tasks, respectively.
  - **Code-agent (skills ablated)**: Performance dropped to 91.4% and 36.7%.
  - **Agent-only (domain package also omitted)**: Performance further plummeted to 38.6% and **0%**.
- **Efficiency Comparison**: Compared to the Code-agent variant, Vibe-FDTR reduced computational cost by **87.7%** and cut execution time by over **60%**.
- **Additional Features**: An optional "expert mode" supports experimental planning via autonomous sensitivity and uncertainty evaluations, providing physically grounded recommendations for underspecified tasks.

## 4. Conclusion
Vibe-FDTR successfully addresses the high barrier, error-proneness, and reproducibility issues in FDTR data analysis by encapsulating domain code and expert knowledge into agent skills. Experiments demonstrate that this approach significantly improves analysis success rates and reliability while substantially reducing computational resource consumption, offering a promising path toward low-barrier, autonomous, and trustworthy thermal metrology.
