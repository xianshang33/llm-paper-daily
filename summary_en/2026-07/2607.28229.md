## 1. What the Paper Does
- **Background**: AI agents are increasingly accessing the web, particularly in life sciences where they assist in literature summarization, bioinformatics, and hypothesis generation. These tasks rely heavily on scientific literature resources like Europe PMC, which indexes over 40 million records.
- **Limitations of Existing Work**: Current resources are not built for AI agents; they require complex syntax and keywords, returning entire papers. This forces agents to learn specific search syntaxes, perform multiple searches, and read full texts to find evidence, which is inefficient and cumbersome.

## Core Contributions
- **Proposed EMBL AI Librarian**: A knowledge layer that upgrades the Europe PMC interface for AI agents, allowing them to ask questions in natural language and receive direct evidence-based answers.
- **Challenge 1: Mapping unstructured natural language to precise retrieval**. The difficulty lies in translating vague natural language queries into efficient database queries. The paper addresses this by using a single LLM orchestrator to plan complementary sub-queries executed against the live Europe PMC search engine.
- **Challenge 2: Locating fine-grained evidence within massive full texts**. The challenge is that returned documents are long and evidence is scattered. The method solves this by having the LLM read selected papers and pinpoint relevant evidence snippets, providing them directly to downstream tasks without requiring the agent to parse full texts.

## Implementation and Evaluation
- **Implementation**: The system is orchestrated by a single LLM connected to the live Europe PMC search engine. Code is publicly available.
- **Evaluation & Comparison**:
    - **Literature Synthesis (ScholarQA-Bench)**: Librarian improves Citation F1 by more than 16 points over strong recently published baselines.
    - **Claim Verification (ProClaim-eval)**: When used as a retrieval layer, it increases agreement with expert consensus (average agreement improved from 70.3% to 78.9%).
    - **Open-Domain QA (LitQA2)**: A GPT-5.4 agent grounded in Librarian scores about 8 points higher than one using web search (accuracy improved from 55.9% to 73.8%).
    - **Foundational Biology Tasks (LAB-Bench)**: Significant accuracy improvements were observed in tasks involving protocols and sequence manipulation (from 50.5% to 54.6%).

## 4. Conclusion
EMBL AI Librarian successfully transforms human-centric literature infrastructure into an AI-agent-ready knowledge layer. By leveraging LLM-orchestrated natural language query planning and evidence extraction, it significantly lowers the barrier for AI agents to access life-science knowledge. It substantially outperforms existing web search and baseline methods across benchmarks in literature synthesis, fact-checking, and open-domain QA, demonstrating the critical importance of specialized knowledge layers for vertical domain AI agents.
