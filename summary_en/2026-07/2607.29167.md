## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents are evolving into persistent systems with long-term memory, allowing them to reuse user preferences and workflows. However, this mechanism also transforms untrusted external observations (e.g., web pages, emails) into persistent action contexts.
- **Limitations of Existing Work**: Current defenses such as prompt filters, content sanitizers, and tool guards focus on immediate text or call boundaries. They fail to enforce "source-authority non-amplification" after lossy memory consolidation. When LLMs summarize external information into compact memories, they often strip away low-trust source markers, causing malicious content to be rewritten as high-authority user history or workflow support, thereby bypassing existing defenses.

## Core Contributions
- **Proposed PPMF (Provenance-Preserving Memory Firewall)**: A lightweight memory middleware designed to address memory provenance laundering.
- **Challenge 1: Source Washing and Authority Amplification during Memory Consolidation**. The difficulty lies in LLMs losing source metadata during summarization, making low-trust external inputs appear as high-trust user instructions in later retrievals. PPMF solves this by preserving platform-maintained source metadata, ensuring memories retain their original trust levels during storage and retrieval, thus preventing illegal authority elevation.
- **Challenge 2: Dynamic Tool Call Authorization based on Memory Authority**. The challenge is matching static memory source trust levels with dynamic high-risk tool calls. PPMF implements a risk-authority gate that authorizes tool calls by matching action risk with the authority level of relevant memories, allowing only confirmed benign or low-risk memories to trigger specific operations.

## Implementation and Evaluation
- **Implementation**: PPMF is deployed as a lightweight middleware at the memory layer, operating without modifying the LLM itself. It maintains platform-level provenance, confirmation status, and risk labels.
- **Evaluation Results**: In schema-grounded evaluations with fixed risk policies, vulnerable memory consolidation mechanisms showed an Attack Success Rate (ASR) of up to 1.000. In contrast, with PPMF enabled, all unauthorized high-risk actions were blocked (ASR of 0), while confirmed benign actions and targeted low-risk memory usage remained executable.
- **Comparison**: Compared to existing works like prompt-flow integrity checks, IFC (Information Flow Control), and CaMeL, PPMF specifically addresses the binding of source authority after memory consolidation. Other works primarily focus on isolating active prompt or tool call boundaries and cannot defend against indirect injection attacks that have undergone memory laundering.

#### Summary
This paper identifies a new security threat in LLM agent long-term memory systems called "memory provenance laundering," where untrusted external information is disguised as high-authority internal states through memory consolidation. The authors propose the PPMF firewall, which effectively blocks such attacks by preserving source metadata and implementing risk-authority matched access control, while maintaining system usability for legitimate operations.
