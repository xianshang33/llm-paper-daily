## 1. What the Paper Does
- **Background**: As Large Language Models (LLMs) evolve towards persistent and adaptive intelligence, long-term memory mechanisms that preserve and reuse information across interactions are increasingly critical. Existing memory systems generally fall into two categories: those that compress and structure histories for efficient access, and those that perform deep research over broader trajectories.
- **Limitations of Existing Work**: Compression-based methods reduce online costs but may omit temporal, causal, or cross-step dependencies. Deep research methods improve evidence coverage but incur substantial latency and inference costs. There is a lack of memory systems that can achieve strong answer quality while maintaining low online latency.

## Core Contributions
- **Proposed Router-Mem**: An evidence-conditioned progressive execution framework for long-horizon agent memory.
- **Challenge 1: How to reduce inference latency while ensuring evidence sufficiency?**
  - **Difficulty**: Traditional methods either process all memory at once (high latency) or over-compress (information loss). It is difficult to dynamically determine when to stop retrieval.
  - **Solution**: Introduces a lightweight "Sufficiency Router" that predicts whether the context supports early termination after obtaining a low-cost retrieval prefix. Trained with evidence-level supervision and rationale-conditioned representation distillation, it enables single-token decision-making at inference time.
- **Challenge 2: How to efficiently supplement information when initial evidence is insufficient without wasting resources?**
  - **Difficulty**: Re-searching fully is costly if initial retrieval is inadequate, but giving up affects answer quality.
  - **Solution**: When the router deems evidence insufficient, Router-Mem reuses previous retrieval hits to expand memory blocks and performs deeper analysis and aggregation, enabling flexible resource allocation and progressive execution.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on AMA-Bench and BEAM benchmarks.
- **Key Results**:
  - Achieved scores of 55.17% on AMA-Bench and 38.77% on BEAM.
  - Reduced average inference time by 27.3% and 25.5% respectively, compared to full memory execution.
- **Comparison**: Compared to preprocessing memory methods (e.g., Mem0, A-MEM) and query-time reconstruction methods (e.g., GAM, E-mem), Router-Mem significantly reduces latency while maintaining high answer quality, effectively addressing the trade-off between quality and efficiency.

## 4. Conclusion
Router-Mem successfully addresses the conflict between quality and efficiency in long-term memory systems by introducing an evidence-conditioned progressive execution mechanism. Its core innovation lies in using a lightweight router to dynamically decide between early termination and deep analysis, avoiding unnecessary computational overhead while ensuring evidence sufficiency for complex tasks. This approach provides new insights for building efficient and persistent LLM agent memory systems.
