## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents require the retention and utilization of cross-step information to act coherently in long-horizon tasks such as web navigation and embodied interaction.
- **Why Existing Work Falls Short**: Current methods primarily focus on improving memory "accessibility" (e.g., context extension, retrieval, compression). However, they fail to ensure that accessed information effectively guides decision-making. Even if relevant information is retrieved, poor formatting, organization, prioritization, or presentation can prevent it from influencing action selection, a phenomenon termed the "Memory-Action Gap."

## Core Contributions
- **Proposed**: MemArbiter, a function-aware memory arbitration framework designed to address the memory-management-induced component of the Memory-Action Gap.
- **Challenge 1: Mismatch between heterogeneous memory needs and homogeneous management**. Historical information (goals, states, constraints, episodic traces, facts) has varying persistence and salience requirements, which uniform management systems cannot handle effectively. MemArbiter decomposes interaction histories into atomic items and organizes them into five functional "Memory Banks," allowing for differentiated management tailored to specific decision functions.
- **Challenge 2: Dynamically controlling memory salience for optimal decision guidance**. Mere retrieval is insufficient; key information must be highlighted at the right moment. MemArbiter dynamically controls memory salience by combining bank-level demand, item-level relevance, focal-ambient representations, and a temporal presentation gate, ensuring critical information influences action selection appropriately.

## Implementation and Evaluation
- **Setup**: Evaluated on the ALFWorld benchmark against baselines like Flat Retrieval and Flat Recency, under unified per-step memory budgets using an open-weight action-generation model.
- **Results**:
  - With a 500-token budget, MemArbiter achieved an 82.8% success rate, outperforming the strongest baseline by 20.9 percentage points.
  - With a 750-token budget, it achieved a 92.5% success rate, surpassing the strongest baseline by 25.4 percentage points.
- **Additional Benefits**: The framework improved post-failure recovery and reduced the repetition of failed actions and state-action recurrences.

## 4. Conclusion
MemArbiter effectively bridges the "Memory-Action Gap" in long-horizon LLM agents by introducing function-aware memory arbitration. By shifting focus from simple retrieval to optimized organization, prioritization, and presentation of information, it significantly enhances task success rates and robustness under strict token constraints. This demonstrates that refined memory management is crucial for improving the decision-making quality of LLM agents.
