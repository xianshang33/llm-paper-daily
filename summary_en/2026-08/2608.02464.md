## 1. What the Paper Does
- **Background**: LLM agents frequently fail mid-episode due to looping, cascading tool errors, goal drift, fabrication, or silent absorption of corrupted content. The standard remedy—judging every step with a second LLM—is prohibitively expensive, often costing more than the agent itself.
- **Limitations of Existing Work**: Current LLM-based monitoring methods suffer from high latency and cost, preventing real-time, fine-grained detection. Purely statistical monitors struggle to cover all failure types (e.g., content fabrication) and face challenges in generalization across different deployment environments and balancing false alarm rates.

## Core Contributions
- **Proposed**: A real-time detection and repair system based on observable step telemetry (semantic embeddings, token uncertainty, action metadata), featuring a lightweight monitor and a deterministic verification layer.
- **Challenge 1: How to achieve efficient fault detection with ultra-low latency and cost?**
  - **Difficulty**: Traditional methods rely on expensive LLM judges, unable to achieve microsecond-level response; one-class learning faces distribution shift and false alarm trade-offs.
  - **Solution**: Proposed a One-Class Echo-State-Network (ESN) ensemble with CUSUM alarms, trained only on healthy runs. This monitor costs ~200 microseconds per step (three orders of magnitude faster than an LLM judge) and achieves a 0.71 failure detection rate at a 5% false-alarm budget across multiple frameworks and models.
- **Challenge 2: How to address blind spots of statistical monitors (e.g., content fabrication) and cross-environment generalization issues?**
  - **Difficulty**: Statistical monitors struggle to detect subtle content tampering or fabrication and require recalibration for different deployment environments, performing poorly in cold-start scenarios.
  - **Solution**: Introduced a "deterministic verification" layer that recomputes totals from actual tool results and confirms required calls. It requires no thresholds or calibration, catching 60% of failures (96% with coverage check) with zero false positives. Additionally, a content-grounding telemetry channel significantly improved content corruption detection.

## Implementation and Evaluation
- **Implementation & Deployment**: Validated on 2,823 agent episodes across three frameworks, three local models (Qwen2.5 7B/3B, Llama3.1 8B), and one commercial API (Gemini-2.5-flash). The entire detection path takes under 1 millisecond per step.
- **Evaluation Results**:
  - **Monitor Performance**: The ESN ensemble achieved an AUROC of 0.872, showing particular strength in long-horizon fault detection. Adding the content-grounding channel lifted content detection from 0.28 to 0.59.
  - **Deterministic Verification Performance**: On the same test set, deterministic verification caught 60% of failures (96% with coverage check) with 0/63 false positives, outperforming the monitor's 54% detection rate and 17% false alarm rate. It transferred seamlessly across model families (110/110 detection on Llama3.1:8B with 0/10 false positives).
  - **Repair Effectiveness**: Upon flagging, the system rolls back to the last fact-gathering step and re-runs live. This recovered 45% of failures compared to a 16% resampling control, lifting task success from 52% to 73% with only ~1 extra model call per run.
- **Comparison**: Compared to standard per-step LLM judging, this approach is three orders of magnitude cheaper. Compared to pure statistical monitoring, the deterministic verification layer eliminates false positives and solves cold-start generalization issues.

#### Summary
This paper presents an efficient, low-cost framework for real-time detection and repair of LLM agent failures. By combining a lightweight one-class ESN monitor with a parameter-free deterministic verification layer, the system identifies various failure modes (including loops, error cascades, and content corruption) with microsecond-level latency. Experiments demonstrate that this method not only significantly reduces monitoring costs but also substantially improves final task success rates through real-time rollback and re-execution, offering a practical solution for building robust autonomous agent systems.
