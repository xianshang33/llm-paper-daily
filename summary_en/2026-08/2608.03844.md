## What the Paper Does
- **Background**: Memory-augmented LLM agents rely on external memory banks for long-horizon reasoning, but these modules expose attack surfaces for malicious records, making the study of memory poisoning threats imperative.
- **Why Existing Work Fails**: Existing query-only attacks often fail in two realistic settings: large-scale benign memory pools (high retrieval competitiveness) and active input auditing (rigorous semantic checks). Current approaches cannot simultaneously handle high competition for retrieval slots and strict semantic audits.

## Core Contributions
- **Proposed MAFIA**: A query-only Memory Attack framework via probing and Factual Injection against Audit, tailored to an extended threat model.
- **Challenge 1: High Retrieval Competitiveness**. In large memory pools with thousands of benign entries, malicious records struggle to be retrieved. **Solution**: MAFIA introduces a placement strategy using memory probing, budget allocation, and scheduling to ensure injected records are retrieval-competitive.
- **Challenge 2: Rigorous Semantic Audits**. Production platforms use LLM-based safety classifiers to reject inputs with adversarial cues. **Solution**: MAFIA designs payloads using compact factual cloaks that maintain high semantic similarity to bypass audits while preserving malicious effects.

## Implementation, Deployment, and Evaluation Results
- **Evaluation Setup**: Tested under pressures of input auditing and large-scale benign memory pools, compared against the baseline method MINJA.
- **Attack Success Rate (ASR)**: MAFIA achieves up to 90.7% ASR. In memory-density stress tests, MAFIA significantly outperforms MINJA, showing a +37 percentage point advantage in ASR at the largest memory size (5,842 entries).
- **Audit Detection Rate (DR)**: MAFIA suppresses audit detection from a peak of 83.3% to at most 7.4%. In contrast, MINJA suffers high detection rates (68.9% general, 75% targeted), whereas MAFIA achieves only 0.0% and 3.3% respectively.
- **Conclusion**: The results expose critical vulnerabilities in agentic memory systems, demonstrating MAFIA's effectiveness under strict real-world constraints.

## Summary
The MAFIA framework successfully addresses the dual challenges of large-scale memory competition and strict auditing through innovative placement strategies and factual cloaking. Its performance highlights the vulnerability of current memory-augmented LLM agents to sophisticated attacks, providing crucial insights for improving agent security.
