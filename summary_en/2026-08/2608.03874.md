## What the Paper Does
- **Background**: Modern agent frameworks enhance Large Language Models (LLMs) with external skill libraries to solve complex tasks. However, it remains unclear whether agents can autonomously synthesize and evolve skills from user interactions (task descriptions and feedback) and whether these evolved skills genuinely improve task-solving capabilities.
- **Why Existing Work Falls Short**: Previous evaluations typically test agents on isolated tasks with fixed skill documents, lacking a systematic assessment of continuous feedback learning and capability expansion. While some works explore automatic skill generation, there is no unified benchmark to measure their limits and the effectiveness of skill reuse.

## Core Contributions
- **Proposed ContinualSkillBench**: A dynamic evaluation framework for in-context continual skill learning. It covers five representative domains (e.g., Law, Healthcare, Finance), each containing 100 interconnected subtasks ordered by increasing difficulty and skill dependencies, designed to assess skill evolution and reuse.
- **Challenge 1: Distinguishing "Context Adaptation" from true "Skill Abstraction/Reuse".**
  - **Difficulty**: Performance gains might stem from simple adaptation to prior context and feedback rather than forming transferable, abstract skills.
  - **Solution**: By comparing "sequential agents" (continuously updating skills) with "independent baselines" (starting from scratch), the study finds that in-context learning performs comparably to explicit skill maintenance on average. This suggests much improvement comes from context adaptation, though explicit skills offer selective benefits for tasks requiring precise outputs or reusable procedures.
- **Challenge 2: Understanding differences in skill accumulation across models of varying capabilities.**
  - **Difficulty**: Less capable models may fail to distill core skills, leading to redundant and fragmented skill libraries that hinder long-term evolution.
  - **Solution**: Experiments reveal that weaker models tend to accumulate larger, more fragmented collections of task-specific skills. This indicates that while current mechanisms support continual adaptation, they struggle to consistently consolidate experience into robust and transferable skills.

## Implementation, Deployment, and Evaluation Results
- **Implementation**: ContinualSkillBench includes 5 domains with 100 subtasks each, featuring logical skill dependencies. The code is open-sourced.
- **Evaluation Results**:
  1. **Sequential Execution Benefit**: Sequential execution generally improves performance over independent execution, but gains vary significantly across models and domains.
  2. **Context vs. Explicit Skills**: On average, in-context learning matches explicit skill maintenance, highlighting that adaptation to prior context drives much of the improvement. However, explicit skills remain beneficial for specific high-precision or high-reuse scenarios.
  3. **Model Disparities**: Less capable models accumulate more fragmented skills, indicating poorer abstraction and generalization abilities.
- **Comparison**: Unlike traditional benchmarks with static skills, this framework emphasizes dynamic skill evolution and cross-task reuse, exposing limitations in current skill consolidation methods.

## Summary
ContinualSkillBench addresses the gap in evaluating continual skill evolution in LLM agents. The study shows that while current in-context learning mechanisms support continual adaptation, agents still struggle to consistently consolidate experience into robust, transferable skills. Explicit skill management retains value in specific scenarios, and weaker models are prone to skill fragmentation.
