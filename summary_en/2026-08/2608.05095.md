## 1. What the Paper Does
- **Background**: Agents for long-term reasoning require memory mechanisms that can be efficiently and effectively updated as new facts and external feedback arrive. Graph-based memory has been adopted to support multi-hop retrieval and reasoning.
- **Limitations of Existing Work**: Existing methods store all memories in a flat graph structure. As historical memories accumulate, retrieval introduces substantial irrelevant context, increasing the cost of evidence selection. Furthermore, these methods typically update memory units independently. Since answers rely on interconnected evidence paths, independent updates may omit relevant evidence or retain outdated dependencies, necessitating repeated rewrites to cover related changes, which leads to excessive token consumption and low update efficiency.

## Core Contributions
- **Proposed HiGram**: An evolving hierarchical graph memory framework with path-level localization and rewriting.
- **Challenge 1: Retrieval noise and high cost due to flat structures**. As memory scales, flat graphs introduce significant irrelevant information during retrieval, making it difficult to locate key evidence efficiently. **Solution**: The paper proposes a hierarchical graph memory structure, organizing memory into a coarse-to-fine architecture composed of upper-level nodes and MemoryUnits, thereby significantly reducing irrelevant information during retrieval.
- **Challenge 2: Dependency fragmentation and inefficient rewriting due to independent updates**. Traditional methods update individual memory units in isolation, failing to handle cross-unit dependency propagation, which requires multiple rewrites to maintain consistency. **Solution**: The paper introduces MicroGraph-based path-level localization and coordinated rewriting. It leverages query and update-conditioned MicroGraphs to identify support subgraphs and evidence paths, jointly revising intra-unit memory and inter-unit dependencies to ensure valid dependency structure updates within localized evidence paths.

## Implementation and Evaluation
- **Experimental Setup**: Experiments were conducted on benchmarks for long-term conversational question answering and conflict-aware memory evaluation.
- **Key Results**: HiGram demonstrates substantial improvements over baselines in both answer quality and token efficiency.
- **Comparative Advantage**: The method improves answer accuracy and query-valid evidence selection under dynamic, static, and conditional conflicts. Compared to existing baselines, HiGram localizes evidence more precisely and handles memory updates more efficiently, reducing unnecessary token consumption.

#### Summary
This paper addresses the issues of high retrieval noise and low update efficiency in graph memory for long-term reasoning agents by proposing the HiGram framework. By introducing a hierarchical graph structure to optimize retrieval and employing MicroGraph-based path-level localization with coordinated rewriting to resolve dependency consistency during updates, the method significantly enhances answer accuracy and evidence selection effectiveness across various conflict scenarios while improving token efficiency. This provides a new perspective for building efficient and evolvable memory systems for agents.
