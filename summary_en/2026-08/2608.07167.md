## 1. What the Paper Did
- **Background**: As Large Language Model (LLM) agents gain capabilities to send emails, query databases, and execute commands, they face new attack surfaces including prompt injection, hallucinated reasoning, and unsafe tool calls.
- **Limitations of Existing Work**: Current defenses rely on software checks (system prompts, filters) running on the same potentially compromised machine as the attacker. This lacks verifiability; external parties cannot confirm if safety checks were actually executed or executed correctly, relying entirely on trust in the execution environment.

## Core Contributions
- **Proposed Niyam-AI**, a framework that makes safety enforcement for AI agents provable using Zero-Knowledge Proofs (ZKPs).
- **Challenge 1: How to ensure safety checks are untampered and genuinely executed?**
  - **Difficulty**: Traditional software checks run in untrusted environments where attackers can bypass or disable them, leaving no evidence of execution.
  - **Solution**: Niyam-AI locks permitted tools and constraints into an "Intent Contract" committed via SHA-256 at session start. An isolated Judge model validates each tool call, generating a zk-SNARK proof via EZKL upon approval, ensuring the check logic was executed according to the contract.
- **Challenge 2: How to allow third-party verification without exposing model privacy?**
  - **Difficulty**: Verifying decision processes typically requires exposing model weights or internal states, risking intellectual property or sensitive data leakage.
  - **Solution**: By leveraging zero-knowledge proofs, Niyam-AI allows any third party to verify the validity of the safety check without accessing the Judge model's weights, achieving transparency and trust while preserving privacy.

## Implementation and Evaluation
- **Implementation Details**: Uses the EZKL library for zk-SNARK generation. Proof generation adds approximately 2260.6 ± 218.4 ms per approved action, with verification taking 53.1 ± 11.8 ms.
- **Evaluation Results**: Evaluated on 2,000 real-world scenarios from Agent-SafetyBench using 5-fold stratified cross-validation. Niyam-AI achieved an F1 score of 88.5% with a 1.1% false-positive rate.
- **Comparison with Related Work**:
  - vs. NeMo Guardrails: Niyam-AI won in 390 discordant scenarios vs. 20 losses.
  - vs. Meta's Llama Prompt Guard 2: Won in 115 scenarios vs. 13 losses.
  - vs. OpenAI's GPT-OSS-Safeguard: Won in 384 scenarios vs. 19 losses.
  - McNemar's exact paired tests confirmed statistical significance with p < 0.0001 in all cases.

## 4. Conclusion
Niyam-AI introduces a novel paradigm for AI agent security by combining intent contracts with zero-knowledge proofs, addressing the lack of verifiable guarantees in traditional trust-based mechanisms. It demonstrates superior accuracy and lower false-positive rates compared to mainstream baselines (NeMo, Prompt Guard 2, GPT-OSS-Safeguard) while enabling mathematically verifiable safety execution without exposing model weights. Despite some computational overhead, it establishes a new foundation of trust for deploying autonomous AI agents in high-risk environments.
