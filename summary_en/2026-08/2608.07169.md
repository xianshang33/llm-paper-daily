## 1. What the Paper Does
- **Background**: Memory systems have demonstrated significant potential in enhancing the performance of Large Language Model (LLM) agents by reusing successful behavioral patterns and avoiding past failures. However, the potential of memory systems for Small Language Models (Small LLMs) remains largely unexplored.
- **Why Existing Work Fails**: Small agents typically suffer from low task success rates, resulting in memory repositories dominated by failed trajectories and a scarcity of successful experiences. This fundamentally limits the utility of self-generated memory. Furthermore, naively transferring raw memories from large teacher models to small student models yields marginal gains due to the "capability gap," where students struggle to comprehend or effectively utilize the teacher's complex knowledge.

## Core Contributions
- **Proposed Agent Memory Distillation (AMD)**: A training-free framework that transfers structured knowledge from a large teacher agent to a small student agent via hierarchical memory.
- **Challenge 1: How to bridge the capability gap to make teacher knowledge comprehensible to students?**
    - **Difficulty**: Directly transferring complex reasoning chains or raw logs exceeds the processing and understanding capacity of small models.
    - **Solution**: AMD constructs three complementary hierarchical memory types: Workflow memory (task-level strategies), Subtask memory (concrete behavioral examples at intermediate granularity), and Function memory (calling conventions and pitfalls). This structured representation makes knowledge digestible for small models.
- **Challenge 2: How to inject memory efficiently at different stages to maximize utility?**
    - **Difficulty**: Indiscriminate injection of all memories causes context redundancy or interference and fails to address specific execution errors.
    - **Solution**: AMD employs a hybrid injection strategy. Workflow and Subtask memories are injected proactively at the start of each task for macro guidance and reference. Function memory is retrieved and injected reactively only upon tool-calling errors to provide targeted corrections.

## Implementation and Evaluation
- **Implementation & Deployment**: AMD is a training-free framework evaluated using GPT-5-mini as the teacher and four small student models (4B–8B parameters). It relies on prompt engineering to inject hierarchical memories rather than fine-tuning.
- **Evaluation Results**: Evaluated on three tool-use benchmarks (AppWorld, BFCL V3, ToolSandbox), AMD achieved average accuracy gains of 27.2%, 11.2%, and 3.4% respectively.
- **Comparison with Related Work**: AMD consistently outperforms existing memory-based baselines. Analysis reveals that Subtask memory contributes the most to performance gains. Notably, 4B-sized student models benefit the most from AMD, and teacher effectiveness is shown to depend on both teacher capability and student compatibility.

#### Summary
This paper addresses the failure of memory systems in small LLM agents due to the scarcity of successful trajectories by proposing Agent Memory Distillation (AMD). By constructing hierarchical memories (Workflow, Subtask, Function) and combining proactive injection with reactive retrieval, AMD effectively distills knowledge from large teacher models to small student models. Experiments demonstrate significant improvements in tool-use capabilities across multiple benchmarks without additional training costs, offering a new pathway for deploying high-performance agents in resource-constrained environments.
