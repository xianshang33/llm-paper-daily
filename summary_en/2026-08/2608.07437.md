## 1. What the Paper Did
- **Background**: Reliable hypothesis testing is foundational to empirical scientific claims. Large Language Model (LLM) agents are increasingly used to automate this workflow by inspecting datasets, generating code, and producing end-to-end analyses.
- **Limitations of Existing Work**: Current benchmarks fail to capture a critical failure mode: LLMs often make subtle inferential errors leading to incorrect conclusions, even when the code execution is technically correct. Existing benchmarks rarely assess whether the reported p-value is statistically valid given the underlying assumptions of the data (e.g., normality, outliers).

## Core Contributions
- **Proposed P-Bench benchmark and Fisher-R1 open-weight LLM agent**.
- **Challenge 1: Lack of realistic benchmarks for statistical inference validity.**
  - **Difficulty**: Existing data science benchmarks focus on code correctness or exact answer matching, ignoring the logical consistency between statistical method selection and data distribution assumptions, making it hard to measure "statistical rationality".
  - **Solution**: Constructed P-Bench, comprising 425 open-ended, realistic hypothesis-testing tasks across economics, biology, and medicine. Each task requires the agent to select a statistical method, compute a p-value, and draw a conclusion based solely on a hypothesis and dataset, specifically evaluating statistical rigor.
- **Challenge 2: LLM agents lack reliable reasoning capabilities in complex statistical scenarios.**
  - **Difficulty**: General-purpose LLMs often fail to correctly identify data characteristics (such as outliers or non-normality) and choose robust statistical tests (e.g., incorrectly using linear regression instead of rank-based tests), leading to false positives or negatives.
  - **Solution**: Introduced Fisher-R1, an open-weight LLM agent trained using synthetic tasks and Reinforcement Learning (RL). By training on tasks with verified statistical rewards, the model's reliability in statistical reasoning is significantly improved, enabling it to dynamically select the most appropriate test based on data features.

## Implementation and Evaluation
- **Implementation**: Fisher-R1 is an open-weight LLM agent trained via reinforcement learning on synthetic data to optimize the rigor of hypothesis testing.
- **Evaluation Results**:
  - On P-Bench, Fisher-R1-14B showed substantial improvement over its backbone model.
  - **Comparison with Related Work**: Fisher-R1-14B outperformed strong proprietary and open-source baselines, including GPT-5.4 and DeepSeek-V4-Pro.
  - **Specific Performance**: Fisher-R1-14B achieved a 21% average relative improvement in single-trial success over DeepSeek-V4-Pro, with gains up to 26% on the most challenging tasks. For instance, when handling data with outliers, GPT-5.4 might incorrectly persist with linear regression leading to false discoveries, whereas Fisher-R1 correctly identifies outliers and employs rank-based tests for accurate conclusions.

## 4. Conclusion
This paper highlights the lack of reliable statistical reasoning in current LLM agents for hypothesis testing, where correct code execution coexists with flawed statistical inference. By building P-Bench, a new benchmark focused on statistical validity, and introducing Fisher-R1, an RL-trained agent, the study demonstrates that reinforcement learning on tasks with verified statistical rewards significantly enhances reliability. Fisher-R1 outperforms state-of-the-art models across various domains and difficulty levels, providing a more trustworthy tool for automated scientific discovery.
