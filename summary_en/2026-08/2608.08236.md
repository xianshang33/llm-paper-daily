## 1. What the Paper Does
- **Background**: Multi-agent LLM systems often fail not due to a lack of candidate answers, but because they lack a persistent mechanism to decide which conflicting claims to trust. Existing aggregation strategies (e.g., majority vote, debate, judge-based selection) choose an output without recording which claim won, which was contested, or why a later update supersedes previous ones.
- **Why Existing Work Fails**: Current agent memory architectures focus on retrieval, compression, and reflection, treating contradiction handling as secondary. Free-form summarization erases the provenance of trust, while raw concatenation lacks suppression mechanisms. This leads to recurring conflicts that must be re-litigated from scratch, lacking a persistent conflict-aware memory structure.

## Core Contributions
- **Proposed LatticeMind**: A conflict-aware structured memory primitive that handles contradictions at write time by maintaining explicit item status, applying cheap symbolic conflict checks, and invoking LLM reconciliation only for unresolved semantic cases.
- **Challenge 1: How to efficiently and accurately detect mechanical conflicts?**
  - **Difficulty**: Relying solely on LLMs for all conflict detection is computationally expensive and slow, making it impractical for high-frequency write operations.
  - **Solution**: LatticeMind introduces cheap symbolic conflict checks to detect mechanical conflicts like dependency cycles or resource violations, filtering out obvious contradictions without significant computational cost.
- **Challenge 2: How to handle complex semantic conflicts and determine trust relationships?**
  - **Difficulty**: When symbolic checks fail, the system must distinguish between "credibility decisions" (one claim defeats another) and "coordination decisions" (multiple locally valid claims coexist), requiring deep semantic understanding.
  - **Solution**: The LLM reconciler is invoked only when necessary, classifying remaining conflicts into credibility or coordination decisions, thereby achieving high-precision conflict resolution with minimal LLM calls.

## Implementation and Evaluation
- **Evaluation Setup**: Evaluated on a label-blind ConflictBank benchmark that anonymizes source names to remove trust biases.
- **Main Results**: LatticeMind achieved 0.97 accuracy, significantly outperforming the strongest aggregation baseline (0.61), with a statistically significant gap (p < 10^-6).
- **Ablation Studies**: Removing either the checker or the reconciler resulted in a 12-14 point drop in accuracy, demonstrating the necessity of both components.
- **Secondary Benchmarks**: Performance was mixed across four planning benchmarks; LatticeMind outperformed naive merge on three but did not replace deliberation methods in tasks requiring iterative search.

## 4. Conclusion
LatticeMind reframes contradiction handling in multi-agent systems as a memory problem rather than just an answer selection problem. By combining cheap symbolic checks with selective LLM reconciliation, it achieves efficient and high-precision conflict management. Experiments demonstrate its superiority over existing baselines in handling knowledge conflicts, providing a foundational step towards building multi-agent systems with persistent conflict-aware memory, despite limitations in complex planning tasks.
