## 1. What the Paper Did
- **Background**: Anthropic introduced the "Agent Skill" open specification in October 2025, a folder structure containing a SKILL.md file to guide language model agents. By July 2026, millions of such files existed in public GitHub repositories.
- **Why Existing Work Falls Short**: Agent Skills differ from traditional software artifacts as they are primarily natural language, selected probabilistically by models at runtime, and lack compiler or type-checker verification. They spread via copying without a central registry or package manager. No existing dataset captures this population, preventing large-scale empirical studies on how developers write, reuse, and maintain these skills.

## Core Contributions
- **Proposed GitSkills Dataset**: A comprehensive dataset of 3,797,117 SKILL.md files collected from 282,200 public GitHub repositories, addressing the data gap for Agent Skills research.
- **Challenge 1: Non-deterministic Selection and Lack of Static Verification**. Since skills are loaded probabilistically and lack static analysis tools, detecting issues like vague descriptions is difficult. GitSkills addresses this by retaining every file occurrence with content hashes and enriched metadata (e.g., parsed front matter), enabling researchers to correlate description quality with selection and reuse patterns.
- **Challenge 2: Difficulty in Tracking Decentralized Propagation**. Without a package manager, skills spread via copying, complicating origin and evolution tracking. GitSkills groups identical files into distinct content groups (1,877,981 unique contents) and provides representative files with full text, folder contents, and partial commit histories, while preserving all copy locations, thus supporting analysis of adoption, reuse, and authorship.

## Implementation and Evaluation
- **Implementation and Deployment**: The dataset was collected using a read-only pipeline against GitHub's code search and REST APIs. It is distributed as a single self-contained SQLite file, retaining every file instance's repository, path, and hash, with enriched data for unique content representatives.
- **Evaluation Results**: The paper focuses on dataset construction rather than algorithmic performance. It enables quantification of early adoption, structural characteristics, and maintenance patterns of Agent Skills, such as distribution across repositories and duplication rates.
- **Comparison with Related Work**: Unlike traditional mining software repositories datasets that focus on code or config files, GitSkills targets a new artifact type: natural-language-heavy skill files dynamically loaded by LLMs. It provides the first large-scale, structured corpus for Agent Skills, enabling empirical studies previously impossible due to the lack of specialized data.

## 4. Conclusion
This paper presents GitSkills, the first large-scale publicly available dataset of Agent Skills, covering nearly 3.8 million files from GitHub up to July 2026. It addresses the research gap caused by the non-traditional nature of Agent Skills (natural language, probabilistic loading, decentralization). By providing detailed file contents, metadata, and reuse tracking, GitSkills lays the foundation for the software engineering community to study the adoption, maintenance, security, and best practices of LLM agent skills, facilitating a deeper understanding of this emerging software artifact.
