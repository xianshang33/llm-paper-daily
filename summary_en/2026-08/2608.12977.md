## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents have evolved into interactive systems capable of retrieving external information, invoking tools, and maintaining state. This expansion shifts security risks from isolated text generation to tool-mediated runtime execution, where attacks like prompt injection and memory poisoning can cause severe consequences.
- **Why Existing Work Falls Short**: Current runtime defenses rely heavily on manually designed interventions and lack a principled framework for construction and maintenance. This manual approach is engineering-intensive, difficult to maintain, and struggles to adapt to evolving threats, resulting in limited effectiveness.

## Core Contributions
- **Proposed**: HARD (Harness-based Autonomous Runtime Defense Evolution), a self-evolving runtime defense framework that transforms defense development from manual engineering into an autonomous evolution process.
- **Challenge 1: Lack of a unified theoretical framework for defense construction**. Existing defenses are fragmented and hard to optimize systematically. **Solution**: The paper develops a "harness-level" formulation of runtime defense, systematically characterizing how harness mechanisms enable defense construction and providing a unified view of existing interventions, laying the theoretical groundwork for automation.
- **Challenge 2: Static defenses fail against dynamically evolving attacks**. Handcrafted rules are fixed and vulnerable to adaptive or novel attacks. **Solution**: HARD automatically identifies appropriate intervention strategies and iteratively improves defense artifacts based on observed failure traces. This autonomous evolution allows agents to proactively identify weaknesses and continuously enhance protection, maintaining robustness in dynamic adversarial environments.

## Implementation and Evaluation
- **Experimental Setup**: HARD was evaluated across various attack scenarios, including direct/indirect prompt injection, memory poisoning, and skill poisoning, as well as adaptive attacks (dynamic evolution and long-horizon progressive attacks). Evolvers included Claude-Opus-4.6, Qwen3.7-Max, and GPT-5.6-Sol.
- **Security Comparison**: Under static attacks, HARD reduced attack success rates to 15.4% (direct prompt injection), 1.0% (indirect), 6.7% (memory poisoning), and 10.2% (skill poisoning). In contrast, existing handcrafted defenses showed success rates between 13% and 66%. HARD significantly outperformed baselines like Official Openclaw, SecureClaw, ClawKeeper, and ClawShield.
- **Utility Comparison**: HARD maintained high Benign Utility (BU) ranging from 91.9% to 95.0%. For Utility under Attack (UA), HARD improved performance from 56% to 86% in memory poisoning scenarios and from 52% to 92% in skill poisoning scenarios, demonstrating a superior security-utility trade-off.
- **Adaptive Attack Performance**: HARD maintained strong robustness against adaptive attacks, including dynamic evolution and long-horizon progressive attacks, consistently outperforming handcrafted defenses and proving its generalization and continuous improvement capabilities.

## 4. Conclusion
This paper addresses the limitations of current LLM agent runtime defenses, which rely on manual design and lack systematic frameworks. By proposing a harness-level formalization, the authors developed the HARD framework to enable autonomous defense evolution. Experimental results show that HARD significantly reduces attack success rates in both static and adaptive scenarios while preserving benign task utility, offering a new paradigm for continuous self-improvement in securing deployed LLM agents.
