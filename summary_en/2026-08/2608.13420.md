## 1. What the Paper Did
- **Background**: Embodied intelligent virtual agents are expected to operate as persistent, adaptive, and context-aware entities in complex virtual and Metaverse environments. The Cognitive Embodied Agent Architecture (CEAA) has been proposed as a framework for building components like perception, memory, and reasoning.
- **Why Existing Work Falls Short**: Current implementations often rely on scripted behaviors, rule-based flows, or symbolic AI, which limit adaptability to dynamic user inputs and continuity across interactions. Furthermore, deploying large models for real-time, low-latency responses on edge devices presents significant computational challenges.

## Core Contributions
- **Proposed**: An edge-based virtual agent gateway system prototype leveraging Small Language Models (SLMs) to support the edge-side operation of "Think" and "Memory" components within the CEAA framework.
- **Challenge 1: How to achieve efficient cognitive processing on resource-constrained edge devices?**
  - **Difficulty**: Traditional Large Language Models (LLMs) have high computational demands, making it difficult to run them with low latency on edge hardware (e.g., NVIDIA Jetson), which hinders real-time interaction.
  - **Solution**: The paper explores the use of Qwen2.5 SLMs, which offer lower computational requirements and efficient inference. These were deployed on an NVIDIA Jetson Orin NX to enable low-latency cognitive processing closer to the user.
- **Challenge 2: How to ensure context-awareness and memory persistence for edge agents?**
  - **Difficulty**: Stateless or simple rule-based agents fail to maintain coherence in long-term conversations and deeply understand user intent.
  - **Solution**: By integrating an SLM-driven "memory" reading and processing mechanism, the system handles memory-driven conversations. It evaluates memory-read performance and routing accuracy to support cognitive orchestration and persistence in interactive virtual worlds.

## Implementation and Evaluation
- **Implementation & Deployment**: An edge-based virtual agent gateway system was developed and evaluated on an NVIDIA Jetson Orin NX hardware platform, using various sizes of Qwen2.5 models as the core inference engine.
- **Evaluation Results**: Simulation experiments assessed routing accuracy, memory-read performance, and latency. Results demonstrated that the SLM-driven prototype could effectively process service requests and handle memory-driven conversations, proving the feasibility of running cognitively capable agents on edge devices.
- **Comparison**: Compared to high-latency cloud-based LLM solutions or low-adaptability traditional scripted agents, this approach offers stronger adaptability and context understanding while maintaining low latency. It partially implements CEAA processes, providing a new path for efficient interaction in immersive virtual worlds.

## 4. Conclusion
This paper explores enhancing embodied virtual agents using Small Language Models (SLMs) and edge computing. By deploying Qwen2.5 models on NVIDIA Jetson Orin NX, the study validates the effectiveness of SLMs in supporting the "Think" and "Memory" components of the CEAA architecture. Experimental results show that the system achieves low-latency, context-aware interactions in resource-constrained edge environments, offering a viable technical route and empirical evidence for developing intelligent agents in complex virtual environments like the Metaverse.
