## 1. What the Paper Does
- **Background**: Autonomous LLM agents executing real-world actions (API calls, emails, etc.) are vulnerable to "runtime behavioral drift," a silent deviation from initial goals that can cause irreversible side effects on external systems. Resetting memory does not fix the altered environment state.
- **Limitations of Existing Work**: Current approaches focus on input-level prevention (e.g., isolating untrusted content) but lack structured mechanisms for post-drift detection, risk assessment, and recovery. Since main agents are often large, expensive models that cannot be retrained per deployment, a plug-and-play external recovery module is needed.

## Core Contributions
- **Proposed a Graph-Based Reinforcement Learning Framework**: An external plug-and-play module using a single Small Language Model (SLM) trained via RL to handle drift diagnosis and recovery.
- **Challenge 1: Complexity and Structuring of Multi-step Recovery**. Recovery requires backward tracing, operation detection, risk assessment, and decision-making (rollback vs. escalation), which is brittle in single prompts and lacks structure in free-form CoT. **Solution**: A recovery graph where each node has a specific role (classification, detection, evaluation, decision). The SLM is trained to generate structured XML-formatted reasoning adapted to each node's role.
- **Challenge 2: Balancing Semantic Quality and Format Compliance in SLMs**. Small models may struggle to maintain both strict schema adherence and semantic accuracy. **Solution**: A hybrid reward mechanism combining rule-based structural rewards (schema/length) with an LLM-as-judge semantic quality signal, optimizing both how the model answers and what it says.

## Implementation and Evaluation
- **Implementation & Deployment**: Designed as an external plug-and-play module independent of the main agent. Uses an SLM trained on the AppWorld benchmark with mixed rewards.
- **Evaluation Results**: The method effectively uses information about suspected drift onset to issue correct recovery decisions using an SLM. The trained model reliably respects output schemas and produces semantically appropriate content for each node role.
- **Comparison**: Unlike existing methods that lack step-level structured mechanisms or require retraining large models, this approach provides robust, structured, and cost-effective drift recovery without modifying the main agent.

## 4. Conclusion
This paper addresses behavioral drift in autonomous LLM agents by introducing a graph-based RL framework for structured diagnosis and recovery. By decomposing the recovery process into specialized nodes and training an SLM with hybrid rewards, the method achieves efficient, structured, and semantically accurate recovery. It overcomes the limitations of retraining large models and mitigates irreversible environmental damage, demonstrating strong performance on the AppWorld benchmark.
