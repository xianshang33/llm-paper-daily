## 1. What the Paper Did
- **Background**: The deployment of autonomous AI agents is frequently bottlenecked by unpredictable VRAM consumption, leading to resource stranding or out-of-memory (OOM) failures on constrained hardware. Traditional LLM memory models are designed for single-turn inference, whereas agent workloads involve variable steps, tool invocations, and context expansion.
- **Why Existing Work Falls Short**: Existing complex machine learning regression models attempt to predict peak memory using prompt features but are often opaque and computationally expensive. It remains unclear whether simple analytical models remain effective for dynamic agent workloads, or if complex dynamic modeling is strictly necessary in highly quantized regimes.

## Core Contributions
- **Proposed**: An empirical evaluation of a closed-form analytical model for peak VRAM forecasting in quantized agentic workloads, specifically within code synthesis tasks.
- **Challenge 1: How to accurately forecast peak VRAM in dynamic agent workflows?**
  - **Difficulty**: Agent execution paths are non-deterministic, involving varying step counts, tool calls, and context growth, making static models seemingly inadequate.
  - **Solution**: The paper employs a closed-form analytical model decomposing memory into weights, KV-cache, and activations, calibrated with two empirical constants (loaded weight VRAM and fixed activation overhead). Results show this model matches or outperforms complex learned baselines when provided with live GPU readings and ground-truth trajectory parameters.
- **Challenge 2: Is complex predictive modeling necessary in low-variance scenarios?**
  - **Difficulty**: In highly quantized settings, VRAM consumption variance is extremely low, making it difficult to justify the overhead of complex models over simpler baselines.
  - **Solution**: The study finds that peak memory variance is remarkably low (CV 0.3–9.4%). Learned prompt-feature regression offers only statistically insignificant improvements over a simple constant-mean baseline. Thus, the paper argues against deploying complex predictive models in weight-dominated, quantized regimes.

## Implementation and Evaluation
- **Implementation**: The study uses 'AgentK', a LangGraph-based CUDA-kernel-synthesis agent, with 4-bit quantization (Q4 K M) on a single NVIDIA H100 GPU. It evaluates four LLM backbones (Phi-4-mini, Mistral-7B, Qwen2.5-Coder-7B, Qwen2.5-Coder-14B) across 1,920 trajectories.
- **Evaluation Results**:
  - **Forecasting Accuracy**: The closed-form analytical model achieved competitive accuracy, matching or outperforming the best learned baseline on three of four backbones (Test MAPE 2.2–4.4% vs. 3.4–6.5%, p=0.76). It underperformed only on the smallest backbone (Phi-4-mini) due to minimal VRAM variance.
  - **Functional Success**: Compile success rates bifurcated by backbone capacity (5.7% for Phi-4-mini to 62.0% for Qwen2.5-Coder-14B), indicating that code synthesis quality is constrained by intrinsic LLM capabilities, not just memory availability.
- **Comparison**: Compared to complex ML regressions, the simple analytical model provides comparable or better accuracy with greater transparency and lower overhead. The study demonstrates that complex models do not yield statistically significant gains in these specific low-variance, quantized contexts.

## 4. Conclusion
This paper demonstrates that in highly quantized, weight-dominated agent workloads, VRAM consumption is remarkably stable. A transparent, calibrated closed-form analytical model is sufficient for peak VRAM forecasting, performing as well as or better than complex machine learning models. These findings suggest that deploying complex predictive VRAM models is unjustified in such regimes, offering a reliable, low-overhead foundation for resource scheduling and admission control, thereby facilitating safer and more efficient agent deployment on shared and edge infrastructure.
