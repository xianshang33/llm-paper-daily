## 1. What the Paper Does
- **Background**: Tool-calling LLM agents effectively navigate unfamiliar codebases using generic primitives (ls, cat, grep). Knowledge graphs admit a similar interface, where listing neighbors, reading node content, and searching descriptions are analogous operations on a different substrate.
- **Why Existing Work Falls Short**: Traditional full-context methods require serializing entire schemas or large text bodies into prompts, leading to excessive token usage and performance degradation due to information overload. Existing graph reasoning methods often rely on predefined domain-specific schemas or complex topologies, lacking the flexibility to discover domain-specific information dynamically at runtime.

## Core Contributions
- **Proposed GRA (Graph Reasoning Agent)**: An agent designed to explore hybrid knowledge graphs (comprising textual concepts and relational tables) using seven generic tools, discovering all domain-specific details at runtime without prior schema knowledge.
- **Challenge 1: How to efficiently navigate hybrid data structures without predefined schemas?**
  - **Difficulty**: Hybrid KGs contain heterogeneous nodes (text concepts and relational tables), making it difficult for traditional methods to effectively link semantic and data layers without knowing the specific schema.
  - **Solution**: GRA abstracts graph navigation into generic "list", "read", and "search" operations, similar to code agents. It uses seven generic tools to dynamically explore graph slices and retrieve chunks at runtime, achieving schema-agnostic reasoning.
- **Challenge 2: How to prove performance gains stem from selective access rather than graph topology?**
  - **Difficulty**: It is challenging to distinguish whether improvements come from the graph structure itself or simply from avoiding irrelevant information.
  - **Solution**: The paper introduces a graph-free control experiment (RSA, the same agent logic but with the graph removed). Results show that gains primarily come from selective agentic access, validating the hypothesis that "seeing less, answering better"—selective navigation over a structured substrate beats exhaustive context.

## Implementation and Evaluation
- **Benchmark**: UFK-M (Unified Factory Knowledge Model), an industrial benchmark with 258 analytical questions, where gold answers are generated by executing validated SQL programs.
- **Baselines**:
  - **SQA (SQL Agent)**: Full-context agent receiving serialized full schema and text (~17k tokens upfront).
  - **RSA (Retrieval SQL Agent)**: Same agent logic as GRA but with the graph structure removed, used for control experiments.
- **Results**:
  - **Accuracy**: GRA achieved 88.4% accuracy, outperforming the full-context SQA (83.3%) by 5.1 percentage points.
  - **Efficiency**: GRA read less than one-third of the input tokens compared to SQA.
  - **Key Findings**: The graph-free control indicated that gains are chiefly due to selective access rather than graph topology. Furthermore, the effect depends heavily on the model's ability to drive tools reliably.

## 4. Conclusion
This paper presents GRA, a schema-agnostic graph reasoning agent that applies generic codebase navigation primitives to hybrid knowledge graphs, enabling dynamic discovery of domain knowledge at runtime. Experiments on the industrial UFK-M benchmark demonstrate that GRA outperforms full-context methods in both accuracy and token efficiency. The core insight is that selective navigation over a structured substrate is superior to exhaustive context injection, with tool-call reliability being a critical success factor.
