## 1. What the Paper Did
- **Background**: Large Language Model (LLM) agents have the potential to assist flight crews in safety-critical domains like aviation. However, existing evaluations focus on static knowledge, failing to systematically test procedural execution and safety compliance in interactive environments.
- **Why Existing Work Falls Short**: Conventional question-answering benchmarks cannot assess the ability to translate knowledge into concrete actions via tool calls or verify adherence to hard safety constraints during dynamic, multi-step tasks, leaving a significant "knowing-doing gap."

## Core Contributions
- **Proposed AeroCopilotBench**, a two-tier benchmark, and **AeroCopilot Operational Environment (ACOE)**, a reproducible interactive virtual cockpit.
- **Challenge 1: How to evaluate procedural execution in dynamic interactive environments?**
  - **Difficulty**: Aviation tasks require diagnosing faults and operating systems based on real-time state feedback, which static text cannot simulate.
  - **Solution**: ACOE converts natural-language procedures into executable state transitions, goal conditions, and hard safety constraints, enabling models to interpret cockpit states and operate systems via standardized interfaces.
- **Challenge 2: How to strictly quantify joint assessment of safety and task completion?**
  - **Difficulty**: Traditional metrics often overlook process violations or fail to distinguish partial success from failure in safety-critical contexts.
  - **Solution**: Established a safety-gated evaluation framework where a trajectory succeeds only if all goals are met without violating any hard safety constraints, while separately measuring safe goal progress and trajectory safety.

## Implementation and Evaluation
- **Implementation**: The benchmark consists of Tier-1 (1,200 multiple-choice questions for knowledge) and Tier-2 (73 emergency/abnormal tasks from Pilot's Operating Handbooks instantiated in ACOE).
- **Results**: Tested across 12 models, the highest Tier-2 success rate was 72.6%. Static knowledge performance did not consistently translate to procedural execution success.
- **Failure Analysis**: Analysis of 451 failed episodes from 3 representative models identified recurring issues in procedural completeness, use of state feedback, and long-horizon execution management.
- **Comparison**: Unlike prior static benchmarks, this work reveals the operational limitations of current LLMs, highlighting the need for state-aware orchestration and rigorous regression testing.

## 4. Conclusion
This paper introduces AeroCopilotBench and ACOE to address the lack of interactive evaluation for aviation LLM agents. By employing a two-tier structure and safety-gated metrics, it systematically assesses knowledge application, interactive execution, and operational safety. The findings demonstrate significant challenges in translating static knowledge into safe, complete procedural execution, providing a foundational resource for developing more reliable aviation copilot agents.
