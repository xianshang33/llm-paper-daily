## 1. What the Paper Does
- **Background**: Financial time series exhibit non-stationary and heterogeneous statistical properties, making Change Point Detection (CPD) challenging. No single unsupervised algorithm performs consistently across all assets and market regimes. Consequently, conventional workflows rely heavily on expert-driven model selection, feature engineering, and hyperparameter tuning, limiting scalability and adaptability.
- **Limitations of Existing Work**: Single algorithms fail to handle the complexity of financial data (noise, heavy tails, time-varying volatility). Manual workflows are inefficient, lack automation, and struggle to adapt to varying statistical characteristics across different datasets.

## Core Contributions
- **Proposed EvoTS-Agent**, a validation-guided self-evolving LLM agent for autonomous financial time-series change-point detection.
- **Challenge 1: How to automatically adapt to diverse dataset statistics and avoid local optima?**
  - **Difficulty**: Financial data structures are complex and variable; fixed strategies lack generalization, and the search space is vast, leading to stagnation.
  - **Solution**: Introduced three complementary operators: **Revision** (exploits the current best solution), **Alternative Strategy** (explores fundamentally different modeling directions when progress stalls), and **Recombination** (synthesizes evidence from high-performing trajectories). These allow dynamic adjustment of experiment trajectories.
- **Challenge 2: How to ensure reliability and effectiveness of auto-generated code and execution paths?**
  - **Difficulty**: LLM-generated code may contain errors, and lack of feedback can lead to invalid searches.
  - **Solution**: Uses validation feedback to guide trajectory evolution. The agent performs curated exploratory data analysis to initialize models and uses validation feedback throughout the search to adapt the detection pipeline to specific dataset characteristics while maintaining reliable optimization, achieving a 100% execution success rate.

## Implementation and Evaluation
- **Experiments**: Conducted extensive experiments on four benchmark datasets.
- **Results**: EvoTS-Agent consistently outperforms existing LLM-based agents.
- **Robustness**: Maintained a 100% execution success rate across all evaluated backbone LLMs, demonstrating high stability and generality.

## 4. Conclusion
EvoTS-Agent effectively addresses the automation challenges in financial time-series CPD caused by data non-stationarity and heterogeneity through self-evolution mechanisms and validation guidance. By eliminating heavy reliance on expert experience and dynamically optimizing detection pipelines via Revision, Alternative Strategy, and Recombination operators, it not only surpasses existing LLM agents in performance but also ensures high execution success rates, offering a scalable and adaptable solution for automated financial analysis.
