## 1. What the Paper Does
- **Background**: Modern enterprises generate vast amounts of data across heterogeneous systems. Traditional analysis relies on manual SQL or complex BI tools (e.g., Tableau), making insight generation time-consuming and labor-intensive.
- **Why Existing Work Falls Short**: Single-agent analytical tools struggle with complex reasoning, while general multi-agent systems often suffer from task "drift" in free-form conversations. Furthermore, existing solutions lack robust security architectures for multi-tenant data isolation and standardized evaluation frameworks, failing to meet enterprise requirements for accuracy, security, and reusability.

## Core Contributions
- **Proposed a Multi-Agent Conversational BI Platform built on CrewAI**: The framework employs five specialized AI agents operating in a sequential pipeline to process natural language queries, retrieve/analyze data, generate visualizations via MCP, and deliver insights.
- **Challenge 1: Accuracy and Task Drift in Complex Queries**. The difficulty lies in agents deviating from goals or hallucinating in unstructured dialogues. The paper addresses this by enforcing a structured sequential workflow that decomposes complex queries into discrete steps (planning, retrieval, analysis, aggregation), effectively mitigating drift and improving functional accuracy.
- **Challenge 2: Enterprise Data Security and Insight Reusability**. The challenge is ensuring data isolation in multi-tenant environments and converting transient conversations into lasting value. The solution introduces a defense-in-depth security architecture for data isolation and a query parameterization mechanism that transforms conversational insights into reusable dashboard components.

## Implementation and Evaluation
- **Implementation & Deployment**: Built on the CrewAI framework, integrating the Model Context Protocol (MCP) for visualization. Evaluated on 300 end-to-end test cases across synthetic and production enterprise datasets.
- **Evaluation Results**:
    - Functional accuracy: 95.3%.
    - Mean response latency: 24 seconds.
    - Quality score (LLM-as-a-Judge): 4.52/5.0.
    - Hallucination-free rate: 93.0%.
- **Comparison with Related Work**: The multi-agent architecture achieved a 22.6 percentage point improvement in accuracy and a 20.2% gain in quality over a single-agent baseline. Cross-model evaluation across four LLM backends confirmed architectural generalizability, and ablation studies identified the Data Analysis and Report Aggregation agents as primary drivers of output quality.

#### Summary
This paper presents a multi-agent platform for automated enterprise analytics that addresses the inefficiencies of traditional BI tools and the accuracy limitations of existing AI solutions. By leveraging a structured workflow, the system significantly outperforms single-agent baselines in accuracy and quality. Additionally, its defense-in-depth security and query parameterization features meet critical enterprise needs for safety and practical utility, offering a robust and scalable solution for conversational business intelligence.
