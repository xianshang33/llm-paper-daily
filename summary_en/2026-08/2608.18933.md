## 1. What the Paper Does
- **Background**: Large Language Model (LLM)-based agents excel in automated software issue resolution but often struggle with specific repositories due to a lack of project-specific knowledge (e.g., structural regularities, API contracts, implicit execution paths).
- **Limitations of Existing Work**: Current self-evolving approaches are reactive. History-driven methods rely on past issue-resolution signals, which are limited by data coverage and cannot capture unexercised behaviors. Online test-time exploration methods reduce historical dependence but incur substantial token, time, and trajectory costs per issue, and knowledge is only acquired after the issue has arrived.

## Core Contributions
- **Proposed SkillForge**: A proactive self-distillation framework that acquires project-specific knowledge directly from the repository before encountering real issues.
- **Challenge 1: How to generate high-quality, project-specific learning signals without relying on sparse or biased historical issues?**
    - **Difficulty**: Historical data may be incomplete, missing long-tail components or specific API combinations.
    - **Solution**: SkillForge synthesizes project-specific issues by re-implementing test-covered core functionalities of the repository. This proactively generates comprehensive learning signals derived directly from the codebase structure and tests, independent of external history.
- **Challenge 2: How to efficiently distill knowledge from synthetic issues into reusable capabilities for future real-world problem solving?**
    - **Difficulty**: Raw context is inefficient; knowledge must be structured and linked to specific code elements for accurate retrieval.
    - **Solution**: The framework distills reusable knowledge into "entity-grounded skills" and associates them with relevant repository entities (classes, functions, modules). When resolving real issues, the agent retrieves and applies these pre-distilled skills based on the involved entities, avoiding redundant exploration.

## Implementation and Evaluation
- **Setup**: Extensive experiments were conducted using both open-source and closed-source LLMs.
- **Baselines**: Compared against strong baselines, including generic SWE agents and existing self-evolving methods (both history-driven and online exploration).
- **Results**: SkillForge consistently outperforms strong baselines in issue resolution performance. The results demonstrate that proactively acquiring project-specific knowledge significantly improves downstream software issue resolution by addressing the cold-start problem and reducing the need to rediscover project conventions.

## 4. Conclusion
SkillForge introduces a novel proactive self-distillation paradigm that accumulates project-specific knowledge via synthetic issues and structures it into retrievable skills. This approach effectively addresses the limitations of reactive methods regarding data dependency and inference cost, significantly enhancing the efficiency and effectiveness of LLM agents in resolving issues within specific projects.
