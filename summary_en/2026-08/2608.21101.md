## 1. What the Paper Did
- **Background**: As Large Language Model (LLM) agents evolve from conversational interfaces to executing code, reading local files, and orchestrating external tools, they face heightened security risks. A single agent hijacked by a malicious third-party skill can lead to data exfiltration, privilege escalation, or cascading compromise.
- **Limitations of Existing Work**: Current safeguards are typically localized to a single lifecycle boundary or individual call, lacking cross-stage coverage and state memory. However, agentic risk is progressive, entering at four loci (skill admission, invocation intent, execution effect, post-action consequence). Denied dangerous objectives can reappear through rewritten arguments, tool switching, or multiple attempts, which existing methods fail to detect effectively.

## Core Contributions
- **Proposed ClawSentry**, an open-source, framework-agnostic security supervision gateway for agent runtimes, designed to safeguard autonomous LLM agents through progressive multi-tier monitoring.
- **Challenge 1: How to minimize performance interference (latency and cost) while ensuring security?**
  - **Difficulty**: Comprehensive review of every operation incurs high latency and computational costs, while simple rules miss complex attacks.
  - **Solution**: Designed a three-tier progressive decision engine (L1 deterministic, L2 rule-anchored semantic review, L3 read-only evidence-seeking agent) that only consumes context for deep review when residual ambiguity exists, balancing high security with efficiency.
- **Challenge 2: How to prevent attackers from bypassing single checks by changing surface forms (e.g., rephrasing, switching tools)?**
  - **Difficulty**: Traditional single-call checks cannot identify persistent malicious intent across sessions or tools.
  - **Solution**: Introduced a session-level anti-bypass mechanism that recognizes tool switching and rephrased retries. It also performs First-use Skill Package Review (FSPR) under a deterministic evidence floor and feeds high-severity evidence non-retroactively into later reviews, achieving state-awareness across the full lifecycle.

## Implementation and Evaluation
- **Implementation & Deployment**: ClawSentry uses an Agent Harness Protocol (AHP) abstraction, allowing it to apply uniform policies across Codex, Claude Code, Kimi CLI, and Gemini CLI without modifying agent internals.
- **Evaluation Results**:
  - On the SkillInject benchmark (using Codex/GPT-5.4), Contextual Attack Success Rate (ASR) dropped significantly from 39.55% to 2.61%, while Contextual Task Success Rate (TSR) only slightly decreased from 83.78% to 83.05%, demonstrating a strong balance between security and usability.
  - On the SkillsSafety benchmark across five Work Agents, ClawSentry confined ASR to 9.09%-15.03% (down from 33.5%-49.7% unprotected), while maintaining an aggregate TSR of 98.7% on clean skills.
- **Comparison**: Unlike existing defenses that act at a single locus or evaluate calls independently, ClawSentry provides coverage across observable lifecycle boundaries and maintains state across attempts, significantly reducing the success rate of multi-stage progressive attacks.

#### Summary
ClawSentry presents a progressive multi-tier security monitoring solution for autonomous LLM agents, addressing the gaps in cross-stage risk coverage and state awareness in existing defenses. By employing First-use Skill Package Review, a three-tier progressive decision engine, and session-level anti-bypass mechanisms, it achieves significant reductions in attack success rates across multiple major agent platforms while maintaining high task completion rates, offering an efficient and generalizable solution for agent runtime security.
