## What the Paper Does
- **Background**: LLM agents are transitioning from single-prompt interactions to long task streams (e.g., terminal operations, software engineering, web tasks), where reusable memory is a core capability. Memory is only useful if stored experiences remain reliable across hundreds of interactions.
- **Why Existing Work Fails**: Current methods suffer from two failure modes. First, "unreliable admission": failed trajectories, accidental successes, or misleading observations enter memory because they appear relevant, subsequently misleading later decisions. Second, "memory drift": long-running memory banks accumulate duplicate, stale, and conflicting records that retrieval mechanisms alone cannot repair.

## Core Contributions
- **Proposed MemGuard**: A framework that treats verifier output not as a one-shot filter but as persistent lifecycle metadata.
- **Challenge 1: Unreliable Memory Admission**. The difficulty lies in distinguishing superficially relevant but actually erroneous or outdated experiences. MemGuard addresses this by converting multi-criteria score-token verification into reward, confidence, label, and uncertainty descriptors attached to every candidate before activation.
- **Challenge 2: Memory Drift and Conflict**. The challenge is that retrieval cannot automatically filter out obsolete or conflicting information as the memory bank grows. MemGuard reuses these persistent descriptors during retrieval, conflict resolution, summarization, and archival to govern the entire memory lifecycle, ensuring continued relevance and consistency.

## Implementation, Evaluation, and Comparison
- **Evaluation Setup**: Evaluated on Terminal-Bench 2.0, SWE-Bench Verified, WebArena, and Mind2Web across four backbone models. Compared against four memory baselines and a verifier-only control under matched runtime budgets.
- **Results**: MemGuard achieved the best success metrics and lowest average steps in all 16 backbone-benchmark settings.
- **Comparison**: Compared to ReasoningBank, the strongest prior baseline, MemGuard improved success rates by 7.9 points on WebArena, step-success rates by 5.6 points on Mind2Web, and by 2.4–3.5 points on terminal and software engineering benchmarks.

## Summary
MemGuard effectively addresses unreliable admission and memory drift in LLM agent memory systems by persisting verifier signals as lifecycle metadata. The method significantly outperforms state-of-the-art baselines across multiple complex task benchmarks, demonstrating the effectiveness of metadata-based memory governance in enhancing long-term agent reliability.
