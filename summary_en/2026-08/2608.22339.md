## 1. What the Paper Did
- **Background**: Large Language Model (LLM) agents operating in complex interactive environments require multi-step tool use and planning. To achieve self-evolution without constant human supervision, extracting and reusing "skill memories" from past successful trajectories has become a critical mechanism.
- **Why Existing Work Falls Short**: Prevailing agent self-evolution paradigms assume that skill memories derived from successful trajectories monotonically improve problem-solving capabilities. However, these methods treat success-distilled skills as purely positive transfers, ignoring their applicability boundaries. This leads to the "Skill Imitation Trap," where retrieving semantically similar but inapplicable skills increases the model's confidence in wrong tool calls, causing performance to drop below even memory-free baselines.

## Core Contributions
- **Proposed Boundary-Aware Skill Memory (BASM)**: A framework that augments each skill with explicit boundary fields—applicability conditions, risk cues, avoidance rules, and recovery notes—transforming unconditional action templates into state-conditioned guidance.
- **Challenge 1: Increased confidence in wrong tool calls due to the Skill Imitation Trap**. The difficulty lies in the lack of negative constraints in traditional methods, leading to blind imitation when semantic similarity mismatches logical requirements. BASM addresses this by using "applicability conditions" and "avoidance rules" to suppress inapplicable tool calls when conditions are not met.
- **Challenge 2: Lack of recovery mechanisms upon execution failure**. Traditional skills lack descriptions of potential risks or failure handling. BASM incorporates "risk cues" and "recovery notes," enabling the agent to issue targeted repairs when execution deviates from expectations, thereby enhancing robustness.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated across three agent benchmarks (AppWorld, BFCL, AgentDojo) and four model scales.
- **Results vs. Baselines**: BASM consistently outperforms success-distilled skill-memory baselines.
  - **AppWorld**: Improved task success rate by up to 23.8% and reduced average steps by 6.6% compared to the memory-free baseline.
  - **BFCL**: Improved accuracy by up to 5.0%.
  - **AgentDojo**: Reduced attack success rate by 4.6%, demonstrating enhanced safety and robustness.
- **Conclusion**: BASM effectively applies skills in correct contexts while avoiding erroneous imitation in mismatched scenarios, achieving more reliable and efficient tool use than traditional methods.

#### Summary
This paper identifies the "Skill Imitation Trap" in LLM agent skill memory reuse, showing that relying solely on successful trajectories can degrade performance in semantically similar but logically distinct tasks. To address this, the authors propose Boundary-Aware Skill Memory (BASM), which explicitly models skill boundaries, risks, and recovery strategies. Experiments demonstrate that BASM significantly improves success rates, accuracy, and safety across multiple benchmarks while reducing operational steps, offering a new paradigm for building more reliable self-evolving LLM agents.
