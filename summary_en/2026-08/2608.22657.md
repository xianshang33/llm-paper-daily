## 1. What the Paper Does
- **Background**: Agentic AI frameworks using LLMs interpret open-ended goals and decompose them into multi-step plans for robots. However, mapping semantic planning directly to physical execution carries significant risks.
- **Why Existing Work Falls Short**: Current frameworks improve grounding by providing embodiment-specific capabilities and constraints but fail to eliminate infeasible, mistimed, or unsafe actions. They often conflate planner knowledge with runtime safety, lacking an explicit architectural interface to verify actions against robot capabilities, system state, and workflow constraints before actuation.

## Core Contributions
- **Proposed Physical Agentic AI Framework**: An architecture for skill-grounded robot agent orchestration that isolates deliberative language reasoning from deterministic execution authority.
- **Challenge 1: Hallucinations and Insufficient Grounding in LLM Planners**. Even with retrieval-augmented information, LLMs generate invalid action sequences because they lack deterministic physical constraint checking. The paper addresses this by introducing a "Robot Orchestration layer" that exposes typed skill libraries, robot states, and workflow contracts to a non-actuating Mission Planner, significantly reducing but not eliminating errors.
- **Challenge 2: Lack of Runtime Enforcement Mechanisms**. Improving planner knowledge alone is insufficient to prevent all faulty steps, especially in dynamic environments. The paper designs a deterministic "Robot Orchestrator" that validates and authorizes one skill at a time before execution. This per-dispatch enforcement strips execution authority from the LLM, ensuring any action failing capability, state, or constraint checks is rejected, achieving zero false dispatches.

## Implementation and Evaluation
- **Implementation & Deployment**: Evaluated on two testbeds:
    1. Simulation: Drone-UGV search-and-dispatch mission in Gazebo.
    2. Real Hardware: Object transportation task with Unitree G1 (humanoid) and Go2 (quadruped) robots, including two physical trials using hardware-equivalent skill interfaces.
- **Evaluation Results**:
    - **Grounding Improvement**: Retrieval increased skill grounding from 51% to 96%.
    - **Planner Limitations**: Despite improved grounding, informed planners still dispatched 23-29% faulty steps.
    - **Orchestrator Effectiveness**: The deterministic Robot Orchestrator reduced the false dispatch rate to 0% with no false blocks.
    - **Fault Injection**: Without enforcement, all 8 injected faults crossed the orchestration boundary, causing motion in 6 cases; with enforcement, all 8 were refused before motion occurred.
- **Comparison**: Unlike traditional ROS or three-layer architectures, this framework specifically addresses the architectural vulnerability introduced by foundation models. Experiments demonstrate that while retrieval improves grounding, reliable physical execution requires constraint enforcement outside the language model.

## 4. Conclusion
The paper introduces Physical Agentic AI, arguing for the separation of deliberative language reasoning from deterministic execution authority. It demonstrates that while retrieval enhances LLM grounding, reliable physical execution necessitates external constraint enforcement. By utilizing typed skill libraries and a deterministic orchestrator, the framework ensures safe and reliable collaboration for heterogeneous robot teams in complex tasks.
