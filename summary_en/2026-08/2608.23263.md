## 1. What the Paper Does
- **Background**: The FAIR Digital Object (FDO) framework mandates that metadata attribute values be expressed as Persistent Identifiers (PIDs) to create fully machine-actionable graphs. However, existing cultural heritage aggregators like Europeana store most metadata as plain text, which supports human browsing but lacks machine-traversable semantic links.
- **Why Existing Work Falls Short**: Traditional string matching or simple entity linking cannot automatically distinguish between values that must become PID references (resolvable entities) and those that should remain literals (e.g., notes, dates). Furthermore, existing methods struggle with merging cross-lingual surface forms, preventing automated agents from effectively traversing across records or collections.

## Core Contributions
- **Proposed a pipeline** powered by Large Language Models (LLMs) that transforms flat Europeana records into FDO-compliant knowledge graphs structured with CIDOC-CRM.
- **Challenge 1: Automating the distinction between PID references and literal values**. The difficulty lies in strictly enforcing the FDO specification where only terminal leaves can be literals, a boundary hard to define with traditional rules. The paper addresses this by using an LLM to classify each metadata value, determining whether it should be mapped to an entity or kept as a literal.
- **Challenge 2: Entity linking across controlled vocabularies and cross-lingual disambiguation**. The challenge involves routing unstructured text to specific controlled vocabularies (Getty AAT, Wikidata, VIAF, PeriodO) and resolving synonyms or cross-language variations. The method uses the LLM to route classified entities to these vocabularies, generating shared entity FDOs and successfully merging cross-lingual surface forms that byte-level matching misses.

## Implementation and Evaluation
- **Implementation & Evaluation**: The study evaluated the pipeline using 637 archaeological records from five Europeana providers. Each record was processed by the LLM to create discrete FDOs with PIDs, types, profiles, and metadata layers.
- **Results**: The pipeline linked 86% of metadata slots and resolved 58.5% of values that Europeana had not previously enriched. In terms of cross-lingual surface form merging, manual review confirmed 17 out of 33 merges were correct, demonstrating superiority over traditional byte-level string matching.
- **Comparison Advantage**: Unlike traditional string matching, the resulting FDO graph ensures that every node is typed and resolvable, achieving true machine actionability as required by the FDO specification.

## 4. Conclusion
This paper presents a method for transforming flat cultural heritage records into FAIR Digital Object knowledge graphs using Large Language Models. By automating the distinction between resolvable entities and literals, and linking them to controlled vocabularies, the approach significantly enhances machine actionability. It addresses the critical lack of persistent identifier references in current data models, offering a new paradigm for the automated intelligent processing of cultural heritage data.
