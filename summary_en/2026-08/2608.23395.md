## 1. What the Paper Did
- **Background**: Current LLM-agent systems face conflicting design choices: decomposing work across many narrow agents versus using a single strong tool-using agent. While some industry reports favor multi-agent orchestration, others argue it introduces fragility and context dispersion.
- **Limitations of Existing Work**: Previous comparisons often vary multiple factors simultaneously (orchestration framework, base model, prompt budget, tools, and task), leaving the specific effect of "agent-scope granularity" under-controlled and empirically unresolved.

## Core Contributions
- **Proposed**: A preregistered, controlled pilot study framework for "right-sizing" agent decomposition in VAT determination, releasing the oracle, dataset, harness, raw traces, and analysis pipeline.
- **Challenge 1: Isolating agent count from prompt budget effects.**
  - **Difficulty**: Multi-agent systems typically consume more tokens, making it hard to distinguish whether performance gains come from architectural decomposition or increased computational/prompt budget.
  - **Solution**: Implemented "matched-token" experimental arms to compare single vs. multi-agent configurations under identical token budgets, isolating the pure architectural effect.
- **Challenge 2: Determining optimal decomposition granularity amidst complex dependencies.**
  - **Difficulty**: Tasks involve both parallel lookups and sequential dependencies (e.g., reverse-charge logic); over-decomposition risks context loss, while no decomposition may exceed single-agent capacity.
  - **Solution**: Fixed the activity surface (subtasks, tools, I/O schemas) and varied only subtask assignment across four configurations (1 to 5 workers). Proposed a heuristic: place one partition boundary at the midpoint of the dependency layer.

## Implementation and Evaluation
- **Setup**: Cross-border VAT determination with reverse charge, using a deterministic rule engine as Oracle. 4,400 runs including main sweeps, matched-token arms, and failure-injection arms.
- **Results**:
  - **Accuracy**: Intermediate configurations achieved highest accuracy (0.830), outperforming endpoints (Single: 0.720, Five-Agent: 0.770). However, they did not meet the preregistered bar for statistical significance against the fine endpoint, leaving the "intermediate-optimum" hypothesis directionally supported but unproven at pilot scale.
  - **Pareto Dominance**: The single agent did not Pareto-dominate the orchestrated set.
  - **Budget Effect**: Under matched-token conditions, the single agent trailed the leader by 6.5 points, but the confidence interval included zero, suggesting advantages may be explained by prompt budget rather than architecture.
- **Robustness**:
  - **Availability Faults**: All granularities absorbed timeouts/outages; wide-scope restarts over-recovered baseline by +0.160.
  - **Hallucination Injection**: A single schema-conforming hallucinated record degraded all configurations and inverted performance ordering, hitting fragmented (multi-agent) configurations hardest.

## 4. Conclusion
This paper provides empirical evidence on the non-monotonic impact of agent decomposition granularity. While intermediate decomposition showed higher accuracy, its advantage is confounded by prompt budget effects. The study highlights that simple multi-agent decomposition is not universally superior to single agents and is more vulnerable to structured hallucinations. The key contribution is a reproducible benchmark and a heuristic for right-sizing agent decomposition.
