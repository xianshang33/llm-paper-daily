## 1. What the Paper Does
- **Background**: As LLM agents are widely deployed in healthcare, finance, and personal assistants, memory systems have become default subsystems for providing persistent personalization and continuity. However, this continuous write-read mechanism expands the attack surface, raising concerns about security vulnerabilities.
- **Why Existing Work Fails**: Existing attacks on Retrieval-Augmented Generation (RAG) often assume a static embedding geometry, which becomes brittle under distribution shifts. In contrast, LLM agent memory systems are dynamic and non-stationary. Retrieval is influenced by variable contexts, mixed long/short-term memories, and multi-signal mechanisms, making traditional RAG poisoning methods ineffective or difficult to apply directly.

## Core Contributions
- **Proposed InjecMEM**: A novel memory injection attack paradigm that requires only a single interaction (without read/edit access to the memory store) to steer later responses of related queries toward a pre-specified output.
- **Challenge 1: How to ensure malicious records are accurately retrieved without read access and amidst complex retrieval mechanisms?**
  - **Difficulty**: Memory retrieval relies on dynamic contexts and multi-signal matching, making it hard for attackers to predict ranking mechanisms or thresholds.
  - **Solution**: Designed a retriever-agnostic "Anchor" containing high-recall topical cues, ensuring downstream retrieval consistently associates the injected record with the target topic.
- **Challenge 2: How to maintain the effectiveness of adversarial commands within uncertain and variable fused contexts?**
  - **Difficulty**: Retrieved memories are inserted into prompts of varying lengths and structures, where uncertainty in position and content can neutralize adversarial instructions.
  - **Solution**: Constructed a short "Adversarial Command" optimized via gradient-based coordinate search. By averaging over synthetic prompt templates and insertion positions, the command remains effective in steering outputs even in long prompts with variable placements.

## Implementation and Evaluation
- **Implementation & Deployment**: InjecMEM studies transferability through joint optimization across backbone models and is evaluated on multiple memory systems and backbone models. The code is open-source.
- **Evaluation Results**:
  - **Retrieval Reliability**: Achieved reliable topic-conditioned retrieval.
  - **Attack Success**: Successfully steered target generation and remained effective under memory drift.
  - **Specificity**: The attack only affected target-related queries, leaving non-target queries unaffected, demonstrating precision.
- **Comparison**: Compared to traditional RAG poisoning methods, InjecMEM demonstrates greater robustness and adaptability in dynamic memory systems, overcoming the limitations of static embedding assumptions.

#### Summary
This paper reveals new security threats facing LLM agent memory systems and proposes the InjecMEM attack framework. By decoupling retrieval anchors from adversarial commands and employing gradient optimization strategies, it successfully achieves effective injection and manipulation of memory systems in a single interaction. The results underscore the urgent need to harden memory systems and provide a reproducible framework for agent memory security research.
