## 1. What the Paper Does
- **Background**: Large Language Models (LLMs) are bounded sequential processors whose decisions are limited to model weights and active context. However, long-horizon agency requires external information storage and computation beyond these limits.
- **Limitations of Existing Work**: Current agent frameworks often hardcode workflows or struggle with context management (e.g., simple compaction), leading to "harness failures" being misinterpreted as "model failures." They lack the expressivity to allow models to dynamically construct programs, subagents, and feedback loops at inference time, failing to fully leverage test-time compute and external state management.

## Core Contributions
- **Proposed Prime Agent**, an open-source self-improving Recursive Language Model (RLM) harness designed to standardize long-horizon evaluation and coding-agent workflows, unlocking the model's true maximal capability through a low-friction, expressive interface.
- **Challenge 1: State Persistence and Information Management in Long-Horizon Tasks**. Critical information is easily lost as it exceeds context windows, and traditional methods fail to effectively utilize historical data. **Solution**: Introduces a "Continual Harness" that preserves histories, memories, skills, and prompts across trajectories. It combines this with a persistent IPython REPL acting as an L2 cache, enabling programmatic context processing and allowing the model to read/write addressable external state akin to a von Neumann architecture.
- **Challenge 2: Parallelization and Coordination in Complex Tasks**. Single models struggle to handle multi-threaded tasks or perform self-correction and verification simultaneously. **Solution**: Employs recursive subagents with direct agent-to-agent communication, allowing the model to dynamically construct subagent swarms for parallel work and coordination at inference time, while providing an Agents View for human inspection and management.

## Implementation and Evaluation
- **Implementation**: Prime Agent is an open-source framework that standardizes execution, recovery, verification, and resource accounting. It acts as a low-friction membrane to prevent infrastructure-induced failures, ensuring evaluations reflect the model's actual capabilities.
- **Evaluation Results**:
    - Achieved a significant performance increase on ARC-AGI-3 RHAE Best@1, rising from 30% to 95.5%.
    - Matched or exceeded native and popular harnesses in long-context coding, GPU-kernel generation, emulator construction, and autonomous nanoGPT speedruns.
    - Demonstrated continuous technology progression through refinement and parallelized work via dedicated subagents in Factorio.
- **Comparison**: Compared to other popular harnesses, Prime Agent better uncovers the model's upper bound in long-horizon tasks by avoiding performance underestimation caused by resource counting errors or premature termination.

## 4. Conclusion
Prime Agent addresses the bottlenecks of state management and computational expansion for LLMs in long-horizon tasks by introducing RLM abstractions and a Continual Harness. It transforms the model from a mere sequential processor into a von Neumann-like system capable of leveraging external storage and parallel computation, significantly enhancing performance in complex reasoning and coding tasks, and providing standardized infrastructure for assessing and improving AI agent capabilities.
