## 1. What the Paper Does
- **Background**: Tool-augmented Large Language Models (LLMs) are limited by fixed, human-written APIs. Existing dynamic tool creation systems typically prompt frozen LLMs at inference time, decoupling the model that writes the tool from the one that uses it.
- **Limitations of Prior Work**: In current methods, the tool creator receives no feedback on whether the generated schemas are effectively invocable. Often, a stronger model writes tools while a weaker one uses them, meaning the creator lacks incentive to optimize for usability. Furthermore, these methods do not explicitly optimize for tool quality or reusability during training.

## Core Contributions
- **Proposed SMITH (Schema-grounded Multi-task Iterative Tool Honing)**: A reinforcement learning framework that jointly trains tool creation and tool use within a single policy.
- **Challenge 1: Reward Decomposition**. Generated tools consist of both a schema and backend code implementation; failures in these components require different corrective signals, making reward assignment nontrivial. **Solution**: SMITH employs three separate reward axes to independently catch schema, code, and outcome failures, allowing each failure mode to contribute its own gradient.
- **Challenge 2: Circular Evaluation**. Evaluating tool quality requires a judge, but self-evaluation is unreliable, and external evaluators may suffer from alignment issues or lack the understanding to assess practical callability. **Solution**: By alternating rollouts between "build tasks" (writing tools from examples) and "use tasks" (invoking tools on held-out questions), the framework optimizes directly against answer correctness using exact verifiers, implicitly addressing the evaluation challenge.

## Implementation and Evaluation
- **Implementation**: A 4B parameter Qwen3 model was trained on 13 procedural reasoning tasks with exact verifiers.
- **Key Results**:
    - Achieved 79.8% macro-average accuracy on held-out tasks, outperforming all evaluated methods and surpassing an untrained 30B-A3B tool-writer.
    - Reached 40.4 on TabMWP-Hard and 42.6 on out-of-domain GQA (+7.6 over the best same-backbone inference-time baseline), without any visual or tabular training data.
- **Generalization**: Tools written by this 4B model also improved the performance of LFM-2.5-350M and Qwen3-30B-A3B on the same reasoning tasks.

#### Summary
This paper addresses the decoupling of tool creation and usage in existing tool-augmented LLMs by proposing the SMITH framework. By jointly optimizing schema generation, code implementation, and tool usage via reinforcement learning, it overcomes challenges related to reward decomposition and circular evaluation. Experiments demonstrate that a 4B parameter model can outperform larger baselines on multiple reasoning benchmarks and exhibits strong cross-model tool reusability, validating the effectiveness of joint training for tool creation and use.
