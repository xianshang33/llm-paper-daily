## 1. What the Paper Did
- **Background**: Large Language Model (LLM) agents excel in manually constructed, simple environments but often fail when deployed in complex, real-world web settings.
- **Why Existing Work Falls Short**: Current research attributes this failure to compositional generalization gaps. While large-scale post-training and existing test-time learning strategies (prompting, sampling, planning) offer improvements, they are constrained by the lack of reliable ground-truth rewards and fail to address the degradation in exploration success and self-assessment accuracy in compositionally complex environments.

## Core Contributions
- **Proposed**: A label-free learning framework called Test-Time Environment Decomposition (TTED), enabling LLM web agents to learn from simple environment observations during inference.
- **Challenge 1: Poor Compositional Generalization in Complex Environments.**
  - **Difficulty**: Real-world web pages contain multiple functional sub-structures (search bars, forms, etc.). Agents struggle to combine these individually simple components, leading to failure in cluttered interfaces.
  - **Solution**: Introduces trial steps to decompose complex observations into sub-modules, allowing the agent to gain experience in simpler sub-environments, which effectively composes to improve performance in the full environment.
- **Challenge 2: Ineffective Test-Time Learning without Feedback.**
  - **Difficulty**: Without external rewards, agents suffer from reduced self-assessment accuracy in complex settings, hindering effective learning during inference.
  - **Solution**: Implements a label-free learning method where agents adapt behaviors based on experience gained in decomposed sub-environments, significantly enhancing compositional generalization in real-world web automation tasks.

## Implementation and Evaluation
- **Implementation & Deployment**: The TTED framework is implemented as a test-time learning strategy requiring no additional labeled data. Code and data are open-sourced.
- **Evaluation Results**: Empirical evaluations on both synthetic and realistic benchmarks demonstrate that: (1) experience gains from simpler sub-environments effectively improve performance in the full environment; (2) test-time training on sub-environments significantly boosts compositional generalization in real-world web automation.
- **Comparison**: Unlike existing test-time learning methods that struggle with compositional complexity, TTED explicitly addresses exploration bottlenecks and self-assessment failures by decomposing the environment, showing superior robustness and generalization in complex real-world scenarios.

## 4. Conclusion
This paper addresses the performance collapse of LLM web agents in complex real-world environments by proposing Test-Time Environment Decomposition (TTED). By decomposing complex observations into sub-modules and employing label-free test-time learning, TTED effectively bridges the compositional generalization gap. Experiments confirm its efficacy in enhancing agent performance in real-world web automation, highlighting the critical role of learning environment decomposition skills for robust deployment.
