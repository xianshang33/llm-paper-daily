## 1. What the Paper Did
- **Background**: In LLM agents using external tools, influence-based guardrails are widely used to detect malicious attacks. However, existing guardrails struggle to reliably distinguish between legitimate, user-authorized actions and malicious, unauthorized actions when both rely on external tool information.
- **Limitations of Existing Work**: Current guardrails fail to distinguish "what shaped the action" from "whether the action was authorized." For instance, if a user authorizes a transfer to Alice but the account number is retrieved via a tool, the tool's output has a causal influence on the action. Existing methods misinterpret this legitimate causal signal as an attack, leading to false positives, unnecessary verification, reduced utility, and increased latency.

## Core Contributions
- **Proposed an Authorization-Equivalence Audit Framework**: Systematically evaluated the effectiveness of causal signals in distinguishing legitimate tool use from attacks by constructing 96 test conditions derived from 24 base cases.
- **Challenge 1: Misalignment between Causal Signals and Authorization Status**. The difficulty lies in the fact that legitimate source changes (e.g., from user input to tool output) cause causal scores to shift towards the attack region, with a magnitude greater than that of actual authorization changes. By fixing authorization, action, and intended effect while only changing the value source, the paper demonstrates that this harmless relocation shifts signals towards the attack region in all 24 cases for both Llama and Gemma scorers, revealing that current signals encode "source of influence" rather than "authorization status."
- **Challenge 2: Trade-off between False Positives and False Negatives in Guardrail Architectures**. The challenge is balancing effective attack interception without disrupting legitimate operations. The paper evaluates different architectures, finding that while semantic monitors achieve 0% attack success, they drop utility to 28%. Conversely, shadow-based guardrails allow all harmless runs but fail to reject unauthorized actions more effectively (57.5% of unauthorized runs pass automatically vs. 29.2% of authorized runs), highlighting that reference construction and routing are integral to security decisions.

## Implementation and Evaluation
- **Experimental Setup**: Used Llama and Gemma as scorers to perform an authorization-equivalence audit on 24 base cases, generating 96 test conditions. Compared matched source comparisons against unauthorized control groups.
- **Key Results**:
    - In matched source comparisons, changing the required value source from user input to legitimate tool results shifted causal signals towards the attack region in all 24 cases, despite the action remaining unchanged.
    - The average score shift from benign relocation was larger than that from actual authorization changes.
    - **Architecture-level Evaluation**: With a semantic monitor, attack success was 0%, but utility dropped to 28% (compared to 60% utility and 16% attack success without it).
    - **Shadow Guardrail Evaluation**: While allowing all tested harmless runs, it did not reject matched unauthorized actions more often overall. 57.5% of unauthorized runs passed automatically before later security checks, compared to 29.2% of authorized runs.
- **Comparison Conclusion**: The results indicate that the studied causal signal reveals what shaped an action but does not reliably encode whether it was authorized. This contradicts the traditional view that high causal influence equates to high risk, emphasizing the importance of proper reference construction and routing in guardrail design.

#### Summary
This paper exposes a fundamental flaw in current influence-based guardrails for tool-using LLM agents: the conflation of "causal influence" with "authorization status." Through rigorous auditing, the authors demonstrate that legitimate source changes are misclassified as attack signals, causing significant usability-security trade-offs. The study concludes that relying solely on causal signals is insufficient for effective security; future guardrail designs must integrate more sophisticated reference construction and routing mechanisms to accurately distinguish legitimate tool-assisted operations from malicious indirect prompt injections.
