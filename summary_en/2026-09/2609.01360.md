## 1. What the Paper Does
- **Background**: Failures in Large Language Model (LLM) agents often involve multiple interrelated errors rather than a single mistake. Existing attribution methods typically identify a responsible agent, step, or root cause but fail to explicitly model the dependencies between errors.
- **Limitations of Prior Work**: Current approaches focus on single-error attribution, treating each error as an isolated target. They are inefficient for multi-label outputs and lack understanding of error propagation mechanisms (e.g., upstream triggers causing downstream effects), failing to provide comprehensive step-level multi-error annotations.

## Core Contributions
- **Proposed EDGE Framework**: An Error Dependency Graph-guided framework for multi-error attribution that constructs dependency graphs from observed errors and validates causal subsets via counterfactual rollout.
- **Challenge 1: How to effectively capture and model complex dependencies between errors?**
  - **Difficulty**: Errors play distinct structural roles (upstream triggers, downstream effects, parallel symptoms), and distinguishing correlation from causality is difficult using observation alone.
  - **Solution**: EDGE constructs an error dependency graph using within-trace ordering and cross-trace regularities. It validates edges through counterfactual rollout to isolate a causally reliable subgraph, providing a robust basis for explanation.
- **Challenge 2: How to improve multi-error attribution accuracy while maintaining coverage?**
  - **Difficulty**: Relying solely on intervention validation may miss errors due to limited evidence, while relying only on observational data may introduce noise.
  - **Solution**: A two-stage LLM-as-judge detector is employed. The first stage predicts an initial error set, and the second stage verifies downstream errors suggested by the graph. By combining score-filtered observational edges (for coverage) with intervention-validated edges (for causal interpretability), EDGE achieves efficient and accurate attribution.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on TRAIL and MAST benchmarks, which feature distinct error taxonomies.
- **Key Results**: EDGE significantly improves category-level multi-error attribution across most evaluated models and settings compared to baselines. It successfully recovers downstream errors guided by dependencies, avoiding the limitation of collapsing error cascades into a single trigger.
- **Comparison**: EDGE outperforms existing single-error attribution methods, particularly in scenarios with complex error dependencies. Experiments with adapted Who&When-style prompts demonstrate that the dependency graph enhances performance across various prompting strategies, validating the utility of dependency structures as diagnostic priors.

## 4. Conclusion
This paper addresses the neglect of error dependencies in LLM agent multi-error attribution by proposing EDGE. By constructing and validating error dependency graphs and employing a two-stage detection mechanism, EDGE not only improves attribution accuracy but also provides a reliable causal basis for error explanation and repair. The results indicate that dependency structure is a powerful diagnostic tool beyond isolated root-cause prediction.
