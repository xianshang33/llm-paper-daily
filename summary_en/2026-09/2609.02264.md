## What the Paper Does
- **Background**: Adapting communication topology in LLM multi-agent systems to each query improves both accuracy and efficiency. The field is moving from hand-designed fixed structures to learned, query-conditioned generative designs.
- **Why Existing Work Fails**: Current methods treat topology design as conditional graph generation, using variational, autoregressive, or diffusion decoders to search the $N \times N$ adjacency space, ranked by a graph network proxy based on utility and structural costs (e.g., edge count). This formulation is misaligned because:
    1. The space of useful topologies is tiny (collapsing to ~6 distinct graphs), making generative search overly complex;
    2. Edge count is negatively correlated with actual token consumption (sparser graphs lead to longer completions), invalidating edge-count-based cost proxies;
    3. Message-passing scorers are adjacency-invariant when agents share profiles (common in benchmarks), rendering them unable to rank candidates effectively.

## Core Contributions
- **Proposed Codebook Agent**: An amortized topology design framework that compresses successful topologies into a fixed codebook using a Vector-Quantized Autoencoder (VQ-AE) and selects them via lightweight MLPs.
- **Challenge 1: The effective topology space is sparse and discrete, making generative search inefficient and redundant.**
    - **Difficulty**: Despite the huge search space, very few topologies perform well. Generative models waste capacity searching vast invalid spaces.
    - **Solution**: The paper uses an offline-trained VQ-AE to compress all successful topologies into a query-independent codebook of just 16 entries. At test time, a reward-weighted MLP maps the query embedding directly to a code distribution, retrieving the best topology without any iterative search.
- **Challenge 2: Traditional proxy metrics (like edge count) are inverted relative to real inference costs, and GNN scorers fail under identical node features.**
    - **Difficulty**: Sparse communication often increases LLM completion length (and thus token cost), breaking the "fewer edges = lower cost" assumption. Standard GNN scorers cannot distinguish topologies when node features are identical.
    - **Solution**: A new MLP proxy is designed to read the flattened adjacency matrix directly, regressed on measured utility and per-task normalized token cost. It reranks decoded candidates in a single batched forward pass, avoiding message passing and accurately reflecting true inference costs.

## Implementation, Deployment, and Evaluation Results
- **Implementation & Deployment**: Codebook Agent requires no iterative search or message passing at test time. Topology generation takes only 2.4 ms. The system consists of an offline-trained VQ-AE codebook and online MLPs for query-to-code mapping and reranking.
- **Evaluation Results**:
    - **Accuracy**: Achieves the highest accuracy on all six benchmarks, with an average score of 84.6, outperforming the strongest prior designer (83.0).
    - **Efficiency**: Reduces LLM token usage by 21.9%–33.2% compared to previous methods.
    - **Speed**: Extremely fast topology emission (2.4 ms), significantly faster than iterative generative methods.
- **Comparison**: Compared to variational, autoregressive, or diffusion-based designers, Codebook Agent offers superior accuracy and significantly lower computational and token costs, addressing the misalignment in metrics and search efficiency of existing works.

## Summary
Codebook Agent exposes three critical misconceptions in current LLM multi-agent topology generation: the extreme sparsity of effective topologies, the misleading nature of structural cost proxies, and the limitations of graph scorers. By reframing topology design as a codebook retrieval problem, the method achieves high efficiency and accuracy, demonstrating that simple discrete retrieval outperforms complex continuous space generation in this domain.
