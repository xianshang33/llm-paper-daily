## 1. What the Paper Does
- **Background**: Personalized language agents use persistent memory to adapt to users over time, but this mechanism creates an attack surface. When new information conflicts with stored preferences, agents must distinguish genuine preference drift from temporary context shifts, ambiguity, or adversarial memory poisoning.
- **Limitations of Existing Work**: Current personalization methods treat all updates as authentic, making them vulnerable to manipulation, while memory defenses reject untrusted content without modeling how real preferences evolve. Rules based solely on recency and provenance are insufficient because adversaries can mimic the statistics of legitimate revisions, leading to a trade-off between adaptability and security.

## Core Contributions
- **Proposed CAPTURE Framework**: A system designed to disentangle preference drift from memory poisoning, featuring a neural differential-equation belief tracker, a multi-timescale memory ledger, uncertainty-triggered clarification, and counterfactual auditing.
- **Challenge 1: Distinguishing Genuine Preference Changes from Adversarial Poisoning**. The difficulty lies in the observational similarity between legitimate updates and attacks within single turns, where attackers can mimic legal behavior. CAPTURE addresses this by modeling the latent user state via neural differential equations and using a multi-timescale memory ledger to differentiate anomalous patterns from true evolution based on temporal dynamics and causal influence.
- **Challenge 2: Handling Uncertainty and Avoiding Erroneous Updates**. The challenge is that blind updates under insufficient evidence cause pollution, while excessive conservatism reduces personalization. CAPTURE introduces an uncertainty-triggered clarification mechanism that actively queries the user when belief uncertainty exceeds a threshold, and audits the causal influence of cited memories via counterfactual removal to ensure update authenticity.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on 480 held-out episodes from 96 users, with additional zero-shot evaluation on an independently constructed benchmark and replay of longitudinal interaction histories from 40 users over 2-3 weeks.
- **Key Results**:
    - **Win Rate**: CAPTURE achieved a 71.5% win rate, outperforming an identically supervised baseline (69.3%) and the strongest heuristic baseline (66.1%).
    - **Security vs. Adaptability**: It limited fixed-policy poisoning success to 11.5% while accepting 83.5% of genuine preference updates.
    - **Adaptive Attack**: Under an adaptive attacker with access to model weights, attack success rose to 24.7%, exposing a real adaptation-security trade-off.
- **Comparison**: Compared to methods relying solely on provenance filtering, CAPTURE significantly improves robustness while maintaining high adaptability. The frozen system demonstrated good generalization in zero-shot evaluations, proving the effectiveness of explicitly modeling preference authenticity.

#### Summary
This paper addresses the conflict between security and adaptability in the memory mechanisms of personalized LLM agents by proposing the CAPTURE framework. By formulating the problem as a continuous-time partially observable decision process over a latent user state, CAPTURE effectively decouples genuine preference drift from memory poisoning using neural differential equations, multi-timescale memory, and active clarification. Experiments demonstrate that the method significantly improves personalization accuracy while effectively resisting various forms of memory poisoning attacks, offering a new perspective for building intelligent and secure memory-augmented agents.
