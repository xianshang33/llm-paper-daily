## 1. What the Paper Did
- **Background**: Modern AI agent harnesses expose lifecycle hooks that bind shell commands to runtime events (e.g., session start, tool calls). These commands execute with host privileges but are distributed as configuration and may trigger at times unobserved by the LLM.
- **Why Existing Work Fails**: Prior studies focused on malicious plugin code, tool description poisoning, or skill manipulation, ignoring lifecycle hooks as an independent attack target. Since hook execution occurs outside the LLM's reasoning loop, traditional defenses based on prompt adversarial testing or model alignment cannot inspect or prevent these executions.

## Core Contributions
- **Proposed HookPry**: An open-source, fully automated attack framework that systematically exploits vulnerabilities in lifecycle hook update paths across heterogeneous AI agent harnesses.
- **Challenge 1: Stealthy Command Binding and Execution Outside LLM Monitoring**. The difficulty lies in hook configurations being treated as metadata rather than code, executing without LLM oversight, thus bypassing content-based defenses. HookPry addresses this by controlling plugin metadata and hook configurations to silently bind attacker-chosen commands to benign events during updates, triggering malicious host-side behaviors via event-driven mechanisms.
- **Challenge 2: Cross-Framework Generality and Supply Chain Threat Model Realization**. The challenge is verifying the ubiquity of this attack surface across diverse architectures. HookPry leverages the two-layer plugin architecture (marketplace metadata for discovery, hooks for execution) to demonstrate that controlling only metadata and configuration allows trojanizing benign plugins across 7 major frameworks.

## Implementation and Evaluation
- **Implementation & Deployment**: HookPry realizes 10 attack objectives. It was evaluated across 1,000 end-to-end runs involving 25 combinations of harnesses and backends.
- **Evaluation Results**: HookPry compromised all 7 evaluated harnesses, with per-harness success rates reaching 92.5%.
- **Comparison with Related Work**: Current defenses are insufficient. Microsoft Defender showed 0% recall, and the union of three static defense methods missed 47.5% of malicious artifacts, indicating that current static analysis and endpoint protection fail to detect this configuration-based supply chain attack.

## 4. Conclusion
This paper identifies the lifecycle-hook update path in AI agent harnesses as a new attack surface. Attackers can trojanize benign plugins via supply chains by controlling only plugin metadata and hook configurations, leading to malicious host behaviors like privilege escalation. The proposed HookPry framework demonstrates the prevalence and high success rate of this vulnerability across mainstream frameworks, highlighting the ineffectiveness of existing defenses and the urgent need for specialized security mechanisms for lifecycle hooks.
