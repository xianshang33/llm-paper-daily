## 1. What the Paper Does

### Background
LLM agent systems increasingly integrate provenance tracking, authorization, policy enforcement, protocol adapters, and execution controls to mitigate risks like indirect prompt injection and ensure secure external actions.

### Why Existing Work Falls Short
Existing security mechanisms are typically designed and tested in isolation. However, composing these individually correct components does not guarantee an end-to-end secure system. Security-critical context may be dropped, widened, rebound, or reinterpreted as data crosses component boundaries, a failure mode identified as "security-context discontinuity."

## Core Contributions

### Proposed CONTINUITY Framework
A framework for verifiable composition of agent security controls. It models each component with assume-guarantee contracts and carries authenticated security context across transitions using signed root grants, provenance commitments, role-bound transition receipts, and other cryptographic primitives.

### Challenge 1: Loss or Tampering of Security Context Across Components
**Description & Difficulty**: In complex agent workflows, security-critical information (e.g., data source, authorization state) can be lost or confused during serialization or transformation across multiple components (ingress, policy gateway, adapters), breaking the chain of trust for final actions.
**Solution**: CONTINUITY formalizes "End-to-End Consequence Integrity" (ECI), requiring every external effect to be backed by a valid authorization witness. It uses signed provenance manifests, value-bound typed releases, and independently verifiable transformation witnesses to cryptographically link every step from initial authorization to final execution.

### Challenge 2: Lack of Systematic Verification and Defense Against Composition Failures
**Description & Difficulty**: Traditional testing struggles to cover complex cross-component interaction failures, especially those involving semantic reinterpretation or state replay, leaving systems vulnerable to crafted composition attacks.
**Solution**: The authors implemented a reference verifier and a deterministic cross-layer fault-injection suite covering 32 fault classes. By enforcing single-use execution states, revocation bindings, and replay-bound finality permits, CONTINUITY detects and prevents harmful effects caused by context discontinuity.

## Implementation and Evaluation

### Implementation
A 1.5-KLOC trusted-core prototype was built, including a reference verifier and a deterministic conformance suite.

### Evaluation Results
- **Scale**: Covered 4 application domains, 32 cross-layer fault classes, 2,560 parameterized attack instances, 700 benign tasks, and 200 ambiguous tasks.
- **Security**: The full CONTINUITY configuration committed zero harmful external effects across all 2,560 attack instances, successfully blocking all 128 fault-domain classes.
- **Usability**: Completed all 700 benign tasks and escalated all 200 ambiguous cases.
- **Performance**: Median proof verification time was 4.21 ms; median end-to-end transition production, verification, permit issuance, and finality time was 7.17 ms.

### Comparison with Related Work
- **Baseline**: The strongest incomplete reference configuration (lacking some CONTINUITY mechanisms) committed harmful effects in 65.6% of attack instances.
- **Ablation Studies**: Removing specific invariants reopened 4–24 fault-domain classes, demonstrating the necessity of each contract component.
- **Advantage**: Unlike traditional methods relying on isolated controls, CONTINUITY ensures security across the entire instruction-to-effect path via explicit contracts, achieving deterministic conformance with low latency overhead.

## 4. Conclusion

This paper addresses "security-context discontinuity" in LLM agent systems, where the composition of individual security components can lead to end-to-end failures. The proposed CONTINUITY framework maintains security context integrity across component boundaries using assume-guarantee contracts and cryptographic primitives. Experiments demonstrate that the framework effectively resists various cross-layer composition attacks with minimal latency overhead while ensuring the correct execution of benign tasks, offering a new paradigm for building verifiably secure LLM agents.
