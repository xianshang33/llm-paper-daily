## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents increasingly rely on external skill libraries to extend their capabilities. However, as skill registries grow to tens of thousands of entries, routing user requests efficiently becomes a bottleneck. Complex tasks often require combinations of multiple complementary skills rather than a single tool.
- **Why Existing Work Fails**: Current skill routers typically model selection as a pointwise retrieval or reranking problem, scoring each candidate independently against the query. This approach fails for compositional tasks because it often returns functionally redundant skills (e.g., multiple similar data processing tools), wasting limited context budget and omitting other necessary but distinct complementary skills.

## Core Contributions
- **Proposed**: Diverse Skill Routing (DSR), a diversity-aware reranking framework that utilizes a Determinantal Point Process (DPP) to balance relevance and non-redundancy.
- **Challenge 1: How to remove functional redundancy while maintaining relevance?**
  - **Difficulty**: Traditional diversity methods might penalize skills that are similar simply because they are both relevant to the same query, potentially removing useful complementary tools.
  - **Solution**: DSR introduces a "query-residual diversity kernel" that specifically penalizes redundant overlap between skills while reducing penalties for similarities arising solely from shared query relevance, thus distinguishing true redundancy from necessary similarity.
- **Challenge 2: How to shift from individual ranking to complementary set selection?**
  - **Difficulty**: Independent scoring cannot capture the complementary relationships between skills, leading to incomplete coverage for multi-step workflows.
  - **Solution**: By employing a DPP framework, DSR models skill selection as a set selection problem, globally optimizing the subset of skills to ensure they are both highly relevant and mutually complementary, maximizing coverage for complex tasks.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on the SkillRouter benchmark, which features a pool of approximately 80,000 skills across various complex task scenarios.
- **Baselines**: Compared against strong pointwise reranking baseline methods.
- **Key Results**:
  - DSR outperforms baselines in both recall and full coverage.
  - Performance gains are particularly significant for queries requiring multiple skills.
  - The results demonstrate that treating skill routing as complementary set selection, rather than just relevance ranking, more effectively utilizes context budget and improves agent performance on complex tasks.

## 4. Conclusion
This paper addresses the redundancy issue in current LLM agent skill routing and proposes Diverse Skill Routing (DSR), a framework based on Determinantal Point Processes. By introducing a query-residual diversity kernel, DSR successfully balances relevance and diversity, overcoming the inefficiencies of traditional pointwise ranking in compositional tasks. Experiments show that the method significantly improves coverage and recall in large-scale skill libraries, offering new insights for building more efficient and scalable LLM agent systems.
