## 1. What the Paper Does
- **Background**: Autonomous LLM agents can transform untrusted content into effectful actions like payments or permission changes. If the process interpreting this content also controls a reusable signing credential, prompt injection attacks can cross the judgment boundary and seize execution authority.
- **Limitations of Existing Work**: Multi-agent debate or voting mechanisms improve semantic judgment but produce advisory outputs lacking enforcement; policy and delegation systems constrain privileges but struggle with ambiguous evidence requiring model judgment; traditional threshold signing ensures cryptographic quorum but does not bind model-based review semantics to specific executable actions or fully isolate signing keys from LLM processes.

## Core Contributions
- **Proposed KITA**: A "Review-to-Authorization" architecture that keeps the user's personal secret signing key and all threshold signing-key shares outside all LLM processes.
- **Challenge 1: Preventing prompt injection from crossing the judgment-execution boundary**. The difficulty lies in LLMs both processing untrusted inputs and controlling execution credentials, allowing malicious inputs to trigger unauthorized actions. KITA isolates signing key shares outside LLMs and employs multiple independent LLM reviewers, ensuring that no single compromised proposer or minority of reviewers can generate valid authorization, thus cryptographically blocking direct access to execution rights via injection.
- **Challenge 2: Ensuring strong binding between semantic review and specific execution actions**. The challenge is guaranteeing that the model's approved "semantic intent" accurately corresponds to the underlying "byte-level execution instructions" to prevent tampering. KITA requires proposers to construct canonical authorization objects; isolated signer services release signature shares for these specific actions only after authenticated approval by t distinct reviewers, establishing execution-bound authorization integrity.

## Implementation and Evaluation
- **Implementation**: The authors implemented the complete reviewer-to-executor path using a structured-output LLM adapter and threshold BLS signatures.
- **Evaluation Results**: Six system tests validated quorum gating and message binding at the interface. Cryptographic microbenchmarks measured the online signing path and its scaling behavior, demonstrating feasibility.
- **Comparison**: Unlike protocols like AP2 that rely solely on deterministic code for mandate validation, KITA introduces model-based threshold review as an enforcement condition. Compared to simple multi-agent debates, KITA provides cryptographically guaranteed execution authorization rather than just advice.

## 4. Conclusion
This paper addresses security risks in autonomous LLM agents by proposing the KITA framework. By combining key isolation with threshold signing, KITA ensures that even if some LLM processes are compromised via prompt injection, sensitive operations cannot be executed without approval from a sufficient number of independent reviewers. This approach effectively transforms semantic review into cryptographically enforced execution authorization, enhancing the security and integrity of LLM agents during high-risk operations.
