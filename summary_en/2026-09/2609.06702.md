## 1. What the Paper Does
- **Background**: Processing long documents is a core capability for LLMs, but models suffer from "context rot" and positional bias, where evidence far from input boundaries is ignored, even with million-token context windows.
- **Why Existing Work Fails**: Sequential memory agents (e.g., MemAgent) read chunks sequentially and compress memory. This couples document traversal with reasoning depth, causing sensitivity to evidence placement (due to information deficit during compression) and linear inference latency (due to irreducible sequential dependencies).

## Core Contributions
- **Proposed PARSER**: A framework that decouples reading from reasoning. It uses a bank of lightweight, frozen subagents to read document chunks in parallel, while a lead agent performs deep reasoning through iterative scatter-gather rounds.
- **Challenge 1: Sensitivity to Evidence Placement**. Difficulty: Sequential methods judge relevance with incomplete information, missing scattered evidence in multi-hop reasoning. Solution: PARSER reads all chunks in parallel, allowing the lead agent to aggregate global evidence in each iteration, eliminating positional bias.
- **Challenge 2: High Inference Latency**. Difficulty: Sequential dependency causes latency to grow linearly with document length. Solution: By parallelizing the reading phase and keeping the lead agent's reasoning lightweight, PARSER reduces inference latency by up to 11x.

## Implementation and Evaluation
- **Implementation**: Learnable behavior is concentrated in the lead agent, optimized via reinforcement learning. Subagents are frozen off-the-shelf models.
- **Results**: On multi-hop QA (7K-896K tokens), PARSER (4B backbone) outperforms the strongest sequential baseline by 5.7 points on average and 12.0 points at 896K tokens. With a 9B backbone, it surpasses DeepSeek-V4-Pro by 6.3 points.
- **Comparison**: PARSER is robust to perturbations in evidence position, order, and distance, unlike sequential methods which show large accuracy swings. It also achieves up to 11x lower inference latency.

## 4. Conclusion
PARSER effectively addresses positional bias and high latency in long-context LLM agents by decoupling reading and reasoning. Its parallel reading mechanism ensures comprehensive evidence retrieval, while the RL-optimized lead agent enables deep iterative reasoning. Experiments demonstrate superior accuracy and efficiency compared to state-of-the-art sequential methods and top-tier closed-source models.
