## 1. What the Paper Does
- **Background**: Financial scenarios are diverse and complex, involving varying data conditions, tool configurations, and workflows. Existing Computer-Using Agent (CUA) evaluation tasks are largely manually constructed, limiting scalable coverage of real-world financial scenarios and incurring high costs (e.g., Finch required over 700 hours of expert annotation).
- **Limitations of Existing Work**: Current financial benchmarks primarily assess agents on executing predefined tasks, lacking a unified standard to evaluate "task construction" capabilities. Furthermore, there is no construction agent tailored for dynamic financial CUA tasks; existing automated methods offer limited support for jointly constructing financial evidence, application states, dynamic events, and verification rules.

## Core Contributions
- **Proposed**: The FinCUABuild framework, which includes FinCUABuildBench (a benchmark for evaluating financial CUA task construction) and FinCUABuildAgent (a multi-agent system for automatic task construction).
- **Challenge 1: How to comprehensively and fairly evaluate task construction capabilities?**
  - **Difficulty**: It is difficult to ensure construction requests cover sufficient workflows and runtime variations, and inconsistent input/output standards across methods hinder fair comparison.
  - **Solution**: Introduced FinCUABuildBench with 576 construction requests covering 24 financial workflows and 3 types of runtime variation. It features standardized input, budget, and output specifications, along with a task qualification mechanism based on execution tests and quality checks.
- **Challenge 2: How to automatically generate high-quality, executable dynamic financial tasks?**
  - **Difficulty**: A single model struggles to simultaneously handle task logic generation, environment configuration (e.g., spreadsheet states), and validator generation, leading to low executability and accuracy.
  - **Solution**: Designed FinCUABuildAgent, a multi-agent system with three modules responsible for task construction, environment construction, and validator construction, working collaboratively to improve the strict qualification rate of generated tasks.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on FinCUABuildBench, comparing existing agent-based construction methods with the proposed FinCUABuildAgent.
- **Key Results**: Under the same model backbone, existing agent-based construction methods achieved strict qualification rates of only 1.3%-8.3%, whereas FinCUABuildAgent reached 31.3%, significantly outperforming baselines.
- **Downstream Evaluation**: Further evaluations showed that tasks constructed by FinCUABuildAgent can effectively differentiate the task-execution capabilities of different CUAs, demonstrating their practical evaluation value.

#### Summary
This paper addresses the high cost and low coverage of CUA evaluation task construction in the financial domain. By introducing the FinCUABuildBench benchmark and the FinCUABuildAgent multi-agent system, it achieves automated, high-quality construction of financial CUA tasks. Experiments demonstrate that this method not only significantly improves task construction qualification rates but also generates tasks that effectively serve downstream agent capability evaluation, offering a practical path for expanding evaluation coverage in financial scenarios.
