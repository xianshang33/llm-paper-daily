## 1. What the Paper Does
- **Background**: Linguistic typology relies on expert analysis of reference grammars across languages to uncover linguistic universals. Traditionally, building large typological databases (e.g., WALS) requires years of effort from hundreds of trained linguists, making it labor-intensive and unscalable.
- **Limitations of Existing Work**: Current NLP approaches mostly focus on task-specific or language-specific models. They lack generalist agents capable of actively querying, synthesizing cross-lingual evidence, and performing interpretable reasoning, thus failing to support large-scale typological hypothesis testing and feature coding effectively.

## Core Contributions
- **Proposed AUTOTYPOLOGIST**: The first LLM agent for evidence-grounded typological analysis, capable of actively querying reference grammars to summarize and compare grammatical structures across typologically diverse languages.
- **Challenge 1: How to accurately extract typological features from unstructured text?**
  - **Difficulty**: Reference grammars contain dispersed and implicit information in prose, making direct extraction error-prone.
  - **Solution**: The agent employs a ReAct-style workflow to plan evidence needs, retrieve relevant grammar sections and Interlinear Glossed Text (IGT), analyze evidence using linguistically motivated tools, and iteratively update claims, achieving high agreement with expert annotations when prose is available.
- **Challenge 2: How to conduct cross-lingual hypothesis testing and handle counterexamples?**
  - **Difficulty**: Verifying typological universals requires synthesizing evidence from multiple languages to identify both supporting cases and potential counterexamples, demanding strong cross-lingual reasoning capabilities.
  - **Solution**: The agent synthesizes cross-lingual evidence and constructs a structured evidence graph recording claims, citations, and confidence scores, enabling the identification of both supporting and contradicting evidence in hypothesis testing.

## Implementation and Evaluation
- **Dataset**: Released a typological dataset built from 25 open-source reference grammars across 14 language families, containing structured grammar chunks, extracted IGT examples, and metadata.
- **Evaluation Tasks**:
  1. **Typological Feature Coding**: Compared against expert annotations. The agent reproduces expert codings with high agreement when reference grammar prose is available, though it faces challenges when relying solely on IGTs.
  2. **Typological Hypothesis Testing**: Tested against typological universals. The agent successfully synthesized cross-lingual evidence and identified both supporting cases and counterexamples.
- **Comparison**: Unlike traditional task-specific models, AUTOTYPOLOGIST offers a scalable and inspectable framework. While expert validation is still required, it significantly reduces manual effort and enhances transparency.

## 4. Conclusion
This paper introduces AUTOTYPOLOGIST, an LLM agent designed to address the scalability bottleneck in linguistic typology. By combining retrieval-augmented generation with ReAct reasoning, the agent performs evidence-grounded feature coding and hypothesis testing. Experiments demonstrate its effectiveness in utilizing prose descriptions and identifying cross-lingual evidence, providing a powerful auxiliary tool for linguists and promoting scalable, interpretable typological research.
