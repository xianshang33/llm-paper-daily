## 1. What the Paper Does
- **Background**: Long-horizon Large Language Model (LLM) agents rely on external memory systems to preserve user preferences and task knowledge across extended interactions. However, growing interaction histories accumulate stale, misleading, redundant, or incompatible records.
- **Why Existing Work Fails**: Conventional retrieval mechanisms optimize semantic compatibility rather than downstream utility, frequently introducing harmful evidence into the active context. Existing single-record evaluation methods (e.g., Leave-One-Out) fail when facing memories with complex dependencies (such as redundancy and joint harm), as removing a single record may not yield observable counterfactual changes (a phenomenon known as "redundant conflict masking"). Furthermore, directly modifying persistent memory poses severe safety risks, potentially causing catastrophic cross-task performance regression.

## Core Contributions
- **Proposed MeClear Framework**: A task-conditioned memory clearance framework that identifies memories with negative downstream utility through cooperative attribution and selectively suppresses them during agent execution.
- **Challenge 1: Addressing attribution failure due to redundant conflict masking**. When multiple memories jointly cause task failure, removing one individually may not reveal its negative impact, leading to false negatives in traditional methods. MeClear combines Leave-One-Out screening with sampled cooperative Shapley attribution, measuring marginal contributions across subset permutations to effectively distribute utility among interacting evidence and uncover masked harmful memories.
- **Challenge 2: Avoiding safety risks from permanent memory modification**. Directly deleting memory can undermine the contextual basis for other tasks. MeClear executes a query-scoped minimal clearance strategy over a nested filtration, verifying task recovery on the cleared context without permanently altering the persistent memory bank, ensuring dynamic suppression only for the current query.

## Implementation and Evaluation
- **Experimental Setup**: Comprehensive evaluations were conducted across ten long dialogue memory pools.
- **Key Results**: MeClear achieved a target recall of 85.9% and an overall task recovery rate of 82.3%.
- **Comparison**: It represents a 25.5 percentage point improvement over Leave-One-Out (LOO) baselines, demonstrating its effectiveness in handling complex memory dependencies and clearing harmful contexts.

#### Summary
MeClear addresses the pain points of memory retrieval in long-horizon LLM agents by proposing a risk-aware memory clearance method based on cooperative game-theoretic attribution. It solves the problem of traditional single-point evaluation failing to identify redundant harmful memories via Shapley values and ensures memory system safety through dynamic suppression rather than permanent deletion. Experiments show that this method significantly outperforms existing baselines, offering a new solution for memory management in long-horizon agents.
