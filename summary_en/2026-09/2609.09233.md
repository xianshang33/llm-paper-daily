## 1. What the Paper Did
- **Background**: LLM agents typically leverage reusable knowledge through "Agent Skills," which are multi-file packages containing instructions and scripts. These are executed by loading their instructions directly into the agent's context window.
- **Why Existing Work Fails**: As task horizons lengthen, this approach becomes brittle. Reasoning quality degrades significantly as more information accumulates in the single context window, leading to failures in long-horizon tasks.

## Core Contributions
- **Proposed**: An alternative approach where skill packages are invoked as "Subagents" rather than just loaded as context prompts.
- **Challenge 1: Context Bloat and Reasoning Degradation in Long-Horizon Tasks**. Accumulated context distracts the LLM and lowers reasoning quality. The paper addresses this by spawning fresh, dedicated context windows for each subtask, allowing subagents to focus on specific skill instructions without interference from the main context history.
- **Challenge 2: Efficiency of Modular Knowledge Invocation and Boundary Definition**. Traditional skill loading lacks clear execution boundaries, causing instruction confusion. The method requires skills to expose clear input-output contracts and encode procedural knowledge, strictly isolating execution environments via subagents. This improves accuracy for complex skills, albeit with additional communication overhead.

## Implementation and Evaluation
- **Implementation & Comparison**: The study compares two execution modes: 1) Agent Skill Execution (loading SKILL.md into the main context); 2) Subagent Execution (creating independent sub-contexts for each skill invoked by the main agent).
- **Evaluation Results**: Experiments show that subagent execution outperforms traditional agent-skill execution when skill packages have clear input-output contracts and instructions that encode the necessary procedural knowledge.
- **Trade-off Analysis**: While the subagent approach yields better performance, it introduces additional communication overhead due to the extra tokens required for coordination between the main agent and subagents. The results demonstrate that the benefit of reusable knowledge depends on both its content and its organization/invocation method.

## 4. Conclusion
This paper highlights the scalability issues of simple context-loading "skills" in long-horizon agentic tasks. By introducing a subagent architecture that isolates skill execution in independent context windows, it effectively mitigates reasoning degradation caused by context bloat. Despite increased token consumption, this method significantly improves task success rates for complex skills with clear contracts, emphasizing the critical impact of knowledge organization on LLM agent performance.
