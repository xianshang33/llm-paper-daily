## 1. What the Paper Did
- **Background**: Reinforcement Learning with Verifiable Rewards (RLVR) has advanced LLM reasoning in domains like math and code where answers are easily verified. However, diagnostic reasoning over complex data lacks this advantage, as establishing true causes often requires costly expert investigation and remains ambiguous.
- **Why Existing Work Fails**: Current LLM-as-judge approaches do not resolve the ambiguity of the target itself and are prone to reward hacking. The central obstacle to applying RLVR in diagnostic settings is the lack of scalable, objective ground truth.

## Core Contributions
- **Proposed TRACE**: A framework for Training Reasoning Agents for Causal Exploration using synthesized rewards, engineering verification asymmetry via simulation.
- **Challenge 1: Lack of objective, low-cost ground truth in diagnostic tasks**. Difficulty arises from the ambiguity and high cost of verifying real-world causality. The method solves this by sampling interventions, injecting them into a controlled simulator to generate observations, and using the hidden intervention as an oracle label for deterministic verification.
- **Challenge 2: Multi-step reasoning and tool use amidst noisy, confounded evidence**. Difficulty lies in identifying root causes from distributed, noisy data. The method addresses this by deploying agents in the TRACE digital advertising environment, using Python and SQL for iterative investigation, and optimizing policies via RL to accurately attribute root causes and affected segments.

## Implementation and Evaluation
- **Implementation**: TRACE is a digital advertising diagnostic environment with 12 root causes and fine-grained segment attribution. Agents interact with multi-table databases using Python and SQL.
- **Results**: On a held-out test set of 235 episodes, the strongest prompted baseline, Claude Opus 5, achieved a FullAttr@1 score of 0.686. Supervised Fine-Tuning (SFT) raised Qwen3.5-35B-A3B from 0.159 to 0.637. Subsequent RL with synthesized rewards further improved the score to 0.757.
- **Comparison**: The TRACE-trained policy outperformed all evaluated prompted baselines, including frontier closed-source models and the prompted Qwen3.5-122B-A10B model. It also used substantially fewer tool calls than the prompted 35B base, demonstrating that access to scalable, objective training signals can be more critical than model scale alone.

## 4. Conclusion
This paper demonstrates that simulation-based verification can make ambiguous diagnostic reasoning tasks amenable to scalable reinforcement learning. By engineering verification asymmetry, the TRACE framework enables medium-sized models to surpass larger closed-source models in complex causal exploration tasks while improving inference efficiency.
