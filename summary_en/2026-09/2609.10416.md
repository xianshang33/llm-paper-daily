## 1. What the Paper Does
- **Background**: As coding agents become prevalent in software engineering, their visible trajectories (records of actions like file reads, searches, edits) are crucial for auditing and provenance. However, existing watermarking techniques primarily protect the final generated code or text, failing to authenticate the "process" that produced these results.
- **Limitations of Existing Work**: Current behavioral watermarking methods typically provide global detection signals or identifier recovery. If an attacker locally edits a trajectory, sufficient global ownership evidence may remain, but the specific inconsistent protected region is not revealed, lacking fine-grained integrity verification.

## Core Contributions
- **Proposed TrajMark**: A training-free, symmetric-key, visible-only trajectory watermarking framework that separates robust ownership attribution from fragile local integrity verification.
- **Challenge 1: How to achieve fine-grained tamper localization while maintaining robust ownership evidence?**
  - **Difficulty**: Traditional methods struggle to balance robust global identity extraction with sensitive local modification detection, as high robustness often implies insensitivity to local changes.
  - **Solution**: TrajMark uses a two-layer architecture. The sparse owner layer encodes a 6-bit deployment ID by rewriting selected natural READ actions into masked linear equations, ensuring robust evidence accumulation. The localization layer inserts linked Q12 seals (ordinary, group, terminal) to commit to protected critical action segments, where local modifications perturb nearby key commitments, exposing the affected area.
- **Challenge 2: How to embed watermarks without significantly impacting agent performance or adding action overhead?**
  - **Difficulty**: Embedding watermarks often introduces extra tokens or actions, potentially interfering with the agent's execution flow or reducing code generation success rates.
  - **Solution**: Owner marking adds no new trajectory actions by rewriting existing READ actions; the integrity layer adds only explicit read-only seals. Experiments show comparable Pass@1 scores (26.9% with watermark vs. 26.3% without), demonstrating low intrusiveness.

## Implementation and Evaluation
- **Implementation & Deployment**: TrajMark is a training-free framework compatible with various coding agent frameworks and LLMs, using symmetric keys for cryptographic operations without model fine-tuning.
- **Evaluation Results**:
  - **Ownership Recovery**: Accurately recovered the exact owner in all evaluated clean full-watermark batches across three coding agent frameworks and three LLMs.
  - **Tamper Detection & Localization**: Detected 95.5%-100% of edits under exhaustive single-site attacks; localized 95.8% of modified sites to an accepted protocol region under random single-action corruption.
  - **Performance Impact**: Minimal impact on agent performance, with Pass@1 slightly increasing from 26.3% (no watermark) to 26.9% (with watermark).
- **Comparison**: Unlike behavioral watermarking methods that only provide global signals, TrajMark uniquely offers segment-level tamper detection and localization while maintaining equal or better robustness in ownership attribution.

## 4. Conclusion
TrajMark addresses a critical gap in coding agent trajectory provenance by verifying not just "who" generated the result, but also whether the "process" was tampered with. By separating ownership attribution from integrity verification, the framework achieves high-sensitivity detection and localization of local tampering while ensuring robust global identity recognition, with negligible impact on agent performance, providing a powerful tool for secure auditing of coding agents.
