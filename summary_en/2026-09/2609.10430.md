## 1. What the Paper Did
- **Background**: Enterprise data lakes accumulate tables faster than human stewards can document or classify them, resulting in missing column descriptions and unassigned governance labels. This "documentation debt" undermines data discovery, access control, and regulatory compliance.
- **Limitations of Existing Work**: Manual annotation is economically infeasible at scale (millions of columns). Existing automated solutions are often tied to single storage engines and cannot handle heterogeneous backends (e.g., Iceberg, RDBMS, Cassandra). Commercial scanners typically rely on data value sampling or regexes, lacking understanding of data generation logic and failing to provide auditable provenance.

## Core Contributions
- **Proposed Glyph**, a production-grade multi-strategy agentic system that frames column description generation and data classification ontology tagging as cooperating LLM agents orchestrated by stateful graphs.
- **Challenge 1: How to accurately generate business-meaningful column descriptions without relying on sensitive data values?**
  - **Difficulty**: Directly reading data values poses privacy risks and high computational costs, while metadata alone is often insufficient.
  - **Solution**: The Descriptor agent uses a "reasoning-acting" tool loop (active Retrieval-Augmented Generation) to retrieve pipeline source code from enterprise GitHub on demand, grounding description generation in code logic for value-free, code-grounded descriptions.
- **Challenge 2: How to achieve high-precision, interpretable multi-label classification under a complex governed ontology (275 leaf nodes)?**
  - **Difficulty**: Single models struggle to balance semantic similarity, business rules, and technical metadata features, while high recall is required for compliance.
  - **Solution**: The Tagger agent runs three complementary strategies in parallel (description tagger, line-of-business regex tagger, and metadata tagger backed by a fine-tuned contrastive encoder) and fuses ranked outputs using Reciprocal Rank Fusion (RRF). A fine-tuned 6-layer MiniLM encoder significantly improved same-tag retrieval performance.

## Implementation and Evaluation
- **Implementation**: The system features a value-free, code-grounded design, provides per-tag provenance, and supports graceful degradation. A 6-layer MiniLM encoder was fine-tuned with an in-batch contrastive objective.
- **Evaluation Results**:
  - **Encoder Performance**: Compared to the stock base encoder, the fine-tuned encoder lifted same-tag retrieval NDCG@10 from 0.55 to 0.92 and MAP@100 from 0.19 to 0.90 on an in-distribution held-out split.
  - **Overall Tagging Quality**: End-to-end multi-label tagging quality was reported under a recall-weighted F2 objective across three evaluation groups, with ablation studies validating each strategy and the RRF fusion.
- **Comparison**: Unlike prior column-type-annotation work and commercial sensitivity scanners, Glyph distinguishes itself through its value-free design, code grounding, per-tag provenance, and operability as a robust production service.

#### Summary
Glyph successfully addresses a critical pain point in large-scale enterprise data catalogs. By leveraging multi-agent collaboration and hybrid strategies (code retrieval + multi-path recall fusion), it achieves high-precision, auditable, and scalable automated data documentation and classification while preserving privacy (value-free processing). Validated in Apple's production environment, the system demonstrates the feasibility and superiority of LLM agentic systems in complex enterprise data governance tasks.
