## 1. What the Paper Did
- **Background**: Modern operating rooms (ORs) integrate numerous precision medical devices. Traditional control methods (physical buttons, touchscreens) pose risks of sterile field disruption, cross-contamination, high cognitive load for staff, and difficulties in multi-device coordination.
- **Why Existing Work Falls Short**: Current voice assistants or general-purpose LLMs fail to meet the strict real-time latency, reliability, and sterile interaction requirements of ORs. They lack context optimization for specific surgical phases and suffer from high inference latency, hindering smooth multi-device parallel control.

## Core Contributions
- **Proposed SurgicalRoomAgent**, a voice-interactive multi-agent system for smart ORs based on Large Language Models (LLMs), featuring a layered architecture with a voice interaction pipeline and an agent core.
- **Challenge 1: High LLM inference latency unsuitable for real-time OR control.**
  - **Difficulty**: Frequent device status changes cause KV Cache invalidation, leading to high recomputation overhead (~500ms).
  - **Solution**: Introduced KV Cache prefix warming, utilizing byte-level Longest Common Prefix (LCP) reuse to reduce recomputation overhead from ~500ms to tens of milliseconds.
- **Challenge 2: Long end-to-end latency and limited context window efficiency.**
  - **Difficulty**: Serial processing waits for complete outputs; full system prompts consume excessive context space, limiting effective information density.
  - **Solution**: Implemented streaming partial JSON parsing with early parallel task execution, reducing end-to-end latency by ~30%; and progressive skill prompt disclosure, which dynamically filters prompts based on user role, devices, and surgical phase to maximize context utility.

## Implementation and Evaluation
- **Implementation & Deployment**: Built on the Qwen3-27B model using llama.cpp/sglang inference engines, supporting streaming output and real-time device control.
- **Evaluation Results**: The system operates effectively within a 16,384-token context limit. KV Cache warming significantly reduced inference latency, and streaming parsing cut end-to-end latency by ~30%. Multi-device parallel control response times met OR real-time requirements.
- **Comparison**: Compared to traditional physical controls and unoptimized general LLMs, this system offers significant advantages in maintaining sterility, reducing cognitive load, and improving multi-device coordination, specifically addressing bottlenecks in low-latency inference and context efficiency.

## 4. Conclusion
The proposed SurgicalRoomAgent successfully constructs a low-latency, high-efficiency voice-interactive multi-agent system for ORs through innovative architecture and three key technologies (KV Cache prefix warming, streaming partial JSON parsing with parallel execution, and progressive skill prompt disclosure). It effectively addresses issues of sterile field disruption, cross-contamination, and cognitive overload, providing a viable technical solution for the deployment of smart operating rooms.
