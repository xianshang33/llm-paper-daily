## 1. What the Paper Does
- **Background**: The capabilities of Large Language Model (LLM) agents depend significantly on runtime harnesses (e.g., task planning, tool interaction, context management). Self-evolving runtime harnesses, which automatically modify code based on execution feedback, offer a promising paradigm for optimizing agent execution.
- **Why Existing Work Falls Short**: Current harness evolution methods rely on iterative search, repeatedly evaluating and revising harnesses based on individual task feedback. This approach incurs substantial time overhead due to repeated executions and code modifications. Furthermore, it tends to overfit to observed tasks and specific failure patterns, leading to poor generalization. The key bottleneck is the lack of principled failure diagnosis, failing to distinguish between model-specific deficiencies and systematic harness deficiencies, resulting in unnecessary model-specific accommodations.

## Core Contributions
- **Proposed Ecdysis**: An efficient and effective framework that distinguishes model-specific accommodation from harness-level repair by identifying recurring cross-task failure patterns, biasing adaptation towards systematic harness deficiencies.
- **Challenge 1: Efficiency and Overfitting**. Traditional instance-by-instance iterative optimization is slow and prone to overfitting specific failures. **Solution**: Ecdysis adopts a batch-level cross-instance failure aggregation paradigm to jointly analyze failure evidence from multiple task instances, identifying systemic rather than偶然 (accidental) failure patterns, thereby reducing invalid iterations and improving generalization.
- **Challenge 2: Lack of Principled Failure Attribution**. It is difficult to determine if a failure stems from model limitations or harness logic errors, leading to biased optimization. **Solution**: Introduces Failure-Driven Collaborative Refinement (FDCR), which uses multi-role diagnosis to diagnose failure causes and iteratively refine harness modification specifications, ensuring optimizations target systematic harness flaws.

## Implementation and Evaluation
- **Experimental Results**: Experiments across multiple LLMs and benchmarks show that Ecdysis achieves up to a 1.84x speedup in harness training compared to existing evolution methods.
- **Performance Improvement**: The resulting harnesses improve reasoning accuracy by 18.56%.
- **Generalization and Efficiency**: Harnesses trained with Ecdysis exhibit stronger generalization across different LLMs and reduce inference-time token consumption.
- **Comparison**: Compared to traditional methods suffering from high latency and overfitting, Ecdysis significantly reduces end-to-end training time while achieving higher accuracy.

## 4. Conclusion
Ecdysis addresses the inefficiency and poor generalization of existing LLM Agent harness evolution methods by introducing cross-instance failure analysis and multi-role collaborative diagnosis. By effectively distinguishing between model defects and harness defects, it focuses on repairing systematic harness issues, significantly improving Agent reasoning accuracy and cross-model generalization while drastically reducing training time.
