## 1. What the Paper Does
- **Background**: Large language model (LLM) agents benefit from reusable skills distilled from prior task experience, which encode task-specific guidelines, reasoning strategies, or tool-use procedures. However, manually authoring high-quality skills is labor-intensive, and directly generated skills often lack grounding, failing to reliably improve downstream performance.
- **Why Existing Work Falls Short**: Current experience-grounded and evolutionary methods face two efficiency bottlenecks. First, evaluating candidate utility is expensive as it requires execution on tasks, leading to wasted budgets on low-quality skills. Second, skill refinement is costly due to repeated LLM invocations for trajectory analysis and generation, often requiring substantial task data.

## Core Contributions
- **Proposed COBRA-Skills**: An efficient framework that formulates skill optimization as budgeted sequential optimization over a dynamically evolving candidate space.
- **Challenge 1: High Evaluation Cost and Inefficient Resource Allocation**. The difficulty lies in indiscriminate execution-based evaluation of all candidates. COBRA-Skills addresses this by coupling contextual-bandit-guided prioritization with Linear UCB algorithms to predict skill potential based on historical feedback, selectively allocating evaluations only to promising or informative candidates.
- **Challenge 2: Expensive and Ungrounded Skill Evolution**. The challenge is that pure LLM-based generation can be hallucinatory and computationally heavy. COBRA-Skills employs evidence-grounded skill evolution, continuously refining the skill population using execution feedback to update neural network and UCB scores, replacing low-priority skills with newly evolved, high-potential ones.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated across six heterogeneous agent benchmarks and three target models.
- **Main Results**: COBRA-Skills consistently achieves the strongest average performance among compared methods.
- **Efficiency Comparison**: It reduces optimization cost by 55–58% relative to SkillOpt.
- **Data Efficiency**: Achieves superior results using only 50 unique optimization examples per benchmark, significantly reducing data dependency.
- **Robustness**: The method remains robust to changes in the agent harness and performs effectively when the target model is used for both skill generation and refinement.

## 4. Conclusion
COBRA-Skills effectively addresses the high costs and data dependencies in LLM agent skill optimization by integrating contextual bandit-guided prioritization with evidence-grounded evolution. It significantly lowers computational budgets while enhancing skill quality and agent performance, offering a new paradigm for efficient reusable skill construction.
