## 1. What the Paper Does
- **Background**: The rise of Agentic AI demands low-latency Large Language Model (LLM) inference, driving the deployment of LLMs on distributed edge servers to mitigate cloud transmission delays.
- **Why Existing Work Falls Short**: Traditional edge computing scheduling treats tasks as atomic units completed within a single time slot. However, LLM inference is multi-stage (prefill, decoding) and spans multiple slots. Existing methods fail to capture fine-grained execution dynamics across heterogeneous edge servers with dynamic states, and they struggle with the delayed feedback of scheduling decisions.

## Core Contributions
- **Proposed LYREO**, an online request scheduling framework that jointly minimizes long-term average end-to-end latency and balances workload across heterogeneous edge servers.
- **Challenge 1: Conventional latency models fail to capture fine-grained dynamics of multi-stage LLM execution.**
  - **Difficulty**: LLM inference involves complex stages (transmission, prefill, iterative decoding, KV cache evolution) with varying resource demands, which simplified models overlook.
  - **Solution**: Developed a cross-slot inference model that accurately tracks these stages and characterizes server workload using a "KV cache memory-time consumption" metric.
- **Challenge 2: The latency impact of a scheduling decision is only observed after request completion, making immediate evaluation difficult.**
  - **Difficulty**: The multi-slot nature of LLM inference causes a lag between the scheduling action and the final latency outcome, hindering timely learning.
  - **Solution**: Employed reward redistribution with sequence-based return prediction to convert delayed outcomes into timely learning signals for earlier decisions, combined with Lyapunov optimization to handle long-term load-balancing constraints.

## Implementation and Evaluation
- **Implementation & Evaluation**: The performance of LYREO was evaluated through simulations under various configurations.
- **Results**: Compared to representative learning-based and heuristic baseline schemes, LYREO consistently achieved lower end-to-end latency and more balanced load distribution, demonstrating its effectiveness in handling heterogeneous resources and dynamic requests.

## 4. Conclusion
This paper addresses LLM inference scheduling for Agentic AI at the edge by proposing the LYREO framework. By constructing a precise cross-slot inference model and introducing a reward redistribution mechanism, it effectively tackles the challenges of modeling multi-stage execution dynamics and dealing with delayed decision feedback. Experimental results show that LYREO outperforms existing mainstream methods in reducing latency and optimizing load balancing.
