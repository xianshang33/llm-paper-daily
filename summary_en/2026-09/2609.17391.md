## 1. What the paper did
- **Background**: Model serving is a major cost driver in production recommender systems. Maximizing throughput requires navigating a deeply layered hierarchy: GPU kernels, ML framework computation graphs, model servers, and on-demand feature processing, each requiring specialized domain expertise.
- **Why existing work falls short**: While recent AI agents have achieved human-expert efficiency in standalone GPU kernel optimization, automated tuning for the rest of the serving stack remains largely unexplored. Cross-layer expertise is hard to acquire and does not scale with evolving workloads, leaving significant cost efficiency gains unrealized.

## Core Contributions
- **Proposed**: FlashVector, an agentic system for hierarchical model serving stack optimization.
- **Challenge 1**: How to generalize the single-kernel optimization agent paradigm to heterogeneous technical stacks?
    - **Difficulty**: The serving stack involves multiple programming languages (Golang, C++, Python, CUDA) and diverse system components with different optimization logic and interfaces, making unified handling difficult.
    - **Solution**: FlashVector provides an extensible framework that generalizes LLM-driven optimization from standalone GPU kernels to the entire heterogeneous stack, delivering holistic performance improvements.
- **Challenge 2**: How to achieve cross-layer collaborative optimization in complex distributed infrastructure?
    - **Difficulty**: Complex dependencies exist between layers (e.g., dynamic batching interacting with ML framework runtime, data flow between feature store and model server). Local optimizations may shift or worsen bottlenecks elsewhere.
    - **Solution**: The agent system automatically discovers and executes optimizations across components, including the model server (NVIDIA Triton C++ codebase) and on-demand feature transformation service (Python codebase), achieving end-to-end performance gains.

## Implementation and Evaluation
- **Implementation & Deployment**: FlashVector is deployed in Unity's Vector advertising platform, which manages hundreds of DNN models and serves hundreds of thousands of inference requests per second.
- **Evaluation Results**:
    - Up to 2x throughput increase on the model server.
    - Up to 1.98x latency speedup on the model server.
    - Up to 1.6x throughput increase on the feature store.
- **Comparison**: Unlike prior work focused mainly on isolated GPU kernel optimization, FlashVector demonstrates extensibility to complex system architectures, covering full-stack optimization from low-level kernels to high-level application logic, a capability previously unattained by automated methods.

## 4. Conclusion
FlashVector successfully extends LLM-driven optimization capabilities from single GPU kernels to the entire hierarchical model serving stack through an extensible agentic framework. It achieved significant performance improvements in Unity's production environment, demonstrating the feasibility and potential of automated cross-layer optimization for addressing cost efficiency challenges in large-scale recommender systems.
