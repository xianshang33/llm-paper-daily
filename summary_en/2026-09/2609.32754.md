## 1. What the Paper Does

### Background
Large Language Model (LLM) agents often make reasonable local decisions on short tasks but suffer performance degradation in long-horizon tasks requiring sequences of dependent actions and tool calls. During execution, task requirements, historical evidence, and current states gradually become disconnected, causing later decisions to drift from the original objective.

### Why Existing Work Falls Short
Existing memory architectures (e.g., retrieval-augmented, generative agent memories) expand access to early context but struggle to effectively organize and present the most relevant historical information within limited context windows. Even when information fits in the context, LLMs find it difficult to extract key associations from messy historical trajectories, leading to "lost in the middle" phenomena or context drift. Furthermore, many methods focus on replacing planners or executors rather than optimizing context construction itself.

## Core Contributions

### Proposed Adaptive Consistency Graph (ACG)
ACG is a framework for long-horizon execution that does not replace the base agent's planner or tool executor. Instead, it incrementally organizes execution evidence and provenance in a persistent graph to provide a structured, traceable context view for each decision.

### Challenge 1: Context Drift and Information Disconnection in Long Sequences
**Description & Difficulty**: As execution steps increase, the link between historical evidence, current state, and initial goals weakens, causing agents to forget core objectives or misuse history. The difficulty lies in dynamically filtering the most relevant information from massive historical trajectories under a bounded context budget.
**Solution**: ACG incrementally organizes evidence and provenance in a persistent graph and constructs a temporary, requirement-centered view for each decision. This ensures the context is always structurally reorganized around the current subtask and original requirements, maintaining decision consistency.

### Challenge 2: Enhancing Long-Horizon Capability Without Altering Base Architecture
**Description & Difficulty**: Many existing methods require modifying core planning logic or training specialized memory modules, leading to high deployment costs and poor compatibility. The challenge is designing a plug-and-play intermediate layer that enhances context quality while remaining compatible with various existing agent frameworks (e.g., ReAct).
**Solution**: ACG acts as an independent context management layer that only constructs and provides structured context views without interfering with the base agent's reasoning or execution logic. This decoupled design allows seamless integration into existing LLM agent systems without retraining or major code changes.

## Implementation and Evaluation

### Implementation & Deployment
ACG maintains a persistent graph storing evidence and source relationships during execution. Before each decision, the system extracts relevant nodes based on current requirements and context budget to build a temporary view, which is then injected into the LLM's prompt. The code is open-source.

### Evaluation Results
In matched evaluations, ACG significantly improved GPT-5.6-luna's performance:
- **Average Success Rate**: Increased from 44.5% (ReAct baseline) to 50.2%.
- **Largest Gain**: On the BrowseComp-Plus benchmark, success rate rose from 62.4% to 73.5%.

### Comparison
The paper further analyzes trajectory structure and inference costs, showing that ACG reduces invalid attempts through more precise context retrieval while maintaining reasonable inference overhead. Compared to traditional Retrieval-Augmented Generation (RAG) or full-context input, ACG's structured views better help agents understand long-term dependencies.

## 4. Conclusion

This paper addresses the context drift problem in LLM agents for long-horizon tasks by proposing the Adaptive Consistency Graph (ACG). By constructing a persistent evidence graph and dynamically generating requirement-centered context views, ACG effectively solves the disconnection between historical information and current decisions. Experiments show that ACG significantly improves success rates in complex tasks, especially those requiring long-sequence dependencies, without modifying the underlying agent architecture. This approach offers new insights for enhancing the long-term consistency and traceability of LLM agents.
