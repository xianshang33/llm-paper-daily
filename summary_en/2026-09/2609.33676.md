## 1. What the Paper Does
- **Background**: LLM agents are increasingly deployed in consequential domains (e.g., customer service, finance). Auditing these agents requires tracing specific actions back to their historical basis (e.g., policy compliance, parameter provenance), even when executions succeed.
- **Limitations of Existing Work**: Current attribution formulations lack query-specific traces for diverse auditing objectives. Furthermore, in API-only deployments with long trajectories, existing methods rely on costly input perturbations or expensive external LLM analysis of full trajectories, making them inefficient and impractical.

## Core Contributions
- **Proposed a new task: Query-Conditioned Agent Action Attribution and the $A^3Bench$ benchmark**: This task takes a natural language auditing query as input to recover the source and ordered intermediate evidence for specific aspects of an action. $A^3Bench$ includes 1,396 queries covering policy basis, parameter provenance, failure propagation, and unsafe-behavior tracing.
- **Challenge 1: How to achieve efficient, query-specific attribution?**
  - **Difficulty**: Traditional methods struggle to dynamically adjust attribution focus based on fine-grained queries and suffer from high computational costs.
  - **Solution**: The paper uses small open-weight models as "Attribution Proposers" that combine query-conditioned gradient saliency with query-semantic relevance to rank history units, achieving efficient ranking with only two forward passes and one backward pass.
- **Challenge 2: How to attribute accurately under limited model access (e.g., API-only)?**
  - **Difficulty**: Internal states are inaccessible, and calling frontier LLM APIs is slow and expensive.
  - **Solution**: An end-to-end system built on a proposer ensemble adapts rankings to fine-grained query changes, surpassing frontier model baselines in accuracy while significantly reducing latency.

## Implementation and Evaluation
- **Implementation**: The core component is a small open-weight model acting as an attribution proposer, leveraging gradient information and semantic similarity to rank interaction history units.
- **Performance Comparison**:
  - **Vs. Open-Weight Baselines**: The proposer improves Source MRR by up to 40.9% and Evidence MAP by up to 42.1% with minimal computational overhead.
  - **Vs. Frontier Model Baselines**: The end-to-end system achieves a source accuracy of 64.5%, outperforming the strongest frontier-model baseline (60.4%).
  - **Latency Advantage**: Empirical deployment latency is reduced by 29.9% compared to the fastest frontier API baseline.
- **Validation**: Controlled evaluations confirm that the method improves attribution specificity by adapting to subtle changes in the auditing query.

#### Summary
This paper addresses the lack of targeted tracing and inefficiency in LLM agent auditing by formulating the Query-Conditioned Agent Action Attribution task. By introducing the $A^3Bench$ benchmark and a novel attribution proposer mechanism based on small models, the proposed method achieves higher accuracy and lower latency than state-of-the-art approaches without requiring internal model access or expensive API calls, offering an efficient solution for enhancing agent transparency and safety.
