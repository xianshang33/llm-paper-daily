## 1. What the Paper Does
- **Background**: Modern Large Language Models (LLMs) are increasingly capable autonomous agents but typically follow a sequential "read-think-reply" interaction cycle. However, many real-world applications (e.g., voice assistants, embodied agents, monitoring systems) are non-sequential, requiring the agent to receive new inputs while thinking or executing tasks.
- **Limitations of Existing Work**: Current solutions address concurrency with specialized architectures for specific domains, such as dedicated models for voice/video, dual Actor-Thinker architectures for Vision-Language-Action (VLA) models, or asynchronous tool calling for APIs. These approaches are siloed, lack generality, and often require task-specific training or fine-tuning.

## Core Contributions
- **Proposed a General Asynchronous LLM Framework**: This framework allows users or agents to define inference coroutines with overlapping memory states, enabling LLMs to handle asynchronous inputs similarly to human cognition, without task-specific fine-tuning.
- **Challenge 1: How to maintain context consistency and achieve real-time response under non-sequential inputs?**
  - **Difficulty**: Traditional LLMs process sequences and struggle to dynamically insert new information during generation without disrupting logic or losing state; existing methods are domain-specific and lack generalization.
  - **Solution**: Adopts the async/await programming model via asyncio and extends direct memory sharing algorithms to support hybrid and multimodal LLMs, allowing inference coroutines to run concurrently.
- **Challenge 2: How to achieve multi-scenario asynchronous capabilities without task-specific training?**
  - **Difficulty**: Concurrency patterns vary significantly across scenarios (e.g., video streams vs. gaming), traditionally requiring separate training efforts.
  - **Solution**: Leverages the ability of modern LLMs to mimic human reasoning through proper framing. Demonstrates that models like Qwen 3.x can adapt to streaming video understanding, videogames, and monitoring in a zero-shot manner.

## Implementation and Evaluation
- **Implementation**: Built on Qwen 3.x models using an asyncio-based asynchronous LLM framework. It supports direct memory sharing, enabling concurrent inputs and outputs for hybrid and multimodal models.
- **Evaluation Results**: Experiments demonstrate the framework's effectiveness in three distinct scenarios: streaming video understanding, videogame playing, and system monitoring. The model successfully handles concurrent inputs and reacts in real-time without task-specific training.
- **Comparison**: Unlike existing specialized architectures (e.g., real-time voice models, dual-architecture VLA models), this approach does not require redesigning architectures or fine-tuning for each new task, showing superior generality and adaptability. It unifies previously fragmented research on asynchronous processing across vertical domains.

## 4. Conclusion
This paper proposes a general asynchronous LLM agent framework that overcomes the limitations of traditional sequential LLM interactions. By introducing inference coroutines with overlapping memory states and direct memory sharing, the framework enables off-the-shelf LLMs (such as Qwen 3.x) to effectively handle concurrent inputs in diverse scenarios like voice, video, gaming, and monitoring without fine-tuning. This work demonstrates the potential of LLMs to serve as general asynchronous agents, offering a new paradigm for building more natural and responsive real-world AI applications.
