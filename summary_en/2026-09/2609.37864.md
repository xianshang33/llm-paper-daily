## 1. What the Paper Did
- **Background**: As Large Language Model (LLM) agents become widespread, their surrounding "Harness" (software infrastructure collaborating with LLMs for context management, security, orchestration, etc.) has grown increasingly complex. Implementation bugs in the Harness are a significant source of failures in agentic systems.
- **Why Existing Work Falls Short**: Existing benchmarks contain only a small, fixed number of executable Harness bugs and require hundreds of human hours to construct, severely hindering progress. Furthermore, existing bug reproduction techniques designed for general software perform poorly on Harness bugs due to their unique characteristics, resulting in significantly lower repair success rates for agents compared to general software bugs.

## Core Contributions
- **Proposed AgentBug-Smith and Live-Harness-Bench**: An automated approach for reproducing Harness bugs that continuously discovers and reproduces real-world bugs from open-source agentic systems, resulting in a live, extensible benchmark with 200 reproducible bugs.
- **Challenge 1: General bug reproduction techniques struggle with the uniqueness of Harness bugs**. Harness bugs arise from agent-specific structures and behaviors, making them difficult for generic tools to capture. AgentBug-Smith addresses this by employing an automated mining and reproduction mechanism tailored to agentic systems, achieving 10.67% - 27.56% higher success rates than existing general-purpose techniques across different backbone LLMs.
- **Challenge 2: Lack of large-scale, real-time evaluation data for continuous agent self-improvement**. Static benchmarks cannot reflect the evolving nature of real-world errors. AgentBug-Smith constructs Live-Harness-Bench to transform real-world agent failures into executable evaluation instances and reusable repair knowledge. This enables distilling repair skills from real fixes, improving agents' Harness bug repair rates by 6.32%.

## Implementation and Evaluation
- **Implementation & Deployment**: AgentBug-Smith was applied to open-source agentic systems in the wild to construct Live-Harness-Bench, which currently contains 200 reproducible Harness bugs. The benchmark is designed to be live and extensible.
- **Evaluation Results**:
    1. **Bug Reproduction Performance**: AgentBug-Smith consistently outperforms existing bug reproduction techniques designed for general software, achieving a 10.67% - 27.56% higher success rate in reproducing Harness bugs.
    2. **Downstream Application Assessment**: Using Live-Harness-Bench to evaluate state-of-the-art software agents revealed their limited capabilities in repairing real-world Harness bugs.
    3. **Knowledge Distillation Impact**: By using Live-Harness-Bench as a knowledge base for real-world Harness bug fixes, reusable repair skills were distilled, increasing the Harness bug repair rates of existing agents by 6.32%.
- **Comparison**: Unlike previous benchmarks that were costly and static, Live-Harness-Bench is automated and scalable. Compared to general software bug repair techniques, AgentBug-Smith is optimized for Harness specifics, yielding significant performance gains.

## 4. Conclusion
This paper presents AgentBug-Smith, an automated Harness bug reproduction approach that addresses the high cost, small scale, and incompatibility of existing benchmarks and general techniques. By constructing Live-Harness-Bench, the work provides a real-time benchmark for evaluating agent Harness repair capabilities and enhances agent self-repair through knowledge distillation. This establishes a scalable foundation for continuously evaluating and improving software agents, contributing to the goal of recursively self-improving agents.
