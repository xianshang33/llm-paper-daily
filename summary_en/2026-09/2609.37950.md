## 1. What the Paper Does
- **Background**: Video understanding agents acquire evidence through an executable "harness" that controls observation and reasoning. In long videos, relevant events can be brief, temporally distant, or distracted by similar visuals, requiring iterative retrieval and navigation.
- **Why Existing Work Falls Short**: Execution traces only contain evidence acquired by the current harness. When failures occur, it is difficult to distinguish between sampling gaps and reasoning errors because unobserved parts are not verified. This leaves competing explanations for failure unresolved, limiting the basis for self-improvement without updating model weights.

## Core Contributions
- **Proposed Video-RSI**: A framework for recursive self-improvement of video understanding agents via harness evolution.
- **Challenge 1: Ambiguous Failure Attribution and Insufficient Evidence**. The difficulty lies in execution traces lacking information about unobserved content, making it hard to pinpoint the cause of failure. Video-RSI addresses this by actively revisiting original training videos to test competing failure hypotheses with additional observations, grounding proposed changes in evidence beyond the existing trace.
- **Challenge 2: Reusability and Efficiency of Improvements**. The challenge is to translate diagnoses into reusable code revisions while balancing accuracy and computational cost. Video-RSI introduces cost-aware harness evolution, which considers both answer accuracy and visual cost (frames processed) to select and retain optimal revisions.

## Implementation and Evaluation
- **Implementation**: Video-RSI uses a frozen LLM to act as both the answerer and the investigator/reviser. It evolves the harness offline by revisiting training videos, producing a reusable harness for subsequent queries. Code is available on GitHub.
- **Evaluation Results**: On video understanding benchmarks, the evolved agent improves accuracy while processing fewer frames.
- **Comparison**: Compared to existing video understanding agents, Video-RSI achieves competitive accuracy-efficiency trade-offs, demonstrating the potential for agents to improve their own evidence acquisition and usage through harness evolution.

## 4. Conclusion
Video-RSI presents a new paradigm for enhancing video understanding without updating model weights. By enabling agents to diagnose failures, actively explore unobserved evidence, and optimize their control logic (harness), the method effectively addresses evidence acquisition challenges in long videos, achieving both higher accuracy and lower visual costs.
