## 1. What the Paper Does
- **Background**: Advances in LLM agent coding capabilities enable agents to inspect and modify their own instructions, tools, and execution procedures. Existing self-improvement approaches typically rely on repeated downstream task evaluations to guide the search process.
- **Limitations of Existing Work**: Current methods tie the search process to specific evaluation tasks, requiring multiple executions of candidate agents on development sets to obtain reward signals. This incurs substantial computational costs and limits the generalizability of agent improvements, making them dependent on specific task distributions.

## Core Contributions
- **Proposed SelfSearch**: A reward-free search procedure where agents modify themselves using records from previous self-improvement episodes (capturing reasoning, tool actions, and outcomes), enabling capability evolution without relying on downstream reward signals.
- **Challenge 1: High Evaluation Costs and Task Dependency**. Traditional methods require repeated candidate execution to obtain rewards, leading to costs that grow linearly with task volume and restricting improvements to specific tasks. **Solution**: SelfSearch uses metadata from the self-modification process (such as how limitations were identified, revisions constructed, and failures handled) as optimization signals, guiding search without computing downstream rewards during execution.
- **Challenge 2: Effectively Utilizing Unstructured Self-Modification Experience**. Simple code change records are insufficient for guiding complex logical optimizations; deeper reasoning trajectories need to be captured. **Solution**: The method captures complete episode records, including interaction trajectories, code changes, and check results, allowing agents to learn from past trial-and-error how to better self-diagnose and refactor code, thereby improving both task-solving capabilities and self-modification strategies.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated across six model-benchmark settings, focusing on Terminal-Bench 2.1 and SWE-bench Multilingual.
- **Key Results**:
    - SelfSearch improved population-mean success rates in all six settings, with individual agents gaining up to 11.2 percentage points on Terminal-Bench 2.1.
    - On SWE-bench Multilingual, agent success increased by 5.0 percentage points, while execution cost decreased by 38.5% on tasks solved by both initial and evolved agents.
- **Comparison with Related Work**:
    - Compared to evaluation-guided search baselines, SelfSearch achieved competitive task success at a lower search cost.
    - In a public comparison setting, with only **$4.03** in search cost, a harness generated using DeepSeek V4 Flash solved **82.0%** of Terminal-Bench 2.1 tasks, matching the performance of the top-scoring harness (Codex), demonstrating significant cost-effectiveness.

## 4. Conclusion
SelfSearch introduces a novel reward-free self-improvement paradigm that leverages historical experience records from the self-modification process to guide agent evolution, successfully eliminating dependence on expensive downstream evaluation signals. Experiments demonstrate that this method significantly reduces search and execution costs while achieving performance comparable to or better than top-tier methods across multiple benchmarks, validating the effectiveness of learning from self-modification experience for enhancing agent capability and efficiency.
