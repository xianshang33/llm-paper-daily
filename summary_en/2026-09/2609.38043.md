## 1. What the Paper Did
- **Background**: Interactive agent benchmarks and multi-turn reinforcement learning increasingly employ a second LLM to simulate the user, controlling the information flow to the agent.
- **Limitations of Existing Work**: Current benchmarks score only the agent and fail to measure whether the simulated user correctly executed its assigned role. If the user proxy leaks information or behaves incorrectly, the agent is not solving the intended interaction, even if the task reward remains unchanged, leading to distorted evaluations.

## Core Contributions
- **Proposed UserProxyBench and User Fidelity Score (UFS)**: An evaluation layer over the tau-bench family that measures adherence to private user instructions using task-grounded rubrics, independent of agent success.
- **Challenge 1: Task reward does not subsume user fidelity**. The difficulty lies in traditional metrics ignoring process compliance. The paper addresses this by introducing UFS, revealing that 24.4% of successful episodes contain user contract violations, exposing blind spots in standard metrics.
- **Challenge 2: Behavioral biases in user simulation subtly alter interaction dynamics**. The challenge is that violations like "premature disclosure" have minimal impact on reward and are hard to detect. The paper quantifies this, showing that such behavior reduces agent tool calls by an average of 1.06 in successful episodes, changing the nature of the evaluated interaction while preserving the reward, and establishes a cost-fidelity frontier.

## Implementation and Evaluation
- **Setup**: Evaluated across 375 enterprise tasks with the agent fixed at GPT-5.5, varying only the user proxy. Compared seven different user proxy simulators.
- **Key Results**:
    - Varying only the user proxy changed mean task reward by 15.2 points.
    - 24.4% of successful episodes contained user-specification violations.
    - The dominant failure mode was "premature disclosure," where users provide information before being asked.
    - This behavior caused agents to make 1.06 fewer tool calls on average in successful episodes, altering the interaction without affecting the reward.
- **Cost-Fidelity Frontier**: Identified an empirical trade-off between inference cost and fidelity across seven proxies, enabling practitioners to select the most cost-effective simulator for a required fidelity level.

## 4. Conclusion
The paper highlights the overlooked issue of user proxy compliance in LLM agent benchmarks. By introducing UserProxyBench and UFS, it demonstrates that task success does not equate to high-fidelity user simulation. It reveals the pervasive and subtle impact of "premature disclosure" on interaction dynamics and provides practical guidance for selecting user simulators based on a cost-fidelity trade-off.
