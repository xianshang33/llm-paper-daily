## 1. What the Paper Does
- **Background**: Enterprise AI agent skills are dynamic, evolving with changes in tool APIs, LLM versions, and business specifications. Each revision introduces risks of behavioral regressions.
- **Why Existing Work Fails**: Current evaluation practices focus solely on final output accuracy (e.g., reports, numbers). However, agents can produce correct final outputs via incorrect processes (e.g., wrong API scopes, skipped database reads), leading to invisible process-level drift that compromises data integrity and fails under slight input changes. Outcome-only checks miss these critical deviations.

## Core Contributions
- **Proposed a** continuous evaluation framework combining outcome-level and process-level checks for enterprise agentic skills.
- **Challenge 1: Process deviations are invisible to outcome metrics**. Agents may reach correct results through flawed steps (wrong tool selection, argument errors, execution order issues), which are hard to detect but dangerous for downstream tasks. **Solution**: The framework independently computes per-run ground truth, uses reusable template tests, and employs programmatic checks augmented by a narrowly scoped LLM judge to evaluate tool selection, arguments, execution order, and database integrity.
- **Challenge 2: Noise in failure attribution**. Complex trajectories generate numerous check failures, making root cause analysis difficult. **Solution**: Dependency attribution compresses an average of 6.34 failed checks per run to 2.65 root causes, improving debuggability. Runtime-resolved templates provide reusable regression coverage across different models and harnesses.

## Implementation and Evaluation
- **Implementation & Deployment**: Evaluated on the Business Value Determination (BVD) skill within an enterprise Value Aware Resiliency (VAR) system. The study covered 240 trials across two skills (Revenue and Productivity), two specification variants, two agent harnesses (Claude Code, Codex), and three models (GPT-5.6-Sol, Claude Opus 4.8, Claude Sonnet 4.6).
- **Evaluation Results**:
    - Of 175 trials passing all final numerical checks, 162 (92.6%) contained at least one process-level deviation detected by the evaluator.
    - Under a broader final-state definition, 151 of 164 passing runs (92.1%) still violated trajectory checks.
    - Dependency attribution significantly reduced the noise in failure reporting.
    - Specification sensitivity varied by model and harness, with statistical significance observed in most comparisons.
- **Comparison**: Unlike traditional outcome-only evaluations that missed these errors entirely, this framework exposed that over 90% of "successful" runs had underlying process flaws, demonstrating the necessity of process-level evaluation for reliable agent evolution.

## 4. Conclusion
The paper argues that outcome-only evaluation is insufficient for evolving enterprise AI agents. The proposed continuous process-level evaluation framework effectively captures behavioral drift hidden behind correct final outputs. Experiments show that the majority of seemingly successful runs contain process deviations, validating the framework's role as a essential quality gate for responsible deployment. Future work includes longitudinal validation under actual API evolution.
