## 1. What the Paper Does
- **Background**: Dynamic resource assignment is critical for modern infrastructure. However, industrial deployments rely on hand-written rules due to strict requirements for interpretability, auditability, and low latency, unlike Deep Reinforcement Learning (DRL) which suffers from black-box policies and sim-to-real gaps.
- **Why Existing Work Fails**: Current LLM-based Automatic Heuristic Design (AHD) frameworks are designed for fully specified combinatorial problems and learn only from scalar fitness scores. In real systems, the underlying dynamics (e.g., processor speed, power) are unknown a priori. Scalar scores indicate 'what' works but not 'why'. While system logs contain this missing information, they are massive, noisy, heterogeneous, and objective-dependent, making them unusable for direct LLM input or fixed parsing.

## Core Contributions
- **Proposed TRACE**: A framework coupling an evolutionary AHD loop with an agentic knowledge-extraction workflow to leverage system logs.
- **Challenge 1: How to extract actionable knowledge from massive, heterogeneous system logs?**
  - **Difficulty**: Logs are noisy, vast, and vary in format across stacks; relevant signals depend on the specific optimization objective.
  - **Solution**: A Reasoner agent analyzes log schemas against objectives to hypothesize system dynamics. A Coder agent then writes and executes schema-specific code to test these hypotheses, converting raw logs into structured insights or executable tools.
- **Challenge 2: How to effectively integrate extracted knowledge into heuristic search?**
  - **Difficulty**: Scalar feedback lacks directional guidance, while raw logs overwhelm LLM context windows.
  - **Solution**: The workflow produces 'executable tools' (e.g., regression models) and 'system insights' as enhanced feedback. This allows the LLM to understand underlying mechanisms, generating superior and auditable heuristics within the evolutionary loop.

## Implementation and Evaluation
- **Evaluation Scenarios**: Tested on a synthetic cloud benchmark and a 5G vRAN scenario built from industrial testbed measurements and operational traffic traces.
- **Results**: TRACE consistently outperforms state-of-the-art AHD methods (which rely solely on scalar feedback) in resource assignment tasks.
- **Performance**: The generated heuristics are more auditable and incur less than 2% system overhead.

## 4. Conclusion
TRACE addresses the limitation of existing AHD methods in real-world resource allocation by bridging the gap between scalar performance metrics and complex system dynamics. By employing multi-agent collaboration to automatically extract causal knowledge and executable tools from system logs, it achieves superior scheduling performance compared to traditional scalar-feedback approaches, while maintaining the low latency and high interpretability required for industrial deployment.
