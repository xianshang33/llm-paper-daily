## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents are increasingly involved in organizational work, where decisions are recorded across documents by multiple authors over months. In organizational settings, revised decisions appear as new documents rather than edits to old ones, requiring accurate knowledge of which version was valid at a specific point in time.
- **Why Existing Work Fails**: Most existing memory systems compress records at write time (e.g., extracting facts, notes, or graph edges), fixing what can be answered before any question is asked and leading to information loss. Furthermore, traditional conversational memory systems often overwrite older versions or assume a single authority, failing to handle the complexity of multi-author, multi-version organizational histories where past documents remain valid context.

## Core Contributions
- **Proposed Mem++**: A non-destructive memory framework that shifts from write-time distillation to read-time selection.
- **Challenge 1: How to preserve complete historical records without information loss at write time?**
  - **Difficulty**: Traditional methods lose original context and nuances by extracting summaries or graphs at ingest, and overwritten versions cannot be recovered.
  - **Solution**: Mem++ stores every document in its entirety along with date and author metadata without calling any generative model at write time, ensuring lossless preservation of raw information.
- **Challenge 2: How to accurately identify the valid decision for a specific point in time during querying?**
  - **Difficulty**: Organizational memory contains multiple competing or evolving documents; simply retrieving the latest document may ignore historical constraints or the state at a specific time.
  - **Solution**: At read time, Mem++ retrieves only documents dated up to the time referenced by the question and fuses lexical and semantic rankings, leaving the final choice to the answering model for precise time-sensitive context understanding.

## Implementation and Evaluation
- **Benchmarks**: Evaluated on the organizational memory benchmark OrgMemBench, with additional tests on LoCoMo and LongMemEval-S.
- **Comparison Results**:
  - On OrgMemBench, Mem++ surpasses the strongest memory system baseline by 8.0 to 13.1 points across two answering models.
  - Using gpt-4.1-mini, Mem++ achieves the best overall score, outperforming traditional RAG by 2.6 points.
  - On LoCoMo, Mem++ achieves the best average LLM-judge score.
  - On LongMemEval-S, it ranks second, behind only its entity-graph variant.
- **Comparison with Related Work**: Compared to Mem0 (which resolves conflicts by overwriting, making old decisions unretrievable) and Zep (which stores extracted facts rather than original documents), Mem++ demonstrates superior performance in handling organizational memory with co-existing multi-version documents through its retention of full documents and deferred selection mechanism.

## 4. Conclusion
Mem++ addresses the challenge of tracking historical decisions for LLM agents in long-term organizational work by introducing a non-destructive memory framework. By abandoning traditional write-time compression in favor of write-time full storage and read-time time-and-semantic-based filtering, it significantly outperforms existing RAG and other memory management systems across multiple benchmarks. This approach provides an effective solution for building organizational-level LLM agents with accurate long-term historical awareness.
