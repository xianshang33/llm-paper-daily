## 1. What the Paper Does
- **Background**: The application of Large Language Models (LLMs) is shifting towards coordinated multi-agent systems. Due to privacy and security concerns, there is a growing demand for on-device deployment. However, existing inference systems are primarily designed for cloud environments and struggle with multi-agent workflows on edge devices.
- **Limitations of Existing Work**: On Unified Memory Architectures (UMA), the memory-bound decode phase causes severe bus contention, paralyzing naive CPU-GPU co-execution. Furthermore, speculative decoding in multi-agent workloads suffers from extreme variance in drafting difficulty and frequent tool-induced stalls, leading to highly fragmented execution and hardware underutilization that traditional static batching cannot handle.

## Core Contributions
- **Proposed EdgeAgent**: A cross-layer inference system explicitly co-designed for edge UMA and multi-agent workloads.
- **Challenge 1: Bus contention and underutilization in UMA**. Naive co-execution saturates the memory bus, and rigid graph compilers limit flexibility. **Solution**: At the micro-architectural level, EdgeAgent bypasses rigid graph-compiler constraints to enable zero-copy UMA-aware tensor parallelism, using asymmetric memory layouts to fully saturate both CPU and GPU compute units.
- **Challenge 2: Execution fragmentation and resource waste**. Variance in drafting difficulty and unpredictable tool stalls lead to idle hardware. **Solution**: At the scheduling level, it dynamically allocates draft budgets based on real-time sequence predictability to bound bandwidth waste. An asynchronous suspend-and-yield mechanism actively evicts stalled agents to ensure continuous hardware saturation during unpredictable tool invocations.

## Implementation and Evaluation
- **Implementation & Deployment**: Extensively evaluated on an Apple M4 SoC, representing a typical edge UMA architecture.
- **Results**:
    - UMA-aware execution alone contributes a **1.29x speedup** over batched speculative decoding.
    - The full EdgeAgent system, including agent-aware scheduling, achieves a **1.77x speedup** under extreme tool-use latencies.
- **Comparison**: Outperforms traditional batched speculative decoding, particularly in scenarios with high latency tool calls and execution fragmentation.

## 4. Conclusion
EdgeAgent effectively addresses bus contention and execution fragmentation in on-device multi-agent LLM inference on UMA architectures. By combining zero-copy tensor parallelism at the micro-architectural level with dynamic draft budgeting and asynchronous suspension at the scheduling level, it significantly improves inference speed on platforms like the Apple M4, providing efficient support for privacy-preserving edge multi-agent systems.
