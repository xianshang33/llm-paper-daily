## 1. What the Paper Did
- **Background**: LLM agents increasingly use small prompt-injection detectors to screen tool outputs, with teams selecting detectors based on scores from public benchmarks like BIPIA.
- **Why Existing Work Falls Short**: Current evaluation practices rely on unchecked assumptions. First, benchmark texts do not match the serialized tool outputs agents actually process, meaning high benchmark scores do not reflect real-world false-positive rates (FPR) that cause task failures. Second, prior work fails to audit overlaps between detector training data and benchmarks, inflating scores through data memorization rather than genuine detection capability.

## Core Contributions
- **Proposed a Differential Replay Evaluation Framework**: The paper introduces a method to evaluate detectors on real agent inputs by replaying ground-truth tool calls without an LLM to generate benign-by-construction outputs, and using differential replay to label injected outputs reliably.
- **Challenge 1: Disconnection between benchmark scores and deployment performance**. The difficulty lies in the distributional shift between static benchmarks and dynamic agent environments. The paper addresses this by evaluating directly on tool outputs from AgentDojo and tau-bench, revealing that detector rankings transfer poorly (e.g., the best BIPIA detector catches only 2% of AgentDojo injections at 1% FPR).
- **Challenge 2: Inflated performance due to training data leakage**. It is difficult to distinguish between generalization and memorization of attack strings. By auditing public training data, the paper shows that top-performing detectors on agent benchmarks share no data with the benchmarks and are trained on agent-style inputs, proving performance depends on input form resemblance rather than universal detection skills.

## Implementation and Evaluation
- **Setup**: Evaluated 15 detectors (including Meta's Prompt Guard 2 and DeBERTa classifiers) and 2 task-aware LLM judges on tool outputs from AgentDojo, tau-bench, and the BIPIA benchmark.
- **Key Results**:
    - **Poor Ranking Transfer**: Detection capabilities do not transfer across benchmarks. A detector catching 72% of injections in AgentDojo catches only 15% in tau-bench.
    - **FPR Transferability**: Unlike detection rates, False Positive Rates on tool outputs are consistent across the two agent benchmarks, ranging from 0% to over 90%.
    - **Training Data Impact**: The BIPIA leader was trained on full BIPIA inputs, which did not help detect attacks within serialized tool outputs. The best detector for agent benchmarks was trained on agent-style inputs and shared no data with any benchmark.
- **Comparison**: Contrary to prior claims that certain guardrails effectively detect indirect injection, this study demonstrates that high scores are artifacts of data distribution matching. Existing benchmarks fail to provide reliable guidance for deployment.

## 4. Conclusion
The paper highlights critical flaws in current prompt-injection detector evaluations, showing that benchmark scores do not predict behavior within LLM agents. The core finding is that detector performance is driven by the similarity between training data format and evaluation inputs. The authors recommend that deployment-focused evaluations should use actual agent tool outputs, report detection rates at low false-positive rates, and strictly audit training data sources.
