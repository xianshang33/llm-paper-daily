## 1. What the Paper Did
- **Background**: Modern LLMs exhibit cognitive polarization, possessing implicit parametric knowledge (intuition) but relying on disconnected external mechanisms for non-parametric knowledge. Current agentic frameworks fail to bridge this gap, leading to pathological "induced amnesia."
- **Why Existing Work Fails**: The prevailing "Retrieve-Always" paradigm forces agents to distrust internal knowledge, treating every interaction as a "tabula rasa" requiring external verification. This reflexive dependence is thermodynamically wasteful (high latency/energy), cognitively fragile, and susceptible to noise from irrelevant context, degrading performance.

## Core Contributions
- **Proposed MARTA (Metacognitive Adaptive Retrieval and Thought Architecture)**: A neuro-symbolic framework that arbitrates between parametric and non-parametric knowledge via self-regulating memory architectures.
- **Challenge 1: How to avoid unnecessary retrieval overhead and context noise?**
  - **Difficulty**: Traditional methods retrieve for all queries indiscriminately, causing high latency for trivial questions and introducing irrelevant information that poisons context.
  - **Solution**: MARTA models retrieval as a "thermodynamic cost," executing it only when internal inadequacy is perceived. By allowing the agent to gauge the entropy of its thoughts before acting, it enables deliberative retrieval, restoring balance between efficiency and truth.
- **Challenge 2: How to equip agents with metacognitive capacity to distinguish known from unknown?**
  - **Difficulty**: Existing models lack introspection, failing to distinguish when to rely on internal parameters versus external sources, leading to hallucinations when retrieval fails.
  - **Solution**: It uses Predictive Entropy and Token Margin as signals of "Epistemic Need," projecting internal uncertainty onto external memory manifolds to dynamically control information flow between System 1 (internal intuition) and System 2 (external retrieval).

## Implementation and Evaluation
- **Implementation & Deployment**: MARTA is implemented as a neuro-symbolic framework with a metacognitive bridging layer that monitors internal LLM states (e.g., entropy). It deploys as an inference-time regulation layer without requiring base model retraining.
- **Evaluation Results**: The approach significantly reduces unnecessary retrieval calls, lowering inference latency and computational costs. It maintains high accuracy on tasks requiring precise external knowledge while avoiding performance degradation from context noise in tasks relying on internal knowledge.
- **Comparison with Related Work**: Compared to standard RAG and "Retrieve-Always" agents, MARTA is faster on simple queries and more robust against distracting contexts. It addresses the "induced amnesia" caused by over-reliance on external retrieval, achieving a more efficient balance between internal and external knowledge.

## 4. Conclusion
This paper proposes MARTA, addressing the rift between parametric and non-parametric knowledge in LLM agents through thermodynamic arbitration. By enabling agents to "Look Before They Leap" (assess internal entropy), MARTA achieves adaptive retrieval strategies that preserve the efficiency of internal knowledge while leveraging external sources when necessary, marking a step towards machine intelligence with self-awareness and introspection.
