## 1. What the Paper Does
- **Background**: As cyber-attacks become increasingly sophisticated, Machine Learning-based Intrusion Detection Systems (IDS) have gained prominence. However, their effectiveness heavily relies on input data quality. Benchmark datasets (e.g., UNSW-NB15, NSL-KDD) are high-dimensional and heterogeneous, requiring complex pre-processing (cleaning, normalization, encoding, feature selection).
- **Why Existing Work Falls Short**: Traditional pre-processing pipeline design is labor-intensive, expertise-driven, and involves significant trial-and-error. For large-scale, high-dimensional network traffic data, repeatedly generating, executing, and evaluating candidate pipelines imposes a substantial computational burden and scalability challenges. Moreover, pipelines are often dataset-specific, lacking generalizability and requiring manual redesign for new datasets.

## Core Contributions
- **Proposed AutoDP-LLM**: An automated pre-processing framework leveraging Large Language Models (LLMs) to autonomously generate and validate executable data pre-processing pipelines for IDS.
- **Challenge 1: How to automate the generation of reasonable and executable pre-processing strategies?**
  - **Difficulty**: The vast combination space of pre-processing steps makes it difficult for traditional methods to automatically understand data semantics and generate correct code logic.
  - **Solution**: AutoDP-LLM combines deterministic host-side planning with LLM-based specialist agents. It uses semantic reasoning to analyze dataset metadata and task descriptions, automatically formulating data transformation strategies and synthesizing executable code.
- **Challenge 2: How to efficiently perform feature selection without a predefined feature budget?**
  - **Difficulty**: High-dimensional data contains redundant or irrelevant features. Traditional feature selection methods may require preset feature counts or incur high computational costs, struggling to balance information retention with dimensionality reduction.
  - **Solution**: The framework adaptively determines retained feature sets using semantic reasoning and training-derived statistical evidence, without requiring a predefined feature budget, thereby reducing computational overhead while maintaining detection performance.

## Implementation and Evaluation
- **Implementation & Deployment**: AutoDP-LLM supports parallel execution of candidate pipeline generation, validation, execution, and assessment, making it suitable for scalable computing environments like High-Performance Computing (HPC) systems.
- **Evaluation Results**: Evaluated on UNSW-NB15 and NSL-KDD benchmark datasets for multiclass intrusion detection using multiple downstream classifiers.
- **Comparison with Related Work**: Compared to conventional feature-selection methods, AutoDP-LLM achieves competitive detection performance while automating the generation of compact and executable pre-processing pipelines. Component-level ablation studies demonstrate the complementary contributions of semantic and statistical feature-reduction components.

#### Summary
AutoDP-LLM automates the IDS data pre-processing workflow by integrating LLMs, effectively addressing the high manual costs, inefficiency of trial-and-error, and heavy computational burdens associated with traditional methods. The framework not only generates high-quality pre-processing code automatically but also performs adaptive feature selection by combining semantic and statistical approaches. This significantly reduces the need for human intervention and demonstrates detection performance comparable to or better than traditional methods on standard datasets, offering a new perspective for intelligent cybersecurity defense.
