## 1. What the Paper Did

### Background
The adoption of Large Language Model (LLM) agents is growing as they evolve from conversational assistants into systems capable of planning, tool invocation, and interacting with external environments. This raises governance and security concerns, such as unsanctioned AI use and increased security incidents. Since agent communications are encrypted, there is a need for network administrators to audit agent behavior without inspecting private user content.

### Why Existing Work Falls Short
Existing network traffic datasets lack joint task and stage annotations necessary to evaluate how much network traffic reveals about agent tasks and operations. Current methods struggle to identify risks when malicious workflows resemble benign tasks and have difficulty distinguishing scenarios with similar traffic patterns, resulting in uneven and inaccurate behavioral signal recovery.

## Core Contributions

### Proposed ANT (Agent Network Traffic) Dataset and Benchmark
ANT is a multi-granularity network traffic dataset that provides agent behavior information at risk, scenario, and behavior primitive granularities, along with a corresponding benchmark.

### Challenge 1: How to accurately infer complex agent behaviors and potential risks from encrypted traffic without decryption?
This is challenging because malicious workflows often mimic the traffic patterns of benign tasks, and different scenarios may exhibit highly similar traffic features, making them hard to distinguish using traditional traffic analysis. ANT addresses this by providing a large-scale dataset with 3,114 execution episodes across 20 tasks and 5 scenarios, annotated with 40,049 behavior primitive segments. This enables the training and evaluation of finer-grained traffic analysis models to identify subtle behavioral differences and risk signals.

### Challenge 2: Lack of a unified standard to evaluate agent behavior auditing effectiveness at different granularities.
Previous studies lacked multi-level annotations for behavior primitives, scenarios, and risks, preventing systematic evaluation of traffic analysis techniques for agent auditing. ANT establishes a benchmark for risk identification, scenario recognition, and behavior primitive classification, evaluated using 13 representative traffic analysis baselines, providing a common foundation for developing more precise agent behavior auditing and forensic analysis.

## Implementation and Evaluation

The ANT dataset comprises 276,417 bidirectional flows and 40,049 behavior primitive segments organized into 47 macro groups. A benchmark was established using 13 representative traffic analysis baseline methods. Evaluation results show that existing methods recover useful but uneven behavioral signals:
1. **Risk Identification**: Existing methods struggle to accurately identify risks when malicious workflows resemble benign tasks.
2. **Scenario Recognition**: Discrimination capability is limited for scenarios with similar traffic patterns.
3. **Behavior Primitive Classification**: Classification is reliable for frequent macro groups and those with distinctive traffic patterns, but performs poorly for rare or semantically similar groups.

Compared to related work, ANT fills the gap of lacking joint task and stage annotations, providing finer-grained behavior primitive annotations that enable more precise and systematic auditing of agent behavior.

#### Summary

This paper introduces ANT, a multi-granularity network traffic dataset and benchmark for agent behavior auditing. By providing annotations at three levels—risk, scenario, and behavior primitives—ANT addresses the limitations of existing datasets in evaluating the inferability of agent behavior. Benchmark results indicate that while existing traffic analysis methods can extract some behavioral signals, they remain limited in handling similar traffic patterns and rare behaviors. ANT lays the foundation for future development of more precise tools for agent behavior auditing and forensic analysis.
