## 1. What the Paper Does
- **Background**: The computational demands of modern AI rely on complex Systems-on-Chip (SoCs), yet chip verification workflows remain stubbornly manual. Verification consumes over 70% of the development cycle, creating a major bottleneck.
- **Limitations of Existing Work**: While Large Language Models (LLMs) have advanced Electronic Design Automation (EDA), approximately 74.6% of studies focus on static Register-Transfer Level (RTL) code generation. Post-simulation verification and interactive waveform debugging are largely neglected. Existing LLM-aided verification tools struggle with dynamic debugging because raw waveform dumps are massive, unstructured, and exceed LLM context windows, creating an "Infrastructural Impedance" that locks autonomous agents out of the debugging loop.

## Core Contributions
- **Proposed Back-to-the-Future (BTTF)**: An end-to-end agentic framework enabling natural-language querying for root-cause analysis and formal verification over complex RTL waveforms.
- **Challenge 1: Mismatch between massive unstructured waveform data and LLM context limits**. Raw ASCII waveform dumps are too large and unstructured for direct LLM processing. **Solution**: BTTF distills these unstructured temporal waveforms into a normalized relational SQLite database, providing a structured, queryable interface that bypasses context window limitations.
- **Challenge 2: Mapping natural language to precise hardware verification logic**. Translating engineer queries into exact database queries and linking them to RTL code is complex. **Solution**: A collaborative multi-agent orchestration engine translates natural-language verification queries into schema-aware SQL and correlates signal anomalies with versioned RTL repositories, enabling automated planning, querying, and auditing.

## Implementation and Evaluation
- **Implementation & Evaluation**: The framework was evaluated on a benchmark of 150 expert-annotated queries. BTTF achieved an execution accuracy of 95.33%.
- **Comparison**: In comparison to a monolithic single-agent baseline, BTTF's multi-agent design outperformed the baseline by 17.3% across a five-criteria quality audit. This demonstrates the superiority of its collaborative architecture in handling complex verification tasks, offering a practical path toward autonomous EDA verification.

## 4. Conclusion
This paper addresses the gap in automating post-simulation waveform debugging in chip design verification by introducing the BTTF framework. By converting massive waveform data into relational databases and employing a multi-agent system for natural-language-to-SQL translation and RTL correlation, it effectively overcomes infrastructural impedance. Experimental results show significant improvements in accuracy and quality over baselines, marking a significant step toward autonomous EDA verification workflows.
