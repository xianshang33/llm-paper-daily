## 1. What the Paper Did
- **Background**: Multi-agent LLM systems coordinate tasks through information exchange. Coordination failures often present similar symptoms in execution traces but stem from different issues in information passing, usage, or verification. Communication topology provides structural cues to distinguish these failure modes.
- **Why Existing Work Falls Short**: Prior research (e.g., MAST, Who&When) focuses on categorizing failures or identifying responsible agents/steps, or optimizes topology for performance, but fails to leverage communication topology as diagnostic context. Existing methods struggle to recover structural information from heterogeneous execution traces lacking explicit topology labels, limiting their ability to exploit the relationship between topology and failure patterns.

## Core Contributions
- **Proposed MAScope**: A two-stage framework for topology-conditioned diagnosis of multi-agent LLM failures.
- **Challenge 1: How to recover communication topology from unlabeled, heterogeneous execution traces?**
  - **Difficulty**: Execution traces lack explicit structural labels, and complex message interactions make inferring agent dependencies challenging.
  - **Solution**: Introduced the Trace Structural Extractor (TSE), which recovers communication topology by grounding an interaction graph in message evidence from heterogeneous traces.
- **Challenge 2: How to effectively classify failures using the recovered topology?**
  - **Difficulty**: Pure trace analysis struggles to distinguish similar failure symptoms caused by different topological structures, requiring a mapping between topology and specific failure patterns.
  - **Solution**: Designed the Topology-Conditioned Judge (TC-Judge), which classifies failures by combining the trace, predicted topology, empirical failure priors estimated from separate labeled traces, and short descriptions of topology-specific failure patterns.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on the MAST-clean dataset (851 traces) and 1000 traces under a fixed orchestration structure.
- **Key Results**:
  - Statistical Significance: Demonstrated a statistically significant association between communication topology and failure type ($\\chi^2 = 409.9$, $p = 1.2 \times 10^{-70}$).
  - Performance Improvement: On MAST-clean, ground-truth topology context increased gpt-mini's Macro-F1 from 0.173 to 0.350.
  - Predicted Topology Performance: The pipeline with predicted topology achieved a Macro-F1 of 0.346, approaching the trace-only gpt-5.4 baseline of 0.372.
- **Cost Efficiency**: For 1000 traces under a fixed orchestration structure, the projected pipeline cost (including one topology extraction) is approximately 6% of the cost of repeated gpt-5.4 diagnosis.
- **Comparison**: Compared to trace-only baselines, introducing topology-conditioned context significantly improved the diagnostic accuracy of smaller models (gpt-mini), bringing them close to the performance of larger models (gpt-5.4) while substantially reducing computational costs.

## 4. Conclusion
This paper reveals a strong correlation between communication topology and failure modes in multi-agent LLM systems. It proposes MAScope, which recovers topology via TSE and diagnoses failures using TC-Judge with topology priors. This approach not only significantly improves diagnostic accuracy but also reduces inference costs through topology reuse, offering a new pathway for efficient and low-cost monitoring and debugging of multi-agent systems.
