## 1. What the Paper Does
- **Background**: Conversational agents based on Large Language Models (LLMs) must strictly adhere to policies. Each condition in a policy defines a boundary between user requests, requiring the agent to behave differently on either side. However, existing benchmarks show that agents often fail to comply, exhibiting inconsistent behavior and decreasing accuracy over multi-turn conversations.
- **Why Existing Work Falls Short**: Current evaluation methods (e.g., AgentEval) have limited test coverage and lack a systematic mechanism for generating tests that probe both sides of complex boundaries defined by prompts, code, or knowledge bases, leaving many potential policy violations undetected.

## Core Contributions
- **Proposed AdaT² Framework**: An adaptive test transformation method for black-box boundary testing of conversational agents.
- **Challenge 1: How to extract explicit test conditions from unstructured conversations?**
  - **Difficulty**: Agent policies are implicit in prompts, code, and knowledge bases, making it hard to directly obtain explicit boundary conditions.
  - **Solution**: AdaT² conducts exploratory conversations with an LLM acting as the user and extracts "Statements" from the agent's replies. Each statement describes a condition and its expected behavior, converting implicit policies into explicit test guides.
- **Challenge 2: How to efficiently generate diverse test cases covering both sides of boundaries?**
  - **Difficulty**: The combination space of statements and test transformation instructions (e.g., "omit one required input") is vast, and many combinations are inapplicable, making blind exploration inefficient.
  - **Solution**: Introduces an adaptive pair selection mechanism. It selects statements based on novelty and uses the Bayes-UCB bandit algorithm to dynamically choose optimal transformation instructions based on historical outcomes (whether a valid test was generated and if the agent passed according to an LLM judge), thereby efficiently generating boundary-crossing transformed tests.

## Implementation and Evaluation
- **Benchmark Design**: A new benchmark was constructed that counts both sides of each boundary separately and distinguishes between boundaries explicitly defined by the agent's prompt/code/knowledge base and those inferred by the LLM from domain knowledge.
- **Effectiveness Comparison**: On four domains of the $\tau^3$-bench, 62.7% to 83.3% of AdaT²'s tests were valid boundary tests with explicitly defined expected behaviors. This proportion was higher in every domain compared to the previous AgentEval (47.7% to 68.1%).
- **Boundary Coverage Enhancement**: Transformed tests uncovered 13 to 46 additionally explicitly defined boundaries that plain tests missed.
- **Fault Detection Capability**: As regression tests, AdaT² detected all 8 seeded policy faults in the airline domain and 4 out of 8 in the retail domain. In contrast, AgentEval's test suites (with fewer than one-third the number of tests) detected only 5 and 2, respectively.

#### Summary
AdaT² significantly improves black-box boundary testing for conversational agents by extracting policy statements from exploratory dialogues and combining them with adaptive test transformation instruction generation. The method not only enhances the validity of generated tests but also optimizes the test selection process via the Bayes-UCB algorithm, detecting more policy violations and boundary defects with fewer tests, outperforming the existing AgentEval method.
