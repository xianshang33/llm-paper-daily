## 1. What the Paper Does
- **Background**: Tool-using LLM agents increasingly require a common substrate for building, training, evaluating, distilling, and maintaining agentic systems.
- **Why Existing Work Falls Short**: Existing tools (e.g., TRL, LangGraph, lm-eval) address these stages in isolation with fragmented interfaces. Different representations for RL rollouts, decision workflows, and evaluation traces force developers to repeatedly reconstruct logic for scoring, loss masking, and auditing, leading to inefficiency and inconsistency.

## Core Contributions
- **Proposed AgentTune Framework**: A source-available Python library providing a unified framework for developing and optimizing tool-using agents, centered around a two-tier EventLog representation.
- **Challenge 1: Fragmented Data Representations**. Different lifecycle stages require disparate data formats, creating silos. AgentTune solves this by introducing a two-tier EventLog that records agent interactions once and supports consistent projections for training (SFT rows), evaluation inputs, and audit records.
- **Challenge 2: Isolated Training and Recovery Mechanisms**. Traditional RL and distillation are often disconnected from execution environments. AgentTune provides a shared agent runtime and TRL-backed RL core supporting various algorithms (GRPO, PPO, etc.), enabling the conversion of detected failures into corrective training data for self-healing capabilities.

## Implementation and Evaluation
- **Implementation**: Released as a source-available library with composable interfaces. It integrates tool-calling reinforcement learning, agentic distillation, RAG, and decision workflows, allowing flexible combination of strategies without separate pipelines.
- **Evaluation Results**: Demonstrated on agentic tasks such as legal contract search. A search agent trained on synthesized questions was evaluated on three unseen corpora, illustrating effective trajectory-based optimization and tool-use evaluation.
- **Comparison**: Unlike AgentTuning (a method/dataset), AgentTune is a comprehensive software library covering the full lifecycle. Compared to isolated tools like TRL or LangGraph, it eliminates intermediate data conversion overhead, enhancing development efficiency and system consistency.

## 4. Conclusion
AgentTune addresses the fragmentation in LLM agent toolchains by defining a unified trajectory contract (EventLog) and a shared training stack. It simplifies the development lifecycle from build to maintenance and enhances agent robustness through self-healing and diverse RL support, providing a foundational framework for standardized complex agent system development.
