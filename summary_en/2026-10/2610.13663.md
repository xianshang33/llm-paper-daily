## 1. What the Paper Did
- **Background**: Many machine learning approaches follow a two-level structure where experts select a method class, but the critical choice of key components within that class is usually manual. This manual process is labor-intensive and poorly reproducible.
- **Why Existing Work Falls Short**: Existing automated systems either optimize entire ML scripts or search for architectures in discrete spaces. These approaches lack the flexibility to finely tune specific functional modules within a fixed architecture or are computationally prohibitive, failing to provide a generalizable solution for specialized models like Spiking Neural Networks (SNNs) or Physics-Informed Neural Networks (PINNs).

## Core Contributions
- **Proposed a Multi-Agent LLM Framework**: The system features three roles—analyst, coder, and recorder—integrated with an experiment log and a sandboxed execution environment to automate the tuning of key neural network components.
- **Challenge 1: How to precisely generate code for specific components while keeping the overall network structure unchanged?**
  - **Difficulty**: Generating full scripts is error-prone and hard to control, while traditional architecture search spaces are too vast.
  - **Solution**: The framework operates in an open but semantically narrow space, where agents generate code only for specified components (e.g., input encoding, loss terms), leaving the main network structure intact. This reduces search complexity and improves code accuracy.
- **Challenge 2: How to achieve generalizability and transferability across tasks of different natures?**
  - **Difficulty**: Domains like SNNs and PINNs differ significantly, lacking universal tuning rules.
  - **Solution**: By decomposing diverse models into similar modules (input preprocessing, feature transformation, decoding/output, loss function), the multi-agent collaboration mechanism uniformly handles module tuning, demonstrating cross-domain transferability in both classification and differential equation solving tasks.

## Implementation and Evaluation
- **Implementation**: The system comprises three LLM agent roles, integrates a sandboxed environment for safe code execution, and uses experiment logs to accumulate historical experience. Detailed prompts significantly enhanced the performance of less capable LLMs.
- **Evaluation**: Validated on five tasks: spiking classification on MNIST and Digits, and boundary-value problems for the Generalized Nonlinear Schrödinger Equation (GNLSE) and Kuramoto–Sivashinsky (KS) equations.
- **Comparison with Baselines**:
  - **Classification**: Accuracy improved by 13 percentage points on MNIST and 6 percentage points on Digits compared to baselines.
  - **Physics Equations**: Error against the analytical single-soliton solution in GNLSE was reduced approximately 2491-fold. Invariant-preservation error dropped ~325-fold with Gaussian perturbation and >100-fold on average. Mass drift in the KS problem decreased 14-fold.
  - **Conclusion**: The framework significantly outperforms traditional baselines without altering its internal structure, proving its effectiveness in tuning key components across diverse tasks.

#### Summary
This paper proposes a multi-agent LLM-based automated tuning framework specifically designed for adjusting key functional modules in specialized neural network models. By restricting code generation to specific components while maintaining a stable overall architecture, the method overcomes the flexibility and generalizability limitations of traditional AutoML approaches. Experimental results demonstrate significant performance improvements in both Spiking Neural Network classification and Physics-Informed Neural Network differential equation solving, highlighting the framework's strong cross-domain transferability and potential for automated hyperparameter and component optimization.
