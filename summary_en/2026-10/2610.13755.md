## 1. What the Paper Does
- **Background**: Training long-horizon LLM agents requires assigning credit to intermediate decisions from sparse terminal feedback. Existing group-relative reinforcement learning methods perform critic-free updates by comparing outcomes within groups of sampled responses or trajectories.
- **Limitations of Prior Work**: Current methods (e.g., GiGPO, trajectory-graph methods) typically group decisions based solely on repeated states or transitions. However, identical state summaries can correspond to different stages of task progress (e.g., visiting a countertop before or after acquiring an object). This "context mismatch" causes action comparisons to conflate prior progress with the current action's contribution, leading to inaccurate credit assignment. While adding context can distinguish these decisions, stricter conditions reduce the amount of evidence available for comparison.

## Core Contributions
- **Proposed Matched-Context Group Policy Optimization (MCGPO)**: A procedure for constructing weighted action preferences from collected trajectories by defining comparison contexts that include pre-action state summaries and observed rubric progress.
- **Challenge 1: Noisy credit assignment due to context mismatch**. The difficulty lies in identical state summaries obscuring different prior task progresses, distorting action comparisons. MCGPO addresses this by defining comparison contexts using both state summaries and "observed rubric progress" annotated by task rules, ensuring only decisions at similar task stages are compared.
- **Challenge 2: Data sparsity caused by strict matching**. The difficulty is that overly strict matching conditions drastically reduce the number of comparable action pairs per group, hindering learning efficiency. MCGPO employs a "Two-action support" mechanism that selects between ordered exact and coarse matching rules, using support-dependent evidence weights to scale the auxiliary pairwise objective, thereby balancing match quality with data utilization.

## Implementation and Evaluation
- **Implementation**: MCGPO reuses rollout data and original response histories, maintaining critic-free training. It uses fixed folds to separate candidate decisions from the terminal outcomes used to orient preferences.
- **Results**: Across six environment-backbone settings (with three seeds each), MCGPO significantly outperforms the matched GraphGPO baseline:
    - On ALFWorld and WebShop with Qwen2.5-1.5B and 7B, mean success rates improved by 0.47–1.46 percentage points.
    - On WebShop with Qwen3-4B and 8B, success rates improved by 3.96 and 5.16 points, respectively.
    - Notably, gains on ALFWorld were achieved despite a baseline success rate already exceeding 92%, indicating effectiveness even with limited headroom.
- **Comparison**: Ablation studies showed that joint state-rubric matching achieved the highest mean success in all four representation-control settings, outperforming methods using only opposite-fold evidence or evidence weighting, thus validating the efficacy of combining state and rule progress.

## 4. Conclusion
This paper addresses the long-horizon credit assignment problem in LLM agent training by proposing MCGPO. By introducing a rule-aware context matching mechanism, it resolves the context mismatch issue inherent in traditional group-relative RL methods. Experiments demonstrate that MCGPO surpasses existing GraphGPO methods across multiple benchmarks and model scales, achieving significant gains even in high-performance regimes, offering a more refined credit assignment solution for critic-free LLM agent training.
