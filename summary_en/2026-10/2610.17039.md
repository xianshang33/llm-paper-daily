## 1. What the Paper Does
- **Background**: Tool-using LLM agents are increasingly deployed to automate workflows governed by procedural manuals written in natural language (e.g., corporate travel booking or hardware procurement rules). Ensuring strict compliance with these manuals is challenging.
- **Limitations of Existing Work**: Current state-of-the-art techniques rely on LLM judges or manually written rules to locally block problematic tool calls at runtime. This approach is insufficient because: (i) merely blocking calls leaves the agent clueless about how to proceed correctly, and (ii) it leads to overly conservative behavior, as tool calls may only be problematic in specific contexts which static rules fail to capture.

## Core Contributions
- **Proposed MENTOR**: A procedural shielding framework for tool-using LLM agents that constructs a novel history-dependent runtime shield from procedural manuals via a multi-step auto-formalization pipeline.
- **Challenge 1: Providing Guidance vs. Mere Blocking**
  - **Difficulty**: Simple blocking mechanisms prevent violations but do not inform the agent how to correct its course, leading to task stagnation.
  - **Solution**: MENTOR provides active guidance by identifying outstanding obligations and directing the agent toward procedurally compliant progress, rather than just rejecting invalid actions.
- **Challenge 2: Context-Aware Compliance without Over-Restriction**
  - **Difficulty**: Rules often depend on execution history and current state (e.g., distance checks before booking). Static rules lack this dynamic context, causing false positives or excessive conservatism.
  - **Solution**: The core utilizes a game-based technique to ensure robustness against runtime uncertainty. This allows the shield to be context-aware and history-dependent, preventing violations without unnecessarily restricting the agent's valid actions.

## Implementation and Evaluation
- **Implementation & Deployment**: The shield is synthesized once per manual and then serves every task governed by that manual. This amortizes the offline construction cost, making it a viable and cost-effective choice for repeatedly executed workflows.
- **Evaluation Results**: MENTOR significantly improves compliance rates well beyond existing methods.
- **Comparison with Related Work**: Notably, MENTOR-shielded lightweight open-source LLMs achieve higher compliance than non-shielded proprietary models. This demonstrates the framework's ability to elevate the reliability of smaller models to surpass larger, unshielded counterparts.

## 4. Conclusion
MENTOR addresses the compliance challenges of LLM agents in following natural language procedural manuals by introducing a game-based, history-dependent runtime shield. It goes beyond simple blocking by offering active guidance and ensuring context-aware enforcement. This approach not only enhances compliance but also avoids overly conservative behavior, enabling lightweight open-source models to outperform proprietary ones in regulated tasks, thus offering a robust and cost-effective solution for automated workflows.
