## 1. What the Paper Did
- **Background**: Reusable skills allow LLM agents to load task-specific instructions on demand. Current designs (e.g., Anthropic Agent Skills) use "progressive disclosure," where agents perform implicit routing by selecting skills based on metadata while executing tasks.
- **Why Existing Work Fails**: Existing designs assume agents can accurately filter relevant skills from a growing pool while simultaneously solving complex tasks. However, this implicit routing mechanism suffers from severe scalability issues as the number of irrelevant skills increases, leading to failure in loading necessary skills, a problem previously lacking systematic analysis.

## Core Contributions
- **Proposed a systematic analysis of "Skill Routing Collapse" and a mitigation strategy via Explicit Preselection**: The paper identifies that implicit routing fails due to semantic interference and instruction competition in large-scale skill libraries and evaluates explicit preselection as an effective solution.
- **Challenge 1: Semantic Interference**. As irrelevant skills increase, their descriptions create semantic noise, hindering the agent's ability to identify target skills. The paper demonstrates that masking descriptions of irrelevant skills largely restores skill loading, pinpointing semantic interference as a key cause.
- **Challenge 2: Instruction Interference from Competing Tasks**. Implicit routing forces agents to handle task planning and skill selection simultaneously, causing attention dilution. The paper shows that decoupling retrieval from execution via explicit preselection outperforms even explicit planning within the execution loop, as it reduces instruction conflict in the context.

## Implementation and Evaluation
- **Experimental Setup**: Using SkillsBench, the study fixed tasks and golden skills while varying the number of irrelevant skills (from 0 to 1,000+).
- **Key Results**:
    - **Implicit Routing Collapse**: With 1,000 irrelevant skills, implicit routing's recall dropped from 73.6% to 27.4%, and the zero-load rate surged from 9.3% to 51.6%.
    - **Superiority of Explicit Preselection**: In contrast, explicit selection maintained a 73.9% recall rate under the same conditions, demonstrating robustness.
    - **Ablation Studies**: Masking irrelevant descriptions significantly recovered performance. However, asking agents to explicitly plan skill usage still yielded lower recall than independent preselection modules.
- **Comparisons**: Evaluated three preselectors: LLM direct selection, RAG-based embedding retrieval, and a hybrid approach. Explicit preselection offered a better trade-off between coverage and latency compared to implicit execution.

## 4. Conclusion
This paper uncovers the "Skill Routing Collapse" in LLM agents with large skill libraries, proving that semantic interference and instruction competition cause agents to fail in loading necessary skills as irrelevant options grow. It recommends adopting explicit skill preselection mechanisms (e.g., RAG or LLM filters) to decouple retrieval from execution, thereby enhancing scalability and success rates. These findings provide crucial guidance for future agent skill protocol design and evaluation.
