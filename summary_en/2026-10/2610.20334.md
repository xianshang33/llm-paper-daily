## 1. What the Paper Does
- **Background**: In long-horizon tasks (e.g., deep research, software engineering), agents rarely solve problems in a single linear path. Standard ReAct-style agents accumulate all observations, intermediate results, and failed attempts in a single linear context.
- **Limitations of Existing Work**: As the context grows, stale and off-path information consumes limited capacity and obscures relevant evidence, hindering focused reasoning. While memory compression or summarization methods mitigate context length issues, discarded information cannot be recovered. Traditional tree-search methods (e.g., MCTS) rely on hand-designed traversal rules or independent node scoring, lacking adaptability to dynamic global evidence and struggling to flexibly determine how to proceed from selected states.

## Core Contributions
- **Proposed TreeFlex Framework**: A framework where the agent's own policy decides where to search. It records each intermediate state with a short summary as a node in a search tree, managed by a harness, with a single language model acting in two roles.
- **Challenge 1: How to decouple global vision from local execution under limited context?**
  - **Difficulty**: Traditional methods either suffer from context explosion or lose historical state information, preventing backtracking or leveraging new evidence from early branches.
  - **Solution**: Introduces "Reflection" and "Execution" roles. The Reflection role has a global view via node summaries to select a node and instruction. The Execution role restores only the path context to that node, executing instructions until saving a new node or proposing a solution, ensuring clean local context while maintaining global decision-making capability.
- **Challenge 2: How to train the agent to optimize search strategy without fixed traversal orders or explicit node scoring?**
  - **Difficulty**: Traditional tree searches rely on heuristics or independent value networks, making it hard to jointly optimize navigation, action execution, and checkpointing. Independent scoring often ignores inter-branch influences.
  - **Solution**: Uses a tree-aware adaptation of GRPO for joint reinforcement learning, combining task-level outcome rewards with process rewards. This allows the policy to autonomously decide whether to deepen, branch, revisit, or stop, without artificial traversal orders.

## Implementation and Evaluation
- **Implementation Details**: Uses single language models (4B and 9B scales) trained with small-scale RL. The system maintains a harness-managed search tree, with the model switching between global reflection (viewing summaries) and local execution (restoring specific path contexts).
- **Evaluation Results**:
  - **Deep-research Benchmark**: Under the same active context limit, TreeFlex (4B) achieved 48.8% accuracy, significantly outperforming Flat ReAct (41.5%) and FoldAgent (42.8%). Its Pass@8 was approximately 10 points higher than both baselines.
  - **SWE-bench Verified**: With RL training on the same 9B model, TreeFlex resolved 54.9% of tasks, surpassing FoldAgent (43.3%) and its step-wise variant (45.2%).
- **Comparison Advantage**: Compared to fixed-rule tree searches and linear-context ReAct, TreeFlex demonstrates higher accuracy and robustness in complex reasoning and code repair tasks, particularly in scenarios requiring backtracking and multi-path exploration.

#### Summary
TreeFlex effectively addresses context pollution and state backtracking challenges in long-horizon tasks by introducing a dynamic tree search mechanism driven by the agent's policy. Its core dual-role design (global reflection and local execution), combined with tree-aware reinforcement learning, enables flexible navigation of the search space without relying on manual heuristics or independent scoring models. Experiments show state-of-the-art performance on deep research and software engineering benchmarks, demonstrating the significant potential of adaptive tree structures in enhancing LLM agent reasoning capabilities.
