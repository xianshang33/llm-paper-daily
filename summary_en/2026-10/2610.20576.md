## 1. What the Paper Did

### Background
When Large Language Models (LLMs) are used as agents, their competence is tightly bound to the specific interface (e.g., function names, parameter schemas, descriptions) used during training. In deployment, interfaces often undergo semantics-preserving perturbations (such as renaming actions or adding equivalent tools), which significantly degrade agent performance.

### Why Existing Work Falls Short
Existing methods include Function Masking and Multi-interface Training (Domain Randomization). Function masking removes name cues but leaves other shortcuts like tool position; Multi-interface training only broadens dependence from a single interface to the training distribution, leaving agents vulnerable to out-of-distribution perturbations. Neither fundamentally solves the overfitting to interface forms.

## Core Contributions

### Proposed Cross-Interface Policy Regularization (CIPR)
CIPR is a self-supervised objective that improves robustness by enforcing consistency across different interface views.

### Challenge 1: Agents learn superficial "shortcuts" instead of semantic understanding
**Challenge**: Agents often rely on memorizing tool names or positions to maximize rewards, failing when these surface features change even if the task remains the same.
**Solution**: CIPR replaces action names with uninformative identifiers and presents each sample under two constructed interfaces with equivalent actions. By penalizing the KL divergence between action distributions across these interfaces, it forces the policy to ignore surface forms and focus on semantic consistency.

### Challenge 2: Traditional data augmentation cannot cover all interface variations
**Challenge**: Simple interface randomization covers only seen variations during training, leading to poor generalization against unseen interface perturbations.
**Solution**: Instead of just expanding data diversity, CIPR uses an intrinsic consistency constraint. This decouples the policy from specific interface forms, enabling robust generalization to out-of-distribution interface changes.

## Implementation and Evaluation

### Implementation
CIPR can be applied in both Supervised Fine-Tuning (SFT) and Reinforcement Learning (RL) post-training stages. It requires no extra labeled data, relying only on constructing different interface views for the same task and computing consistency loss.

### Evaluation Results
In Agentic Function Calling tasks:
1. **Baseline**: Standard post-trained agents suffered a nearly 25% accuracy drop under held-out interface perturbations.
2. **CIPR Performance**: CIPR recovered 10.5% of the accuracy while maintaining performance on the unchanged interface, demonstrating improved robustness without sacrificing core capabilities.

### Comparison with Related Work
Compared to Function Masking (which removes partial cues) and Multi-interface Training (which only widens distribution coverage), CIPR more effectively addresses shortcut learning through explicit cross-interface consistency regularization, showing superior generalization to unseen interface changes.

## 4. Conclusion

This paper identifies the vulnerability of LLM agents to interface changes as a result of shortcut learning and proposes Cross-Interface Policy Regularization (CIPR). By minimizing policy distribution differences across different interface views in a self-supervised manner, CIPR successfully decouples agent competence from specific interface forms. Experiments show that CIPR significantly enhances robustness against interface perturbations while preserving original task performance, offering a simple yet effective solution for building more robust LLM agents.
