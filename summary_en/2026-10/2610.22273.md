## 1. What the Paper Does
- **Background**: Large Language Models (LLMs) struggle with reasoning over long document corpora that exceed context windows, where information is dispersed and disconnected. Current agentic systems are skilled at navigating existing file systems for immediate tasks but lack the ability to construct reusable workspaces for future use.
- **Limitations of Existing Work**: Standard Retrieval-Augmented Generation (RAG) methods are inherently reactive, forcing agents to repeatedly search and rediscover cross-document relationships at inference time, creating computational bottlenecks. Pre-computed structures like knowledge graphs rely on rigid heuristics, making them inflexible for diverse queries that require task-specific intermediate artifacts.

## Core Contributions
- **Proposed Librarian Agents**: A framework where a "builder agent" transforms raw documents into a hierarchical file system of synthetic files and reference links, creating a workspace tailored for a downstream "answering agent."
- **Challenge 1: How to shift from passive retrieval to proactive, anticipatory curation?**
  - **Difficulty**: Traditional methods either search in real-time per query (high latency, redundant computation) or pre-build fixed structures (low flexibility). It is difficult to anticipate and organize structures useful for various potential queries without knowing them in advance.
  - **Solution**: Introduces "anticipatory directed curation," formulating workspace construction as a Markov Decision Process (MDP). The builder policy is optimized via reinforcement learning to directly maximize downstream answering accuracy, learning to proactively reorganize unstructured corpora.
- **Challenge 2: How to ensure the constructed workspace genuinely improves downstream efficiency and accuracy?**
  - **Difficulty**: The generated structure must balance information density with clear logical hierarchy to enable efficient navigation by the answering agent. Simple summaries or indices often lose complex cross-document reasoning cues.
  - **Solution**: Through end-to-end reinforcement learning, the builder agent generates synthetic files and reference links specifically designed to aid the answering agent in selective search and reasoning, rather than just storing raw text.

## Implementation and Evaluation
- **Results**: Librarian Agents outperforms the strongest retrieval and pre-computation baselines by 33 percentage points on BrowseComp-Plus. It also demonstrates zero-shot generalization to unseen domains on BRIGHT, with an average accuracy improvement of 31 percentage points.
- **Cost Amortization**: While there is an upfront cost to constructing the workspace, this cost is amortized across repeated queries, making it more efficient than full retrieval for each query in the long run.
- **Comparison**: Compared to reactive RAG, it reduces the search burden during inference; compared to rigid knowledge graphs, the generated hierarchical file system is more flexible and adaptable to diverse query needs.

## 4. Conclusion
Librarian Agents addresses efficiency and flexibility issues in LLM long-context reasoning by training a builder agent to proactively curate workspaces. By optimizing document reorganization strategies via reinforcement learning, the method significantly enhances the performance of downstream QA agents, surpassing existing retrieval and pre-computation methods on multiple benchmarks while demonstrating strong generalization and cost-effectiveness.
