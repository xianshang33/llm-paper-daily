## 1. What the Paper Does
- **Background**: Long-horizon LLM agents need to leverage ever-growing long-term memory to answer user queries. Daily events are often semantically homogeneous (e.g., multiple instances of "dinner with family"), making time a crucial differentiator.
- **Why Existing Work Fails**: Current methods focus on lexical or semantic similarity, causing target memories to be crowded out by temporally mismatched but semantically similar candidates. Even time-aware approaches typically inject temporal cues only during memory organization or answer generation, overlooking temporal constraints at the retrieval stage where candidate selection occurs, which is the root cause of evidence displacement.

## Core Contributions
- **Proposed TIDER (Temporal Interval-driven Dual-channel Evidence Retrieval)**: A time-aware agentic retrieval framework inspired by the temporal contiguity effect in human episodic memory.
- **Challenge 1: Optimizing discrete, non-differentiable retrieval decisions**. Treating temporal window localization as a discrete decision makes it hard to optimize with standard gradients. The paper addresses this by using Reinforcement Learning (RL) to train a temporal interval locator, employing composite rewards to convert sparse answer supervision into fine-grained retrieval feedback for effective optimization.
- **Challenge 2: Target evidence drowned out by semantically similar but temporally mismatched memories**. In vast historical data, semantically similar but wrong-time memories interfere with retrieval. The paper solves this via a dual-channel mechanism: the RL locator defines a "temporal retrieval channel" based on inferred windows, which is then merged with the "semantic channel" and reranked by proximity to the windows, ensuring temporally aligned evidence is prioritized.

## Implementation and Evaluation
- **Implementation**: The core component is a lightweight 1.7B parameter locator used to infer temporal windows.
- **Evaluation Results**: TIDER achieves State-of-the-Art (SOTA) accuracy on two long-horizon memory benchmarks.
  - LifeBench: 61.52% accuracy (+8.82% improvement).
  - LoCoMo: 78.96% accuracy (+3.66% improvement).
- **Comparison**: The results demonstrate that temporal cues are critical for pinpointing target evidence amidst semantically similar historical events. TIDER significantly outperforms existing methods that rely solely on semantics or inject time information post-retrieval.

#### Summary
This paper addresses the issue of key evidence loss in long-horizon agent memory retrieval due to temporal misalignment. It proposes TIDER, which introduces an RL-trained temporal interval locator to precisely infer time windows during the retrieval stage. By combining this with a dual-channel retrieval and reranking mechanism, TIDER effectively mitigates interference from semantically similar but temporally incorrect memories. Experiments show SOTA performance on multiple benchmarks, validating the critical value of time-aware retrieval in long-term memory management.
