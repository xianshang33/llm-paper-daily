## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents tackling long-horizon tasks accumulate extensive interaction histories, including code, tool outputs, and intermediate decisions, leading to context window overflow. Agents need to dynamically manage context by retaining critical evidence and discarding irrelevant information.
- **Limitations of Existing Work**: Current approaches fall into two categories, both with significant drawbacks. Rule-based methods (e.g., fixed-threshold truncation or summarization) trigger based solely on context length, ignoring semantic value. Tool-based methods expose context management as external tool calls, binding the learned policy to specific environment interfaces and resulting in poor generalization across diverse workflows.

## Core Contributions
- **Proposed the Native Context Editing (NCE) framework**: This framework provides LLM agents with a "grammar" for natively editing their own context, establishing context editing as an atomic and inherent capability of the agent.
- **Challenge 1: How to internalize context editing as a native model capability rather than an external dependency?**
  - **Difficulty**: Traditional methods place editing logic outside the model (rules or external tools), preventing the model from dynamically understanding when and how to edit based on semantics, and causing heavy reliance on specific environment schemas.
  - **Solution**: Encodes context-editing operations into a grammar of dedicated special tokens, teaching agents to invoke edits through the language itself, making editing an integral part of the model's generation process.
- **Challenge 2: How to achieve efficient and accurate dynamic context management during long-horizon reasoning?**
  - **Difficulty**: As interactions grow, contexts become noisy. Simple truncation loses key information, while complex tool calls increase latency and error rates.
  - **Solution**: Trains agents on iteratively constructed trajectory segments where each teacher edit is conditioned on the evolving context, enabling agents to dynamically modify context while generating responses for long-horizon tasks.

## Implementation and Evaluation
- **Implementation & Training**: NCE constructs an editing grammar using dedicated special tokens and trains agents on iteratively built trajectory segments. Teacher edits are conditioned on the evolving context to ensure the model learns editing strategies aligned with the current task state.
- **Evaluation Benchmarks**: Evaluated on four long-horizon agentic benchmarks: Terminal-Bench 2.0, SWE-bench Verified, SWE-bench Multilingual, and SWE-bench Pro.
- **Results**:
  - **LongCat-Flash-Lite-Sparse**: Improved average task success rate by 5.6 percentage points over the base model, while reducing average token usage by 36%.
  - **Qwen3.6-35B-A3B**: Improved average task success rate by 4.5 percentage points over the base model, while reducing average token usage by 15%.
- **Comparison**: Unlike methods that learn to generate tool-use code within specific external harness environments, NCE integrates context editing as an internal mechanism of the model's native generation process, demonstrating superior generalization across diverse real-world workflows and significantly reduced token consumption.

#### Summary
This paper proposes the Native Context Editing (NCE) framework, which enables LLM agents to natively edit their context by encoding editing operations into a grammar of special tokens. This approach overcomes the limitations of traditional rule-based or external tool-based methods by transforming context management into an intrinsic model capability. Experiments demonstrate that NCE significantly improves task success rates and substantially reduces token usage across multiple long-horizon agentic benchmarks, showcasing excellent generalization and efficiency in diverse real-world workflows.
