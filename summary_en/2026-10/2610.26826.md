## 1. What the Paper Does
- **Background**: As Large Language Models (LLMs) advance in coding and tool use, effectively incorporating visual references into agentic generation is crucial for real-world productivity applications. Webpage development serves as a practical and evaluable setting for this capability.
- **Limitations of Existing Work**: Current benchmarks are largely idealized, focusing either on reconstructing single visual targets or generating webpages from text instructions alone. They overlook the common real-world workflow of developing from multiple visual examples (screenshots) combined with natural language instructions.

## Core Contributions
- **Proposed RefCraft Benchmark**: A benchmark comprising 300 realistic multimodal webpage-development tasks. Each task combines natural-language instructions with screenshots from one to five reference webpages, requiring agents to selectively interpret references, render, visually inspect, and iteratively refine outputs.
- **Challenge 1: Selective Interpretation of Multi-Source Visual References**
  - **Difficulty**: Agents must extract and fuse specific visual features (e.g., color palette from Source A, layout from Source B) from potentially conflicting or complementary sources, rather than simply copying.
  - **Solution**: RefCraft designs tasks with varying reference intensities and multi-source combinations. It evaluates performance using independently verifiable keypoints, forcing models to demonstrate precise extraction and fusion capabilities.
- **Challenge 2: Automated Evaluation of Open-Ended Artifacts**
  - **Difficulty**: Webpage generation produces open-ended artifacts where traditional exact-match code evaluation fails to capture visual fidelity and functional correctness.
  - **Solution**: The paper employs a hybrid evaluation strategy combining independently verifiable keypoints, programmatic judges (for structure/validity), and Vision-Language Model (VLM) judges to comprehensively assess generation quality.

## Implementation and Evaluation
- **Evaluation Setup**: Evaluated across nine frontier (Multi-modal) LLMs.
- **Key Results**: The strongest system achieved an overall score of only 52.12 out of 100, revealing that visual-reference-conditioned agentic generation remains a substantial challenge.
- **Comparison**: Analysis shows that performance drops significantly as the number of reference pages increases (1-5). Most models struggle with multi-reference tasks. The study highlights a trade-off between token usage and performance (Pareto frontier), demonstrating that existing benchmarks fail to capture this complexity due to their simplified nature.

## 4. Conclusion
RefCraft fills a critical gap in evaluating visual-reference-conditioned agentic generation. By establishing realistic multimodal web development tasks, it exposes the limitations of state-of-the-art models in handling complex visual references and multi-source information fusion. This benchmark provides a more practical standard for future research, emphasizing the need for improved visual understanding and iterative optimization capabilities in AI agents.
