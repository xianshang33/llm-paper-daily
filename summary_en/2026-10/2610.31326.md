## 1. What the Paper Does
- **Background**: Evolutionary program search with Large Language Models (LLMs) retains the structure of evolutionary algorithms, using LLMs as variation operators. Existing methods (e.g., FunSearch, AlphaEvolve) typically generate candidate programs in a single request based on parent programs and their scores.
- **Why Existing Work Falls Short**: In current LLM-based systems, models lack execution tools during candidate generation. They reason solely from parent programs, scores, and textual feedback. Empirical information about program behavior enters the search only through formal evaluations, which are costly and often involve hidden instances, limiting the model's ability to deeply understand and analyze code behavior.

## Core Contributions
- **Proposed AgenticEvolve Framework**: An evolutionary program search framework where each "island" is managed by a persistent LLM agent. Between formal evaluations, the agent designs and runs experiments on candidate programs.
- **Challenge 1: How to obtain richer program behavior information under limited evaluation budgets?**
  - **Difficulty**: Traditional methods rely on expensive black-box evaluations, preventing the model from actively exploring code logic or edge cases before generation.
  - **Solution**: AgenticEvolve introduces persistent agents that autonomously design and execute experiments (e.g., running code, inspecting outputs) between formal evaluations. This provides deep feedback without consuming the formal evaluation budget, guiding more precise variations.
- **Challenge 2: How to demonstrate the actual contribution of experimental analysis to evolutionary search?**
  - **Difficulty**: It is difficult to isolate the impact of "LLM generation capability" from "experimental analysis capability."
  - **Solution**: A "No-analysis" baseline was designed, identical to AgenticEvolve but with experimentation disabled. By comparing AgenticEvolve against No-analysis and OpenEvolve, the specific contribution of the experimentation mechanism to improving program quality and reducing evaluation counts was quantified.

## Implementation and Evaluation
- **Experimental Setup**: Tested on two heuristic design tasks using three different LLMs, and validated on twelve equation discovery problems.
- **Baselines**: No-analysis (ablation baseline), OpenEvolve, existing LLM baselines, and Genetic Programming baselines.
- **Results**:
  - In heuristic design tasks, AgenticEvolve produced higher-quality programs than No-analysis and OpenEvolve on both hidden and unseen instances.
  - AgenticEvolve reached the final quality of baselines with significantly fewer evaluations and comparable cost.
  - In equation discovery tasks, AgenticEvolve recovered the ground-truth structure of more equations than No-analysis and existing LLM and Genetic Programming baselines.

## 4. Conclusion
AgenticEvolve addresses the lack of code execution and analysis capabilities in traditional methods by integrating persistent LLM agents into the evolutionary search loop. By autonomously designing experiments between evaluations, the method significantly improves search efficiency and program quality, outperforming state-of-the-art baselines in heuristic design and symbolic regression tasks, thereby demonstrating the critical value of autonomous experimentation in evolutionary program search.
