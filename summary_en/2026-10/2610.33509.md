## 1. What the Paper Does
- **Background**: LLM agents are increasingly adopted for security-focused code review to catch vulnerabilities before merging. However, existing benchmarks mostly derive reviewed changes from later fixes rather than real-world bug-introducing commits.
- **Limitations of Existing Work**: Current detection datasets score binary labels on single functions, where models may get right answers for wrong reasons. Reproduction benchmarks start from known vulnerabilities to generate PoCs. Existing security PR-review benchmarks (e.g., MalPR-Bench) often use reverted or partially applied fixes, centering diffs on repaired code, which fails to measure diagnostic capability on original vulnerability-introducing changes.

## Core Contributions
- **Proposed SecPRBench**: The first comprehensive benchmark for evaluating agentic security review on validated real-world code changes.
- **Challenge 1: Lack of evaluation on real vulnerability-introducing scenarios**. Difficulty: Existing benchmarks rely on fix-based diffs, failing to assess diagnosis on unknown vulnerabilities. Solution: Built an automated agentic pipeline to autonomously harvest, build, and validate massive real-world bug-introducing commits from critical systems like Firefox, V8, and OpenSSL.
- **Challenge 2: Precision in evaluation and diagnostic depth**. Difficulty: Simple binary labels or file matching do not prove understanding of the vulnerability mechanism. Solution: Adopted LLM-as-a-judge to credit findings only if they explain the root cause of the target vulnerability, ensuring precise assessment of diagnostic quality.

## Implementation and Evaluation
- **Implementation & Data**: SecPRBench contains 265 tasks from nine critical systems (millions of lines of code). Each task provides the diff of a real historical change, commit message, and repository context without describing the flaw.
- **Evaluation Results**: Tested on eight frontier models, recall ranges from 32.5% to 78.1%, with Grok 4.6 and GPT-6 sol ranking at the top.
- **In-depth Analysis**: Most misses are not simple oversights; in 68% of cases, the agent reports the correct file but argues for a different mechanism. Security harnesses behave differently: OpenAI's Codex Security lowers recall by 8.3 points (mostly by abstaining), while Anthropic's Defending Code harness raises it by 7.7 points at a higher cost.
- **Comparison**: Unlike MalPR-Bench which uses fix-based patches, SecPRBench offers a realistic pre-merge review scenario, revealing significant diagnostic biases in current models.

## 4. Conclusion
This paper introduces SecPRBench, filling the gap in evaluating agentic security code review on real vulnerability-introducing commits. By leveraging an automated pipeline for data collection and LLM-as-a-judge for fine-grained diagnostic evaluation, the study reveals that even top-tier models suffer from diagnostic misalignment. It also highlights how different security optimization strategies impact recall differently, providing a crucial foundation for future improvements in LLM-based security review.
