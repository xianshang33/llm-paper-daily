## 1. What the Paper Does
- **Background**: LLM-based multi-agent systems (MAS) show strong capabilities but often suffer from static memory and collaboration architectures post-deployment, limiting long-term adaptation.
- **Why Existing Work Falls Short**: Recent self-evolving approaches typically evolve memory or collaboration independently. This leads to misalignment: an evolved workflow may require memory support that isn't available, or evolved memory may contain guidance unusable by the current workflow, causing performance bottlenecks.

## Core Contributions
- **Proposed CoEvolve**: A skill-centered framework for aligned co-evolution of memory and collaboration.
- **Challenge 1: Misalignment between Memory and Collaboration Evolution**. The difficulty lies in the interdependence of these components; optimizing one in isolation breaks the synergy with the other. CoEvolve addresses this by representing reusable local collaboration patterns as "skills" that explicitly link evolving collaboration decisions to their supporting memories, ensuring synchronized updates.
- **Challenge 2: Identifying Effective Evolution Signals**. Extracting precise improvement signals from complex interaction traces is difficult. CoEvolve compares original and counterfactual trajectories to identify local evolution signals, coordinating updates across the skill library, skill memory, and executor memories.

## Implementation and Evaluation
- **Benchmarks**: Evaluated on ALFWorld and WebShop.
- **Baselines**: Compared against state-of-the-art methods like MemEvolve, MemSkill, GPTSwarm, HFlow, and EvoChamber.
- **Results**: CoEvolve achieved the best overall performance among all evaluated baselines. Ablation studies confirmed the effectiveness of both aligned co-evolution and counterfactual-guided evolution mechanisms.

## 4. Conclusion
CoEvolve effectively addresses the misalignment issue in MAS evolution by introducing "skills" as a bridging mechanism and using counterfactual analysis for guided updates. This approach ensures synchronized optimization of memory and collaboration structures, significantly enhancing system adaptability and task performance in dynamic environments.
