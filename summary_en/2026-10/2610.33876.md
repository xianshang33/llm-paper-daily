## 1. What the Paper Does
- **Background**: AI agents are increasingly used for recurring tasks (e.g., weekly report updates). However, current agents regenerate their reasoning and action paths on every run, leading to inconsistent results even for similar tasks and failing to reuse procedural knowledge from successful prior executions.
- **Why Existing Work Falls Short**: Prior approaches, such as "skill distillation," save past experiences but still require the agent to re-execute the full reasoning process. This remains costly (high token usage and latency) and suffers from LLM non-determinism, lacking the consistency and testability of traditional software.

## Core Contributions
- **Proposed FlashScript**: A compilation framework that transforms a successful agent execution trace into a reusable Neuro-Symbolic Program (NSP).
- **Challenge 1: How to convert unstructured agent traces into structured code?**
  - **Difficulty**: Agent runs contain natural language reasoning, tool calls, and data operations. Directly hardcoding them leads to overfitting specific instances and lacks generalization.
  - **Solution**: FlashScript identifies three layers, converting actions and data transformations into deterministic code, extracting instance-specific values as parameters, and retaining only necessary model judgments as LLM calls. It uses three techniques to replace most LLM calls with code.
- **Challenge 2: How to handle inevitable non-determinism while ensuring reliability?**
  - **Difficulty**: Completely eliminating LLM involvement is unrealistic, but non-determinism makes programs hard to debug and verify.
  - **Solution**: FlashScript localizes non-determinism rather than removing it. By separating deterministic program logic from sparse neural calls, developers can review and test the deterministic parts independently, treating NSPs as maintainable software assets.

## Implementation and Evaluation
- **Setup**: Evaluated on 120 WorkBench analytics tasks using Claude Haiku 4.5, including generalization tests on 108 unseen instances of the same templates.
- **Baseline**: Compared against skill-guided agents.
- **Key Results**:
  - **Consistency & Correctness**: NSPs produced correct results and identical tool calls in every run; in contrast, skill-guided agents showed inconsistency.
  - **Efficiency**: NSPs used approximately 70x fewer input tokens and one-third of the runtime compared to skill-guided agents.
  - **Complex Tasks**: In composite task versions, the accuracy of skill-guided agents dropped to 23% with increased inconsistency, while NSPs remained correct and identical across all runs.
  - **Generalization**: NSPs successfully generalized to all 108 unseen instances.

## 4. Conclusion
FlashScript addresses the high cost and inconsistency of recurring agent workflows by compiling successful execution traces into Neuro-Symbolic Programs. By codifying deterministic logic and localizing necessary LLM calls, it significantly reduces token consumption and latency while enhancing reliability and testability. The work demonstrates that NSPs derived from agent trajectories can serve as cumulative software assets for end-users to test, maintain, and reuse.
