## 1. What the Paper Did
- **Background**: In long-session LLM Agent applications, the dominant cost is re-sending prefix tokens, and the main risk is context window overflow or key information being buried. Existing production frameworks (e.g., Claude Code, Codex) use fixed token thresholds for compaction, configured by operators, without model involvement.
- **Why Previous Work Failed**: Earlier studies found open-weight models could not manage context without scaffolding (e.g., fixed checks, gates). However, these studies did not verify if current frontier closed-source models possess this metacognitive ability, nor did they compare autonomous management with traditional threshold-based methods in terms of cost and performance.

## Core Contributions
- **Proposed CTXAgent**: A framework where the model autonomously decides when to compact, what to keep, and how to write hand-off summaries, using only two tools and a paragraph of guidance.
- **Challenge 1: Can models manage context without complex scaffolding?**
  - **Difficulty**: Models must accurately judge task states and context relevance to avoid premature forgetting or late compaction.
  - **Solution**: Testing seven frontier models revealed that most strongest models can regularly compact and curate context, keeping active context below 100k tokens with no significant drop in benchmark scores, proving sufficient metacognitive ability.
- **Challenge 2: What are the advantages of autonomous management over threshold-based management?**
  - **Difficulty**: Reducing token costs while maintaining task success rates and adapting to dynamic task needs.
  - **Solution**: Using a mixed benchmark (coding, SciCode, etc.), the study found substantial cost reductions for well-performing models. For instance, Claude Opus 5.5 matched Claude Code's success rate at 34% lower cost than its 200k-window configuration and 49% lower than default, without needing window selection.

## Implementation and Evaluation
- **Implementation & Benchmark**: A mixed benchmark from existing suites (coding, SciCode, SWE-bench Pro, Terminal-Bench 4.0) with planted facts and ephemeral observations, simulating 35-212 turn sessions. All checks are deterministic.
- **Evaluation Results**:
  - **Model Capability**: Most strongest models managed context effectively, keeping active context under 100k tokens with stable performance.
  - **Cost Efficiency**: Cost reduction varied; some models over-compacted. Claude Opus 5.5 achieved the best results, saving 34-49% in costs while matching performance.
- **Comparison**: Compared CTXAgent with three widely used frameworks on two models, showing that self-managed frameworks significantly reduce costs while maintaining performance, outperforming fixed-threshold methods.

## 4. Conclusion
CTXAgent demonstrates that frontier LLMs can autonomously manage context without complex scaffolding. By allowing the model to decide compaction timing and content, the method significantly reduces token costs while maintaining task success rates, particularly for advanced models like Claude Opus 5.5 (34-49% cost reduction). The study releases the agent, benchmark, and results, offering a new direction for efficient Agent system design.
