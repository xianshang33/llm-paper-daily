## 1. What the Paper Does
- **Background**: In finance, answers are highly time-sensitive (e.g., stock prices, interest rates), making the retrieval of up-to-date facts a core capability for financial agents. However, most existing financial benchmarks overlook timeliness by fixing answers at annotation time, causing ground truth to become stale as markets move.
- **Limitations of Existing Work**: Current benchmarks suffer from three main issues: (1) High curation costs requiring expert hours without reusable answer-generation programs; (2) Static answers become outdated and, once leaked into training data, reward memorization over fresh retrieval; (3) Evidence sources deviate from professional practice, often relying on general web content rather than specialized financial databases.

## Core Contributions
- **Proposed LiveSearch**: A live benchmark that stores each question as executable verifier code.
- **Challenge 1: Static benchmarks fail to capture the dynamic nature of financial data.**
  - **Difficulty**: Financial data changes constantly, rendering fixed "question-answer" pairs obsolete quickly. Data leakage allows models to rely on memory rather than real-time reasoning.
  - **Solution**: LiveSearch converts questions into typed programs that call professional financial data services. The gold answer is determined by executing this code at evaluation time, with daily automated re-execution ensuring timeliness and forcing models to use tools for current information.
- **Challenge 2: High cost and difficulty in automating high-quality financial benchmark construction.**
  - **Difficulty**: Traditional methods rely on expensive manual annotation and validation, which must be repeated for every update, limiting scale and frequency.
  - **Solution**: An fully automated construction pipeline where LLMs only verbalize programs enumerated from real tool responses into natural language questions, without selecting answers. This eliminates manual answer labeling, enabling low-cost, sustainable benchmark generation.

## Implementation and Evaluation
- **Implementation & Deployment**: LiveSearch operates as a real-time benchmark, automatically re-executing verification code daily without human or LLM intervention. It uses professional financial data services to ensure data authority.
- **Evaluation Results**:
  - Six contemporary tool-calling models achieved 70.9% to 76.7% accuracy under general web search conditions.
  - **Timeliness Validation**: Over three consecutive days, 70% of questions saw their gold values change. Even with tolerance-aware matching, reusing a previous day's snapshot failed on the majority of questions within a single day.
  - **Granular Analysis**: Per-question tracking revealed dynamic shifts in correctness masked by aggregate accuracy metrics.
- **Comparison**: Unlike benchmarks like FinSearchComp that only partially support scripted updates, LiveSearch comprehensively addresses answer staleness. Compared to web-based benchmarks, it better aligns with professional financial practices.

## 4. Conclusion
LiveSearch successfully constructs a dynamic benchmark reflecting real-time financial market changes through the innovative "questions as code" paradigm. It resolves issues of answer staleness, high construction costs, and deviation from professional practice found in traditional benchmarks. Experiments show that current models still face significant challenges in handling real-time financial information, positioning LiveSearch as a crucial tool for evaluating and enhancing the real-time retrieval and analysis capabilities of financial agents.
