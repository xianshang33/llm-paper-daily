## 1. What the Paper Does
- **Background**: LLM agents increasingly perform consequential actions via external tools (e.g., modifying records, making bookings). However, these proposed actions are often executed without independent verification of policy compliance or task completion.
- **Limitations of Existing Work**: Reflection methods (e.g., Self-Refine, Reflexion) improve future proposals but do not verify specific actions against domain policies immediately before execution. Using a separate generative LLM as a judge is costly and produces free-form explanations that are hard to act upon deterministically. Traditional runtime checks often lack the ability to probabilistically assess conversational context.

## Core Contributions
- **Proposed JevAct**: A runtime verification framework that intercepts selected agent actions before execution and enables feedback-driven correction.
- **Challenge 1: How to efficiently and accurately verify if an action complies with domain policies and context?**
    - **Difficulty**: Deterministic code checks cannot understand complex dialogue contexts, while using LLMs for judgment is expensive and high-latency.
    - **Solution**: JevAct compiles domain policies into executable state checks and structured questions. These are evaluated by a prefill-only decision model (Kev) which outputs probability-based judgments without relying on token generation, combining deterministic fact-checking with probabilistic context assessment.
- **Challenge 2: How to effectively guide the agent to correct errors without disrupting the workflow?**
    - **Difficulty**: Simply blocking actions may cause task failure, while simple rejection lacks guidance.
    - **Solution**: When potentially invalid actions or premature terminations are identified, JevAct provides targeted feedback and allows for bounded revision. It operates independently of the underlying agent model, requiring no parameter or tool modifications.

## Implementation and Evaluation
- **Implementation**: JevAct runs as an independent harness. It offline compiles policies and at runtime combines code checks (for tool states) with the Kev decision model (for conversation context). It acts as a gatekeeper rather than replacing the agent's action selection.
- **Evaluation Results**: Evaluated across 11 LLM agents on $\tau^2$-bench (Airline and Telecom tasks) and BFCL.
- **Comparison & Performance**: Results show improved agent reliability across multiple models and benchmarks. Gains are particularly consistent and significant on Telecom and BFCL tasks, while performance on Airline tasks is mixed. The approach demonstrates that combining structured decision models with executable verification outperforms baselines in reducing invalid action execution.

## 4. Conclusion
This paper introduces JevAct, a runtime verification framework for LLM agents. By compiling domain policies into executable checks and structured questions evaluated by a lightweight decision model, JevAct effectively intercepts non-compliant or inappropriate actions before execution. The method is non-intrusive, requiring no model modifications, and enhances agent reliability and safety through targeted feedback and bounded revision, as demonstrated by empirical results on multiple benchmarks.
