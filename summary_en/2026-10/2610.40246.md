## What the Paper Does
- **Background**: Large Language Model (LLM)-based computer-use agents operate in stateful applications where the environment can change during execution (e.g., appointment rescheduling, policy updates). Existing evaluations often assume a static state after an episode begins, which does not reflect real-world dynamics.
- **Limitations of Existing Work**: While prior work has expanded interactive evaluation to dynamic environments, it fails to distinguish whether agent failures are due to the agent's limitations or benchmark machinery errors (e.g., failed state transitions, missed updates, or incorrect grading). This ambiguity compromises both benchmark accuracy and the reliability of training signals for Reinforcement Learning with Verifiable Rewards.

## Core Contributions
- **Proposed EnvOS Framework**: A framework for constructing and certifying environments that change mid-task, ensuring intervention validity, task solvability, and accurate grading.
- **Challenge 1: Ensuring Intervention Validity**. It is difficult to guarantee that environmental state transitions occur as intended at specific workflow points without side effects. EnvOS addresses this by pre-checking that each change fires correctly and the task remains solvable before the agent runs.
- **Challenge 2: Ensuring Evaluation Validity and Attribution**. It is challenging to attribute failure correctly when it is unclear if the agent missed an update or the grader used outdated evidence. EnvOS solves this by re-checking verdicts against archived evidence using separate code after each run, providing an auditable, evidence-based evaluation.

## Implementation, Deployment, and Evaluation Results
- **Implementation & Scenarios**: EnvOS is applied to "stale information" scenarios in clinic booking and insurance-claim approval tasks.
- **Evaluation Results**:
    - **Clinic Booking**: Claude Opus 5 succeeded in 0/16 tasks with no extra info, 2/16 when reminded to re-check, and 15/16 when the updated value was explicitly shown. The gain from showing updates over reminders was statistically significant (p = 0.00293) after correction.
    - **Insurance Claims**: Opus 5 succeeded in 10/10 by self-rechecking. Claude Sonnet 5 improved from 1/10 to 9/10 when the current policy was reshown, though this gain was not significant after multiple test corrections.
- **Comparison with Related Work (Grader Stress Test)**:
    - In blind tests with corrupted episodes, EnvOS rejected all 26 corrupted cases (0% acceptance rate).
    - On an externally generated set, EnvOS detected 25 out of 39 corrupted cases, whereas simple log checks only detected 4. This demonstrates EnvOS's superior ability to detect grading errors and environmental corruption compared to traditional methods.

## Summary
EnvOS addresses the trust deficit in evaluating agents in dynamic environments by implementing pre-run certification and post-run evidence auditing. Experiments show that an agent's ability to handle dynamic changes varies significantly by model and interface. Furthermore, because EnvOS environments are seed-generated and verified by an audited automatic verifier, they serve as ideal candidates for training agents via Reinforcement Learning from Verifiable Rewards.
