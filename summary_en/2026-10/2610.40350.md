## 1. What the Paper Does
- **Background**: LLM-driven agents have shown remarkable progress in complex reasoning tasks by integrating external tools and operating through a Thought-Action-Observation cycle for long-horizon tasks.
- **Why Existing Work Falls Short**: Current context optimization paradigms rely on rule-based heuristics (e.g., fixed-interval truncation or compression upon window saturation). These passive methods fail to address the root cause: redundant context generated by the agent's own imperfect planning. Suboptimal tool use creates irrelevant feedback, cluttering the context and degrading reasoning in a vicious cycle. Direct truncation risks losing key information, while external compression adds latency and cost.

## Core Contributions
- **Proposed CORAL (Cognitive Resource Self-Allocation)**: A novel reasoning paradigm that empowers agents to proactively optimize their context, implemented as an agent-callable working memory management toolset.
- **Challenge 1: Cognitive Overload and Context Noise Accumulation in Long-Horizon Tasks**. As tasks progress, irrelevant information and failed attempts clutter the context, diluting attention and hindering planning. **Solution**: CORAL allows the agent to checkpoint task progress and verified facts, and adaptively initiate new problem-solving episodes by resetting the cluttered context while preserving only checkpointed information, enabling reasoning from a clean state.
- **Challenge 2: Optimizing Checkpointing Strategy for Long-Term Gain**. Simple resetting may lose critical intermediate steps or occur at suboptimal times. **Solution**: Introduced a Multi-episode Agentic Reinforced Policy Optimization algorithm to enhance the agent's checkpointing capabilities, teaching it when and what to save and when to reset, maintaining coherence and efficiency in long-horizon reasoning.

## Implementation and Evaluation
- **Implementation**: CORAL is integrated as a working memory management system with modules for storing tasks/facts and control logic for checkpointing and resetting.
- **Evaluation Results**:
  - On the GAIA benchmark, CORAL with an 8B model achieved 42.8% average accuracy, with strong gains on challenging Level 2 and Level 3 tasks.
  - Crucially, CORAL consumes 6-7x fewer input tokens than a ReAct agent, significantly lowering inference costs.
  - Generalization: It performs well on multi-hop Knowledge QA benchmarks and improves a strong proprietary agent by 8.0 points on the harder BrowseComp benchmark.
- **Comparison**: Compared to baselines like ReAct, CORAL achieves higher accuracy while significantly reducing computational costs and token consumption associated with long contexts, avoiding performance degradation due to context bloat.

#### Summary
This paper addresses cognitive overload in LLM agents during long-horizon tasks caused by accumulated context noise. It proposes CORAL, a framework enabling proactive context optimization through self-managed working memory checkpoints and resets. Combined with reinforcement learning to optimize this process, CORAL achieves high accuracy with substantially lower inference costs, outperforming existing methods on complex benchmarks and offering a new paradigm for efficient long-horizon LLM agents.
