## 1. What the Paper Does
- **Background**: Long-horizon language agents rely on recursive textual memory to guide subsequent decisions. This memory system continuously updates by combining previous memory summaries with the latest interaction records.
- **Why Existing Work Falls Short**: Existing methods primarily train memory using task feedback or specific credit assignment, but improved task performance alone does not establish memory reliability. Prior research has overlooked "self-consistency bias," where incorrect claims, once entered into memory, persist in subsequent recursive updates due to reuse rather than independent regeneration. Furthermore, simply reducing errors may lead to the loss of valid historical information, and existing works lack simultaneous evaluation of error persistence and valid information retention.

## Core Contributions
- **Proposed KEEPER Framework**: A comparative analysis framework that evaluates four auxiliary objectives along two axes—"information content" and "update sensitivity"—within a shared recursive interface, examining how supervision targets relate to agent performance.
- **Challenge 1: Error Persistence due to Self-Consistency Bias**. The difficulty lies in the recursive memory mechanism, which predisposes the model to reuse previous memory content, causing erroneous claims to persist even when new observations do not correct them. KEEPER addresses this by introducing reward-related prediction as an auxiliary objective, optimized via offline reinforcement learning, which significantly reduces this bias and outperforms joint supervision methods.
- **Challenge 2: Retaining Valid Historical Information While Correcting Errors**. The challenge is that interventions aimed at eliminating errors may also discard correct historical facts crucial for later decisions. KEEPER documents the persistence of errors despite corrective observations through claim-level analysis of baseline trajectories and demonstrates that reward-based prediction better balances error reduction with information retention while improving task performance.

## Implementation and Evaluation
- **Implementation & Evaluation**: The study compares four different auxiliary supervision targets within a shared recursive memory interface. Evaluation metrics include not only traditional task success rates but also analyses of error persistence and valid-information retention.
- **Results & Comparison**: Experimental results show that "reward-related prediction" achieves the highest task performance both before and after offline reinforcement learning, outperforming other baselines such as joint supervision.
- **In-depth Analysis**: Claim-level analysis of baseline trajectories documents the phenomenon where erroneous claims persist due to self-consistency bias despite the presence of corrective observations, validating the limitation of relying solely on task scores to reflect memory quality.

## 4. Conclusion
This paper identifies the "self-consistency bias" in recursive memory systems for long-horizon agents, where erroneous information stubbornly persists during memory updates. The proposed KEEPER framework systematically compares different auxiliary learning objectives and finds that reward-based prediction signals most effectively improve agent performance and mitigate this bias. The study emphasizes that evaluating recursive memory systems requires combining error persistence and valid information retention with task outcomes, offering new perspectives and methodological support for building more reliable long-range agent memory mechanisms.
