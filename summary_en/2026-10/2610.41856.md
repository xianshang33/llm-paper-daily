## 1. What the Paper Does
- **Background**: Conversational Explainable AI (ConvXAI) agents typically employ GUS-style architectures with separate modules for intent recognition, dialogue management, and template-based response generation. While faithful to underlying XAI methods, these pipelines are rigid and struggle with context-dependent follow-up questions.
- **Limitations of Existing Work**: Traditional GUS architectures rely on multiple separately fine-tuned models and handcrafted rules, making them inflexible to contextual changes in multi-turn dialogues and expensive to maintain.

## Core Contributions
- **Proposed SimXAI**: A lightweight, LLM-centric conversational layer that replaces traditional GUS modules with a single tool-calling LLM, serving as a modular interface to bridge existing XAI resources.
- **Challenge 1: Difficulty in handling context-dependent follow-ups**. Traditional rule-based or template systems fail to accurately track references and state changes across turns (e.g., resolving "it" in subsequent queries). SimXAI leverages a single tool-calling LLM's natural language understanding and memory to directly parse intent and select appropriate XAI tools, effectively managing contextual dependencies.
- **Challenge 2: High adaptation complexity and rigidity**. Existing pipelines require specific fine-tuning and complex rule maintenance. SimXAI simplifies dialogue logic into an LLM tool-selection task via standardized function specifications, allowing it to plug into existing systems without fine-tuning, significantly reducing deployment barriers.

## Implementation and Evaluation
- **Implementation & Deployment**: SimXAI acts as a modular conversational interface rather than a standalone agent. It interacts with external XAI resources (e.g., SHAP, counterfactuals) by defining callable functions (e.g., `get_prediction`, `explain_what_if`). Source code and evaluation suites are open-sourced.
- **Evaluation Results**:
    - **Automatic Evaluation**: On both existing and new datasets, SimXAI achieves strong function-selection accuracy and high response-to-tool faithfulness, outperforming baselines in handling context-dependent requests.
    - **User Study**: When replacing only the conversational layer of TalkToModel (a representative GUS-based agent) with SimXAI, users completed tasks with higher accuracy and in fewer turns.
- **Comparison**: Compared to traditional GUS baselines like TalkToModel, SimXAI significantly improves interaction quality and user understanding efficiency while preserving faithfulness to the underlying XAI methods.

## 4. Conclusion
SimXAI demonstrates that a single, tool-calling LLM can effectively replace complex and rigid traditional GUS architectures as a conversational layer. It not only simplifies the development and deployment of ConvXAI systems but also enhances user interaction experience and model understanding through superior context handling, offering a simple, drop-in, and efficient solution.
