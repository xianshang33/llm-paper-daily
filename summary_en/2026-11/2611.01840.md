## 1. What the Paper Does
- **Background**: LLM-based agentic workflows organize complex tasks into reusable step sequences. However, invoking an LLM at every step incurs significant inference costs and latency, making them unsuitable for time-sensitive interactions.
- **Limitations of Existing Work**: Current approaches lack systematic methods to distinguish between steps requiring model reasoning and those solvable by deterministic code. Furthermore, static workflows struggle to adapt to dynamic interactive environments based on execution feedback, leading to poor adaptability in complex scenarios like negotiation and bargaining.

## Core Contributions
- **Proposed a Self-Evolving Agentic Workflow Framework via Semantic Decomposition (SeaFlow)**: This framework organizes complex interactive decisions into a hierarchy of subtasks, each with explicit applicability conditions and solution procedures (code execution or model invocation).
- **Challenge 1: High Inference Cost and Latency**. Traditional workflows call LLMs at every step, wasting resources. **Solution**: By semantically decomposing tasks, subtasks with clear solutions are converted into executable code, invoking models only when necessary, thereby significantly reducing overhead and improving response speed.
- **Challenge 2: Static Nature and Poor Adaptability**. Fixed pipelines cannot handle dynamic interaction changes. **Solution**: A feedback-driven self-evolution mechanism is introduced, where the agent uses execution records to identify inefficient or erroneous subtasks, dynamically adjusting their scope or modifying solution procedures for continuous iterative optimization.

## Implementation and Evaluation
- **Implementation**: The framework operates in a closed loop of construction, execution, problem localization, code revision, and evaluation. Code is open-sourced.
- **Evaluation Results**: Tested across three GLEE environments (bargaining, negotiation, persuasion). The study analyzed 725 development iterations and 12,249 action records.
- **Comparison and Findings**: Experiments showed that most final decision procedures in the optimized workflows were implemented in code rather than LLM reasoning. This demonstrates that the method effectively shifts complex logical judgments to efficient code execution, significantly reducing cost and latency compared to pure LLM-driven workflows while maintaining performance.

## 4. Conclusion
This paper proposes a new paradigm for constructing self-evolving agentic workflows through semantic task decomposition. By breaking down complex tasks into subtasks with explicit conditions and dynamically optimizing workflows using execution feedback, the method successfully transfers a large portion of decision-making from expensive LLM reasoning to efficient code execution. Performance on the GLEE benchmark proves its effectiveness in reducing inference costs, minimizing latency, and enhancing capabilities in complex interactive tasks, offering new insights for building efficient and adaptive agent systems.
