## What the Paper Did
- **Background**: Large Language Model (LLM)-based agents increasingly rely on external tools for complex tasks like file access and web interaction. These tools evolve via software updates from open-source or third-party sources.
- **Why Existing Work Fails**: Current security research focuses primarily on "Prompt Injection," where defenses monitor model-visible inputs. However, tool code executes outside the LLM's context window. Existing defenses cannot detect malicious logic embedded in tool implementation updates, creating a significant security blind spot known as the "Tool Update Gap."

## Core Contributions
- **Proposed ETUDE (Exploiting Tool Updates for Direct Execution)**, an attack framework that exploits the supply-chain vulnerability in agent systems.
- **Challenge 1: How to bypass defenses based on LLM context?**
  - **Difficulty**: Traditional attacks use adversarial instructions visible to the LLM, making them susceptible to prompt injection detectors. The LLM cannot perceive changes in underlying code execution.
  - **Solution**: ETUDE operates entirely outside the LLM's context without using adversarial prompts. It embeds malicious payloads into updates of previously trusted tools, completely bypassing defenses restricted to model-visible content.
- **Challenge 2: How to maintain legitimacy while injecting malicious functionality?**
  - **Difficulty**: If the update breaks normal functionality, it raises alerts or causes rollback, breaking the attack chain.
  - **Solution**: ETUDE preserves the tool's original legitimate functions while embedding malicious logic. Experiments show it maintains a high legitimate task completion rate, ensuring stealth and persistence.

## Implementation, Evaluation, and Comparison
- **Evaluation Setup**: Tested across three representative attack workloads and seven widely used commercial and open-source agent frameworks (including Gemini CLI, Codex CLI, Claude Code, and OpenCode).
- **Key Results**:
  - **Attack Success Rate (ASR)**: ETUDE achieved a **97.6%** ASR.
  - **Stealth/Usability**: Maintained a **95.9%** legitimate task completion rate during attacks, demonstrating high stealth.
- **Comparison with Related Work**:
  - Existing defenses against prompt injection are ineffective against ETUDE's code-update-based supply chain attacks.
  - The study reveals that agent frameworks often persist permissions from initial installation to subsequent updates without re-verifying code safety, allowing ETUDE to exploit this "trust persistence" vulnerability easily.

## Summary
This paper exposes a fundamental blind spot in LLM agent security: **trust established for a tool does not remain valid after its implementation updates**. By introducing ETUDE, the authors demonstrate that attackers can distribute benign tools to establish trust and then inject malicious code via updates, bypassing all LLM-context-based defenses. This highlights the urgent need for dynamic, continuous integrity verification mechanisms for tools in agent ecosystems, rather than relying solely on static admission checks or prompt-level defenses.
