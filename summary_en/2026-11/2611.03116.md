## 1. What the Paper Does
- **Background**: Large Language Models (LLMs) are enabling autonomous agents to interact with real-world environments, particularly the Web. However, training agents for long-horizon web tasks is challenging.
- **Limitations of Existing Work**: Current agentic reinforcement learning approaches rely on naive exploration strategies. They suffer from two main issues: (1) Successful trajectories are extremely rare due to the complexity and dynamics of web environments; (2) Sparse terminal rewards lead to the discarding of failed trajectories, wasting valuable feedback and causing repetitive, inefficient trial-and-error.

## Core Contributions
- **Proposed SCOPE (Skill-Composed Progressive Exploration)**: A short-to-long learning framework inspired by skill acquisition theory, which decomposes complex task exploration into a gradual expansion from local skills to full task-solving capability.
- **Challenge 1: Sparse Successes and Inefficient Exploration**. Obtaining complete successful trajectories via end-to-end exploration is difficult in long-horizon tasks. **Solution**: SCOPE extracts reusable local skills and failure experiences from historical rollouts via "Skill Discovery," breaking down complex tasks into locally verifiable sub-steps to facilitate easier exploration.
- **Challenge 2: Underutilization of Failure Experiences**. Traditional methods ignore partial progress in failed attempts. **Solution**: SCOPE uses "Skill Orchestration" to compose discovered skills into high-level chains and "Skill Expansion" to leverage failure experiences aligned with current chains. This guides the agent to explore new sub-skills, progressively building complete skill chains and internalizing them via agentic on-policy distillation.

## Implementation and Evaluation
- **Experimental Setup**: Extensive experiments were conducted on three major benchmarks: WebArena, WebVoyager, and WebShop.
- **Results**: SCOPE consistently improved exploration dynamics across all settings. It achieved relative gains of 3.9% to 18.6% over the strongest baselines.
- **Comparison**: The method outperforms existing state-of-the-art approaches by effectively utilizing failure data and structuring exploration, thereby overcoming the sparse reward problem inherent in web agent training.

## 4. Conclusion
This paper addresses the inefficiencies in exploring long-horizon Web tasks for LLM agents by proposing SCOPE. By mimicking human skill acquisition, SCOPE iteratively discovers, orchestrates, and expands local skills using both successful and failed experiences. This progressive approach significantly enhances performance compared to baseline methods, offering a robust paradigm for training autonomous web agents.
