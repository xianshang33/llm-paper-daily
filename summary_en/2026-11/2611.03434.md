## 1. What the Paper Did
- **Background**: Government intelligence teams require LLM agents to analyze large, messy, and heterogeneous evidence collections. However, security sensitivity and cost constraints often preclude the use of hosted frontier models and necessitate strict control over exposed tool surfaces.
- **Why Existing Work Falls Short**: Current harness designs are often overly broad, hard to audit, or rely on complex toolsets that do not fit high-security environments. Traditional optimization focuses on model scaling or predefined tools, lacking a method to balance accuracy, generality, and auditability on fixed, self-hostable small models via minimal agent architecture.

## Core Contributions
- **Proposed CLEO (Constrained Loop for Environment Optimization)**: A method for fitting a minimal agent harness to a fixed, self-hostable LLM.
- **Challenge 1: How to maintain high accuracy under strict security and audit constraints?**
  - **Difficulty**: Reducing tools limits capability, while increasing complexity violates security minimization principles, creating a difficult trade-off.
  - **Solution**: Introduces an "explicit justification gate" that only admits harness changes (tools, guardrails, memory policies) if they improve accuracy and are proven to be generic, auditable, and worth the added capability surface.
- **Challenge 2: How to avoid over-engineering and ensure harness minimality?**
  - **Difficulty**: Traditional methods often build complex systems first and prune later, leaving redundant code that fails security reviews.
  - **Solution**: Adopts a "bottom-up" construction strategy where the harness starts nearly empty and grows only when evaluation proves a new component is necessary, optimizing minimality by construction.

## Implementation and Evaluation
- **Implementation & Deployment**: CLEO was used to deploy an investigative agent around a fixed self-hosted model, emphasizing evaluation-driven development where every component is tested against an expert-validated dataset.
- **Evaluation Results**: The CLEO harness achieved an 83.8% pass rate on the held-out dataset.
- **Comparison**: This performance is within 1.2 points of the strongest out-of-the-box Claude Code SDK baseline, while being two orders of magnitude smaller, significantly reducing audit burden and deployment costs.

## 4. Conclusion
This paper addresses investigative analysis in high-security contexts by proposing CLEO. Through bottom-up minimal construction and strict justification gating, it successfully achieves near-frontier model performance on self-hostable small LLMs. The method significantly enhances auditability and security while maintaining high accuracy, offering a new paradigm for LLM applications in constrained environments.
