## 1. What the Paper Does
- **Background**: With the widespread deployment of Large Language Models (LLMs), inference workloads have scaled significantly. The long input prompts and generation sequences common in agentic and reasoning tasks lead to substantial Key-Value (KV) cache usage, making GPU memory a critical bottleneck.
- **Limitations of Existing Work**: Classical queueing models fail to address LLM inference scheduling because the processing duration depends on both prefill computation and KV-cache I/O. Existing works often do not jointly account for how computational speed, memory bandwidth, and memory occupancy collectively determine service capacity.

## Core Contributions
- **Proposed a fluid-model-based $c\\mu$ priority rule**: The effective service rate $\\mu$ in this rule is jointly determined by computational speed, memory bandwidth, and memory capacity.
- **Challenge 1: Modeling service capacity under multi-dimensional resource coupling**. It is difficult to describe LLM service rates with single-dimensional parameters as they are dynamically constrained by both computation and memory access. **Solution**: The paper develops a fluid model that reduces the system to a multiclass single-server queue with an effective service rate that captures computation, memory access, and memory capacity.
- **Challenge 2: Proving asymptotic optimality for discrete stochastic systems**. Ensuring optimal performance in practical, finite, discrete request systems under heavy load is theoretically challenging. **Solution**: The paper proves that the $c\\mu$ rule minimizes cumulative holding cost in the fluid model and constructs a feasible scheduling policy for the original finite system, proving its scaled dynamics converge to the optimal fluid policy, thereby minimizing completion time and maximizing throughput.

## Implementation and Evaluation
- **Experimental Setup**: Experiments were conducted on a real LLM serving engine using an NVIDIA H800 GPU.
- **Results vs. Related Work**: Compared to existing scheduling policies, the practical implementation of the proposed priority rule substantially reduces average latency while maintaining high throughput.
- **Performance Advantage**: The experiments validate the theoretical analysis, demonstrating that scheduling strategies jointly optimizing computation and memory resources outperform traditional methods that consider only single dimensions in memory-constrained scenarios.

## 4. Conclusion
This paper studies the online scheduling problem for LLM inference under memory constraints from a queueing perspective. By establishing a fluid model incorporating both computation and memory factors, it derives an asymptotically optimal $c\\mu$ priority rule. Both theoretical proofs and real-hardware experiments demonstrate that this strategy effectively balances responsiveness and resource utilization, significantly reducing latency and improving throughput, thus providing strong theoretical support and practical solutions for addressing memory bottlenecks in large-scale LLM inference.
