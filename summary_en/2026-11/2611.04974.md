## 1. What the Paper Does
- **Background**: With the rise of physical AI, robotic tasks have become increasingly complex. Reinforcement Learning (RL) is key for handling long-horizon and uncertain tasks, but the bottleneck lies in formulating the Markov Decision Process (MDP)—defining states, actions, rewards, and termination conditions. This process is currently manual, expensive, and hard to scale.
- **Why Existing Work Fails**: Current approaches often use Large Language Models (LLMs) as execution-time decision-makers or direct code generators. This introduces execution risks and lacks understanding of RL-specific structures. Existing automation attempts often produce syntactically correct code where semantic misalignment between RL components renders the resulting policies unlearnable or unstable.

## Core Contributions
- **Proposed ARPG**: A Dependency-Aware Agentic Framework for Automated Robot Policy Generation, positioning LLMs as "designers" that construct RL pipelines before deployment.
- **Challenge 1: Strong Dependencies and Sequential Nature of MDP Modeling**. MDP components have strict logical dependencies (e.g., state space defines action space). Monolithic LLMs struggle with these long-range dependencies. ARPG addresses this by identifying a phase-wise structure, employing sequential MDP modeling, and externalizing intermediate artifacts to ensure logical consistency at each step.
- **Challenge 2: Semantic Alignment and Learnability Guarantee**. Syntactically correct code may still yield unlearnable policies if components are semantically misaligned. ARPG introduces localized verification and correction mechanisms, along with a modular simulator implementation structure, to ensure the generated environment is not only executable but also conducive to learning effective policies.

## Implementation and Evaluation
- **Implementation & Deployment**: The ARPG framework was tested in the Isaac Sim simulation environment. It decomposes the task into sequential MDP modeling, localized verification/correction, and structured simulator implementation.
- **Evaluation Results**: Experiments demonstrate that ARPG significantly improves modeling correctness, environment executability, and policy-generation success rates compared to monolithic LLM baselines and off-the-shelf agentic systems.
- **Comparison & Generalization**: Beyond the main benchmark suite, additional demonstrations on custom robotics, standard RL tasks, and engineering-domain MDPs show that the modeling pipeline is reusable and generalizable.

#### Summary
This paper proposes a new paradigm using LLMs as designers to automatically generate robot RL policies. By introducing the dependency-aware ARPG framework, it addresses the issue of unlearnable policies caused by semantic misalignment in traditional automation methods. Through sequential modeling and localized verification, ARPG significantly enhances the efficiency and quality of translating natural language descriptions into executable RL pipelines, offering an effective solution to lower the barrier for robot RL development.
