## 1. What the Paper Did
- **Background**: In LLM-based recommendation systems, memory modules typically act as user-level agents. However, existing paradigms suffer from significant asymmetry: only users have structured profiles, which are used solely in bandwidth-limited reranker prompts and remain frozen after warmup.
- **Limitations of Existing Work**: Current methods treat recommendation as one-way retrieval and reranking, ignoring structured item representations and thus lacking equitable "communication" between users and items. Specifically, items lack comparable self-descriptions; profile signals are trapped in the reranking stage, unable to leverage context tokens during retrieval; and user profiles lack a principled update mechanism, failing to evolve with interactions.

## Core Contributions
- **Proposed HARP**, a training-free Dual-Profile Agentic Communication framework, recasting LLM recommendation into four stages: BUILD, TRANSMIT, UNDERSTAND, and SYNC.
- **Challenge 1: One-sided BUILD (Lack of structured item descriptions)**. The difficulty lies in traditional methods relying only on metadata, failing to align semantically with user profiles. HARP addresses this by generating symmetric item profiles via rule extraction, requiring zero extra LLM calls, achieving cost-free bidirectional profile construction.
- **Challenge 2: Prompt-trapped UNDERSTAND & Absent SYNC (Bandwidth limits and static profiles)**. The challenge is that reranking has limited context windows, and static profiles cannot adapt to shifting user interests. HARP introduces a channel-decomposable homophily gate consumed at retrieval time and implements gradient-free in-context profile evolution via single-pass reflective updates, solving both bandwidth and dynamic update issues.

## Implementation and Evaluation
- **Implementation & Deployment**: HARP is a training-free plugin module operating on top of a frozen LLM backbone. It comprises three core operators: rule-based item profile extraction, homophily gating at the retrieval stage, and reflection-based user profile updates. With zero additional LLM calls for items and minimal overhead for user reflection, it offers low deployment costs.
- **Evaluation Results**: Tested on four public benchmarks (Yelp, Books, MovieTV, Goodreads). HARP improved Hit@1 by 6.9% to 24.0% over the strongest published baselines. Family-wise Holm-corrected p-values were < 1e-9 across all datasets, indicating high statistical significance.
- **Comparison & Analysis**: Ablation studies and case attribution analyses show complementary gains from each operator, with the retrieval-side gating being the primary source of improvement. The paper also reports the trade-offs introduced by the reflective update pass.

## 4. Conclusion
This paper identifies the asymmetry in user-item interactions within current LLM recommendation systems and innovatively models it as an agentic communication process. The proposed HARP framework significantly enhances recommendation performance by constructing symmetric dual profiles, introducing homophily gating at the retrieval stage, and enabling training-free dynamic user profile updates. The method requires no additional training, offering efficiency and plug-and-play capabilities, thus providing a new paradigm for LLM-based recommendation systems.
