## 1. What the Paper Does

### Background
Large language model (LLM) coding agents develop software through experimentation, creating an opportunity to design the serving systems that support their own operation. Effective serving requires coordinating implementation and operational decisions under session dependencies, latency constraints, and correctness requirements.

### Why Existing Work Falls Short
Existing benchmarks typically focus on code generation accuracy or single performance metrics, lacking evaluation for the design of complete, specialized LLM serving systems. They fail to address how agents can autonomously design and verify efficient serving systems under complex constraints (such as session state preservation and cost-efficiency optimization), and lack a unified objective like "dollars per dollar" (latency-qualified token value per GPU cost).

## Core Contributions

### Proposed ServerBench
ServerBench is a benchmark for evaluating the agentic design of complete, specialized LLM serving systems. It introduces "dollars per dollar" as the core optimization objective, preserves session dependencies through stateful replay, and checks the correctness of submitted systems via independent verification.

### Challenge 1: How to maximize cost-efficiency while meeting latency and correctness constraints?
**Challenge Description**: Serving system design involves complex trade-offs between GPU cost, inference latency, and throughput, while ensuring session state continuity and output correctness, making it a multi-objective optimization problem.
**Solution**: ServerBench defines a unified "dollars per dollar" metric, forcing agents to coordinate capacity improvements with load selection during experiments. Stateful replay ensures session dependencies are preserved, guiding agents toward high-value designs.

### Challenge 2: How to ensure the reliability and correctness of the optimized systems generated by agents?
**Challenge Description**: Performance optimizations introduced by agents may alter execution paths, leading to potential logical errors or undefined behaviors that static checks cannot fully cover.
**Solution**: ServerBench incorporates an independent verification mechanism that runtime-checks the submitted serving systems, ensuring that execution paths introduced by optimizations still meet correctness requirements, thus guaranteeing reliable delivery.

## Implementation and Evaluation

### Implementation and Deployment
ServerBench was tested across three different deployment environments involving 11 coding agent models. The benchmark includes stateful replay to preserve session context and uses an independent verifier to check system functionality.

### Evaluation Results
- **Best Performance**: Claude Sonnet 5.5 achieved 2.97 dollars per dollar on the Gemma E4B model.
- **Baseline Comparison**: This performance is 4.87x that of the vLLM reference baseline.
- **Success Rate**: Out of 33 runs, 22 yielded verified systems, with 13 exceeding the strongest baseline.
- **Other Models**: Models like GPT-6.1 Sol showed capability, but Claude Sonnet 5.5 performed best (e.g., achieving 4.9x or 2.7x the baseline depending on hardware configurations like L40 GPU counts).

### Comparison with Related Work
Unlike traditional code generation benchmarks (e.g., HumanEval) or single-metric performance benchmarks, ServerBench focuses on "system-level design" and "cost-efficiency optimization." Results show that advanced coding agents can design specialized serving architectures that outperform human-optimized reference systems (vLLM), demonstrating the potential of agents in system optimization.

## 4. Conclusion

ServerBench supports the systematic study of how agents translate service objectives and feedback into effective, verified serving systems. The analysis identifies three key findings: high-value designs coordinate capacity improvements with load selection; agents interpret performance feedback through workload-relevant experiments; and reliable delivery requires verification of execution paths introduced by optimization. This benchmark advances practical research in LLM agent-based system design and optimization.
