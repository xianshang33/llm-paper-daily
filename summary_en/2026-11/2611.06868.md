## 1. What the Paper Did
- **Background**: Large Language Model (LLM) agents excel at complex, long-horizon tasks but suffer from inconsistency due to stochastic action sampling. Inference-time scaling is a key technique to improve performance without parameter updates by leveraging additional compute.
- **Why Existing Work Falls Short**: Trajectory-level Best-of-N sampling only selects the best outcome after full execution, failing to optimize intermediate action distributions. Meanwhile, search methods like DFS or MCTS require environment state checkpointing and restoration, which is often impractical in interactive settings.

## Core Contributions
- **Proposed a**: Turn-Level Best-of-N Sampling (Turn-BoN) framework utilizing a "generator-selector" architecture.
- **Challenge 1: How to optimize intermediate steps in irreversible or hard-to-reset environments?**
  - **Difficulty**: Traditional search algorithms rely on rolling back environment states, which is costly or infeasible in real-world applications (e.g., terminal operations).
  - **Solution**: Turn-BoN generates N candidate actions at each turn and selects the best one for immediate execution, achieving one-step policy improvement without requiring state rollback.
- **Challenge 2: How to effectively evaluate and select intermediate actions without expensive trained reward models?**
  - **Difficulty**: Training specialized Critic models or Outcome Reward Models (ORMs) requires significant data and compute, with limited generalization.
  - **Solution**: The paper demonstrates that off-the-shelf, open-weight LLMs can effectively serve as selectors by directly comparing candidate actions, eliminating the need for additional model training.

## Implementation and Evaluation
- **Implementation & Deployment**: Uses a dual-LLM setup where a Generator proposes N candidate actions per turn, and a Selector chooses the best action for execution in the environment.
- **Evaluation Results**: Experiments on long-horizon terminal tasks show significant improvements, with accuracy gains of 5-10% and enhanced consistency across repeated attempts.
- **Comparison with Related Work**:
  - Compared to trajectory-level Best-of-N (e.g., Kwok et al., 2026), Turn-BoN corrects errors during the decision process rather than post-hoc, leading to better agent behaviors (fewer attempts, improved instruction following, debugging).
  - Unlike Zainullina et al. (2025) which used trained critic models, this work validates the effectiveness of using raw, off-the-shelf LLMs for comparison, lowering deployment barriers.

## 4. Conclusion
This paper presents Turn-Level Best-of-N Sampling (Turn-BoN), a simple yet effective inference-time scaling method. By generating multiple candidate actions at each step and selecting the best using off-the-shelf LLMs, it overcomes the limitations of state-dependent search methods and the delayed feedback of trajectory-level sampling. Results indicate that Turn-BoN significantly boosts accuracy and consistency in complex long-horizon tasks, promoting desirable agent behaviors such as better debugging and instruction adherence, offering a low-cost, high-efficiency path for enhancing LLM agent performance.
