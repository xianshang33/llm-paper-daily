## 1. What the Paper Did
- **Background**: LLM Agent Arenas have emerged as a paradigm for studying multi-agent behavior at scale using economic incentives (e.g., token rewards, progressive taxation, continuation bonuses) in dynamic ecosystems, unlike static benchmarks.
- **Why Existing Work Falls Short**: Current incentive designs are typically validated via simulation or theoretical arguments, lacking direct empirical measurement in live, large-scale, real-time multi-agent systems. This gap makes it difficult to detect "incentive pathologies" such as discrepancies between announced and implemented rules, or unexpected resource concentration.

## Core Contributions
- **Proposed**: An empirical audit framework for a live LLM agent arena (AITRAP), utilizing code-level reconstruction and statistical trend tests to uncover biases and pathologies in actual incentive mechanisms.
- **Challenge 1: Discrepancy between Announced and Implemented Reward Rules**. The difficulty lies in the black-box nature of platforms where users trust announced rules, but actual code logic may differ significantly and is hard to detect externally. The paper addresses this by reconstructing the code, revealing that the announced "10x depth-based continuation bonus" was actually a four-condition anti-abuse gate paying only 2.85x in typical cases and permanently blocking the self-continuation it superficially rewarded, activated 40 hours before the announcement.
- **Challenge 2: Quantifying the Real Impact of Incentive Changes on Network Structure and Activity**. The challenge is isolating effects when multiple changes (progressive tax V2.9.3 and seed inversion V3.0) are deployed simultaneously. The paper uses Gini coefficients, Top-K concentration shares, and Mann-Kendall trend tests to show that the Top-4 node activity score share dropped from 97.2% to 49.4%, and the events-per-node ratio significantly declined, identifying trends of network dilution and decentralization amidst confounded interventions.

## Implementation and Evaluation
- **Implementation & Deployment**: An observational audit of the AITRAP platform over 9 days (Oct 16-25, 2026), covering 22 autonomous agent seats and ~96,000 reasoning nodes. Two bundled incentive changes were deployed: progressive tax reform (V2.9.3) and seed inversion with explorer-side action update (V3.0).
- **Evaluation Results**:
    - **Concentration**: Top-4 Node Activity Score (NAS) share dropped from 97.2% (pre-V2.9.3) to 49.4% (post-V3.0; 56.7% under merge-seat assumption).
    - **Incentive Discrepancy**: Code analysis revealed a significant gap between announced and implemented continuation bonuses, with actual rewards being much lower and functionally blocking certain behaviors.
    - **Network Dilution**: Events-per-node ratio significantly declined from 7.36 to 7.069 (p=8.3e-5), indicating reduced activity density.
    - **Gini Coefficient**: Inconclusive at 95% confidence, with bootstrap intervals straddling the 0.7 threshold.
- **Comparison**: Unlike traditional peer review used for efficacy comparison, this study treats public peer review as an event record, emphasizing the necessity of direct measurement in real systems over simulation, highlighting a gap in existing literature regarding empirical studies of live incentive pathologies.

## 4. Conclusion
This paper empirically audits the live LLM agent arena AITRAP, revealing severe incentive pathologies, particularly the discrepancy between announced rules and code implementation, and the resulting changes in network concentration and activity dilution. The findings suggest that simulations and official announcements are insufficient for predicting behavior in complex multi-agent systems. Code-level auditing and real-time data monitoring are essential for validating incentive mechanisms, warning designers to prioritize implementation transparency and use public peer review as an objective record of system behavior.
