## 1. What the Paper Does
- **Background**: LLM agents leverage memory systems to enhance performance in long-horizon, multi-session tasks. However, this introduces a critical attack surface where malicious instructions encountered in one session can be stored, propagated, and executed in later sessions, converting transient exposures into persistent harmful behaviors.
- **Limitations of Existing Work**: Prior research primarily compares memory systems based on task performance, lacking a systematic understanding of how different memory architectures affect the persistence and behavioral impact of poisoned observations across sessions. There is no unified benchmark to quantify these security risks given the diverse processing and retrieval mechanisms of various memory systems.

## Core Contributions
- **Proposed MemoryDojo**: A benchmark for tracing the lifecycle of poisoned information through agent memory and measuring its influence on subsequent agent behavior.
- **Challenge 1: Lack of Comparable Evaluation Across Architectures**. Different memory systems (e.g., fact extraction, linked notes, graph traversal) process information differently, making it hard to compare vulnerabilities. MemoryDojo addresses this by supporting five distinct memory systems and providing 155 multi-session trajectories across four domains for standardized comparison.
- **Challenge 2: Variability in Poisoning Efficacy**. Simple injections may fail due to memory compression or filtering. The paper proposes a "memory-aware poison optimization process" that tailors attack payloads to specific memory architectures, significantly increasing poisoning efficacy and highlighting architectural differences.

## Implementation and Evaluation
- **Implementation**: MemoryDojo is extensible, currently supporting five memory systems and covering four application domains with 155 multi-session trajectories. It tracks poisoned information from input through storage, retrieval, and behavioral impact.
- **Evaluation Results**: All evaluated memory systems are susceptible to memory poisoning, but with substantial variation in downstream effects. Some architectures allow poisoned information to persist and cause widespread harm more easily than others.
- **Comparison with Related Work**: Unlike works focusing on single-session or static contexts, MemoryDojo emphasizes the cumulative risks of multi-session and long-term memory updates. The proposed optimization process demonstrates that architecture-specific attacks are more destructive than generic ones, filling a gap in dynamic memory security assessment.

## 4. Conclusion
This paper introduces MemoryDojo, the first benchmark dedicated to evaluating poisoning risks in LLM agent memory systems. Through large-scale multi-session experiments, it reveals that all major memory architectures have security vulnerabilities, with risk levels varying by design. The proposed memory-aware optimization method further proves the efficiency of targeted attacks. This work provides essential tools and directions for understanding and mitigating agentic memory risks.
