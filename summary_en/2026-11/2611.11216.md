## 1. What the Paper Did
- **Background**: Reproducibility in Large Language Model (LLM) agent evaluation hinges on "replay fidelity"—determining which parts of an execution trace are reconstructed, controlled, and compared. This is critical for agent debugging, failure analysis, and counterfactual evaluation of stateful tool use.
- **Why Existing Work Falls Short**: Current evaluation methods often conflate different validation targets (e.g., printed output, database changes, native verdicts). Simple text matching or loose validation criteria may mask underlying state inconsistencies, while strict replay controls (such as failing to reset random number generators) can lead to the erroneous rejection of reproducible cases. There is a lack of detailed empirical analysis on the interaction between hidden states and test oracles.

## Core Contributions
- **Proposed**: A bounded empirical characterization framework for replay fidelity in the AppWorld benchmark, systematically analyzing the relationship between replay eligibility, hidden states, and test oracle integration.
- **Challenge 1: High replay failure rates due to randomness and state reset issues.**
  - **Difficulty**: Without full control over random sources, identical inputs during replay can yield different internal states or outputs, causing false failures and making it hard to distinguish code errors from stochastic noise.
  - **Solution**: By resetting the Random Number Generator (RNG) before each interaction, the number of admitted replay cases increased from 42 to 68, demonstrating that controlling randomness is key to improving replay success rates.
- **Challenge 2: Discrepancies in materialized state despite consistent surface outputs.**
  - **Difficulty**: Even when API responses and final verdicts match, subtle differences in underlying database row effects or authentication credentials (e.g., JWT) may exist. These hidden state discrepancies affect the determinism of subsequent operations and are difficult to detect via standard output checks.
  - **Solution**: The gap was narrowed using database/oracle checks. Specific continuity controls and credential equality programs identified four materialized state discrepancies. Native exports from retained output trackers restored reference comparisons for affected cases without altering original cached content.

## Implementation and Evaluation
- **Implementation**: The study audited 71 unsuccessful executions from a fixed historical AppWorld corpus using 284 isolated fixed-code replay attempts. A pilot study with 12 cases from the Berkeley Function Calling Leaderboard (BFCL) was also conducted for comparison.
- **Evaluation Results**:
  - Under printed output, pre-oracle database delta, and native verdict checks, only 42 cases were admitted.
  - Resetting the RNG increased admitted cases to 68.
  - Under stricter database/oracle checks, the 26-case gap contracted to 4 (with one endpoint unknown).
  - Mechanism studies revealed 4 cases with materialized state discrepancies despite matching outputs and verdicts.
  - The BFCL pilot showed no discrepancies under its tested public-state, return, and verdict checks.
- **Comparison**: Unlike studies focusing on debugger accuracy or method-ranking distortion, this paper does not estimate new debugging performance but defines the boundaries of replay feasibility. Compared to BFCL's public state checks, AppWorld's complex state environment exposed more hidden inconsistencies.

## 4. Conclusion
This paper reveals the complexity of replay fidelity in LLM agent evaluation through a detailed audit of failed cases in AppWorld. It demonstrates that controlling randomness and deeply inspecting underlying materialized states (such as database rows and credentials) are crucial for accurately assessing replay success. The contribution lies in providing an empirical characterization of these boundaries, clarifying the conditions under which replay is trustworthy and how hidden states impact evaluation, offering foundational insights for future agent debugging and counterfactual assessment.
