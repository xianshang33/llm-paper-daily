## 1. What the Paper Does
- **Background**: LLM agents reading untrusted content (e.g., emails, web pages) are vulnerable to prompt injection attacks, where hidden instructions cause the model to leak user data or perform unauthorized actions.
- **Why Existing Work Falls Short**: Classical "noninterference" is too strict for useful agents that must process untrusted inputs. Existing defenses (heuristics, isolation architectures, label checks) lack a unified formal security criterion, cannot guarantee protection against all adaptive attacks, and rely on benchmarks that do not cover all possible attack vectors.

## Core Contributions
- **Proposed PlanTERS**, a formal framework for defining and verifying "Relative Security" in LLM agents.
- **Challenge 1: Defining a practical yet provable security standard.**
  - **Difficulty**: Absolute security prohibits any information leakage, rendering agents useless for tasks involving untrusted data; declassification policies require manual crafting for each task, lacking scalability.
  - **Solution**: Introduces "Relative Security" by comparing the agent to a "Reference Agent" (using a model that never obeys untrusted content). An agent is secure if its leaks are no worse than those inherent to the reference agent.
- **Challenge 2: Proving defense effectiveness in a formal model.**
  - **Difficulty**: LLM behavior is non-deterministic, and attackers can use complex injection sequences, making exhaustive verification in infinite state spaces difficult.
  - **Solution**: Constructs a small agent language and runtime monitor composition in Isabelle/HOL. Proves the "Fence Theorem," showing that revoking injectable tool permissions upon the first read of untrusted content ensures relative security at the event level for finite runs, extending to infinite runs under fairness conditions.

## Implementation and Evaluation
- **Implementation & Verification**: The work focuses on formal verification using the Isabelle/HOL theorem prover rather than software deployment.
- **Evaluation Results**: Mechanically proves or refutes relative security properties for various agent architectures, including those with fences, budgets, approvals, loops, and dual-LLM setups. It confirms the theoretical efficacy of the "fence" mechanism under specific threat models.
- **Comparison**: Unlike heuristic methods (e.g., Spotlighting) or specific architectures (e.g., CaMeL, FIDES) evaluated only against known benchmarks, this paper provides mathematically rigorous security guarantees covering worst-case model behaviors and all defenses expressible within the formal model.

#### Summary
This paper addresses prompt injection in LLM agents by proposing PlanTERS, a framework based on "Relative Security." By introducing a reference agent comparison, it overcomes the impracticality of absolute security standards. Formal proofs in Isabelle/HOL demonstrate that strict tool permission revocation (fencing) when reading untrusted content theoretically guarantees agent security. This work establishes a solid theoretical foundation and formal verification methodology for designing secure LLM agents.
