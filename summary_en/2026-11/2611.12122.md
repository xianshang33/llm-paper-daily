## 1. What the Paper Does
- **Background**: AI Agent Harnesses provide Large Language Models (LLMs) with an interface to computing environments, enabling long-horizon tasks like code fixing and terminal operations. As model context windows expand, the cost of agent execution has increased significantly.
- **Why Existing Work Falls Short**: Recent studies indicate that task accuracy depends primarily on the LLM itself, with minimal impact from harness-side variations (e.g., system prompts or tools). However, these harness-side variations significantly impact execution costs (up to a 2.6x difference). Existing optimizations focus largely on models or prompt engineering, lacking a unified system-level mechanism to optimize harness costs, leading to excessive token consumption and API call fees in long-running tasks.

## Core Contributions
- **Proposed Agency**: A harness interposition platform that provides a unified abstraction, allowing easy and portable implementation of system-level optimizations on existing off-the-shelf harnesses (e.g., Claude Code, OpenAI Codex).
- **Challenge 1: High Cost of Context Reading**. Reading existing context is the largest source of cost (up to 73% of total), even with caching, due to the processing of large historical token sets in long-context scenarios. **Solution**: Agency analyzes cost accumulation patterns and implements optimization techniques to reduce unnecessary token usage and LLM calls, lowering reading overhead without modifying the model.
- **Challenge 2: Inefficient and Sparse Tool Calls**. Tool calls can cause significant cost spikes (up to 26x cost increase at the same token count) without proportional information gain, as outputs are often information-sparse. **Solution**: As an interposition layer, Agency intercepts and optimizes these interactions, demonstrating through proof-of-concept implementations how to target these system opportunities to reduce redundant tool call overhead without compromising accuracy.

## Implementation and Evaluation
- **Implementation & Deployment**: The authors designed the Agency platform and implemented proof-of-concept optimization techniques based on their analysis. The platform is designed to be compatible with existing harnesses without requiring model modifications.
- **Evaluation Results**: Across various real-world benchmarks, the optimization techniques implemented via Agency achieved up to 35% cost reduction on existing harnesses.
- **Comparison**: Compared to standard unoptimized harness executions, this approach significantly reduces token usage and LLM calls while maintaining task accuracy. The study highlights that system-level harness optimizations offer a potent avenue for cost savings, complementing model improvements (building on findings that harness variations can cause up to 2.6x cost differences, this work achieves an additional 35% savings through systematic optimization).

## 4. Conclusion
This paper identifies overlooked opportunities for cost optimization at the harness level in AI Agent systems. By pinpointing context reading and inefficient tool calls as primary cost drivers, the authors propose Agency, a system platform for harness interposition. It significantly reduces agent execution costs (by up to 35%) without altering the model or sacrificing accuracy, offering a new system perspective and practical tools for building cost-efficient AI Agent systems.
