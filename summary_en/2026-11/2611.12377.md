## 1. What the Paper Does
- **Background**: Shadow IT (unapproved technology use) is a longstanding governance issue. The rise of autonomous AI agents accelerates this problem because agents make tool creation nearly free, operate with user privileges, and leave behind unsanctioned scripts and automations, leading to exponential growth in shadow IT.
- **Limitations of Existing Work**: Current detection methods rely on behavioral rules based on process structures and network connections. These methods fail to distinguish between an "AI agent" and its "behavioral twin" (a standard program performing identical actions but connecting to non-AI services), resulting in inability to accurately detect unsanctioned agents based on behavior alone.

## Core Contributions
- **Proposed Agent Detector**, an open-source Windows detector, along with a taxonomy of nine agent classes and six layers of endpoint footprints.
- **Challenge 1: False positives due to behavioral similarity**. Standard programs and AI agents can share identical process and network structures (behavioral twins). **Solution**: Agent Detector anchors behavior to the identity of the remote service and correlates it with configuration, installation, and execution history, using a catalog of 39 tools and 184 LLM endpoints to differentiate agents from non-AI programs.
- **Challenge 2: Balancing detection with user experience and capturing ephemeral agents**. Direct blocking disrupts workflows, and intermittent agents are hard to catch. **Solution**: The system notifies users for acknowledgment instead of blocking. It performs lightweight scans (~154ms), though detection is limited by temporal windows (DNS cache validity of 1-5 minutes), yet it successfully detects active agents in the majority of runs.

## Implementation and Evaluation
- **Implementation**: Agent Detector is an open-source tool for Windows that identifies unsanctioned AI activity by checking DNS caches, process history, and configurations against a known directory of LLM endpoints and tools.
- **Evaluation Results**: In a controlled benchmark with 12 synthetic agents, 3 AI components, and 9 benign workloads (repeated 5 times):
    - **Comparison**: Two behavioral rule-based detectors flagged all "behavioral twins," indicating high false positive rates and an inability to distinguish AI from non-AI traffic.
    - **Agent Detector Performance**: Flagged zero behavioral twins (zero false positives) and detected every agent in the majority of runs.
    - **Limitations**: Detection is temporally constrained; attribution is only possible while the DNS cache holds the provider's name (1-5 minutes). Intermittent agents were detected in approximately one out of three scans.

## 4. Conclusion
The paper argues that autonomous AI agents exponentially accelerate shadow IT growth and demonstrates that behavioral analysis alone is insufficient for detection. The proposed Agent Detector successfully distinguishes AI agents from standard programs by combining remote service identity recognition with historical context correlation, achieving zero false positives and high detection rates in controlled experiments. Despite limitations regarding time windows and intermittent activity, the study provides a viable new direction for endpoint shadow AI detection, emphasizing the importance of multi-source evidence correlation.
