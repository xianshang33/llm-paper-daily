## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents use external memory to distill lessons from past task trajectories, aiming to improve efficiency and avoid repeated exploration in new tasks.
- **Limitations of Existing Work**: Current memory methods infer lessons based solely on binary success/failure labels without providing the underlying trajectories. This leads to "Memory-induced Degradation," where agents fail on tasks they could otherwise solve by following incorrect, misapplied, or misread lessons. The lack of source traceability prevents agents from verifying the validity of these lessons.

## Core Contributions
- **Proposed WikiTrace**: An evidence-linked memory system that connects each concise lesson (insight) to a summary of its outcome and the raw execution trajectory, enabling agents to verify lessons against original evidence.
- **Challenge 1: Unverifiable Lessons and Error Propagation**. Isolated lessons in existing systems lack context, causing agents to blindly follow incorrect advice. WikiTrace addresses this by linking lessons to their source trajectories. When a lesson is ambiguous, conflicting, or derived from a failed task, the agent can "descend" through these links using terminal tools to retrieve missing details or correct the insight before acting.
- **Challenge 2: Memory-Induced Performance Degradation**. Traditional memory mechanisms often cause performance regression on simple tasks. WikiTrace mitigates this by dynamically validating and correcting memory content prior to action, significantly reducing failures caused by blind trust in erroneous memories while maintaining high gain rates.

## Implementation and Evaluation
- **Experimental Setup**: WikiTrace was validated across five agentic benchmarks.
- **Results**: It consistently outperformed existing memory approaches and a baseline that used the same insights without evidence linking.
- **Key Metrics**: The system not only improved overall task success rates but also significantly reduced memory-induced degradation. Analysis showed that while existing methods suffer from high regression rates, WikiTrace effectively alleviates this issue through its evidence-backtracking mechanism, demonstrating the importance of evidence linking for reliable memory.

#### Summary
This paper addresses the problem of "Memory-induced Degradation" in LLM agents, where faulty memories hinder performance on solvable tasks. The authors propose WikiTrace, a memory system that links abstract lessons to concrete execution trajectory evidence. By allowing agents to backtrack and verify memory sources before acting, WikiTrace effectively corrects erroneous lessons. It achieves superior performance and lower degradation rates compared to existing methods across multiple benchmarks, offering a new paradigm for building more reliable agent memory systems.
