## 1. What the Paper Does
- **Background**: As LLM-powered agents become prevalent in applications like personal assistants, persistent memory systems are crucial for maintaining conversational continuity. Currently, these systems rely heavily on human expertise to manually design components such as representation, organization, maintenance, and retrieval.
- **Why Existing Work Falls Short**: While prior research has explored LLM-driven evolutionary search for memory optimization, these approaches often constrain the search space to specific components (e.g., prompts or configurations) or start from established architectures. They primarily focus on accuracy, overlooking the potential for discovering novel design patterns from scratch and ignoring how service costs influence computational allocation across the memory lifecycle.

## Core Contributions
- **Proposed MAPE Framework**: A framework that evolves entire agent memory programs from minimal seeds (e.g., a program with no memory) using a standardized lifecycle interface and an iterative diagnosis-proposal loop.
- **Challenge 1: How to automatically discover efficient and novel memory architectures from minimal starting points?**
  - **Difficulty**: Traditional methods rely on human priors or fixed architectures, limiting the discovery of counter-intuitive, high-performance designs.
  - **Solution**: MAPE exposes memory construction, retrieval, and composition as programmable stages. By iteratively diagnosing failure patterns in execution traces and proposing code modifications, it evolves complete pipelines from scratch, uncovering structures that surpass manual designs.
- **Challenge 2: How to optimize service cost alongside accuracy and understand computational allocation?**
  - **Difficulty**: Optimizing solely for accuracy often leads to prohibitive computational costs, and it is unclear whether computation is better spent on memory construction or query-time processing.
  - **Solution**: MAPE supports multi-objective optimization. Results show that jointly optimizing for cost and accuracy shifts computation from LLM-based memory construction to selective processing at query time, maintaining competitive accuracy while significantly reducing serving costs.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on LoCoMo and LongMemEval benchmarks.
- **Key Results**:
  - Achieved an absolute accuracy gain of up to 12% over manually designed baselines.
  - Operated at only 35% of the serving cost of these baselines.
  - Demonstrated robust transferability across different serving backends and benchmarks.
- **Design Pattern Validation**:
  - Identified and validated two key patterns: (1) Retaining raw conversations as retrievable evidence preserves details lost in extracted memories; (2) Composing retrieved evidence based on query intent helps the answering model utilize information more effectively.
  - Transplanting the evolved "composition module" into five existing memory systems improved accuracy in all cases.
- **Comparison**: Unlike prior work that optimizes partial components or focuses only on accuracy, MAPE's whole-program evolution and multi-objective approach not only yield superior performance but also reveal optimal computational allocation strategies across the memory lifecycle.

## 4. Conclusion
This paper introduces MAPE, a framework that uses whole-program evolution from minimal seeds to discover effective agent memory designs. It significantly outperforms human-designed baselines in both accuracy and cost-efficiency. The study provides empirical insights into critical design patterns, such as retaining raw evidence and intent-based composition, and demonstrates how optimization objectives shape computational allocation, offering valuable guidelines for future agent memory system design.
