## 1. What the Paper Did
- **Background**: Prompt injection is a critical threat to tool-using Small Language Model (SLM) agents. Existing strong defenses (e.g., CaMeL, Progent, IPIGuard, DRIFT) rely on the agent's own model to generate security artifacts (programs, policies, graphs) which are then enforced by code.
- **Why Existing Work Fails**: The study reveals that SLMs (1.7B-12B parameters) cannot be trusted to write these artifacts. In evaluations across 15 open-weight models, artifacts generated by SLMs contained vulnerabilities that allowed successful attacks in most cases for Progent, IPIGuard, and DRIFT, while CaMeL's programs failed to execute in up to 68% of episodes.

## Core Contributions
- **Proposed CapLite**: A prompt-injection defense framework for SLM agents that does not require the model to write security artifacts.
- **Challenge 1: Unreliability of SLM-generated Security Artifacts**. SLMs often produce syntactically incorrect or logically flawed security code/policies due to limited capacity. CapLite addresses this by eliminating the need for model-generated artifacts entirely, instead deriving policies directly from tool schemas, thereby removing vulnerabilities introduced by model generation errors.
- **Challenge 2: Ensuring Write Integrity Aligned with User Intent**. Preventing injected text from inducing unauthorized write operations (e.g., sending to unspecified recipients). CapLite solves this by committing write calls before reading any tool results and only admitting a write if every argument determining the target (recipient, amount, object) is explicitly stated in the user's request.

## Implementation and Evaluation
- **Setup**: Evaluated on the AgentDojo benchmark with 13,935 attacked episodes across 15 open-weight models (mostly 1.7B-12B parameters).
- **Security Results**: CapLite was the only defense with zero successful attacks (0% Attack Success Rate) across all tested episodes. In contrast, other defenses showed significant vulnerability across multiple models.
- **Utility and Efficiency Comparison**:
    - **Utility**: CapLite achieved a utility under attack of 29.0%, comparable to the best existing defense, CaMeL (27.2%), and significantly outperforming others.
    - **Efficiency**: CapLite used only 17.1k tokens per episode, which is 18% of CaMeL's consumption and fewer tokens than any other enforcement defense or even the undefended agent.
    - **Overall Performance**: CapLite achieved the highest utility per token among all enforcement defenses, dominating the Pareto frontier of attack success rate and utility.

## 4. Conclusion
CapLite demonstrates that effective defense against prompt injection is possible without relying on SLMs to generate security artifacts. By deriving policies from tool schemas and strictly enforcing write integrity based on user-request parameters, CapLite achieves zero attack success rates while surpassing state-of-the-art methods in both resource efficiency and task utility. This work highlights the importance of shifting security logic from model generation to structured verification for deploying secure LLM agents in resource-constrained environments.
