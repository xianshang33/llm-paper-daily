## 1. What the Paper Did
- **Background**: Web agents powered by large language and vision-language models are increasingly applied to realistic browser tasks spanning heterogeneous applications, multimodal content, and stateful workflows.
- **Limitations of Existing Work**: Existing reproducible benchmarks cover only a small number of web applications from limited categories and restrict modalities to text and vision. Live benchmarks offer broader coverage but sacrifice reproducibility due to data drift. Furthermore, current benchmarks fail to meaningfully evaluate agents' ability to understand and use embedded audio and video content.

## Core Contributions
- **Proposed WebArena-Pro**: A benchmark comprising 300 tasks across 20 self-hosted web applications in six domain categories, offering the broadest application coverage and most comprehensive multimodal support to date.
- **Challenge 1: Difficulty in understanding and interacting with multimodal content (audio/video)**. The difficulty lies in the neglect of these modalities in traditional benchmarks and the lack of standard interfaces for them. WebArena-Pro treats audio and video as core observations and introduces dedicated actions (e.g., Extract_frames, Transcribe) to enable effective processing.
- **Challenge 2: Balancing breadth and reproducibility**. The challenge is that real-world sites change dynamically, harming reproducibility, while static environments are often too simple. WebArena-Pro addresses this by self-hosting 20 heterogeneous applications and running tasks in isolation, ensuring both diversity and full reproducibility with parallel evaluation support.

## Implementation and Evaluation
- **Implementation & Deployment**: Tasks are authored via a dedicated annotator interface, filtered by LLM-assisted triage, and validated by humans. The benchmark supports isolated task execution and parallel evaluation.
- **Evaluation Results**:
    - Top performance was achieved by Codex (GPT 6.1 Sol) and Claude Code (Claude Opus 5.5), both at 62.3% success rate.
    - OpenCode (Kimi 3.1 Pro) followed closely at 60.7%.
    - The strongest GenericAgent configurations, Gemini 3.1 Pro omni and Gemma4 31B, both achieved 30.3%.
- **Comparison**: Among reproducible, human-curated web agent benchmarks, WebArena-Pro provides the widest application coverage and the most comprehensive multimodal support, addressing gaps in heterogeneity and modality diversity found in prior works.

## 4. Conclusion
WebArena-Pro fills critical gaps in current web agent benchmarks regarding heterogeneous application coverage, multimodal (especially audio/video) support, and reproducibility. By constructing a diverse environment with 20 self-hosted applications and 300 curated tasks, it provides a high-standard, reproducible platform for evaluating next-generation multimodal web agents, advancing the assessment of agent capabilities in complex real-world scenarios.
