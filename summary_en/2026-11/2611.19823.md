## 1. What the Paper Does
- **Background**: Reflective skill optimizers improve multi-turn LLM agents by revising instructions based on execution traces. However, existing methods primarily optimize for task accuracy alone.
- **Limitations of Existing Work**: Optimizing solely for accuracy leads to prompt bloat from accumulated edge-case rules, inflating token usage and causing agents to enter long, error-prone loops. Current efficiency methods either penalize tokens too early (stifling necessary exploration and stalling optimization) or only compress static instructions without reducing runtime-generated reasoning tokens, failing to address the quadratic cost growth of multi-turn history.

## Core Contributions
- **Proposed EfficientSkill**: A two-step framework that first discovers a reliable skill without token penalties and then performs accuracy-guarded pruning to compress instructions and offload reusable code.
- **Challenge 1: Conflict between Early Exploration and Token Efficiency**. The difficulty lies in the fact that early token penalties suppress the exploratory steps needed for unfamiliar environments, causing optimization to stall at low accuracy. EfficientSkill addresses this by using Phase 1 to repair failed rollouts without length penalties, establishing a high-accuracy "Anchor Skill" (A*) before optimizing for efficiency.
- **Challenge 2: Prompt Over-fitting and Multi-turn Drift**. Repeatedly patching instructions leads to hesitant re-inspection loops and cascading errors, while static compression fails to shorten runtime reasoning. EfficientSkill addresses this in Phase 2 by warm-starting from A* and pruning episodic output tokens under an accuracy gate (e.g., ≥90% of A*), replacing stalled loops with compact workflows and offloading code to workspace utilities with zero prompt cost.

## Implementation and Evaluation
- **Setup**: Evaluated on MATH-500, ALFWorld, and SpreadsheetBench using four frontier, mid-tier, and open-weight models.
- **Baselines**: Compared against unconstrained skill evolution (EvoSkill) and post-hoc compressors like SkillReducer.
- **Results**:
  - **Token Efficiency**: EfficientSkill reduced output tokens compared to EvoSkill in 11 out of 12 configurations, with reductions of up to 80%.
  - **Accuracy Gains**: Mean accuracy improved across all benchmarks. Notably, on SpreadsheetBench, Gemini 3.8 Flash and Grok 4.1 Fast saw accuracy gains of +14.3 and +17.5 percentage points, respectively, by replacing stalled loops with compact workflows.
  - **Cost Reduction**: By shrinking both generated tokens and replayed history, total token usage and serving costs were lowered across all configurations, with or without full-prefix KV caching.
  - **Comparison**: Unlike SkillReducer, which only trims static input tokens (-27%) without shortening runtime actions, EfficientSkill significantly reduces both input and output overheads while improving execution efficiency.

#### Summary
EfficientSkill effectively addresses prompt bloat and reasoning redundancy in multi-turn agents by decoupling accuracy discovery from efficiency optimization. It significantly lowers token consumption and serving costs while improving accuracy on complex tasks by eliminating ineffective loops, offering a new paradigm for building cost-effective and efficient multi-turn LLM agents.
