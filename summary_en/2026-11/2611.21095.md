## 1. What the Paper Does
- **Background**: With the increasing use of coding agents in real-world development, datasets recording interactions between users and agents have emerged. These sessions capture valuable insights into how users specify tasks, correct errors, and steer agents, offering an ideal resource for evaluating agents on real-world tasks.
- **Why Existing Work Falls Short**: Current evaluation methods cannot simply replay these recorded sessions. User replies are reactive to specific agent behaviors (e.g., correcting an agent's mistake). If a new agent takes a different trajectory (e.g., avoiding the mistake), the original recorded reply becomes logically invalid. Previous user simulators either rely on synthetic goals lacking personalization or are constrained to sending recorded messages in a fixed order, failing to adapt to divergent agent trajectories.

## Core Contributions
- **Proposed SWE-WhatIf**: A framework that models user intents, satisfaction criteria, and triggering conditions from recorded sessions to simulate user replies that adapt to new agent trajectories while remaining grounded in the original recording.
- **Challenge 1: How to adapt simulated user responses to unseen agent trajectories?**
    - **Difficulty**: Real conversations are highly context-dependent; a single deviation by the agent causes the dialogue to branch, making simple message replay semantically broken.
    - **Solution**: Instead of replaying messages, SWE-WhatIf extracts an "intent model" (intent content, satisfaction criteria, triggers). The simulator dynamically judges which intents are met or triggered based on the current agent state, generating new replies that fit the specific trajectory while maintaining fidelity to the user's original logic.
- **Challenge 2: How to verify if simulated replies accurately reflect the original user's preferences and logic?**
    - **Difficulty**: There is a lack of objective metrics to measure consistency between simulated replies and the hypothetical "real user response in this new trajectory."
    - **Solution**: Validated through "counterfactual testing," where agents are instructed to repeat or avoid actions previously rejected by the user. SWE-WhatIf achieved a 66.3% win rate in avoiding repeated errors (significantly above chance), proving it accurately captures user feedback logic and intent boundaries.

## Implementation and Evaluation
- **Setup**: Evaluated on 89 real-world session records, comparing SWE-WhatIf against strong baselines (e.g., session rewriting methods).
- **Key Results**:
    1. **Similarity**: SWE-WhatIf generated replies most similar to real users and matched the strongest baseline in session rewriting tasks.
    2. **Adaptation Validation**: In tests where agents were instructed to avoid or repeat user-rejected actions, SWE-WhatIf achieved the highest win rate (66.3%), significantly outperforming random chance, demonstrating effective adaptation to new trajectories.
    3. **Practical Utility**:
        - **Model Ranking**: Used to rank 5 LLMs as coding agents, revealing that the best model depends on how users specify and develop their intents.
        - **User Study**: In a study with 16 participants, replaying their own sessions changed the agent rankings for 14 participants, guiding their future agent selection.
- **Comparison**: Unlike prior simulators (e.g., SWE-Together) which are limited to the order and content of recorded messages, SWE-WhatIf generates adaptive responses to unseen agent turns.

## 4. Conclusion
SWE-WhatIf addresses the core challenge of trajectory dependence in evaluating coding agents using real session data. By constructing fine-grained user intent models, it successfully simulates dynamic user responses to diverse agent behaviors. Experiments demonstrate that the method surpasses existing baselines in reply realism and adaptability, helping developers select and optimize coding agents based on their personal work styles, thus establishing a new paradigm for personalized agent evaluation.
