## 1. What the Paper Did
- **Background**: Agents built on Large Language Models (LLMs) increasingly forecast real-world events by searching the web and reasoning over retrieved evidence. Performance depends on both the quality of retrieved evidence and the model's reasoning capabilities.
- **Limitations of Existing Work**: Current evaluation methods are flawed. Live evaluations entangle retrieval with reasoning, making it hard to isolate model performance. Retrospective evaluations suffer from "information leakage," where date filters or current search rankings inadvertently reveal post-event information, leading to unfair and non-reproducible assessments.

## Core Contributions
- **Proposed ForecastGym**: A live, controlled, and replayable benchmark for forecasting agents that treats evidence as a controlled experimental variable.
- **Challenge 1: Information Leakage in Evidence Reconstruction**. It is difficult to accurately reconstruct what was knowable at a specific past time without leaking future knowledge via updated pages or ranking algorithms. ForecastGym addresses this by prospectively recording results from four commercial search APIs while questions are still open, then freezing this evidence for offline replay after outcomes are known.
- **Challenge 2: Entangled Retrieval/Reasoning and Uncontrolled Source Variation**. When agents search independently, it is impossible to separate model capability from search quality or compare search providers fairly. ForecastGym fixes the evidence acquisition policy, allowing for decoupled comparison of models, memory strategies, and search sources on identical evidence trajectories.

## Implementation and Evaluation
- **Implementation & Data**: The system queries four search APIs (Tavily, Exa, Serper, Parallel) every two days. The first release includes 150 questions, 614 evidence states, and 131k search results.
- **Evaluation Results**:
    - **Leakage Verification**: Re-running queries after settlement reveals that up to 92% of results effectively state the outcome, highlighting severe leakage in traditional retrospective methods.
    - **Model Performance**: All tested LLMs trail the prediction market in accuracy when using frozen evidence.
    - **Diagnostic Analysis**: The primary cause of error in high-gap states is missing public information rather than misreading existing information.
    - **Search Source Impact**: Switching search APIs changes the Brier score by up to 0.043, an effect larger than the performance spread across different models, indicating that evidence source matters as much as the model.
    - **Memory Strategy**: Persistent notes perform similarly to re-reading all evidence but use half the input tokens.

## 4. Conclusion
ForecastGym solves critical issues of information leakage and variable coupling in forecasting agent evaluation by prospectively capturing and freezing search evidence. The study demonstrates that the quality of evidence seen by an agent (determined by the search source) is as critical as the reasoning model itself. This benchmark provides a controlled, replayable environment for independently optimizing retrieval and reasoning components.
