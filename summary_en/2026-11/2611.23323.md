## 1. What the Paper Did
- **Background**: General-purpose coding agents have been used to write code for hydrological and Earth-system models. However, in existing studies, evaluation criteria (e.g., test periods, scoring functions) were predefined by human researchers, with agents only tasked to meet these fixed standards.
- **Limitations of Prior Work**: No previous study has tested scenarios where agents make these research decisions autonomously. There is a lack of assessment regarding how many of the agent's claims are supported by its own data/code and whether these claims are verifiable by readers. Existing agents lack domain-specific tools and standardized research protocols, leading to questions about reliability and reproducibility.

## Core Contributions
- **Proposed HydroMind**: A hydrological modeling system and a structured agent framework (Harness) designed to enhance autonomy, accuracy, and checkability in hydrological research.
- **Challenge 1: Unsubstantiated Claims (Hallucinations/Logic Errors)**
  - **Difficulty**: When making autonomous decisions, agents may generate conclusions that contradict their actual code outputs, with no traceability to specific runs.
  - **Solution**: HydroMind provides fixed command interfaces for running 84 hydrological models and metrics, automatically archiving settings, trained models, and predictions. This ensures every reported number is traceable to a specific execution, reducing inconsistencies.
- **Challenge 2: Opaque Research Process and Lack of Statistical Rigor**
  - **Difficulty**: Agents often state conclusions (e.g., "Model A is better") without providing statistical tests, confidence intervals, or decision rules, making it impossible for readers to verify significance.
  - **Solution**: Introduced a "Research Procedure" requiring the agent to write a research design before running models and record all changes. This forces the agent to define evaluation criteria and statistical methods explicitly, significantly improving verifiability.

## Implementation and Evaluation
- **Experimental Setup**: Compared three agent "harnesses" using the same underlying LLM:
  1. Agent's native generic harness.
  2. Native harness + HydroMind modeling tools (fixed commands, auto-archiving).
  3. Native harness + HydroMind tools + HydroMind research procedure (design-first approach).
- **Task**: Agents investigated four open hydrological questions using only provided data.
- **Metrics**:
  1. **Claim Validity**: Whether recomputed results match the claim and the code actually compares the stated models.
  2. **Checkability**: Whether statistical tests, confidence intervals, or decision rules were reported.
- **Results**:
  - **Invalid Claims**: Rates were 30%, 20%, and 5% for the three harnesses, respectively. HydroMind significantly reduced unsupported claims.
  - **Checkable Claims**: Rates were 48%, 53%, and 83%. The full HydroMind framework ensured most claims included necessary statistical evidence.
- **Comparison Conclusion**: Without changing the LLM, improving the toolchain and research protocol (Harness) drastically reduced error rates and enhanced the verifiability of scientific claims.

#### Summary
This paper addresses the reliability and verifiability issues of general-purpose AI agents in hydrological research due to the lack of domain-specific tools and norms. The authors developed HydroMind, creating a "checkable agent" through standardized model execution and mandatory research design protocols. Experiments demonstrate that this approach effectively mitigates agent hallucinations, ensures claims are data-backed, and provides sufficient statistical evidence for human review, offering a more reliable infrastructure for autonomous scientific discovery.
