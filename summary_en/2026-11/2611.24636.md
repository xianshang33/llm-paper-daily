## 1. What the Paper Does
- **Background**: Diffusion Language Models (DLMs) offer an alternative to autoregressive generation by reconstructing sequences through iterative denoising, allowing for parallel token prediction and flexible generation orders. Recent advances in scaling and block diffusion have expanded DLMs from specialized tasks to general-purpose capabilities, particularly promising for Agent applications requiring complex tool use and efficient interaction.
- **Why Existing Work Falls Short**: While previous models (e.g., LLaDA, Dream series) have improved text reconstruction and code generation, they struggle to balance strong reasoning capabilities (Thinking-mode) with high inference efficiency in demanding Agent tasks. Limitations exist in effectively integrating long-range historical memory with bidirectional attention within current blocks, and in achieving optimal speed and joint decision-making accuracy under constrained memory deployment.

## Core Contributions
- **Proposed**: Clover-35B-A3B-Preview, a Mixture-of-Experts (MoE) diffusion language model with 35 billion total parameters and 3 billion activated parameters, supporting "thinking-mode" generation via Gated Delta Networks adapted for block diffusion.
- **Challenge 1: How to effectively fuse historical context memory with parallel denoising within blocks?**
    - **Difficulty**: Balancing recurrent memory of previously generated context with bidirectional softmax attention inside the current block is complex, as competing mechanisms can lead to information conflict or forgetting.
    - **Solution**: Clover adapts Gated Delta Networks where historical memory readout competes with current-block tokens in a shared softmax, supplemented by learnable block-size calibration to harmonize long-term dependencies with local parallel generation.
- **Challenge 2: How to achieve efficient Agent inference and joint decision-making without sacrificing accuracy?**
    - **Difficulty**: Agent tasks often require multi-turn interactions and verification, making serial generation slow; independent prediction of related questions ignores inter-question correlations, limiting overall group accuracy.
    - **Solution**: The model employs a zero-initialized right-context convolution branch for enhanced local perception and introduces a decision-model variant that generates answers to related questions in a single denoising pass, significantly boosting both speed and joint prediction accuracy.

## Implementation and Evaluation
- **Performance**: Clover leads in seven evaluated Agent metrics, achieving a score of 73.6 on SWE-bench Verified and 51.7 on Terminal-Bench 2.1.
- **Inference Efficiency**: On internal Agent workloads, it achieves a generation speed of 680 tokens/s using a single NVIDIA GB300 GPU (BF16 precision, batch size 1), demonstrating efficient deployment under memory constraints.
- **Joint Decision Advantage**: On an internal set of 500 question groups, joint prediction increased individual question accuracy from 90.37% to 93.88% and all-correct group accuracy from 65.4% to 77.0% compared to independent prediction.
- **Comparison**: Compared to prior works like the Dream series and LLaDA, Clover leverages its MoE architecture to maintain high capacity with lower activated parameters, delivering superior comprehensive performance in Agent benchmarks and real-world generation speed.

## 4. Conclusion
Clover-35B-A3B-Preview successfully addresses the trade-off between long-context memory integration and efficient parallel generation in diffusion language models by innovatively combining Gated Delta Networks with block diffusion. Its MoE architecture enables efficient inference at a 35-billion-parameter scale while achieving state-of-the-art results on challenging Agent benchmarks like SWE-bench. Furthermore, its joint decision-making mechanism highlights the unique advantages of diffusion models in handling correlated tasks, paving the way for future efficient and powerful general-purpose Agent deployments.
