## 1. What the Paper Did
- **Background**: LLM agents often fail in long-horizon tasks due to recurring procedural errors (e.g., API pagination mistakes, wrong entity resolution) rather than knowledge gaps. These errors are learnable from the agent's own history.
- **Limitations of Existing Work**: While systems like ExpeL and ACE allow agents to record and recall experiences, there is a lack of detailed empirical analysis on building, rigorously measuring, and productizing such systems. Specifically, the interaction between memory volume and model capability, as well as hidden deployment pitfalls, remains under-explored.

## Core Contributions
- **Proposed a Self-Distilled Memory Pipeline**: A three-stage process that mines short "lessons" from agent trajectories, consolidates them into fewer "guidelines" (tracking support counts), and delivers either all or a selected subset of guidelines at inference.
- **Challenge 1: Matching Memory Volume to Model Capability**. The difficulty lies in the fact that not all models benefit from extensive memory; weak models may suffer from noise. The paper finds that "the right amount of memory is a property of the model": strong models (e.g., DeepSeek-V3.2) improve with more guidelines, while weak models (e.g., gpt-oss-120b) perform better with a small, selected subset (~29 guidelines) than with the full set (199 guidelines).
- **Challenge 2: Hidden Failure Modes in Deployment**. Real-world deployment faces issues like plausible but incorrect logs, silently dropped provenance, and misleading baseline comparisons. The paper documents these failures (e.g., backfiring high-support guidelines, swallowed API errors) to provide concrete best practices.

## Implementation and Evaluation
- **Implementation & Deployment**: The pipeline is part of the open-source `altk-evolve` library and is deployed in IBM's CUGA agent and watsonx Orchestrate platform.
- **Evaluation Results**: Tested on the AppWorld benchmark across models with 40-92% baseline completion.
  - **Strong Models**: DeepSeek-V3.2 gained +9.5 points in task completion and +16.1 points in scenario completion with its full set of 191 guidelines.
  - **Weak Models**: gpt-oss-120b improved from 39.9% baseline to 51.2% with all 199 guidelines, but reached 55.4% with a selected subset of ~29 guidelines.
- **Comparison & Insights**: Unlike prior works that may suffer from baseline confounds, this study highlights that memory strategy must be model-specific. It warns against one-size-fits-all memory usage and provides insights into avoiding misleading comparisons with previous methods.

#### Summary
This paper focuses on practical lessons from productizing a self-distilled memory system rather than proposing a novel algorithm. The key finding is that optimal memory volume depends on model capability: strong models benefit from more memory, while weak models require curated subsets to avoid interference. Additionally, it details common deployment pitfalls, offering valuable engineering recommendations for teams implementing agent memory.
