## 1. What the Paper Does
- **Background**: Large web platforms operate massive fleets of ranking models, each selecting features from a shared pool of tens of thousands. Feature selection involves a trade-off between prediction accuracy and costs, including per-model serving constraints (throughput, latency) and shared feature pipeline budgets.
- **Why Existing Work Falls Short**: Previous LLM-based feature selection or engineering efforts typically study single models in isolation. They lack scalability for fleet-wide optimization, fail to account for shared infrastructure costs across models, and often require manual intervention for feature management, preventing fully automated end-to-end optimization.

## Core Contributions
- **Proposed**: A Cost-Aware Agentic Feature Optimization System for fleet-scale ranking models.
- **Challenge 1**: How to efficiently generate high-quality feature crosses from a vast combinatorial space while overcoming the limitations of isolated single-model optimization?
  - **Difficulty & Solution**: Traditional methods struggle with the huge search space and cannot leverage cross-model knowledge. The paper proposes using LLM agents to hypothesize and a single retrieval LLM, fine-tuned on outcomes across the fleet, to generate and shortlist cross features, allowing feature creation capabilities to improve collectively as more models are optimized.
- **Challenge 2**: How to optimize shared feature pipeline costs while adhering to individual model serving cost caps?
  - **Difficulty & Solution**: Optimizing models individually can lead to redundant pipeline costs. The paper introduces a fleet-aware pipeline cost trimming mechanism where features already used by other models under the same budget incur no additional pipeline cost. An LLM Researcher agent then tunes feature selection via asynchronous trials under resource caps.

## Implementation and Evaluation
- **Implementation & Deployment**: The system integrates LLM-driven feature creation, a novel feature importance blending algorithm using Pareto optimality and mixed estimators, and an agentic feature selection module. It is deployed in production, automatically re-selecting features at every refresh without manual addition or removal.
- **Evaluation Results**:
  - Across production models, the system improved Normalized Entropy by an average of 0.31% within each model's budget.
  - The trimming step reduced pipeline costs by 2.3% with no performance regression beyond measurement noise.
  - Online A/B tests showed a 0.20% improvement in a primary online metric.
- **Comparison**: Unlike prior tools that focus on single models without fleet-level cost awareness, this system achieves end-to-end automation, significantly reducing infrastructure costs while boosting model performance.

## 4. Conclusion
This paper presents an innovative end-to-end agentic system that addresses feature optimization challenges in large-scale ranking model fleets. By combining LLM-based reasoning with deterministic experimentation and leveraging fleet-wide knowledge sharing and cost-aware mechanisms, the system automates the feature engineering process. It effectively controls computational and storage costs while ensuring model performance improvements, offering a scalable solution for optimizing recommendation systems on large web platforms.
