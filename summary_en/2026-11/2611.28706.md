## 1. What the Paper Does
- **Background**: As LLM agents are increasingly used for complex, multi-step workflows, developers externalize procedural knowledge into reusable "Skills" (packages of instructions, scripts, and examples). Maintaining these skills requires connecting code revisions to changes in behavior and task outcomes.
- **Limitations of Existing Work**: Current workflows fragment evidence across version control, evaluation cases, and execution traces. Automated optimization methods often lack deep diagnostic capabilities and struggle to maintain context across iterations, making it difficult for developers to prioritize failures, reconstruct case-level evidence, and preserve context during revisions.

## Core Contributions
- **Proposed SkillLens**: An interactive human-LLM system for diagnosing and refining agent skills. It links performance changes, case transitions, skill diffs, invocation sequences, traces, and outputs into a recoverable workflow, keeping model-generated refinements under human review.
- **Challenge 1: Prioritizing Failures and Fragmented Evidence**. The difficulty lies in scattered data across tools, hindering quick error localization. SkillLens addresses this by directly linking performance changes to summarized error patterns and case evidence, providing a unified view for rapid identification of high-priority failures.
- **Challenge 2: Context Loss and Uncontrolled Optimization**. The difficulty is the loss of modification rationale across versions and unpredictable behaviors from fully automated optimizations. SkillLens addresses this by recording skill diffs and invocation sequences, offering bounded refinement plans within a human-in-the-loop review process to ensure interpretability and context continuity.

## Implementation and Evaluation
- **Implementation**: SkillLens is an interactive system integrating version comparison, case-level evidence display, and human-reviewed optimization. It allows developers to view historical changes, execution traces of failed cases, and model-suggested modifications.
- **Evaluation Results**:
    - **Formative Study**: Identified key challenges (prioritization, evidence reconstruction, context preservation) through interviews with 5 developers/researchers.
    - **User Study**: A between-subjects study with 20 participants showed that SkillLens supports a more usable and less cognitively demanding workflow compared to baselines. Participants demonstrated improved efficiency in diagnosing and refining skills and better understanding of behavior changes.
- **Comparison**: Unlike traditional automated optimization or disjointed manual debugging, SkillLens emphasizes a "human-in-the-loop" diagnostic process, focusing not just on metric improvement but on developer understanding and control over skill behavior.

## 4. Conclusion
SkillLens addresses the issues of fragmented evidence and context loss in LLM agent skill maintenance. By building an interactive system that connects version comparison, case evidence, and human-reviewed optimization, it significantly reduces the cognitive load of diagnosing and refining skills. The findings highlight that combining technical tracking capabilities with human judgment is an effective approach to enhancing the maintainability and reliability of LLM agents.
