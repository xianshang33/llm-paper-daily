## 1. What the Paper Does
- **Background**: Web-scale recommender models typically evolve through retraining or fine-tuning to adapt to changing user interests and business goals. This conventional approach relies on modifying data, loss functions, or hyperparameters followed by gradient-based optimization.
- **Limitations of Existing Work**: Traditional methods suffer from long iteration cycles (days per iteration) and high computational costs. Gradient-based updates indirectly adjust weights, often resulting in uncontrollable, widespread minor changes that make it difficult to precisely control specific model behaviors (e.g., freshness, specific categories).

## Core Contributions
- **Proposed "Weight Coding"**: A methodology for model evolution through direct, executable weight edits driven by LLM agents, eliminating the need for backpropagation.
- **Challenge 1: How to efficiently search the vast parameter space without gradient information?**
  - **Difficulty**: Recommender models have massive parameter counts (e.g., 147M), making blind search inefficient and prone to local optima.
  - **Solution**: An LLM agent inspects model structure and parameters, formulates hypotheses, and implements edits. The process evolves from localized changes to targeted searches and composition, allowing edited components to adapt. A cached engine enables rapid forward evaluation without backpropagation.
- **Challenge 2: How to ensure the effectiveness and safety of direct weight edits in industrial production environments?**
  - **Difficulty**: Direct weight modification risks model performance collapse or unpredictable biases, and must be deployed without altering serving infrastructure.
  - **Solution**: An iterative strategy with offline evaluation feedback loops is used. Experiments on Pinterest's image search retriever show a 15.0 percentage point increase in Recall@10 (24% relative) using only ~1/4 of the GPU hours required for full fine-tuning. No serving changes are needed, and online A/B tests showed significant gains in user saves.

## Implementation and Evaluation
- **Implementation & Deployment**: Implemented on Pinterest's 147M-parameter two-tower image search retriever. A cached engine accelerates evaluation, and LLM agents generate/execute weight edit scripts. The method requires no changes to the serving architecture.
- **Evaluation Results**:
  - **Offline Metrics**: Weight Coding improved Hold-out Recall@10 by 15.0 percentage points (24% relative) over the production model, whereas common launches improve by only ~1%. Even after randomly reinitializing the 13.6M-parameter interaction module, searching just 2,448 mixing/normalization parameters yielded a 9.8-point gain over production.
  - **Generalizability**: Gains span the full funnel (dense retrieval, generative retrieval, ranking) with up to 1.37B learnable parameters.
  - **Online A/B Tests**: Edited retrieval sources increased saves per user by 8.4% to 10.7%, aligning with business objectives.
- **Comparison**: Compared to traditional fine-tuning which takes days and high compute, Weight Coding completes in ~1/4 of the GPU time and offers finer-grained behavioral control (e.g., steering edits for freshness).

## 4. Conclusion
The paper introduces Weight Coding, a novel approach using LLM agents to directly edit model weights, breaking away from traditional gradient-based training paradigms. It demonstrates practical effectiveness in Pinterest's large-scale production system, significantly reducing computational cost and time for model evolution while providing explicit control over model behavior, offering a new tool for both pre-training and post-training stages.
