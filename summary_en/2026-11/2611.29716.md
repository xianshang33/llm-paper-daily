## 1. What the Paper Does
- **Background**: As Large Language Models (LLMs) become more capable, financial agents require tools they can easily discover and utilize. However, financial software is fragmented across various libraries with inconsistent interfaces and conventions, making it difficult to build reliable agent workflows.
- **Limitations of Existing Work**: Current methods lack unified interfaces, causing agents to make errors when handling complex financial conventions (e.g., stock splits, look-ahead bias). Furthermore, the absence of effective self-checking and improvement mechanisms leads to generated code that often fails validation or contains logical errors, requiring developers to rebuild integrations for each model inefficiently.

## Core Contributions
- **Proposed Fin-RSI**: A unified Python library of financial skills, checks, and self-improvement designed specifically for LLM agents, offering shared interfaces across models and agent frameworks.
- **Challenge 1: Fragmentation and Difficulty in Tool Discovery**. Financial libraries have disparate interfaces, making it hard for agents to find suitable tools from natural language requests. **Solution**: Fin-RSI integrates tools for market analysis, forecasting, and portfolio construction under a unified interface, allowing agents to automatically discover and reuse tested implementations without rebuilding integrations for each model.
- **Challenge 2: Correctness of Generated Code and Self-Improvement**. Financial tasks demand high accuracy, and subtle errors (like look-ahead bias) are common; pure reasoning correction is often ineffective. **Solution**: The library introduces property-based and metamorphic checks, along with a self-improvement workflow that uses feedback to repair programs, ensuring agents can identify and correct code violating financial conventions.

## Implementation and Evaluation
- **Implementation & Deployment**: Fin-RSI is released as an open-source library, allowing developers to extend tools without re-integrating for every model. It includes a benchmark suite for evaluating agent performance on trading position tasks.
- **Evaluation Results**: Evaluated on 20 open-weight models across six trading-position tasks. The proportion of episodes producing valid programs increased from 9.7% to 29.2% with Fin-RSI's tool discovery. For models with at least 14 billion parameters, this rate rose significantly from 23.6% to 64.6%.
- **Comparison**: Compared to traditional disjointed library usage, Fin-RSI significantly improves code generation success rates and reliability through its unified interface and self-improvement mechanisms, addressing the lack of independent reference validation in existing benchmarks.

## 4. Conclusion
Fin-RSI effectively addresses pain points in tool discovery, code correctness, and workflow reliability for LLM financial agents by providing unified interfaces, rigorous checks, and recursive self-improvement capabilities. Experiments demonstrate its ability to significantly enhance the generation of valid financial programs, offering a scalable shared resource for the community and advancing the development of financial agents.
