## 1. What the Paper Did
- **Background**: The rise of Large Language Model (LLM) coding agents has popularized "Vibe Coding," a paradigm where software is created via natural language prompts with minimal source code inspection. This lowers barriers for non-professionals but reduces human oversight.
- **Gap in Existing Work**: Prior research largely focuses on functional correctness or security, lacking a systematic evaluation of accessibility in end-to-end LLM-generated websites. It remains unclear whether Vibe Coding inherently produces accessible outputs and if agent-level interventions can effectively mitigate accessibility defects without compromising functionality.

## Core Contributions
- **Proposed an empirical study framework** to evaluate the accessibility of websites generated by LLM coding agents and assess the impact of agent-level accessibility "Skills."
- **Challenge 1: Quantifying the scale and nature of accessibility defects in Vibe Coding.** The difficulty lies in capturing real-world user interaction issues rather than static code errors. The paper addressed this by evaluating complete interaction journeys of 90 generated websites using three converging tools (axe-core, IBM Equal Access, QualWeb). It found that none of the baseline websites were fully accessible, with an average of 80.43 violated interface elements per site, primarily due to color contrast issues.
- **Challenge 2: Assessing the efficacy and trade-offs of accessibility interventions.** The challenge is improving accessibility without degrading functional correctness. The paper reran 24 configurations with general and contrast-specific accessibility Skills. Results showed significant improvement in accessibility scores but not total elimination of violations, while functional correctness decreased, highlighting a trade-off between accessibility enhancements and functional stability.

## Implementation and Evaluation
- **Experimental Setup**: Generated 90 websites across 3 projects using 3 coding agents, 4 LLMs, and varying reasoning efforts. Evaluated using automated tools and corroborated with user testing involving blind individuals. Re-evaluated 24 matched configurations with added accessibility Skills.
- **Results**:
    - **Baseline**: 100% of baseline sites had accessibility violations. 13 WCAG Success Criteria were violated, with color contrast being the most prevalent issue.
    - **Intervention**: Accessibility Skills significantly improved scores but did not eliminate all violations. User testing confirmed the negative experiential impact of remaining defects.
    - **Trade-off**: Functional correctness declined when accessibility Skills were applied.
- **Comparison**: Unlike previous works focusing on code snippets, this study demonstrates systemic accessibility failures in end-to-end generation and identifies the critical trade-off where agentic interventions improve accessibility at the cost of functional reliability.

## 4. Conclusion
The study concludes that accessibility does not reliably emerge from current Vibe Coding workflows. While agent-level accessibility interventions can significantly improve compliance, they do not guarantee full accessibility and may introduce functional regressions. Future developments must address the balance between automated accessibility improvements and maintaining core functional correctness.
