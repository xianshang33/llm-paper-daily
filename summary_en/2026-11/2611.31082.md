## 1. What the Paper Does
- **Background**: Understanding a system that can be run but not inspected is a core engineering skill, involving designing experiments, forming hypotheses about hidden state and timing, refuting incorrect ones, and building a correct and efficient replacement. This is common in hardware when dealing with encrypted third-party IP or legacy blocks with lost design data.
- **Limitations of Existing Work**: Current AI benchmarks typically provide explicit specifications, allowing Agents to build without discovering behavior; interactive benchmarks focus only on abstract experimentation steps without final construction; software benchmarks like ProgramBench do not address hardware-specific complexities such as clocked state, reset semantics, backpressure, and standard cell costs. There is no benchmark evaluating the full loop from experimentation to efficient circuit generation in hardware.

## Core Contributions
- **Proposed ChiProgramBench**: A benchmark suite with 18 tasks derived from open-source processors, accelerators, codecs, etc. Agents can only drive and read pins of a hidden, stateful simulated reference and submit gate-level netlists composed of public library cells.
- **Challenge 1: Behavioral Recovery and State Inference under Black-Box Conditions**. The difficulty lies in selecting input sequences that expose differences to recover how computation, concurrent signals, and internal state interact at clock boundaries, as a replacement may match on tried inputs but fail on new ones. The method addresses this via a "black-box discovery" setting, providing only anonymized functional pins and fixed memory interfaces, forcing Agents to reverse-engineer logic through active experimentation and hypothesis testing.
- **Challenge 2: Dual Constraints of Functional Correctness and Efficiency Optimization**. The challenge is that agents must achieve cycle-exact functional matching while also optimizing Power, Performance, and Area (PPA) relative to the reference, recognizing that behavioral recovery and efficient implementation are distinct challenges. The method introduces a "function-guided reconstruction" setting, providing circuit purpose and pin roles, and enforces strict evaluation: PPA credits are awarded only after all hidden test cases pass.

## Implementation and Evaluation
- **Experimental Setup**: 432 trials were conducted across 6 LLM Agent configurations. Tasks included black-box discovery (anonymized pins only) and function-guided reconstruction (additional functional descriptions).
- **Evaluation Results**:
    - **Functionality**: Only 12.0% of black-box trials and 14.8% of function-guided trials passed all test cases. Function guidance raised the mean functional score (cycle-weighted share of passed cases) from 24.6% to 30.9%.
    - **Efficiency**: Of the 58 designs that fully passed functional tests, only three outperformed the reference in combined PPA. This indicates that even when Agents recover algorithms and numerical conventions, implementing efficient circuits remains highly challenging.
- **Comparison**: Unlike existing benchmarks that provide specifications or test only experimentation steps, ChiProgramBench is the first to evaluate the full closed loop from active experimentation to efficient circuit generation in hardware, revealing significant limitations in current LLM Agents' capabilities in hardware reverse engineering and optimization.

## 4. Conclusion
ChiProgramBench fills a gap in hardware Agent benchmarks, highlighting the significant gap between recovering behavior from black-box experiments and implementing efficient circuits. Results show that while LLM Agents have some algorithm recovery capability, they struggle significantly with complex hardware state interactions and PPA optimization. Function guidance offers limited improvement, suggesting a need for deeper Agent capability enhancements targeting hardware-specific timing and state management.
