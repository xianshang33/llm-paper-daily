## 1. What the Paper Does
- **Background**: Reinforcement Learning (RL) significantly improves the performance of Large Language Model (LLM) search agents (up to 32 exact-match points), but overall accuracy gains do not reveal which underlying functional capabilities improve or interact during training.
- **Limitations of Existing Work**: Current evaluation and credit-assignment methods fail to isolate the causal contribution of each functional role under closed-loop execution. Observational analyses only measure surface statistics (e.g., response length) without verifying causality, while single-role ablations miss complex multi-role interactions, leading to inaccurate attribution of RL gains.

## Core Contributions
- **Proposed CO-GRAFT**: A reward-agnostic interventional attribution framework that uses role-level policy grafting to decompose total RL gains via Shapley values and Möbius interaction terms from cooperative game theory.
- **Challenge 1: How to precisely quantify the independent contribution of each functional role to performance improvement without retraining?**
  - **Difficulty**: Traditional methods require separate fine-tuning or ablation for each role, which is computationally expensive and disrupts internal synergies.
  - **Solution**: CO-GRAFT defines a cooperative game with four mutually exclusive roles (intermediate reasoning, search/answer decision, query generation, final answer extraction). By evaluating all 16 role assignment combinations (2^4), it computes Shapley values to decompose gains without any additional training or weight modifications.
- **Challenge 2: How to distinguish standalone role improvements from multi-role coupling effects?**
  - **Difficulty**: Overall performance gains may stem from single capability enhancements or synergistic optimizations of multiple capabilities, which existing methods struggle to decouple.
  - **Solution**: Introduces Möbius interaction terms to explicitly distinguish standalone improvements from multi-role couplings. For instance, it reveals that smaller base models rely on "reasoning-decision" coupling, while larger models benefit more from improved answer extraction.

## Implementation and Evaluation
- **Implementation & Setup**: Applied CO-GRAFT to Search-R1 agents across Qwen2.5 and Llama-3.2 models (varying sizes, initializations, optimizers like GRPO/PPO) on NQ and HotpotQA datasets.
- **Key Findings**:
  1. **Query Generation Overrated**: Search query generation contributes no more than 15% to total gains.
  2. **Primary Drivers**: Gains are governed by pre-RL answer validity, search retention, model scale, and fixed search budgets.
  3. **Shift in Credit**: As model size increases or answer formatting improves, credit shifts from "reasoning" to "answer extraction"; smaller base models rely heavily on "reasoning-decision" coupling.
- **Comparison Advantage**: Unlike traditional methods focusing on surface statistics or isolated ablations, CO-GRAFT provides fine-grained, causally clear attribution, revealing that RL optimizes answer extraction and decision logic rather than just query generation.

## 4. Conclusion
This paper introduces CO-GRAFT to address the black-box attribution problem in RL-enhanced search agents. Using cooperative game theory, the authors demonstrate that RL gains primarily stem from improved answer extraction and reasoning-decision coupling, rather than search query generation. This finding challenges previous assumptions about optimization priorities in search agents and provides theoretical guidance for future targeted training strategies.
