## 1. What the Paper Does
- **Background**: LLM-based agents access remote services via tool calls. Remote service providers have incentives to identify the backend LLM of an agent for security reasons (e.g., defending against model-specific prompt injection) or commercial purposes (e.g., "cloaking" or delivering manipulated content specifically to AI agents).
- **Why Existing Work Fails**: Current LLM identification methods typically assume direct access to the model or control over inputs. In the agent scenario, remote services cannot interact directly with the backend LLM; they can only observe responses through the agent's tool usage. Any extra interaction deviating from the task may be rejected by the agent as malicious, rendering traditional fingerprinting or active probing methods ineffective.

## Core Contributions
- **Proposed CAPTA (Completely Automated Preference Test to tell LLMs Apart)**: An automated model identification approach inspired by CAPTCHA, which uses multiple-choice questions to exploit differences in selection preferences among LLMs.
- **Challenge 1: How to distinguish highly similar LLMs through limited, indirect interactions?**
  - **Difficulty**: Different LLMs behave similarly on standard tasks, and remote services only see the final output of the agent, lacking access to raw logits or chain-of-thought.
  - **Solution**: CAPTA designs multiple-choice challenges based on "cross-model option-generation diversity." It leverages the subtle preference biases of different models when facing specific distractor options as fingerprints, achieving high discrimination with very few questions.
- **Challenge 2: How to automatically generate efficient and discriminative test questions?**
  - **Difficulty**: Manually constructing questions that significantly distinguish dozens of models is costly, and questions must appear as legitimate task contexts to avoid being blocked by the agent.
  - **Solution**: Introduces an LLM-guided search algorithm to optimize option sets. This algorithm automatically searches for and generates question-option combinations that maximize disagreement among different models, thereby automating the construction of efficient identification tests.

## Implementation and Evaluation
- **Experimental Setup**: Evaluated on 25 LLMs from 10 model families, and further tested on 28 combinations of 4 widely used agent frameworks and 7 representative LLMs.
- **Key Results**:
  - Achieved **99.0%** mean identification accuracy across 25 LLMs using only 10 questions.
  - In the agent scenario (28 Agent-LLM combinations), achieved **99.7%** mean identification accuracy with 30 submitted answers.
- **Comparison**: Compared to traditional statistical or direct probing methods, CAPTA achieves near-perfect accuracy with minimal interactions without disrupting the agent's normal workflow, demonstrating the effectiveness of black-box identification via "selection preferences."

## 4. Conclusion
This paper addresses the challenge of identifying the backend LLM of AI agents for remote services. It proposes CAPTA, which transforms model identification into a CAPTCHA-like multiple-choice preference test. By using LLM-guided search to generate highly discriminative questions, it exploits selection preference differences for fingerprinting. Experiments show that CAPTA achieves near-perfect accuracy with very few interactions, providing a robust technical means for defending against model-specific attacks and implementing differentiated content strategies.
