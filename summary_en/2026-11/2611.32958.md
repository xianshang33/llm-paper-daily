## 1. What the Paper Does
- **Background**: As Large Language Models (LLMs) converge with High-Performance Computing (HPC), AI agents are automating data analysis and orchestration. This introduces a security threat existing cluster defenses cannot address: the "hijacked authorized agent." Adversaries can subvert agents via prompt injection, poisoned data, or compromised tools, exfiltrating data through legitimate encrypted LLM API traffic.
- **Why Existing Work Fails**: Current HPC security relies on authentication (e.g., Kerberos) and authorization (e.g., POSIX permissions). Since hijacked agents possess valid user credentials and privileges, they pass these checks. Furthermore, traditional monitoring does not inspect encrypted HTTPS traffic to LLM backends and cannot detect injections via shared parallel file systems or co-located node resources.

## Core Contributions
- **Proposed AEGIS**: A runtime defense system based on "behavioral attestation" to establish a zero-trust architecture for HPC AI agents.
- **Challenge 1: Detecting malicious behavior without decrypting traffic.**
  - **Difficulty**: Communication with LLM backends is encrypted, and attack payloads are hidden within legitimate system calls and data access, rendering network monitoring ineffective.
  - **Solution**: AEGIS compiles task-derived behavioral constraint profiles and uses eBPF-based syscall interception to monitor agent actions. It verifies evidence against these profiles at runtime to identify deviations indicative of compromise.
- **Challenge 2: Handling multi-agent coordination attacks and minimizing false positives.**
  - **Difficulty**: Individual agent actions may appear benign while coordinated actions lead to data exfiltration; strict monitoring risks disrupting scientific workflows.
  - **Solution**: AEGIS correlates behavior across agents and triggers Slurm-level containment upon violation. Experiments show it covers all four attack classes with no observed false positives on benign workflows and low verifier overhead.

## Implementation and Evaluation
- **Implementation**: AEGIS integrates with HPC environments using eBPF for low-level syscall interception and links with the Slurm job scheduler for rapid response, operating at a 1-second monitoring interval.
- **Evaluation Results**:
  - **Detection**: Detected all four implemented attack classes (prompt injection, data poisoning, compromised tools, multi-agent coordination) on the real attestation path.
  - **Performance**: Achieved sub-second median detection latency with low verifier overhead.
  - **Accuracy**: Zero false positives observed on evaluated benign workflows.
- **Comparison**: Controlled experiments demonstrate full attack-suite coverage and stronger detection capabilities compared to representative baselines, addressing blind spots in traditional identity and network-based defenses.

## 4. Conclusion
This paper addresses the "hijacked authorized agent" threat in HPC environments by proposing AEGIS. By leveraging behavioral attestation, eBPF monitoring, and Slurm integration, AEGIS detects and contains complex injection and coordination attacks in real-time with low latency and overhead, filling a critical gap in zero-trust security for AI agents in HPC.
