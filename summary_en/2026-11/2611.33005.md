## 1. What the Paper Does
- **Background**: Large Language Model (LLM) agents rely on external memory systems to retain and reuse information across interactions. Existing systems treat memory as a record of the past, evaluating quality based on fidelity to the original conversation.
- **Why Existing Work Fails**: Current methods assume that high-fidelity memory naturally leads to better future responses, but this creates two gaps: 1) **The Memorization Gap**: Faithful summaries or extracted facts may omit details crucial for future, unseen requests; 2) **The Serving Gap**: Retrieving memory based on similarity to the current request may miss implicit context needed for a high-quality response (e.g., unstated long-term preferences). Thus, faithful memory does not guarantee improved agent performance.

## Core Contributions
- **Proposed Leto**: A utility-centric memory system for LLM agents that treats memory as a prediction problem, focusing on its utility for future responses rather than fidelity to the past.
- **Challenge 1: Unknown future requests make it difficult to predict which details to retain**. Traditional methods lose details via summarization. Leto addresses this by using **memory indexing** to preserve access to raw conversation details, allowing it to replay and supply necessary context beyond the explicit request when needed.
- **Challenge 2: The utility of served context is uncertain until the response is generated**. Leto introduces a **utility loop** that uses the outcome of the generated response as feedback to refine and optimize future memory selection strategies.

## Implementation and Evaluation
- **Evaluation Setup**: Leto was evaluated against six existing memory systems across five benchmarks in three scenarios.
- **Personalization**: On the PrefEval benchmark, Leto outperformed the strongest baseline by 16.3 percentage points in accuracy. On PERMA, it achieved a 3.1-point higher task completion rate.
- **Long-Horizon Tasks**: Leto achieved the best overall performance on MemoryArena (averaged over five environments), with performance gains increasing as task chain depth increased.
- **Long-Context Understanding**: Leto performed on par with retrieval over raw history while serving significantly fewer context tokens, demonstrating higher efficiency.

#### Summary
Leto shifts the paradigm of memory systems from "past fidelity" to "future utility." By preserving detailed indices and employing a feedback-driven utility loop based on response outcomes, Leto effectively addresses the memorization and serving gaps. Experimental results demonstrate that Leto significantly outperforms state-of-the-art methods in personalization, long-horizon tasks, and efficiency, offering a new framework for memory management in LLM agents.
